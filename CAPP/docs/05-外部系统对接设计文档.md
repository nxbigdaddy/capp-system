## 1. 概述

### 1.1 集成目标

本文档旨在定义CAPP系统与外部系统（CAXA PLM、U8 ERP、MES系统、MaxKB专业版）的对接方案，实现以下目标：

1. **数据互通**: 打通PLM、ERP、MES之间的数据孤岛，实现产品数据、工艺数据、生产数据的无缝流转
2. **流程协同**: 建立跨系统的业务流程协同机制，减少人工干预，提高工作效率
3. **知识赋能**: 通过MaxKB知识库和智能体，为工艺设计提供智能辅助决策
4. **实时监控**: 建立统一的集成监控体系，确保数据同步的可靠性和及时性

### 1.2 集成原则

| 原则 | 说明 |
|------|------|
| 松耦合 | 各系统通过标准接口交互，降低系统间依赖 |
| 高可用 | 采用异步处理、重试机制、补偿机制保障集成可靠性 |
| 安全性 | 接口认证、数据加密、访问控制、审计追溯 |
| 可扩展 | 采用总线架构，便于后续新增对接系统 |

## 2. CAXA PLM 对接

### 2.1 对接概述

#### PLM系统介绍

CAXA PLM是面向离散制造企业的产品生命周期管理系统，提供产品数据管理（PDM）、工艺管理、变更管理、文档管理等功能。在本企业中，CAXA PLM主要用于：

- 产品结构设计及BOM管理
- 工程图纸及技术文档管理
- 设计变更流程管理
- 零部件版本控制

#### 对接范围

| 对接模块 | 数据方向 | 说明 |
|----------|----------|------|
| 产品信息 | PLM → CAPP | 获取产品结构、零部件信息 |
| BOM数据 | PLM → CAPP | 获取设计BOM（EBOM） |
| 图纸文档 | PLM → CAPP | 获取关联图纸、技术文件 |
| 变更通知 | PLM → CAPP | 接收设计变更通知 |
| 工艺数据 | CAPP → PLM | 回传工艺BOM（PBOM） |

### 2.2 产品数据同步

#### 产品信息获取

CAPP系统通过定时任务或事件触发方式从PLM获取产品信息：

- **全量同步**: 每日凌晨执行，同步所有有效产品
- **增量同步**: 每15分钟执行，同步变更产品
- **实时同步**: 接收PLM变更通知后立即同步

同步字段包括：产品编码、产品名称、产品型号、规格参数、材料、重量、设计状态、版本号、创建人、创建时间、修改时间等。

#### BOM数据同步

EBOM（Engineering BOM）同步策略：

1. 按产品层级递归获取BOM结构
2. 记录BOM层级关系（父件-子件关系）
3. 同步BOM属性：用量、单位、位号、替代料标识
4. 标记BOM生效日期和失效日期

#### 图纸文档关联

- 通过文档ID建立CAPP工艺与PLM图纸的关联关系
- 支持图纸预览（转换为PDF格式缓存）
- 记录文档版本，确保工艺使用正确版次图纸
- 图纸变更时自动提醒工艺人员

#### 变更通知处理

PLM通过Webhook推送变更通知，CAPP接收后处理流程：

1. 验证变更通知签名
2. 解析变更类型（新增/修改/作废）
3. 根据变更类型触发相应同步任务
4. 更新本地数据版本标记
5. 通知相关工艺人员

### 2.3 接口设计

#### 接口协议

采用REST API over HTTPS，JSON数据格式。

| 属性 | 值 |
|------|-----|
| 协议 | HTTPS |
| 数据格式 | JSON (UTF-8) |
| 字符编码 | UTF-8 |
| 超时时间 | 30秒 |
| 重试次数 | 3次 |

#### 认证方式

采用OAuth 2.0 Client Credentials模式：

1. CAPP使用Client ID和Client Secret向PLM认证服务器请求Access Token
2. Access Token有效期2小时，提前5分钟刷新
3. 请求头携带: `Authorization: Bearer {access_token}`

#### 接口清单

| 接口编号 | 接口名称 | 方法 | URL路径 | 说明 |

| PLM-002 | 获取产品详情 | GET | `/api/v1/products/{id}` | 获取单个产品完整信息 |
| PLM-003 | 获取EBOM | GET | `/api/v1/products/{id}/bom` | 获取产品设计BOM |
| PLM-004 | 获取文档列表 | GET | `/api/v1/products/{id}/documents` | 获取产品关联文档 |
| PLM-005 | 下载文档 | GET | `/api/v1/documents/{id}/download` | 下载文档文件 |
| PLM-006 | 推送PBOM | POST | `/api/v1/products/{id}/pbom` | 回传工艺BOM |
| PLM-007 | 推送工艺路线 | POST | `/api/v1/products/{id}/routing` | 回传工艺路线 |
| PLM-008 | 变更通知回调 | POST | `/capp/webhook/plm/change` | PLM推送变更通知 |

### 2.5 PHP实现方案

#### API客户端封装

```php
<?php

class PlmApiClient
{
    private string $baseUrl;
    private string $clientId;
    private string $clientSecret;
    private ?string $accessToken = null;
    private ?int $tokenExpiresAt = null;
    private int $timeout = 30;
    private int $retryCount = 3;

    public function __construct(array $config)
    {
        $this->baseUrl = rtrim($config['base_url'], '/');
        $this->clientId = $config['client_id'];
        $this->clientSecret = YOUR_SECRET'client_secret'];
        $this->timeout = $config['timeout'] ?? 30;
        $this->retryCount = $config['retry_count'] ?? 3;
    }

    private function getAccessToken(): string
    {
        if ($this->accessToken && $this->tokenExpiresAt && time() < ($this->tokenExpiresAt - 300)) {
            return $this->accessToken;
        }

        $ch = curl_init();
        curl_setopt_array($ch, [
            CURLOPT_URL => "{$this->baseUrl}/oauth/token",
            CURLOPT_POST => true,
            CURLOPT_POSTFIELDS => http_build_query([
                'grant_type' => 'client_credentials',
                'client_id' => $this->clientId,
                'client_secret' => $this->clientSecret,
            ]),
            CURLOPT_RETURNTRANSFER => true,
            CURLOPT_TIMEOUT => $this->timeout,
            CURLOPT_SSL_VERIFYPEER => true,
        ]);

        $response = curl_exec($ch);
        $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
        curl_close($ch);

        if ($httpCode !== 200) {
            throw new RuntimeException("PLM认证失败: HTTP {$httpCode}");
        }

        $data = json_decode($response, true);
        if (!isset($data['access_token'])) {
            throw new RuntimeException("PLM认证响应异常");
        }

        $this->accessToken = YOUR_SECRET'access_token'];
        $this->tokenExpiresAt = time() + ($data['expires_in'] ?? 7200);

        return $this->accessToken;
    }

    private function request(string $method, string $path, array $params = []): array
    {
        $url = "{$this->baseUrl}{$path}";
        $token = YOUR_SECRET);
        $attempt = 0;

        while ($attempt < $this->retryCount) {
            $ch = curl_init();
            $options = [
                CURLOPT_URL => $method === 'GET' && $params ? "{$url}?" . http_build_query($params) : $url,
                CURLOPT_RETURNTRANSFER => true,
                CURLOPT_TIMEOUT => $this->timeout,
                CURLOPT_SSL_VERIFYPEER => true,
                CURLOPT_HTTPHEADER => [
                    "Authorization: Bearer {$token}",
                    "Content-Type: application/json",
                    "X-Request-ID: " . uniqid('plm-', true),
                ],
            ];

            if ($method === 'POST') {
                $options[CURLOPT_POST] = true;
                $options[CURLOPT_POSTFIELDS] = json_encode($params);
            }

            curl_setopt_array($ch, $options);
            $response = curl_exec($ch);
            $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
            $error = curl_error($ch);
            curl_close($ch);

            if ($error) {
                $attempt++;
                if ($attempt >= $this->retryCount) {
                    throw new RuntimeException("PLM请求失败: {$error}");
                }
                usleep(1000000 * $attempt);
                continue;
            }

            if ($httpCode === 401) {
                $this->accessToken = null;
                $token = YOUR_SECRET);
                continue;
            }

            $data = json_decode($response, true);
            if ($httpCode >= 400) {
                throw new RuntimeException("PLM请求失败: HTTP {$httpCode}");
            }

            return $data;
        }

        throw new RuntimeException("PLM请求超过最大重试次数");
    }

    public function getProducts(int $page = 1, int $pageSize = 50, string $status = 'active'): array
    {
        return $this->request('GET', '/api/v1/products', [
            'page' => $page,
            'pageSize' => $pageSize,
            'status' => $status,
        ]);
    }

    public function getProduct(string $productId): array
    {
        return $this->request('GET', "/api/v1/products/{$productId}");
    }

    public function getBom(string $productId): array
    {
        return $this->request('GET', "/api/v1/products/{$productId}/bom");
    }

    public function getDocuments(string $productId): array
    {
        return $this->request('GET', "/api/v1/products/{$productId}/documents");
    }

    public function downloadDocument(string $documentId, string $savePath): bool
    {
        $token = YOUR_SECRET);
        $url = "{$this->baseUrl}/api/v1/documents/{$documentId}/download";

        $fp = fopen($savePath, 'w');
        $ch = curl_init();
        curl_setopt_array($ch, [
            CURLOPT_URL => $url,
            CURLOPT_RETURNTRANSFER => true,
            CURLOPT_TIMEOUT => 120,
            CURLOPT_SSL_VERIFYPEER => true,
            CURLOPT_HTTPHEADER => ["Authorization: Bearer {$token}"],
            CURLOPT_FILE => $fp,
        ]);

        $result = curl_exec($ch);
        $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
        curl_close($ch);
        fclose($fp);

        return $httpCode === 200 && $result;
    }

    public function pushPbom(string $productId, array $pbomData): array
    {
        return $this->request('POST', "/api/v1/products/{$productId}/pbom", $pbomData);
    }
}
```

#### 数据同步任务

```php
<?php

class PlmSyncService
{
    private PlmApiClient $client;
    private PDO $db;
    private $logger;

    public function __construct(PlmApiClient $client, PDO $db, $logger)
    {
        $this->client = $client;
        $this->db = $db;
        $this->logger = $logger;
    }

    public function fullSync(): array
    {
        $result = ['synced' => 0, 'errors' => 0, 'message' => ''];
        $page = 1;
        $pageSize = 50;

        try {
            $this->db->beginTransaction();

            do {
                $response = $this->client->getProducts($page, $pageSize);
                $products = $response['data']['items'] ?? [];

                foreach ($products as $product) {
                    try {
                        $this->syncProduct($product);
                        $result['synced']++;
                    } catch (Exception $e) {
                        $result['errors']++;
                        $this->logger->error("产品同步失败: {$product['code']}", [
                            'error' => $e->getMessage(),
                        ]);
                    }
                }

                $page++;
            } while (count($products) === $pageSize);

            $this->db->commit();
            $this->logger->info("PLM全量同步完成", $result);
        } catch (Exception $e) {
            $this->db->rollBack();
            $result['message'] = $e->getMessage();
            $this->logger->error("PLM全量同步异常", ['error' => $e->getMessage()]);

    public function incrementalSync(DateTime $since): array
    {

        $sinceStr = $since->format('Y-m-d\TH:i:s\Z');

        try {
            $response = $this->client->getProducts(1, 1000, "updated_after:{$sinceStr}");
            $products = $response['data']['items'] ?? [];

            $this->db->beginTransaction();
            foreach ($products as $product) {
                $this->syncProduct($product);
                $this->syncProductBom($product['id']);
                $result['synced']++;

        }

        return $result;
    }

{

}

    {
```

```php
            $options[CURLOPT_POSTFIELDS] = json_encode($params);
        }

        curl_setopt_array($ch, $options);
        $response = curl_exec($ch);
```

#### 批量处理

```php
<?php

class U8BatchProcessor
{
    private U8ApiClient $client;
    private int $batchSize;
    private int $delayBetweenBatches;

    public function __construct(U8ApiClient $client, int $batchSize = 50, int $delay = 1000)
    {
        $this->client = $client;
        $this->batchSize = $batchSize;
        $this->delayBetweenBatches = $delay;
    }

    public function batchPushRouting(array $routings): array
    {
        $result = ['success' => 0, 'failed' => 0, 'errors' => []];
        $batches = array_chunk($routings, $this->batchSize);

        foreach ($batches as $index => $batch) {
            foreach ($batch as $routing) {
                try {
                    $convertedData = U8DataConverter::convertRouting($routing);
                    $this->client->pushRouting($convertedData);
                    $result['success']++;
                } catch (Exception $e) {
                    $result['failed']++;
                    $result['errors'][] = [
                        'routing_code' => $routing['routing_code'],
                        'error' => $e->getMessage(),
                    ];
                }
            }

            if ($index < count($batches) - 1) {
                usleep($this->delayBetweenBatches * 1000);
            }
        }

        return $result;
    }

    public function batchPushLaborQuota(array $quotas): array
    {
        $result = ['success' => 0, 'failed' => 0, 'errors' => []];
```

## 4. MES系统对接

### 4.1 对接概述

#### MES系统介绍

MES（Manufacturing Execution System）制造执行系统，是面向车间生产管理的执行层系统。在本企业中，MES主要用于：

- 生产订单管理
- 工序报工管理
- 质量检验管理
- 设备管理
- 生产追溯

#### 对接范围

| 对接模块 | 数据方向 | 说明 |
|----------|----------|------|
| 工艺文件 | CAPP → MES | 下发工艺路线、工序卡片 |
| 作业指导书 | CAPP → MES | 下发SOP文档 |
| 完工汇报 | MES → CAPP | 接收工序完工数据 |
| 质量数据 | MES → CAPP | 接收检验结果 |
| 设备状态 | MES → CAPP | 查询设备运行状态 |
| 工时统计 | MES → CAPP | 接收实际工时 |

#### 数据流向

```mermaid
sequenceDiagram
    participant CAPP as CAPP系统
    participant MQ as 消息队列
    participant MES as MES系统
```

### 4.2 工艺文件下发

#### 工艺路线下发

CAPP审核通过的工艺路线自动下发到MES：

- 产品编码、工艺路线编码
- 工序序列及工艺要求
- 工艺参数、检验要求
- 下发版本、生效日期

#### 工序卡片下发

工序卡片包含详细加工信息：

- 工序号、工序名称
- 加工设备、工装夹具
- 加工参数（转速、进给、温度等）
- 检验项目及标准
- 注意事项

#### 作业指导书下发

- SOP文档PDF/图片格式
- 关联工序号
- 版本号控制
- 下发状态跟踪

#### 版本控制

工艺文件版本管理策略：

1. 每次下发生成唯一版本号
2. MES端记录当前生效版本
3. 新版本下发时标记旧版本失效
4. 支持历史版本追溯
5. 变更需重新审核后方可下发

### 5.1 对接概述

#### MaxKB专业版介绍

MaxKB是一款基于大语言模型的知识库问答系统专业版，提供：

- 知识库管理：文档上传、解析、向量化
- 智能体管理：创建、配置、调用AI智能体
- 对话管理：多轮对话、上下文管理
- API开放：提供完整的REST API接口

在本企业中，MaxKB主要用于：

- 工艺知识库：存储工艺规范、标准、经验
- 智能工艺辅助：通过智能体辅助工艺设计
- 标准查询：快速检索国家标准、行业标准
- 故障诊断：基于历史数据的智能诊断

#### 对接范围

#### 流式响应处理

```php
<?php

class StreamResponseHandler
{
    private $onChunk;
    private $onComplete;
    private $onError;

    public function __construct(callable $onChunk, ?callable $onComplete = null, ?callable $onError = null)
    {
        $this->onChunk = $onChunk;
        $this->onComplete = $onComplete;
        $this->onError = $onError;
    }

    public function handle(string $response): void
    {
        $lines = explode("\n", $response);

        foreach ($lines as $line) {
            $line = trim($line);
            if (empty($line)) {
                continue;
            }

            if (str_starts_with($line, 'data: ')) {
                $data = substr($line, 6);

                if ($data === '[DONE]') {
                    if ($this->onComplete) {
                        ($this->onComplete)();
                    }
                    return;
                }

                $json = json_decode($data, true);
                if ($json && isset($json['content'])) {
                    ($this->onChunk)($json['content'], $json);
                }
            }
        }
    }
}
```

```php
                        }

                        if ($json && isset($json['content'])) {
                            $onChunk($json['content'], $json);
                        }
                    }
                }
                return strlen($data);
            },
        ]);

        $result = curl_exec($ch);
        $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
```

```php
            if ($transformer && is_callable($transformer)) {

            $current = $current[$key];
        }
```

#### 失败重试

```php
<?php

class TaskRetryHandler
{
    private PDO $db;
    private $logger;
    private int $maxRetries;
    private array $retryDelays;

    public function __construct(PDO $db, $logger, int $maxRetries = 3)
    {
        $this->db = $db;
        $this->logger = $logger;
        $this->maxRetries = $maxRetries;
        $this->retryDelays = [60, 300, 900];
    }

    public function executeWithRetry(callable $task, array $context = []): array
    {
        $attempt = 0;
        $lastError = null;

        while ($attempt < $this->maxRetries) {
            try {
                $result = $task();
                $this->logSuccess($context, $attempt);
                return ['success' => true, 'result' => $result];
            } catch (Exception $e) {
                $lastError = $e;
                $attempt++;

                if ($attempt < $this->maxRetries) {
                    $delay = $this->retryDelays[$attempt - 1] ?? 900;
                    $this->logRetry($context, $attempt, $e->getMessage(), $delay);
                    sleep($delay);
                }
            }
        }

        $this->logFailure($context, $lastError->getMessage());
        return [
            'success' => false,
            'error' => $lastError->getMessage(),
            'attempts' => $attempt,
        ];
    }

    private function logSuccess(array $context, int $attempt): void
    {
        $this->logger->info("任务执行成功", [
            'context' => $context,
            'attempts' => $attempt + 1,
        ]);
    }

    private function logRetry(array $context, int $attempt, string $error, int $delay): void
    {
        $this->logger->warning("任务重试", [
            'context' => $context,
            'attempt' => $attempt,
            'error' => $error,
            'next_delay' => $delay,
        ]);
    }

    private function logFailure(array $context, string $error): void
    {
        $this->logger->error("任务执行失败", [
            'context' => $context,
            'error' => $error,
            'max_retries' => $this->maxRetries,
        ]);

        $this->saveToFailedQueue($context, $error);
    }

    private function saveToFailedQueue(array $context, string $error): void
    {
```

### 6.3 数据一致性

#### 事务管理

采用本地事务+最终一致性方案：

1. **本地事务**: CAPP内部数据操作使用数据库事务
2. **消息事务**: 外部系统调用通过消息队列保证最终一致性
3. **补偿事务**: 失败任务通过补偿机制恢复一致性

```php
<?php

class IntegrationTransactionManager
{
    private PDO $db;
    private $logger;

    public function __construct(PDO $db, $logger)
    {
        $this->db = $db;
        $this->logger = $logger;
    }

    public function execute(callable $operation, array $compensation): array
    {
        $this->db->beginTransaction();

        try {
            $result = $operation();
            $this->db->commit();

            $this->logTransaction('success', $result);
            return ['success' => true, 'result' => $result];
        } catch (Exception $e) {
            $this->db->rollBack();

            $this->logger->error("集成事务失败", ['error' => $e->getMessage()]);

            try {
                $compensation($e);
                $this->logger->info("补偿操作执行成功");
            } catch (Exception $compError) {
                $this->logger->error("补偿操作失败", ['error' => $compError->getMessage()]);
            }

            return ['success' => false, 'error' => $e->getMessage()];
        }
    }

    private function logTransaction(string $status, $result): void
    {
        $this->logger->info("集成事务{$status}", ['result' => $result]);
    }
}
```

#### 对账机制

```php
<?php

class ReconciliationService
{
    private PDO $db;
    private $logger;

    public function __construct(PDO $db, $logger)
    {
        $this->db = $db;
        $this->logger = $logger;
    }

    public function reconcilePlmData(): array
    {
        $result = ['total' => 0, 'matched' => 0, 'mismatched' => 0, 'details' => []];

        $plmStmt = $this->db->query("SELECT COUNT(*) as cnt FROM plm_sync_products WHERE sync_status = 1");
        $plmCount = $plmStmt->fetch(PDO::FETCH_ASSOC)['cnt'];

        $cappStmt = $this->db->query("SELECT COUNT(*) as cnt FROM capp_products WHERE plm_product_id IS NOT NULL");
        $cappCount = $cappStmt->fetch(PDO::FETCH_ASSOC)['cnt'];

        $result['total'] = $plmCount;

        if ($plmCount !== $cappCount) {
            $diffStmt = $this->db->query("
                SELECT p.plm_product_id, p.product_code 
                FROM capp_products p
                LEFT JOIN plm_sync_products s ON p.plm_product_id = s.plm_product_id
                WHERE s.plm_product_id IS NULL
            ");

            while ($row = $diffStmt->fetch(PDO::FETCH_ASSOC)) {
                $result['mismatched']++;
                $result['details'][] = $row;
            }
        } else {
            $result['matched'] = $plmCount;
        }

        $this->logger->info("PLM数据对账完成", $result);
        return $result;
    }

    public function reconcileErpMaterials(): array
    {
        return $this->reconcileByTable('u8_materials', 'capp_materials', 'u8_material_id');
    }

    private function reconcileByTable(string $sourceTable, string $targetTable, string $joinField): array
    {
        $stmt = $this->db->query("
            SELECT COUNT(*) as total,
                   SUM(CASE WHEN t.{$joinField} IS NOT NULL THEN 1 ELSE 0 END) as matched,
                   SUM(CASE WHEN t.{$joinField} IS NULL THEN 1 ELSE 0 END) as mismatched
            FROM {$sourceTable} s
            LEFT JOIN {$targetTable} t ON s.{$joinField} = t.{$joinField}
        ");

        return $stmt->fetch(PDO::FETCH_ASSOC);
    }
}
```

```php
<?php

class EncryptionUtil
{
    private string $key;

    public function __construct(string $key)
    {
        $this->key = $key;
    }

    public function encrypt(string $data): string
    {
        $iv = random_bytes(16);
        $encrypted = openssl_encrypt($data, 'AES-256-CBC', $this->key, 0, $iv);
        return base64_encode($iv . $encrypted);
    }

    public function decrypt(string $encryptedData): string
    {
        $data = base64_decode($encryptedData);
        $iv = substr($data, 0, 16);
        $encrypted = substr($data, 16);
        return openssl_decrypt($encrypted, 'AES-256-CBC', $this->key, 0, $iv);
    }

    public static function maskString(string $str, int $visibleStart = 4, int $visibleEnd = 4): string
    {
        $length = strlen($str);
        if ($length <= ($visibleStart + $visibleEnd)) {
            return str_repeat('*', $length);
        }
        return substr($str, 0, $visibleStart) . str_repeat('*', $length - $visibleStart - $visibleEnd) . substr($str, -$visibleEnd);
    }
}
```
