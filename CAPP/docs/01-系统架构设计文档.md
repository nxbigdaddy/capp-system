## 1. 系统概述

### 1.1 公司背景

本公司是一家专注于**工业压缩机**和**压力容器**研发、设计、生产的现代化制造企业。核心业务涵盖：

- **工业压缩机**: 特种气体压缩设备，广泛应用于石化、军工、新能源等领域
- **压力容器**: 各类标准/非标压力容器设计与制造，持有A1/A2/A3级压力容器制造许可证
- **核心能力**: 自主研发、精密加工、质量检测、工程总包

企业数字化转型需求：
- 工艺设计标准化、规范化
- 设计数据与生产数据打通
- 工艺知识沉淀与复用
- 跨系统数据协同

### 1.2 系统目标

CAPP（Computer Aided Process Planning，计算机辅助工艺设计系统）旨在实现：

| 目标维度 | 具体描述 |
|---------|---------|
| 工艺标准化 | 建立企业标准工艺库，实现工艺路线、工序、工步的标准化管理 |
| 设计效率提升 | 通过典型工艺库、工艺模板、智能推荐，缩短工艺设计周期50%以上 |
| 知识沉淀 | 将专家经验数字化，建立可复用的工艺知识库 |
| 数据打通 | 与PLM、ERP、MES系统无缝集成，实现数据闭环 |
| 智能决策 | 引入AI能力，实现工艺参数智能推荐、工艺方案智能评审 |
| 移动协同 | 通过企业微信实现移动审批、消息通知、工艺查询 |

**核心功能模块**:

1. **基础数据管理**: 材料库、设备库、工装夹具库、量具库
2. **工艺设计**: 工艺路线设计、工序设计、工步设计、工艺卡片生成
3. **典型工艺库**: 典型零件工艺模板、相似工艺推荐
4. **工时定额**: 标准工时计算、工时统计与分析
5. **辅料定额**: 切削液、焊材、油漆等辅料计算
6. **工艺审批**: 多级审批流程、电子签名
7. **版本管理**: 工艺文件版本控制、变更管理
8. **报表中心**: 工艺BOM、工艺路线表、汇总报表
9. **AI决策**: 工艺参数推荐、工艺方案评审、异常预警
10. **系统管理**: 用户、角色、权限、日志、配置

### 1.4 设计原则

| 原则 | 说明 |
|-----|------|
| 高内聚低耦合 | 模块间通过标准接口通信，降低依赖 |
| 开闭原则 | 对扩展开放，对修改封闭 |
| 单一职责 | 每个模块/类只负责一项职责 |
| 配置优先 | 业务规则通过配置实现，减少硬编码 |
| 安全可控 | 全链路安全防护，数据加密传输存储 |
| 可追溯性 | 所有操作可审计，数据变更可追溯 |

### 2.3 分层架构

| 层级 | 职责 | 技术实现 | 目录结构 |
|-----|------|---------|---------|

| **集成层** | 外部系统对接、协议转换、数据映射 | API Client、Adapter模式 | `/app/integrations/` |
| **公共层** | 通用工具、配置管理、日志记录 | Helper类、单例模式 | `/app/core/`, `/app/utils/` |

```php
class DataEncryptor {
    private const METHOD = 'AES-256-CBC';
    private const KEY = ''; // 从环境变量获取

    public static function encrypt(string $data): string {
        $iv = random_bytes(16);
        $encrypted = openssl_encrypt($data, self::METHOD, self::KEY, 0, $iv);
        return base64_encode($iv . $encrypted);
    }

    public static function decrypt(string $data): string {
        $decoded = base64_decode($data);
        $iv = substr($decoded, 0, 16);
        $encrypted = substr($decoded, 16);
        return openssl_decrypt($encrypted, self::METHOD, self::KEY, 0, $iv);
    }
}
```

### 9.1 缓存策略

**缓存架构**:


**缓存层级**:

| 层级 | 技术 | 用途 | TTL |
|-----|------|------|-----|
| 浏览器缓存 | HTTP Cache | 静态资源 | 1天-30天 |
| CDN缓存 | CDN | 静态资源分发 | 1天 |
| 应用缓存 | Redis | 会话、配置、热点数据 | 5分钟-24小时 |
| 数据库缓存 | MySQL Query Cache | 查询结果 | 自动 |
| OpCode缓存 | OPcache | PHP字节码 | 重启失效 |

**缓存策略设计**:

```php
class CacheManager {
    private Redis $redis;

    // 缓存键前缀
    private const PREFIX = 'capp:';
    
    // 缓存时间配置
    private const TTL = [
        'user_info' => 3600,          // 用户信息 1小时
        'config' => 86400,            // 系统配置 24小时
        'material_list' => 3600,      // 材料列表 1小时
        'process_template' => 7200,   // 工艺模板 2小时
        'permission' => 1800,         // 权限数据 30分钟
        'session' => 7200,            // 会话 2小时
        'dict' => 86400,              // 字典数据 24小时
    ];

    public function get(string $key): mixed {
        $fullKey = self::PREFIX . $key;
        $data = $this->redis->get($fullKey);
        return $data ? json_decode($data, true) : null;
    }

    public function set(string $key, mixed $value, ?int $ttl = null): bool {
        $fullKey = self::PREFIX . $key;
        $ttl = $ttl ?? (self::TTL[$key] ?? 3600);
        return $this->redis->setex($fullKey, $ttl, json_encode($value));
    }

    public function delete(string $key): bool {
        return $this->redis->del(self::PREFIX . $key) > 0;
    }

    // 缓存穿透防护: 布隆过滤器
    public function bloomFilterCheck(string $key): bool {
        // 布隆过滤器实现
    }

    // 缓存雪崩防护: 随机TTL
    public function setWithJitter(string $key, mixed $value, int $baseTtl): bool {
        $jitter = random_int(0, (int)($baseTtl * 0.2));
        return $this->set($key, $value, $baseTtl + $jitter);
    }
}
```

| `capp:user:{id}` | Hash | 用户基本信息 |
| `capp:config:{key}` | String | 系统配置项 |
| `capp:permission:{role_id}` | Set | 角色权限列表 |
| `capp:material:list` | List | 材料列表缓存 |
| `capp:session:{token}` | Hash | 会话数据 |
| `capp:dict:{type}` | Hash | 字典数据 |

5. 大表查询使用分页，避免全表扫描
