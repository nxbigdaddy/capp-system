## 技术栈

| 层级 | 技术 |
|------|------|
| 后端 | PHP 8.x（原生开发，不使用框架） |
| 数据库 | MySQL 8.x |
| 缓存 | Redis 7.x |
| 前端 | Vue.js 3 + Element Plus |
| 消息队列 | RabbitMQ |
| 向量数据库 | Milvus（AI功能） |
| 知识库 | MaxKB 专业版 |

## 核心功能

- ✅ 工艺路线设计、工序设计、工步设计
- ✅ 工艺卡片编制与管理
- ✅ 产品BOM管理
- ✅ 工时定额计算
- ✅ 模板管理
- ✅ 审批流程
- ✅ 企业微信集成（扫码登录、消息推送、用户同步）
- ✅ AI决策与AI助手
- ✅ MaxKB专业版知识库对接
- ✅ MaxKB专业版智能体对接
- ✅ 外部系统对接（CAXA PLM、U8 ERP、MES）
