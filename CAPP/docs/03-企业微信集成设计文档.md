### 2.2 OAuth2.0授权流程

#### 2.2.1 授权码模式流程

企业微信扫码登录采用OAuth2.0授权码模式，具体流程如下：

**第一步：构造授权URL**

`GET https://open.work.weixin.qq.com/wwopen/sso/qrConnect?appid=CORPID&agentid=AGENTID&redirect_uri=REDIRECT_URI&state=STATE`

| 参数 | 必填 | 说明 |
|------|------|------|
| appid | 是 | 企业微信CorpID |
| agentid | 是 | 授权方应用AgentID |
| redirect_uri | 是 | 授权后重定向的回调链接，需URL Encode |
| state | 是 | 用于保持请求和回调的状态，防CSRF攻击 |

**第二步：用户扫码确认**

用户打开企业微信扫描二维码，确认授权登录。

**第三步：回调处理**

企业微信将用户重定向到redirect_uri，并携带参数：

`GET /capp/auth/wecom/callback?code=CODE&state=STATE`

| 参数 | 说明 |
|------|------|
| code | 授权码，用于换取用户身份，有效期5分钟，只能使用一次 |
| state | 原样返回，用于校验请求合法性 |

**第四步：获取用户身份**

使用code换取用户userid：

`GET https://qyapi.weixin.qq.com/cgi-bin/auth/getuserinfo?access_token=YOUR_SECRET`

返回示例：

```json
{
    "errcode": 0,
    "errmsg": "ok",
    "userid": "ZhangSan",
    "user_ticket": "USER_TICKET",
    "expires_in": 7200
}
```

**第五步：获取用户详情**

使用user_ticket获取用户详细信息：

`POST https://qyapi.weixin.qq.com/cgi-bin/auth/getuserdetail?access_token=YOUR_SECRET`

请求体：

```json
{
    "user_ticket": "USER_TICKET"
}
```

返回示例：

```json
{
    "errcode": 0,
    "errmsg": "ok",
    "userid": "ZhangSan",
    "name": "张三",
    "department": [1, 2],
    "position": "工艺工程师",
    "mobile": "13800138000",
    "email": "zhangsan@company.com",
    "avatar": "http://wework.qpic.cn/xxx/0"
}
```

### 2.3 回调处理逻辑

1. 接收回调请求，校验state参数（与Session对比），失败则返回403
2. 检查code是否存在，不存在则返回400
3. 调用getuserinfo API换取userid，失败则记录错误日志并返回500
4. 调用getuserdetail获取用户详细信息
5. 查询本地用户表（按userid匹配），不存在则自动创建用户（首次登录）
6. 检查用户状态，禁用则返回403
7. 更新用户信息（姓名、部门等）
8. 生成登录凭证（Session/JWT）
9. 记录登录日志，重定向到首页

### 2.4 Token管理策略

#### 2.4.1 企业微信access_token管理

- **存储方式**: Redis / 数据库 / 文件缓存，推荐Redis（支持分布式部署场景）
- **获取Token时**:
  1. 先检查缓存是否存在且未过期
  2. 若存在且有效，直接返回
  3. 若不存在或已过期，重新获取
  4. 获取失败时，使用旧Token（若仍在有效期内）
  5. 记录Token获取日志，便于排查问题
- **Token刷新策略**:
  - 企业微信access_token有效期: 7200秒（2小时）
  - 本地缓存有效期设置: 7000秒（提前200秒刷新）
  - 最大重试次数: 3次
  - 重试间隔: 指数退避（1s, 2s, 4s）

#### 2.4.2 本地用户登录凭证管理

| 凭证类型 | 有效期 | 刷新策略 | 存储位置 |
|---------|--------|---------|---------|
| Session Cookie | 8小时 | 用户活跃时自动续期 | 服务端Session + 客户端Cookie |
| JWT Token | 2小时 | 静默刷新(Refresh Token) | 客户端LocalStorage |
| Refresh Token | 7天 | 重新企业微信授权 | 服务端数据库 |

```php
class HttpClient
{
    public static function get($url, $timeout = 30)
    {
        $ch = curl_init();
        curl_setopt_array($ch, [
            CURLOPT_URL => $url,
            CURLOPT_RETURNTRANSFER => true,
            CURLOPT_TIMEOUT => $timeout,
            CURLOPT_SSL_VERIFYPEER => true,
            CURLOPT_SSL_VERIFYHOST => 2,
            CURLOPT_HTTPHEADER => ['Accept: application/json', 'Content-Type: application/json'],
        ]);
        $response = curl_exec($ch);
        $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
        $error = curl_error($ch);
        curl_close($ch);
        if ($error) throw new RuntimeException("HTTP请求失败: {$error}");
        $data = json_decode($response, true);
        if ($data === null) throw new RuntimeException("JSON解析失败: {$response}");
        return ['http_code' => $httpCode, 'data' => $data];
    }

class WeComTokenManager
{
    public static function getAccessToken()
    {
        $cache = self::loadTokenCache();
        if ($cache && isset($cache['expires_at']) && time() < ($cache['expires_at'] - WeComConfig::TOKEN_REFRESH_BUFFER)) {
            return $cache['access_token'];
        }
        return self::refreshAccessToken();
    }

    private static function refreshAccessToken()
    {
        $url = sprintf('%s/cgi-bin/gettoken?corpid=%s&corpsecret=%s',
            WeComConfig::API_BASE_URL, WeComConfig::CORP_ID, WeComConfig::APP_SECRET);
        $maxRetries = 3;
        $lastError = null;
        for ($i = 0; $i < $maxRetries; $i++) {
            try {
                $result = HttpClient::get($url);
                if ($result['data']['errcode'] !== 0) {
                    throw new RuntimeException("获取Token失败: {$result['data']['errmsg']} (errcode: {$result['data']['errcode']})");
                }
                $tokenData = [
                    'access_token' => $result['data']['access_token'],
                    'expires_at' => time() + $result['data']['expires_in'],
                    'created_at' => date('Y-m-d H:i:s'),
                ];
                self::saveTokenCache($tokenData);
                self::logTokenRefresh('success');
                return $tokenData['access_token'];
            } catch (Exception $e) {
                $lastError = $e;
                if ($i < $maxRetries - 1) sleep(pow(2, $i));
            }
        }
        self::logTokenRefresh('failed', $lastError->getMessage());
        throw $lastError;
    }

    private static function loadTokenCache()
    {
        if (!file_exists(WeComConfig::TOKEN_CACHE_FILE)) return null;
        return json_decode(file_get_contents(WeComConfig::TOKEN_CACHE_FILE), true);
    }

    private static function saveTokenCache($data)
    {
        $dir = dirname(WeComConfig::TOKEN_CACHE_FILE);
        if (!is_dir($dir)) mkdir($dir, 0755, true);
        $fp = fopen(WeComConfig::TOKEN_CACHE_FILE, 'w');
        if (flock($fp, LOCK_EX)) {
            fwrite($fp, json_encode($data, JSON_PRETTY_PRINT));
            flock($fp, LOCK_UN);
        }
        fclose($fp);
    }

    private static function logTokenRefresh($status, $message = '')
    {
        $logEntry = sprintf("[%s] Token刷新: status=%s, message=%s\n", date('Y-m-d H:i:s'), $status, $message);
        $logFile = __DIR__ . '/logs/wecom_token.log';
        $dir = dirname($logFile);
        if (!is_dir($dir)) mkdir($dir, 0755, true);
        file_put_contents($logFile, $logEntry, FILE_APPEND);
    }
}

class WeComStateManager
{
    public static function generateState()
    {
        $state = bin2hex(random_bytes(32));
        $_SESSION['wecom_state'] = ['value' => $state, 'created_at' => time()];
        return $state;
    }

    public static function validateState($state)
    {
        if (!isset($_SESSION['wecom_state'])) return false;
        $stored = $_SESSION['wecom_state'];
        if (time() - $stored['created_at'] > WeComConfig::STATE_EXPIRE_TIME) {
            unset($_SESSION['wecom_state']);
            return false;
        }
        $valid = hash_equals($stored['value'], $state);
        unset($_SESSION['wecom_state']);
        return $valid;
    }
}
```

### 2.6 安全考虑

#### 2.6.1 防重放攻击

| 防护措施 | 实现方式 | 说明 |
|---------|---------|------|
| state参数 | 随机生成32字节hex字符串，一次性使用 | 防止CSRF攻击和请求重放 |
| code一次性 | 企业微信code只能使用一次 | 防止授权码被重复使用 |
| Session绑定 | state与服务端Session绑定 | 确保请求来源合法 |
| 时效控制 | state有效期10分钟，code有效期5分钟 | 缩短攻击窗口期 |
| 时序安全 | 使用hash_equals比较state | 防止时序攻击泄露信息 |

#### 2.6.2 Token安全策略

- **access_token**: 服务端文件缓存（加文件锁），仅用于服务端API调用，不暴露给客户端，提前5分钟刷新，文件权限0600
- **Session Cookie**: Secure=true（仅HTTPS传输），HttpOnly=true（JavaScript不可访问），SameSite=Lax（防CSRF），有效期8小时，登录时session_regenerate_id()
- **传输安全**: 全站HTTPS，HSTS头max-age=31536000，TLS 1.2+

### 3.5 冲突处理机制

- **场景1**: 企微有，本地没有 -> 创建新用户
- **场景2**: 企微有，本地有 -> 更新本地数据（以企微为准）
- **场景3**: 企微无，本地有 -> 标记为待确认（不直接删除）
- **场景4**: 双方都有但数据不同 -> 以企微为准，记录变更日志
- **特殊规则**: 本地扩展字段（工号、资质等）不受同步影响；本地手动修改的字段标记为"锁定"，同步时跳过
- **冲突解决优先级**: 1.企业微信数据（基础信息） 2.CAPP本地数据（扩展信息） 3.手动锁定字段（最高优先级）

### 3.6 PHP实现代码示例

#### 3.6.1 用户同步核心类

```php
<?php
/**
 * CAPP系统 - 企业微信用户同步模块
 * 原生PHP实现
 */

class WeComSyncManager
{
    private $accessToken;
    private $pdo;
    private $syncLog = [];

    public function __construct()
    {
        $this->accessToken = YOUR_SECRET);
        $this->pdo = Database::getConnection();
    }

    public function fullSync()
    {
        $startTime = microtime(true);
        $this->logSync('开始全量同步');
        try {
            $this->syncDepartments();
            $this->syncUsers();
            $this->handleOrphanUsers();
            $duration = round(microtime(true) - $startTime, 2);
            $report = $this->generateSyncReport($duration);
            $this->logSync('全量同步完成', $report);
            return $report;
        } catch (Exception $e) {
            $this->logSync('同步失败: ' . $e->getMessage());
            throw $e;
        }
    }

    private function syncDepartments()
    {
        $url = sprintf('%s/cgi-bin/department/list?access_token=%s', WeComConfig::API_BASE_URL, $this->accessToken);
        $result = HttpClient::get($url);
        if ($result['data']['errcode'] !== 0) throw new RuntimeException("获取部门列表失败: {$result['data']['errmsg']}");
        $wecomDepts = $result['data']['department'];
        $syncedIds = [];
        foreach ($wecomDepts as $dept) {
            $this->upsertDepartment($dept);
            $syncedIds[] = $dept['id'];
        }
        $this->syncLog['synced_dept_ids'] = $syncedIds;
        $this->logSync("部门同步完成，共同步 " . count($wecomDepts) . " 个部门");
    }

    private function upsertDepartment($dept)
    {
        $deptPath = $this->calculateDepartmentPath($dept);
        $stmt = $this->pdo->prepare('INSERT INTO departments (wecom_dept_id, dept_name, parent_wecom_dept_id, sort_order, dept_path, updated_at) VALUES (?, ?, ?, ?, ?, NOW()) ON DUPLICATE KEY UPDATE dept_name = VALUES(dept_name), parent_wecom_dept_id = VALUES(parent_wecom_dept_id), sort_order = VALUES(sort_order), dept_path = VALUES(dept_path), updated_at = NOW()');
        $stmt->execute([$dept['id'], $dept['name'], $dept['parentid'], $dept['order'], $deptPath]);
    }

    private function calculateDepartmentPath($dept)
    {
        $path = [$dept['name']];
        $parentId = $dept['parentid'];
        $maxDepth = 10;
        $depth = 0;
        while ($parentId > 0 && $depth < $maxDepth) {
            $stmt = $this->pdo->prepare('SELECT dept_name, parent_wecom_dept_id FROM departments WHERE wecom_dept_id = ?');
            $stmt->execute([$parentId]);
            $parent = $stmt->fetch();
            if ($parent) {
                array_unshift($path, $parent['dept_name']);
                $parentId = $parent['parent_wecom_dept_id'];
            } else break;
            $depth++;
        }
        return implode('/', $path);
    }

    private function syncUsers()
    {
        $stmt = $this->pdo->query('SELECT wecom_dept_id FROM departments');
        $deptIds = $stmt->fetchAll(PDO::FETCH_COLUMN);
        $syncedUserIds = [];
        $newCount = 0;
        $updateCount = 0;
        foreach ($deptIds as $deptId) {
            $users = $this->fetchDepartmentUsers($deptId);
            foreach ($users as $user) {
                if (in_array($user['userid'], $syncedUserIds)) continue;
                $result = $this->upsertUser($user);
                if ($result === 'insert') $newCount++; else $updateCount++;
                $syncedUserIds[] = $user['userid'];
            }
        }
        $this->syncLog['synced_user_ids'] = $syncedUserIds;
        $this->syncLog['new_users'] = $newCount;
        $this->syncLog['updated_users'] = $updateCount;
        $this->logSync("用户同步完成，新增 {$newCount} 人，更新 {$updateCount} 人");
    }

    private function updateUser($existing, $user)
    {
        $lockedFields = $this->getLockedFields($existing['id']);
        $updates = [];
        $params = [];
        $fieldMapping = [
            'real_name' => ['wecom' => 'name', 'locked' => in_array('real_name', $lockedFields)],
            'phone' => ['wecom' => 'mobile', 'locked' => in_array('phone', $lockedFields)],
            'email' => ['wecom' => 'email', 'locked' => in_array('email', $lockedFields)],
            'job_title' => ['wecom' => 'position', 'locked' => in_array('job_title', $lockedFields)],
            'avatar_url' => ['wecom' => 'avatar', 'locked' => in_array('avatar_url', $lockedFields)],
        ];
        foreach ($fieldMapping as $cappField => $config) {
            if ($config['locked']) continue;
            $wecomField = $config['wecom'];
            if (isset($user[$wecomField]) && $user[$wecomField] !== $existing[$cappField]) {
                $updates[] = "{$cappField} = ?";
                $params[] = $user[$wecomField];
            }
        }
        $newStatus = $this->mapWecomStatus($user['status'] ?? 1);
        if ($newStatus !== $existing['account_status']) { $updates[] = "account_status = ?"; $params[] = $newStatus; }
        if (empty($updates)) return;
        $updates[] = "updated_at = NOW()";
        $params[] = $existing['id'];
        $sql = 'UPDATE users SET ' . implode(', ', $updates) . ' WHERE id = ?';
        $stmt = $this->pdo->prepare($sql);
        $stmt->execute($params);
        $this->logUserChange($existing, $user, $updates);
    }

    private function handleOrphanUsers()
    {
        $syncedIds = $this->syncLog['synced_user_ids'] ?? [];
        if (empty($syncedIds)) return;
        $placeholders = implode(',', array_fill(0, count($syncedIds), '?'));
        $stmt = $this->pdo->prepare("UPDATE users SET account_status = 0, updated_at = NOW() WHERE wecom_userid NOT IN ({$placeholders}) AND account_status != 0 AND wecom_userid IS NOT NULL");
        $stmt->execute($syncedIds);
        $affected = $stmt->rowCount();
        if ($affected > 0) $this->logSync("发现 {$affected} 个企微不存在的用户，已标记为待确认");
    }

    private function mapWecomStatus($wecomStatus) { $map = [1 => 1, 2 => 2, 4 => 0]; return $map[$wecomStatus] ?? 0; }
    private function mapWecomGender($wecomGender) { $map = ['1' => 1, '2' => 2, '0' => 0]; return $map[$wecomGender] ?? 0; }

    {
        $stmt = $this->pdo->prepare('SELECT field_name FROM user_field_lock WHERE user_id = ?');
        $stmt->execute([$userId]);
        return $stmt->fetchAll(PDO::FETCH_COLUMN);
    }

    {
        $stmt = $this->pdo->prepare('INSERT INTO user_sync_logs (user_id, wecom_userid, change_type, change_detail, sync_time) VALUES (?, ?, "update", ?, NOW())');
        $stmt->execute([$existing['id'], $existing['wecom_userid'], json_encode($updates, JSON_UNESCAPED_UNICODE)]);
    }

    {
        return ['sync_type' => 'full', 'sync_time' => date('Y-m-d H:i:s'), 'duration' => "{$duration}s", 'departments' => count($this->syncLog['synced_dept_ids'] ?? []), 'new_users' => $this->syncLog['new_users'] ?? 0, 'updated_users' => $this->syncLog['updated_users'] ?? 0];
    }

    {

    }
```

#### 4.4.2 队列工作模式

- **生产端**: 业务代码调用MessageService::send() -> 消息写入message_queue表(status=pending) -> 返回message_id给调用方
- **消费端**: CLI脚本定时执行(每10秒)或守护进程持续运行 -> 查询status=pending且next_retry_at<=NOW的消息 -> 逐条发送到企业微信 -> 更新状态和日志 -> 失败消息按指数退避设置下次重试时间
- **重试策略**: 第1次重试30秒后，第2次重试2分钟后，第3次重试10分钟后，超过最大次数标记为failed并触发告警
- **并发控制**: 使用SELECT ... FOR UPDATE锁定待处理消息，多Worker进程通过行锁避免重复消费，单次批量处理上限100条

```php
// 消息发送Worker
class WeComMessageWorker
{
    private $pdo;
    private $batchSize = 100;
    private $maxRetries = 3;
    public function __construct() { $this->pdo = Database::getConnection(); }

    public function run()
    {
        echo "[" . date('Y-m-d H:i:s') . "] 消息发送Worker启动\n";
        while (true) {
            try {
                $processed = $this->processQueue();
                if ($processed === 0) sleep(10);
            } catch (Exception $e) {
                echo "[" . date('Y-m-d H:i:s') . "] Worker异常: " . $e->getMessage() . "\n";
                sleep(30);
            }
        }
    }

    public function processQueue()
    {
        $stmt = $this->pdo->prepare("SELECT * FROM message_queue WHERE status = 'pending' AND (next_retry_at IS NULL OR next_retry_at <= NOW()) ORDER BY created_at ASC LIMIT ? FOR UPDATE SKIP LOCKED");
        $stmt->execute([$this->batchSize]);
        $messages = $stmt->fetchAll(PDO::FETCH_ASSOC);
        if (empty($messages)) return 0;
        $processed = 0;
        $accessToken = YOUR_SECRET);
        foreach ($messages as $message) { $this->sendMessage($message, $accessToken); $processed++; }
        return $processed;
    }

    private function sendMessage($message, $accessToken)
    {
        $queueId = $message['id'];
        $attempt = $message['retry_count'] + 1;
        $startTime = microtime(true);
        $this->updateQueueStatus($queueId, 'sending');
        try {
            $url = sprintf('%s/cgi-bin/message/send?access_token=%s', WeComConfig::API_BASE_URL, $accessToken);
            $payload = json_decode($message['content'], true);
            $payload['touser'] = $message['touser'];
            $payload['toparty'] = $message['toparty'];
            $payload['totag'] = $message['totag'];
            $payload['agentid'] = WeComConfig::AGENT_ID;
            $result = HttpClient::post($url, $payload);
            $duration = round((microtime(true) - $startTime) * 1000);
            $success = ($result['data']['errcode'] === 0);
            $this->logSendAttempt($queueId, $message['message_id'], $attempt, json_encode($payload, JSON_UNESCAPED_UNICODE), json_encode($result['data'], JSON_UNESCAPED_UNICODE), $success, $success ? '' : $result['data']['errmsg'], $duration);
            if ($success) {
                $this->updateQueueStatus($queueId, 'success');
                echo "[{$message['message_id']}] 发送成功 ({$duration}ms)\n";
            } else {
                $this->handleSendFailure($queueId, $message, $result['data']['errmsg'], $attempt);
            }
        } catch (Exception $e) {
            $duration = round((microtime(true) - $startTime) * 1000);
            $this->logSendAttempt($queueId, $message['message_id'], $attempt, '', '', false, $e->getMessage(), $duration);
            $this->handleSendFailure($queueId, $message, $e->getMessage(), $attempt);
        }
    }

    private function handleSendFailure($queueId, $message, $errorMessage, $attempt)
    {
        if ($attempt >= $this->maxRetries) {
            $this->updateQueueStatus($queueId, 'failed', $errorMessage);
            echo "[{$message['message_id']}] 发送失败(已达最大重试): {$errorMessage}\n";
            $this->triggerAlert($message, $errorMessage);
        } else {
            $delaySeconds = $this->calculateRetryDelay($attempt);
            $nextRetryAt = date('Y-m-d H:i:s', time() + $delaySeconds);
            $stmt = $this->pdo->prepare('UPDATE message_queue SET status = "pending", retry_count = retry_count + 1, next_retry_at = ?, updated_at = NOW() WHERE id = ?');
            $stmt->execute([$nextRetryAt, $queueId]);
            echo "[{$message['message_id']}] 发送失败，{$delaySeconds}秒后重试({$attempt}/{$this->maxRetries})\n";
        }
    }

    private function calculateRetryDelay($attempt) { $delays = [30, 120, 600]; return $delays[$attempt - 1] ?? 600; }

    private function updateQueueStatus($queueId, $status, $errorMessage = '')
    {
        if ($status === 'success') {
            $stmt = $this->pdo->prepare('UPDATE message_queue SET status = ?, sent_at = NOW(), updated_at = NOW() WHERE id = ?');
            $stmt->execute([$status, $queueId]);
        } else {
            $stmt = $this->pdo->prepare('UPDATE message_queue SET status = ?, error_message = ?, updated_at = NOW() WHERE id = ?');
            $stmt->execute([$status, $errorMessage, $queueId]);
        }
    }

    private function logSendAttempt($queueId, $messageId, $attempt, $requestPayload, $responsePayload, $success, $errorMessage, $duration)
    {
        $stmt = $this->pdo->prepare('INSERT INTO message_send_logs (queue_id, message_id, attempt, request_payload, response_payload, success, error_message, duration_ms, created_at) VALUES (?, ?, ?, ?, ?, ?, ?, ?, NOW())');
        $stmt->execute([$queueId, $messageId, $attempt, $requestPayload, $responsePayload, $success ? 1 : 0, $errorMessage, $duration]);
    }

    private function triggerAlert($message, $errorMessage)
    {
        $alertMessage = sprintf("[CAPP消息推送告警] 消息发送失败\n消息ID: %s\n接收人: %s\n错误: %s\n已重试%d次", $message['message_id'], $message['touser'], $errorMessage, $message['retry_count']);
        file_put_contents(__DIR__ . '/logs/message_alert.log', date('Y-m-d H:i:s') . ' ' . $alertMessage . "\n", FILE_APPEND);
    }
}
```

```sql
-- 查询发送失败的消息
SELECT mq.message_id, mq.touser, mq.template_code, mq.retry_count, mq.error_message, mq.created_at, msl.attempt, msl.error_message as attempt_error, msl.duration_ms

-- 统计消息发送成功率
SELECT DATE(created_at) as date, COUNT(*) as total,
    SUM(CASE WHEN status = 'success' THEN 1 ELSE 0 END) as success_count,
    SUM(CASE WHEN status = 'failed' THEN 1 ELSE 0 END) as failed_count,
    ROUND(SUM(CASE WHEN status = 'success' THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 2) as success_rate
FROM message_queue WHERE created_at >= DATE_SUB(NOW(), INTERVAL 7 DAY)
GROUP BY DATE(created_at) ORDER BY date DESC;
```

### 6.2 审批状态同步

#### 6.2.1 审批状态流转

1. CAPP发起审批 -> 调用企微审批API创建审批单
2. 记录映射关系: CAPP审批单ID <--> 企微审批单号(sp_no)
3. 等待审批 -> 企微审批流转动
4. 企微回调通知 -> CAPP接收审批状态变更事件
5. 更新CAPP审批状态: 审批中(approving) / 已通过(approved) / 已驳回(rejected) / 已撤销(cancelled)
6. 触发后续业务逻辑: 通过则工艺文件状态变更为"已审核"，驳回则通知提交人修改后重新提交，撤销则恢复为草稿状态

#### 6.2.2 审批状态映射

| 企微审批状态 | CAPP审批状态 | 说明 |
|-------------|-------------|------|
| 1 (审批中) | approving | 审批流程进行中 |
| 2 (已通过) | approved | 全部审批节点通过 |
| 3 (已驳回) | rejected | 任一节点驳回 |
| 4 (已撤销) | cancelled | 提交人主动撤销 |
| 6 (审批终止) | terminated | 审批流程被管理员终止 |

### 6.3 回调处理

#### 6.3.1 审批回调事件

企业微信审批状态变更时，会向CAPP系统推送回调事件（XML格式），包含审批单号(SpNo)、审批状态(SpStatus)、提交人信息、审批记录等。

#### 6.3.2 审批回调处理PHP代码

```php
<?php
/**
 * CAPP系统 - 企业微信审批回调处理
 */

class WeComApprovalCallback
{
    private $pdo;
    public function __construct() { $this->pdo = Database::getConnection(); }

    public function handleCallback($xmlData)
    {
        $xml = simplexml_load_string($xmlData, 'SimpleXMLElement', LIBXML_NOCDATA);
        $spNo = (string)$xml->ChangeType->SpNo;
        $spStatus = (int)$xml->ChangeType->SpStatus;
        $applyerId = (string)$xml->ChangeType->Applyer->UserId;
        $cappStatus = $this->mapApprovalStatus($spStatus);
        $approval = $this->findApprovalBySpNo($spNo);
        if (!$approval) { $this->logWarning("未找到关联的CAPP审批单: sp_no={$spNo}"); return 'success'; }
        $this->updateApprovalStatus($approval['id'], $cappStatus, $xml);
        $this->triggerPostApprovalActions($approval, $cappStatus, $xml);
        $this->logApprovalEvent($spNo, $cappStatus, $applyerId);
        return 'success';
    }

    private function mapApprovalStatus($wecomStatus)
    {
        $map = [1 => 'approving', 2 => 'approved', 3 => 'rejected', 4 => 'cancelled', 6 => 'terminated'];
        return $map[$wecomStatus] ?? 'unknown';
    }

    private function findApprovalBySpNo($spNo)
    {
        $stmt = $this->pdo->prepare('SELECT * FROM approvals WHERE wecom_sp_no = ?');
        $stmt->execute([$spNo]);
        return $stmt->fetch(PDO::FETCH_ASSOC);
    }

    private function updateApprovalStatus($approvalId, $status, $xml)
    {
        $approvalComment = '';
        $spRecord = $xml->ChangeType->SpRecord;
        if ($spRecord && $spRecord->ApproverAttr) $approvalComment = (string)$spRecord->ApproverAttr->Approval;
        $stmt = $this->pdo->prepare('UPDATE approvals SET status = ?, approval_comment = ?, approved_at = NOW(), updated_at = NOW() WHERE id = ?');
        $stmt->execute([$status, $approvalComment, $approvalId]);
    }

    private function triggerPostApprovalActions($approval, $status, $xml)
    {
        switch ($status) {
            case 'approved': $this->handleApprovalPassed($approval); $this->notifyApprovalResult($approval, 'approved'); break;
            case 'rejected': $this->notifyApprovalResult($approval, 'rejected'); break;
            case 'cancelled': $this->handleApprovalCancelled($approval); break;
        }
    }

    private function handleApprovalPassed($approval)
    {
        $stmt = $this->pdo->prepare('UPDATE process_documents SET status = "approved", approved_at = NOW() WHERE id = ?');
        $stmt->execute([$approval['document_id']]);
    }

    private function handleApprovalCancelled($approval)
    {
        $stmt = $this->pdo->prepare('UPDATE process_documents SET status = "draft" WHERE id = ?');
        $stmt->execute([$approval['document_id']]);
    }

    private function notifyApprovalResult($approval, $result)
    {
        $messageService = new WeComMessageService();
        $content = sprintf("【CAPP系统】审批结果通知\n审批单号：%s\n审批结果：%s\n审批人：%s\n审批意见：%s\n请登录CAPP系统查看详情。", $approval['approval_no'], $result === 'approved' ? '已通过' : '已驳回', $approval['approver_name'] ?? '系统', $approval['approval_comment'] ?? '');
        $messageService->sendText($approval['submitter_wecom_id'], $content);
    }

    private function logApprovalEvent($spNo, $status, $applyerId)
    {
        $stmt = $this->pdo->prepare('INSERT INTO approval_event_logs (wecom_sp_no, capp_status, applyer_id, event_time) VALUES (?, ?, ?, NOW())');
        $stmt->execute([$spNo, $status, $applyerId]);
    }

    private function logWarning($message)
    {
        file_put_contents(__DIR__ . '/logs/approval_warning.log', date('Y-m-d H:i:s') . ' WARNING: ' . $message . "\n", FILE_APPEND);
    }
}
```

```php
            if (strpos(trim($line), '#') === 0) continue;

                list($key, $value) = explode('=', $line, 2);
                $key = trim($key);
                $value = trim(trim($value), '"\'');
                self::$config[$key] = $value;
                if (getenv($key) === false) putenv("{$key}={$value}");
            }
        }
    }

    public static function get($key, $default = null)
    {
        $value = getenv($key);
        if ($value === false) $value = self::$config[$key] ?? $default;
        return $value;
    }

    public static function getWeComConfig()
    {
        return [
```

### 8.3 配置加密存储

#### 8.3.1 敏感配置加密方案

针对企业微信Secret、数据库密码等敏感配置，采用AES-256-CBC加密存储：

```php
<?php
/**
 * CAPP系统 - 配置加密工具
 */

class ConfigEncryptor
{
    private $key;
    private $cipher = 'AES-256-CBC';

    public function __construct($key = null)
    {
        $this->key = $key ?? getenv('CONFIG_ENCRYPTION_KEY');
        if (!$this->key) throw new RuntimeException('未配置加密密钥 CONFIG_ENCRYPTION_KEY');
        $this->key = hash('sha256', $this->key, true);
    }

    public function encrypt($plaintext)
    {
        $ivLength = openssl_cipher_iv_length($this->cipher);
        $iv = openssl_random_pseudo_bytes($ivLength);
        $ciphertext = openssl_encrypt($plaintext, $this->cipher, $this->key, OPENSSL_RAW_DATA, $iv);
        if ($ciphertext === false) throw new RuntimeException('加密失败');
        return base64_encode($iv . $ciphertext);
    }

    public function decrypt($ciphertext)
    {
        $data = base64_decode($ciphertext);
        if ($data === false) throw new RuntimeException('解密失败: base64解码错误');
        $ivLength = openssl_cipher_iv_length($this->cipher);
        $iv = substr($data, 0, $ivLength);
        $ciphertext = substr($data, $ivLength);
        $plaintext = openssl_decrypt($ciphertext, $this->cipher, $this->key, OPENSSL_RAW_DATA, $iv);
        if ($plaintext === false) throw new RuntimeException('解密失败');
        return $plaintext;
    }

    public static function generateKey() { return bin2hex(random_bytes(32)); }
}

// 使用示例：在配置加载时自动解密
class SecureConfig extends Config
{
    private static $encryptor = null;

    public static function get($key, $default = null)
    {
        $value = parent::get($key, $default);
        if (is_string($value) && strpos($value, 'ENC:') === 0) {
            if (self::$encryptor === null) self::$encryptor = new ConfigEncryptor();
            return self::$encryptor->decrypt(substr($value, 4));
        }
        return $value;
    }
}
```
