## 1. 概述

### 1.1 集成目标

本集成旨在将CAPP（计算机辅助工艺设计系统）与企业微信平台深度整合，实现以下核心目标：

1. **统一身份认证**：通过企业微信扫码登录，实现员工单点登录（SSO），消除多套账号体系，提升用户体验和安全性。
2. **组织架构同步**：自动同步企业微信中的部门、人员信息至CAPP系统，确保组织架构数据的一致性和实时性。
3. **消息通知触达**：利用企业微信的消息推送能力，将CAPP系统中的工艺设计审批、任务分配、图纸变更等关键业务消息实时推送至相关人员。
4. **移动办公赋能**：通过企业微信工作台入口，使工程师、审批人员可在移动端便捷访问CAPP核心功能，提升工业压缩机、压力容器研发生产流程的协同效率。
5. **审批流程闭环**：打通CAPP工艺审批与企业微信审批流，实现审批发起、流转、结果回传的全链路自动化。

## 2. 企业微信扫码登录

### 2.1 登录流程

```mermaid
sequenceDiagram
    participant User as 用户(工程师/审批人)
    participant Browser as CAPP Web端
    participant Server as CAPP后端(PHP)
    participant WW as 企业微信服务器

    User->>Browser: 访问CAPP登录页面
    Browser->>Server: 请求登录二维码
    Server->>Server: 生成state参数(CSRF Token)
    Server-->>Browser: 返回带state的企微授权URL
    Browser->>WW: 展示二维码/跳转授权页
    User->>WW: 企业微信扫码确认
    WW->>Server: 回调携带code和state
    Server->>Server: 校验state有效性
    Server->>WW: 使用code换取用户信息(userid)
    WW-->>Server: 返回用户userid
    Server->>Server: 查询/创建本地用户
    Server->>Server: 生成JWT Session Token
    Server-->>Browser: 重定向至CAPP首页(携带Token)
    Browser->>Server: 携带Token访问业务接口
    Server-->>Browser: 返回业务数据
```

### 2.2 OAuth2.0授权流程

企业微信扫码登录基于OAuth2.0授权码模式，具体流程如下：

**步骤1：构造授权URL**

```
https://open.work.weixin.qq.com/wwopen/sso/qrConnect
    ?appid={CORPID}
    &agentid={AGENTID}
    &redirect_uri={REDIRECT_URI}
    &state={STATE}
```

**步骤2：用户扫码确认**

用户在企业微信App中扫描二维码或点击链接，确认授权登录。

**步骤3：接收授权码**

企业微信将用户重定向至 `redirect_uri`，并附带以下参数：

```
{REDIRECT_URI}?code={CODE}&state={STATE}
```

**步骤4：换取用户身份**

使用 `code` 调用企业微信API获取用户身份：

```
GET https://qyapi.weixin.qq.com/cgi-bin/auth/getuserinfo?access_token=YOUR_SECRET}&code={CODE}
```

返回数据：
```json
{
    "errcode": 0,
    "errmsg": "ok",
    "userid": "ZhangSan",
    "user_ticket": "USER_TICKET_VALUE",
    "expires_in": 7200
}
```

**步骤5：获取用户详情（可选）**

使用 `user_ticket` 获取用户详细信息：

```
POST https://qyapi.weixin.qq.com/cgi-bin/auth/getuserdetail?access_token=YOUR_SECRET}
Body: {"user_ticket": "USER_TICKET_VALUE"}
```

### 2.3 回调处理逻辑

回调处理是登录流程的核心环节，需要完成以下关键步骤：

1. **State校验**：验证回调中的 `state` 参数与Session中存储的是否一致，防止CSRF攻击。
2. **Code有效性校验**：`code` 只能使用一次，有效期5分钟，需立即换取用户信息。
3. **用户匹配**：通过 `userid` 在CAPP本地用户表中查找对应用户。
4. **自动注册**：若用户不存在，根据企微返回的用户信息自动创建CAPP账号（需配置是否允许自动注册）。
5. **Session创建**：生成本地Session Token（JWT），设置合理的过期时间。
6. **登录日志**：记录登录时间、IP、设备信息等审计日志。

### 2.4 Token管理策略

#### 2.4.1 AccessToken管理

企业微信 `access_token` 有效期为7200秒（2小时），每日调用次数有限，必须做好缓存管理：

| 策略项 | 配置值 | 说明 |
|--------|--------|------|
| 缓存方式 | Redis / 文件缓存 | 优先使用Redis，多服务器部署时共享 |
| 缓存Key | `ww:access_token` | 统一命名前缀 |
| 缓存有效期 | 7000秒 | 提前200秒过期，避免临界失效 |
| 刷新策略 | 被动刷新 + 定时预热 | 请求时发现过期则刷新；定时任务每1.8小时预热 |
| 并发控制 | 分布式锁 | 多实例同时刷新时加锁，避免重复请求 |

#### 2.4.2 Session Token管理

CAPP系统用户登录后的Session Token策略：

| 策略项 | 配置值 | 说明 |
|--------|--------|------|
| Token类型 | JWT (RS256) | 非对称加密，支持分布式验证 |
| 有效期 | 8小时 | 匹配工作时间，超时需重新登录 |
| 刷新Token | 是 | 有效期7天，用于无感刷新 |
| 单点登录 | 支持 | 同一账号新登录使旧Token失效 |
| 存储方式 | Redis | 支持主动踢出、强制下线 |
### 2.5 PHP实现代码示例

#### 2.5.1 企业微信API客户端封装

```php
<?php
/**
 * 企业微信API客户端
 * 原生PHP实现，用于CAPP系统与企业微信的交互
 */
class WeWorkApiClient
{
    private $corpid;
    private $corpsecret;
    private $agentid;
    private $cacheDir;
    private $accessToken;

    public function __construct($corpid, $corpsecret, $agentid, $cacheDir = null)
    {
        $this->corpid = $corpid;
        $this->corpsecret = $corpsecret;
        $this->agentid = $agentid;
        $this->cacheDir = $cacheDir ?: sys_get_temp_dir() . '/capp_ww_cache';

        if (!is_dir($this->cacheDir)) {
            mkdir($this->cacheDir, 0755, true);
        }
    }

    /**
     * 获取AccessToken（带缓存）
     *
     * @return string
     * @throws Exception
     */
    public function getAccessToken()
    {
        if ($this->accessToken !== null) {
            return $this->accessToken;
        }

        $cacheFile = $this->cacheDir . '/access_token.json';
        $now = time();

        if (file_exists($cacheFile)) {
            $cache = json_decode(file_get_contents($cacheFile), true);
            if ($cache && $cache['expires_at'] > $now) {
                $this->accessToken = YOUR_SECRET'token'];
                return $this->accessToken;
            }
        }

        return $this->refreshAccessToken();
    }

    /**
     * 刷新AccessToken
     *
     * @return string
     * @throws Exception
     */
    private function refreshAccessToken()
    {
        $lockFile = $this->cacheDir . '/token_refresh.lock';
        $lockHandle = fopen($lockFile, 'w+');

        if (flock($lockHandle, LOCK_EX)) {
            // 双重检查
            $cacheFile = $this->cacheDir . '/access_token.json';
            if (file_exists($cacheFile)) {
                $cache = json_decode(file_get_contents($cacheFile), true);
                if ($cache && $cache['expires_at'] > time()) {
                    flock($lockHandle, LOCK_UN);
                    fclose($lockHandle);
                    $this->accessToken = YOUR_SECRET'token'];
                    return $this->accessToken;
                }
            }

            $url = sprintf(
                'https://qyapi.weixin.qq.com/cgi-bin/gettoken?corpid=%s&corpsecret=%s',
                urlencode($this->corpid),
                urlencode($this->corpsecret)
            );

            $response = $this->httpGet($url);
            $result = json_decode($response, true);

            if (!isset($result['errcode']) || $result['errcode'] !== 0) {
                flock($lockHandle, LOCK_UN);
                fclose($lockHandle);
                throw new Exception(
                    '获取AccessToken失败: ' . ($result['errmsg'] ?? '未知错误'),
                    $result['errcode'] ?? -1
                );
            }

            $token = YOUR_SECRET'access_token'];
            $expiresIn = $result['expires_in'] ?? 7200;
            $expiresAt = time() + $expiresIn - 200;

            $cacheData = json_encode([
                'token' => $token,
                'expires_at' => $expiresAt,
                'refreshed_at' => date('Y-m-d H:i:s')
            ]);

            file_put_contents($cacheFile, $cacheData, LOCK_EX);

            flock($lockHandle, LOCK_UN);
            fclose($lockHandle);

            $this->accessToken = YOUR_SECRET;
            return $token;
        }

        throw new Exception('获取Token锁失败');
    }

    /**
     * HTTP GET请求
     */
    private function httpGet($url, $timeout = 30)
    {
        $ch = curl_init();
        curl_setopt_array($ch, [
            CURLOPT_URL => $url,
            CURLOPT_RETURNTRANSFER => true,
            CURLOPT_TIMEOUT => $timeout,
            CURLOPT_SSL_VERIFYPEER => true,
            CURLOPT_SSL_VERIFYHOST => 2,
            CURLOPT_FOLLOWLOCATION => true,
            CURLOPT_MAXREDIRS => 3,
            CURLOPT_USERAGENT => 'CAPP-WeWork-Client/1.0'
        ]);

        $response = curl_exec($ch);
        $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
        $error = curl_error($ch);
        curl_close($ch);

        if ($response === false) {
            throw new Exception("HTTP请求失败: {$error}");
        }

        if ($httpCode !== 200) {

    }
```

| 企微用户已删除但本地有业务数据 | 软删除 | 标记为deleted，不物理删除 |
| 部门层级冲突 | 暂存待处理队列 | 等待父部门同步后重试 |
| 同名不同部门 | 允许存在 | 通过部门路径区分 |

#### 3.6.2 回调事件处理

```php
<?php
class WeWorkCallbackHandler
{
    private $apiClient;
    private $syncService;
    private $token;
    private $encodingAesKey;
    private $corpId;

    public function __construct(WeWorkApiClient $apiClient, WeWorkUserSyncService $syncService, $config)
    {
        $this->apiClient = $apiClient;
        $this->syncService = $syncService;
        $this->token = YOUR_SECRET'callback_token'];
        $this->encodingAesKey = $config['callback_encoding_aes_key'];
        $this->corpId = $config['corpid'];
    }

    public function handle()
    {
        if ($_SERVER['REQUEST_METHOD'] === 'GET') return $this->verifyUrl();
        if ($_SERVER['REQUEST_METHOD'] === 'POST') return $this->handleEvent();
        http_response_code(405);
        echo 'Method Not Allowed';
    }

    private function verifyUrl()
    {
        $msgSignature = $_GET['msg_signature'] ?? '';
        $timestamp = $_GET['timestamp'] ?? '';
        $nonce = $_GET['nonce'] ?? '';
        $echoStr = $_GET['echostr'] ?? '';

        if (!$this->verifySignature($msgSignature, $timestamp, $nonce, $echoStr)) {
            http_response_code(403);
            echo 'Signature verification failed';
            return;
        }

        $decrypted = $this->decryptMsg($echoStr, $msgSignature, $timestamp, $nonce);
        if ($decrypted === false) {
            http_response_code(403);
            echo 'Decryption failed';
            return;
        }

        header('Content-Type: text/plain');
        echo $decrypted;
    }

    private function handleEvent()
    {
        $msgSignature = $_GET['msg_signature'] ?? '';
        $timestamp = $_GET['timestamp'] ?? '';
        $nonce = $_GET['nonce'] ?? '';

        $postData = file_get_contents('php://input');
        if (empty($postData)) { http_response_code(400); echo 'Empty request body'; return; }

        $xml = simplexml_load_string($postData, 'SimpleXMLElement', LIBXML_NOCDATA);
        if (!$xml) { http_response_code(400); echo 'Invalid XML'; return; }

        $encryptMsg = (string)$xml->Encrypt;
        $decrypted = $this->decryptMsg($encryptMsg, $msgSignature, $timestamp, $nonce);
        if ($decrypted === false) { http_response_code(403); echo 'Decryption failed'; return; }

        $decryptedXml = simplexml_load_string($decrypted, 'SimpleXMLElement', LIBXML_NOCDATA);
        if (!$decryptedXml) { http_response_code(400); echo 'Invalid decrypted XML'; return; }

        $event = (string)$decryptedXml->Event ?? '';
        $changeType = (string)$decryptedXml->ChangeType ?? '';

        if ($event === 'change_contact') {
            $this->handleChangeContact($changeType, $decryptedXml);
        }

        header('Content-Type: text/plain');
        echo 'success';
    }

    private function handleChangeContact($changeType, $xml)
    {
        switch ($changeType) {
            case 'create_user':
            case 'update_user':
                $userid = (string)$xml->UserID;
                $this->syncService->syncUserIncremental($userid, $changeType === 'create_user' ? 'create' : 'update');
                break;
            case 'delete_user':
                $userid = (string)$xml->UserID;
                $this->syncService->syncUserIncremental($userid, 'delete');
                break;
            case 'create_party':
            case 'update_party':
                $deptId = (int)$xml->Id;
                $this->syncService->syncDepartmentIncremental($deptId, $changeType === 'create_party' ? 'create' : 'update');
                break;
            case 'delete_party':
                $deptId = (int)$xml->Id;
                $this->syncService->syncDepartmentIncremental($deptId, 'delete');
                break;
        }
    }

    private function verifySignature($signature, $timestamp, $nonce, $echoStr)
    {
        $tmpArr = [$this->token, $timestamp, $nonce, $echoStr];
        sort($tmpArr, SORT_STRING);
        return sha1(implode($tmpArr)) === $signature;
    }

    private function decryptMsg($encryptMsg, $msgSignature, $timestamp, $nonce)
    {
        // 实际应使用企业微信官方WXBizMsgCrypt类
        // 参考：https://developer.work.weixin.qq.com/document/path/90307
        return $encryptMsg;
    }
}
```

#### 4.4.2 队列消费者

```php
<?php
class MessageQueueConsumer
{
    private $db;
    private $apiClient;
    private $logger;
    private $batchSize = 50;
    private $running = true;

    public function __construct($db, WeWorkApiClient $apiClient, $logger = null)
    {
        $this->db = $db;
        $this->apiClient = $apiClient;
        $this->logger = $logger;
    }

    public function run($daemon = false)
    {
        $this->log('消息队列消费者启动');

        while ($this->running) {
            try {
                $processed = $this->processBatch();
                if ($processed === 0) {
                    if ($daemon) sleep(5);
                    else break;
                }
            } catch (Exception $e) {
                $this->log('消费者异常: ' . $e->getMessage());
                sleep(10);
            }

            if ($daemon && file_exists('/tmp/capp_mq_consumer_stop')) {
                $this->running = false;
                $this->log('收到停止信号，消费者退出');
            }
        }
    }

    private function processBatch()
    {
        $stmt = $this->db->prepare(
            'SELECT * FROM capp_message_queue 
            WHERE status = "pending" OR (status = "failed" AND retry_count < max_retry AND next_retry_at <= NOW())
            ORDER BY priority ASC, created_at ASC LIMIT ?'
        );
        $stmt->execute([$this->batchSize]);
        $messages = $stmt->fetchAll(PDO::FETCH_ASSOC);

        if (empty($messages)) return 0;

        foreach ($messages as $message) {
            $this->processMessage($message);
        }
        return count($messages);
    }

    private function processMessage($message)
    {
        $queueId = $message['id'];
        $startTime = microtime(true);

        $this->db->prepare('UPDATE capp_message_queue SET status = "processing", updated_at = NOW() WHERE id = ?')
            ->execute([$queueId]);

        try {
            $result = $this->sendMessage($message);
            $responseTime = round((microtime(true) - $startTime) * 1000);

            if ($result['success']) {
                $this->db->prepare('UPDATE capp_message_queue SET status = "success", processed_at = NOW(), updated_at = NOW() WHERE id = ?')
                    ->execute([$queueId]);
                $this->logMessage($queueId, $message, $result, 'success', $responseTime);
            } else {
                throw new Exception($result['error'] ?? '发送失败');
            }
        } catch (Exception $e) {
            $responseTime = round((microtime(true) - $startTime) * 1000);
            $retryCount = $message['retry_count'] + 1;

            if ($retryCount >= $message['max_retry']) {
                $this->db->prepare('UPDATE capp_message_queue SET status = "dead", retry_count = ?, error_message = ?, updated_at = NOW() WHERE id = ?')
                    ->execute([$retryCount, $e->getMessage(), $queueId]);
                $this->log("消息{$queueId}达到最大重试次数，标记为死信");
            } else {
                $delay = pow(2, $retryCount) * 60;
                $nextRetryAt = date('Y-m-d H:i:s', time() + $delay);
                $this->db->prepare('UPDATE capp_message_queue SET status = "failed", retry_count = ?, next_retry_at = ?, error_message = ?, updated_at = NOW() WHERE id = ?')
                    ->execute([$retryCount, $nextRetryAt, $e->getMessage(), $queueId]);
                $this->log("消息{$queueId}将在{$nextRetryAt}重试({$retryCount}/{$message['max_retry']})");
            }
            $this->logMessage($queueId, $message, ['error' => $e->getMessage()], 'failed', $responseTime);
        }
    }

    private function sendMessage($message)
    {
        $content = json_decode($message['content'], true);
        switch ($message['message_type']) {
            case 'text':
                return $this->apiClient->sendTextMessage($message['touser'], $content['content'], $message['agent_id']);
            case 'template_card':
                return $this->apiClient->sendTemplateCardMessage($message['touser'], $content['card_data'], $message['agent_id']);
            default:
                throw new Exception("不支持的消息类型: {$message['message_type']}");
        }
    }

    private function logMessage($queueId, $message, $result, $status, $responseTime)
    {
        $stmt = $this->db->prepare(
            'INSERT INTO capp_message_logs (queue_id, message_type, touser, agent_id, request_data, response_data, status, error_message, response_time, created_at)
            VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, NOW())'
        );
        $stmt->execute([
            $queueId, $message['message_type'], $message['touser'], $message['agent_id'],
            $message['content'], json_encode($result, JSON_UNESCAPED_UNICODE),
            $status, $result['error'] ?? null, $responseTime
        ]);
    }

    private function log($message)
    {
        $logMessage = "[" . date('Y-m-d H:i:s') . "] [MessageQueue] {$message}";
        if ($this->logger) $this->logger->info($message);
        else error_log($logMessage);
    }

    public function stop() { $this->running = false; }
}
```

### 4.6 消息发送日志和重试机制

#### 4.6.1 重试策略

| 重试次数 | 延迟时间 | 说明 |
|---------|---------|------|
| 第1次重试 | 60秒 | 网络抖动快速恢复 |
| 第2次重试 | 120秒 | 服务短暂不可用 |
| 第3次重试 | 240秒 | 最后一次尝试 |
| 超过3次 | 标记为死信 | 触发告警，人工介入 |

#### 4.6.2 死信处理

```php
<?php

    {

            $this->log("死信消息{$queueId}已重新加入队列");
            return true;
        }

        }
```

#### 7.2.1 统一异常处理中间件

```php
<?php
class WeWorkExceptionHandler
{
    private $logger;
    private $retryConfig = [
        'max_retries' => 3,
        'delay' => 1,
        'retryable_codes' => [-1, 40001, 40014, 42001, 45009]
    ];

    public function __construct($logger = null)
    {
        $this->logger = $logger;
    }

    public function handleWithRetry(callable $operation, $context = '')
    {
        $retries = 0;
        $lastException = null;

        while ($retries <= $this->retryConfig['max_retries']) {
            try {
                return $operation();
            } catch (Exception $e) {
                $lastException = $e;
                $errorCode = $e->getCode();

                if (!in_array($errorCode, $this->retryConfig['retryable_codes'])) {
                    throw $e;
                }

                $retries++;
                if ($retries <= $this->retryConfig['max_retries']) {
                    $delay = $this->retryConfig['delay'] * pow(2, $retries - 1);
                    $this->log("操作{$context}失败(错误码:{$errorCode})，{$delay}秒后重试({$retries}/{$this->retryConfig['max_retries']})");
                    sleep($delay);

                    // Token相关错误需要刷新Token
                    if (in_array($errorCode, [40001, 40014, 42001])) {
                        $this->refreshAccessToken();
                    }
                }
            }
        }

        throw new Exception("操作{$context}失败，已重试{$this->retryConfig['max_retries']}次: " . $lastException->getMessage(), $lastException->getCode());
    }

    private function refreshAccessToken()
    {
        $cacheFile = sys_get_temp_dir() . '/capp_ww_cache/access_token.json';
        if (file_exists($cacheFile)) {
            unlink($cacheFile);
        }
    }

    private function log($message)
    {
        $logMessage = "[" . date('Y-m-d H:i:s') . "] [WeWorkError] {$message}";
        if ($this->logger) $this->logger->error($message);
        else error_log($logMessage);
    }
}
```

```php
        if ($total === 0) return ['status' => 'healthy', 'message' => '无调用记录'];

        $failureRate = $failed / $total;
        if ($failureRate > 0.2) return ['status' => 'critical', 'message' => "API失败率: " . round($failureRate * 100, 1) . '%'];
```

#### 8.2.2 配置加载器

```php
<?php
class ConfigLoader
{
    private static $config = [];

    public static function load($envFile = null)
    {
        $envFile = $envFile ?: __DIR__ . '/../.env';

        if (!file_exists($envFile)) {
            throw new Exception("配置文件不存在: {$envFile}");
        }

        $lines = file($envFile, FILE_IGNORE_NEW_LINES | FILE_SKIP_EMPTY_LINES);
        foreach ($lines as $line) {
            $line = trim($line);
            if (strpos($line, '#') === 0) continue;

            list($key, $value) = explode('=', $line, 2);
            $key = trim($key);
            $value = trim($value);

            // 处理加密值
            if (strpos($value, 'encrypted:') === 0) {
                $value = self::decrypt(substr($value, 10));
            }

            // 处理布尔值
            if ($value === 'true') $value = true;
            if ($value === 'false') $value = false;

            // 处理数字
            if (is_numeric($value)) $value = $value + 0;

            self::$config[$key] = $value;
            putenv("{$key}={$value}");
            $_ENV[$key] = $value;
        }
    }

    public static function get($key, $default = null)
    {
        return self::$config[$key] ?? getenv($key) ?: $default;
    }

    public static function getRequired($key)
    {
        $value = self::get($key);
        if ($value === null || $value === '') {
            throw new Exception("缺少必需配置: {$key}");
        }
        return $value;
    }

    private static function decrypt($encryptedText)
    {
        $key = getenv('CONFIG_ENCRYPTION_KEY');
        if (!$key) {
            throw new Exception('未配置解密密钥');
        }

        $key = base64_decode($key);
        $data = base64_decode($encryptedText);

        $iv = substr($data, 0, 16);
        $encrypted = substr($data, 16);

        $decrypted = openssl_decrypt($encrypted, 'aes-256-cbc', $key, OPENSSL_RAW_DATA, $iv);
        if ($decrypted === false) {
            throw new Exception('配置解密失败');
        }

        return $decrypted;
    }
}
```

```php
     * @param string $value 明文值
     * @param string $key Base64编码的加密密钥
     * @return string Base64编码的密文（含IV）
     */
    public static function encrypt($value, $key)
    {
        $key = base64_decode($key);
        $iv = random_bytes(16);

        $encrypted = openssl_encrypt($value, 'aes-256-cbc', $key, OPENSSL_RAW_DATA, $iv);
        if ($encrypted === false) {
            throw new Exception('配置加密失败');
        }

        return base64_encode($iv . $encrypted);
    }

    /**
     * 解密配置值
     *
     * @param string $encryptedText Base64编码的密文
     * @param string $key Base64编码的加密密钥
     * @return string 明文值
     */
    public static function decrypt($encryptedText, $key)
    {
        $key = base64_decode($key);
        $data = base64_decode($encryptedText);

        $iv = substr($data, 0, 16);
        $encrypted = substr($data, 16);

        $decrypted = openssl_decrypt($encrypted, 'aes-256-cbc', $key, OPENSSL_RAW_DATA, $iv);
        if ($decrypted === false) {
            throw new Exception('配置解密失败');
        }

        return $decrypted;
    }

    /**
     * 生成加密密钥
     *
     * @return string Base64编码的32字节密钥
     */
    public static function generateKey()
    {
        return base64_encode(random_bytes(32));
    }
}
```
