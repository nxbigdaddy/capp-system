## 1. 工艺路线管理

### 1.1 功能描述

工艺路线管理是CAPP系统的核心模块，用于定义产品从原材料到成品的完整加工路径。针对工业压缩机及压力容器行业，工艺路线需覆盖以下典型制造环节：

- **工业压缩机**：膜片成型→膜片热处理→膜片检验→缸体加工→缸体探伤→装配→气密性试验→性能试验→涂装→入库
- **压力容器**：下料→卷板→焊接→无损检测→热处理→机加工→耐压试验→表面处理→最终检验

工艺路线管理支持以下核心功能：

| 功能点 | 说明 |
|--------|------|
| 工艺路线创建 | 基于产品型号、规格参数创建工艺路线，支持从模板/历史工艺复制 |
| 工艺路线编辑 | 支持工序增删改、顺序调整、并行工序配置 |
| 工艺路线审核 | 三级审核机制：工艺员编制→工艺组长审核→总工程师批准 |
| 工艺路线发布 | 审核通过后发布，发布后锁定编辑，生成正式版本 |
| 版本管理 | 支持版本号规则（V1.0/V1.1/V2.0），保留历史版本追溯 |
| 产品关联 | 与产品主数据（PDM/ERP集成）建立多对多关联关系 |
| 复制与引用 | 支持跨产品复制、建立引用关系（引用工艺变更时同步更新） |

#### 1.4.2 核心接口伪代码

```php
<?php
// /api/process_route/publish.php
require_once '../../inc/db.php';
require_once '../../inc/auth.php';
require_once '../../inc/response.php';

$routeId = (int)($_POST['route_id'] ?? 0);
$user = Auth::currentUser();

if ($user['role'] !== 'chief_engineer') {
    Response::error(403, '仅总工程师可发布工艺路线');
}

try {
    $pdo = DB::getConnection();
    $pdo->beginTransaction();
    
    // 1. 校验状态
    $stmt = $pdo->prepare("SELECT status, route_code FROM process_route WHERE route_id = ? FOR UPDATE");
    $stmt->execute([$routeId]);
    $route = $stmt->fetch(PDO::FETCH_ASSOC);
    
    if (!$route || $route['status'] != 1) { // 1=审核中
        throw new Exception('工艺路线状态不正确');
    }
    
    // 2. 生成新版本号
    $version = generateVersion($pdo, $route['route_code']);
    
    // 3. 更新状态
    $stmt = $pdo->prepare("UPDATE process_route SET status = 2, version = ?, 
        approver_id = ?, approve_time = NOW(), publish_time = NOW() 
        WHERE route_id = ?");
    $stmt->execute([$version, $user['user_id'], $routeId]);
    
    // 4. 作废旧版本
    $stmt = $pdo->prepare("UPDATE process_route SET status = 3 
        WHERE route_code = ? AND route_id != ? AND status = 2");
    $stmt->execute([$route['route_code'], $routeId]);
    
    // 5. 记录日志
    logOperation($pdo, 'process_route', $routeId, 'PUBLISH', $user['user_id']);
    
    $pdo->commit();
    Response::success(['route_id' => $routeId, 'version' => $version]);
} catch (Exception $e) {
    $pdo->rollBack();
    Response::error(500, $e->getMessage());
}

function generateVersion($pdo, $routeCode) {
    $stmt = $pdo->prepare("SELECT version FROM process_route WHERE route_code = ? ORDER BY route_id DESC LIMIT 1");
    $stmt->execute([$routeCode]);
    $last = $stmt->fetchColumn();
    if (!$last) return 'V1.0';
    // V1.0 -> V1.1, V1.9 -> V2.0
    preg_match('/V(\d+)\.(\d+)/', $last, $m);
    $major = (int)$m[1]; $minor = (int)$m[2];
    if ($minor >= 9) { $major++; $minor = 0; } else { $minor++; }
    return "V{$major}.{$minor}";
}
?>
```

### 1.5 关键算法

#### 1.5.1 工艺路线拓扑排序算法

用于校验工序顺序是否存在循环依赖，并生成合理的执行顺序：

```php
function topologicalSort(array $operations): array {
    $graph = [];
    $inDegree = [];
    
    // 构建图
    foreach ($operations as $op) {
        $id = $op['operation_id'];
        $inDegree[$id] = 0;
        $graph[$id] = [];
    }
    
    foreach ($operations as $op) {
        $preIds = json_decode($op['pre_operation_ids'] ?? '[]', true);
        foreach ($preIds as $preId) {
            $graph[$preId][] = $op['operation_id'];
            $inDegree[$op['operation_id']]++;
        }
    }
    
    // Kahn算法
    $queue = new SplQueue();
    foreach ($inDegree as $id => $degree) {
        if ($degree === 0) $queue->enqueue($id);
    }
    
    $result = [];
    while (!$queue->isEmpty()) {
        $node = $queue->dequeue();
        $result[] = $node;
        foreach ($graph[$node] as $neighbor) {
            $inDegree[$neighbor]--;
            if ($inDegree[$neighbor] === 0) $queue->enqueue($neighbor);
        }
    }
    
    if (count($result) !== count($operations)) {
        throw new Exception('工序存在循环依赖，请检查前置工序设置');
    }
    
    return $result;
}
```

## 2. 工序管理

### 2.1 功能描述

工序管理定义制造过程中的最小作业单元。针对工业压缩机及压力容器行业，工序分类体系如下：

| 工序大类 | 工序小类 | 典型工序示例 | 适用对象 |
|----------|----------|--------------|----------|
| 加工 | 机加工 | 车削、铣削、钻削、磨削 | 缸体、活塞、阀座 |
| 加工 | 特种加工 | 线切割、电火花、激光切割 | 膜片型腔、密封槽 |
| 焊接 | 电弧焊 | 手工电弧焊、埋弧焊、氩弧焊 | 压力容器筒体、接管 |
| 焊接 | 特种焊 | 等离子焊、电子束焊 | 工业压缩机膜片夹持器 |
| 热处理 | 常规热处理 | 退火、正火、淬火、回火 | 缸体、曲轴 |
| 热处理 | 表面热处理 | 渗碳、渗氮、高频淬火 | 活塞杆、阀杆 |
| 检验 | 无损检测 | RT（射线）、UT（超声）、MT（磁粉）、PT（渗透） | 焊缝、承压部件 |
| 检验 | 性能检测 | 气密性试验、耐压试验、疲劳试验 | 整机、压力容器 |
| 装配 | 部件装配 | 膜头装配、曲轴箱装配 | 工业压缩机膜头 |
| 装配 | 总装 | 整机装配、管路连接 | 整机 |
| 表面处理 | 涂装 | 底漆、面漆、防腐涂层 | 整机外观 |
| 表面处理 | 清洗 | 酸洗、超声波清洗 | 膜片、密封件 |

工序管理核心功能：
- **工序定义**：建立企业标准工序库，含工序编码、名称、类别、默认参数
- **工序参数管理**：定义每道工序的技术参数（如焊接电流、热处理温度、切削速度）
- **资源分配**：关联设备、工装夹具、模具、人员技能等级
- **顺序与并行**：定义工序串行/并行关系，支持关键路径分析

### 2.5 关键算法

#### 2.5.1 关键路径分析（CPM）算法

用于分析工艺路线中影响总工期的关键工序链：

```php
function calculateCriticalPath(array $operations): array {
    $es = []; // 最早开始
    $ef = []; // 最早结束
    $ls = []; // 最晚开始
    $lf = []; // 最晚结束
    $tf = []; // 总浮动时间
    
    // 拓扑排序
    $sorted = topologicalSort($operations);
    
    // 正向计算最早时间
    foreach ($sorted as $opId) {
        $op = findOperation($operations, $opId);
        $es[$opId] = 0;
        $preIds = json_decode($op['pre_operation_ids'] ?? '[]', true);
        foreach ($preIds as $preId) {
            $es[$opId] = max($es[$opId], $ef[$preId] ?? 0);
        }
        $ef[$opId] = $es[$opId] + ($op['setup_time'] + $op['run_time']);
    }
    
    $maxEf = max($ef);
    
    // 反向计算最晚时间
    foreach (array_reverse($sorted) as $opId) {
        $op = findOperation($operations, $opId);
        $lf[$opId] = $maxEf;
        // 查找后继工序
        foreach ($operations as $nextOp) {
            $nextPreIds = json_decode($nextOp['pre_operation_ids'] ?? '[]', true);
            if (in_array($opId, $nextPreIds)) {
                $lf[$opId] = min($lf[$opId], $ls[$nextOp['operation_id']] ?? $maxEf);
            }
        }
        $ls[$opId] = $lf[$opId] - ($op['setup_time'] + $op['run_time']);
        $tf[$opId] = $ls[$opId] - $es[$opId];
    }
    
    // 关键工序：总浮动时间为0
    $criticalPath = [];
    foreach ($sorted as $opId) {
        if (abs($tf[$opId]) < 0.001) {
            $criticalPath[] = $opId;
        }
    }
    
    return [
        'total_time' => $maxEf,
        'critical_path' => $criticalPath,
        'operations' => array_map(function($op) use ($es, $ef, $ls, $lf, $tf) {
            $id = $op['operation_id'];
            return array_merge($op, [
                'es' => $es[$id], 'ef' => $ef[$id],
                'ls' => $ls[$id], 'lf' => $lf[$id],
                'tf' => $tf[$id], 'is_critical' => abs($tf[$id]) < 0.001
            ]);
        }, $operations)
    ];
}
```

### 3.1 功能描述

工艺卡片是指导现场生产作业的核心技术文件，是工艺设计成果的最终载体。针对工业压缩机及压力容器制造特点，系统支持以下工艺卡片类型：

```php
function renderCardContent($template, $routeData) {
    $content = $template['template_content'];
    
    // 1. 基础字段替换
    $replacements = [
        '{{product_code}}' => $routeData['product_code'],
        '{{product_name}}' => $routeData['product_name'],
        '{{route_version}}' => $routeData['version'],
        '{{create_date}}' => date('Y-m-d'),
        '{{company_name}}' => 'XX压缩机制造有限公司',
    ];
    $content = str_replace(array_keys($replacements), array_values($replacements), $content);
    
    // 2. 工序表格动态生成
    if (strpos($content, '{{operation_table}}') !== false) {
        $tableHtml = generateOperationTable($routeData['operations']);
        $content = str_replace('{{operation_table}}', $tableHtml, $content);
    }
    
    // 3. 参数卡片动态生成
    if (preg_match_all('/\{\{param_card:(\d+)\}\}/', $content, $matches)) {
        foreach ($matches[1] as $operationId) {
            $paramCard = generateParamCard($routeData['operations'], $operationId);
            $content = str_replace("{{param_card:{$operationId}}}", $paramCard, $content);
        }
    }
    
    // 4. 二维码生成（产品追溯）
    if (strpos($content, '{{qrcode}}') !== false) {
        $qrData = json_encode([
            'product' => $routeData['product_code'],
            'route' => $routeData['route_code'],
            'version' => $routeData['version']
        ]);
        $qrBase64 = generateQRCodeBase64($qrData);
        $content = str_replace('{{qrcode}}', "<img src='{$qrBase64}' width='100' />", $content);
    }
    
    return $content;
}

function generateOperationTable($operations) {
    $html = '<table class="op-table"><thead><tr>';
    $headers = ['序号','工序名称','设备','工装','切削参数','工时','检验'];
    foreach ($headers as $h) $html .= "<th>{$h}</th>";
    $html .= '</tr></thead><tbody>';
    foreach ($operations as $i => $op) {
        $html .= '<tr>';
        $html .= '<td>'.($i+1).'</td>';
        $html .= '<td>'.$op['operation_name'].'</td>';
        $html .= '<td>'.$op['equipment_name'].'</td>';
        $html .= '<td>'.$op['tooling_name'].'</td>';
        $html .= '<td>'.$op['cutting_params'].'</td>';
        $html .= '<td>'.$op['standard_time'].'min</td>';
        $html .= '<td>'.$op['inspect_type'].'</td>';
        $html .= '</tr>';
    }
    $html .= '</tbody></table>';
    return $html;
}
```

#### 4.5.1 BOM多级展开算法（递归CTE）

```php
function expandBOM($pdo, $bomId, $maxLevel = 10) {
    $sql = "
        WITH RECURSIVE bom_tree AS (
            -- 锚点：顶层节点
            SELECT 
                item_id, parent_item_id, material_id, material_code, 
                material_name, quantity, unit, level, path, route_id,
                CAST(quantity AS DECIMAL(18,6)) as total_qty,
                1 as calc_level
            FROM bom_item 
            WHERE bom_id = ? AND parent_item_id = 0
            
            UNION ALL
            
            -- 递归：子节点
            SELECT 
                bi.item_id, bi.parent_item_id, bi.material_id, bi.material_code,
                bi.material_name, bi.quantity, bi.unit, bi.level, bi.path, bi.route_id,
                CAST(bt.total_qty * bi.quantity * (1 + COALESCE(bi.loss_rate,0)) AS DECIMAL(18,6)) as total_qty,
                bt.calc_level + 1
            FROM bom_item bi
            INNER JOIN bom_tree bt ON bi.parent_item_id = bt.item_id
            WHERE bi.bom_id = ? AND bt.calc_level < ?
        )
        SELECT * FROM bom_tree ORDER BY path, sort_order
    ";
    $stmt = $pdo->prepare($sql);
    $stmt->execute([$bomId, $bomId, $maxLevel]);
    return $stmt->fetchAll(PDO::FETCH_ASSOC);
}

// 反查：某物料被哪些BOM使用
function whereUsed($pdo, $materialId) {
    $sql = "
        SELECT DISTINCT b.bom_id, b.bom_code, b.product_code, b.version, bi.level
        FROM bom_item bi
        JOIN bom_header b ON bi.bom_id = b.bom_id
        WHERE bi.material_id = ? AND b.status = 1
        ORDER BY b.product_code
    ";
    $stmt = $pdo->prepare($sql);
    $stmt->execute([$materialId]);
    return $stmt->fetchAll(PDO::FETCH_ASSOC);
}
```

#### 4.5.2 BOM差异对比算法

```php
function compareBOMs($treeA, $treeB) {
    $diff = ['added' => [], 'removed' => [], 'modified' => []];
    $mapA = []; $mapB = [];
    
    foreach ($treeA as $item) $mapA[$item['path']] = $item;
    foreach ($treeB as $item) $mapB[$item['path']] = $item;
    
    // 删除的节点
    foreach ($mapA as $path => $item) {
        if (!isset($mapB[$path])) $diff['removed'][] = $item;
    }
    
    // 新增的节点
    foreach ($mapB as $path => $item) {
        if (!isset($mapA[$path])) $diff['added'][] = $item;
    }
    
    // 修改的节点
    foreach ($mapA as $path => $itemA) {
        if (isset($mapB[$path])) {
            $itemB = $mapB[$path];
            $changes = [];
            if ($itemA['quantity'] != $itemB['quantity']) {
                $changes['quantity'] = ['old' => $itemA['quantity'], 'new' => $itemB['quantity']];
            }
            if ($itemA['material_id'] != $itemB['material_id']) {
                $changes['material'] = ['old' => $itemA['material_code'], 'new' => $itemB['material_code']];
            }
            if (!empty($changes)) {
                $diff['modified'][] = ['path' => $path, 'changes' => $changes];
            }
        }
    }
    
    return $diff;
}
```

## 5. 材料定额管理

### 5.1 功能描述

材料定额管理是成本核算与物资采购的基础。针对工业压缩机及压力容器行业，材料定额具有以下特点：

- **板材定额**：压力容器筒体、封头需考虑卷板余量、焊接收缩、切割损耗
- **锻件定额**：缸体、法兰等需考虑锻造余量、机加工余量
- **型材定额**：管路支架、加强圈需考虑下料损耗
- **特殊材料**：膜片用0Cr18Ni9不锈钢薄板（0.25~0.5mm），需考虑成型拉伸系数

核心功能：
- **消耗定额计算**：基于BOM+工艺路线自动计算材料净用量与毛用量
- **材料替代**：建立材料替代关系（如304替代316L），支持审批流程
- **利用率统计**：按产品/工序/时间段统计材料利用率，分析浪费原因

```php
function calculateMaterialQuota($pdo, $productId, $bomId, $routeId) {
    // 1. 展开BOM获取所有材料
    $bomItems = expandBOM($pdo, $bomId);
    
    $quotaItems = [];
    foreach ($bomItems as $item) {
        if ($item['make_buy'] != 1) continue; // 只计算自制件材料
        
        $materialId = $item['material_id'];
        $netQty = $item['total_qty']; // 已考虑层级数量累积
        
        // 2. 获取工艺损耗率
        $lossRate = getProcessLossRate($pdo, $item['route_id'], $materialId);
        
        // 3. 计算毛用量
        $grossQty = $netQty / (1 - $lossRate);
        
        // 4. 材料替代检查
        $substitute = getActiveSubstitute($pdo, $materialId);
        if ($substitute) {
            $materialId = $substitute['sub_material_id'];
            $grossQty *= $substitute['sub_ratio'];
        }
        
        // 5. 获取单价
        $price = getMaterialPrice($pdo, $materialId);
        
        $quotaItems[] = [
            'material_id' => $materialId,
            'net_qty' => $netQty,
            'loss_rate' => $lossRate,
            'gross_qty' => round($grossQty, 4),
            'unit_price' => $price,
            'amount' => round($grossQty * $price, 4),
            'process_id' => $item['route_id']
        ];
    }
    
    // 6. 合并相同材料
    $merged = [];
    foreach ($quotaItems as $item) {
        $key = $item['material_id'];
        if (!isset($merged[$key])) {
            $merged[$key] = $item;
        } else {
            $merged[$key]['net_qty'] += $item['net_qty'];
            $merged[$key]['gross_qty'] += $item['gross_qty'];
            $merged[$key]['amount'] += $item['amount'];
        }
    }
    
    return array_values($merged);
}

// 获取工序材料损耗率（按材料+工序匹配）
function getProcessLossRate($pdo, $routeId, $materialId) {
    $sql = "SELECT loss_rate FROM process_material_loss 
            WHERE route_id = ? AND material_id = ? LIMIT 1";
    $stmt = $pdo->prepare($sql);
    $stmt->execute([$routeId, $materialId]);
    $rate = $stmt->fetchColumn();
    return $rate !== false ? (float)$rate : 0.05; // 默认5%
}
```

```php
function calculateStandardTime($pdo, $operationId, $equipmentId, $quantity = 1) {
    // 1. 获取标准工时数据
    $sql = "SELECT setup_time, unit_time, aux_time_ratio, allowance_ratio 
            FROM standard_time 
            WHERE operation_id = ? AND (equipment_id = ? OR equipment_id IS NULL)
            ORDER BY equipment_id DESC LIMIT 1";
    $stmt = $pdo->prepare($sql);
    $stmt->execute([$operationId, $equipmentId]);
    $std = $stmt->fetch(PDO::FETCH_ASSOC);
    
    if (!$std) {
        throw new Exception('未找到标准工时数据');
    }
    
    $setup = (float)$std['setup_time'];
    $unit = (float)$std['unit_time'];
    $auxRatio = (float)$std['aux_time_ratio'];
    $allowance = (float)$std['allowance_ratio'];
    
    // 2. 计算基本时间
    $basicTime = $unit * $quantity;
    
    // 3. 加入辅助时间
    $auxTime = $basicTime * $auxRatio;
    $operationTime = $basicTime + $auxTime;
    
    // 4. 加入宽放时间（生理3%+疲劳4%+管理3%=10%）
    $allowanceTime = $operationTime * $allowance;
    $standardTime = $operationTime + $allowanceTime;
    
    // 5. 总工时 = 准备时间 + 单件标准时间×数量
    $totalTime = $setup + $standardTime;
    
    return [
        'setup_time' => $setup,
        'basic_time' => round($basicTime, 2),
        'aux_time' => round($auxTime, 2),
        'allowance_time' => round($allowanceTime, 2),
        'standard_time' => round($standardTime, 2),
        'total_time' => round($totalTime, 2),
        'unit_standard_time' => round($standardTime / $quantity, 4)
    ];
}

// 实测法：剔除异常值后计算平均时间
function calculateObservedTime(array $cycleTimes) {
    sort($cycleTimes);
    $n = count($cycleTimes);
    
    // 去掉最快10%和最慢10%
    $trimStart = (int)($n * 0.1);
    $trimEnd = (int)($n * 0.9);
    $validTimes = array_slice($cycleTimes, $trimStart, $trimEnd - $trimStart);
    
    $avg = array_sum($validTimes) / count($validTimes);
    
    // 计算标准差，剔除>3σ的异常值
    $variance = 0;
    foreach ($validTimes as $t) $variance += pow($t - $avg, 2);
    $stdDev = sqrt($variance / count($validTimes));
    
    $finalTimes = array_filter($validTimes, function($t) use ($avg, $stdDev) {
        return abs($t - $avg) <= 3 * $stdDev;
    });
    
    return array_sum($finalTimes) / count($finalTimes);
}
```

#### 7.5.1 文件分片上传与合并算法

```php
<?php
// /api/document/chunk_upload.php
class ChunkUploader {
    private $uploadDir = '/data/uploads/chunks/';
    private $finalDir = '/data/uploads/documents/';
    
    public function handleUpload($file, $uploadId, $chunkIndex, $totalChunks) {
        $chunkDir = $this->uploadDir . $uploadId . '/';
        if (!is_dir($chunkDir)) mkdir($chunkDir, 0777, true);
        
        // 保存分片
        $chunkPath = $chunkDir . sprintf('%04d', $chunkIndex);
        move_uploaded_file($file['tmp_name'], $chunkPath);
        
        // 检查是否全部上传完成
        $uploadedChunks = glob($chunkDir . '*');
        if (count($uploadedChunks) >= $totalChunks) {
            return $this->mergeChunks($uploadId, $totalChunks);
        }
        
        return ['status' => 'uploading', 'progress' => count($uploadedChunks) / $totalChunks];
    }
    
    private function mergeChunks($uploadId, $totalChunks) {
        $chunkDir = $this->uploadDir . $uploadId . '/';
        $finalName = uniqid() . '_' . $uploadId;
        $finalPath = $this->finalDir . $finalName;
        
        $out = fopen($finalPath, 'wb');
        for ($i = 0; $i < $totalChunks; $i++) {
            $chunkPath = $chunkDir . sprintf('%04d', $i);
            if (!file_exists($chunkPath)) {
                fclose($out);
                throw new Exception("分片 {$i} 缺失");
            }
            fwrite($out, file_get_contents($chunkPath));
        }
        fclose($out);
        
        // 清理分片
        array_map('unlink', glob($chunkDir . '*'));
        rmdir($chunkDir);
        
        // 计算哈希
        $hash = md5_file($finalPath);
        
        return [
```

```php
function analyzeChangeImpact($pdo, $ecId) {
    $ec = getChangeById($pdo, $ecId);
    $impacts = [];
    
    // 1. BOM影响分析
    if ($ec['bom_id']) {

            }
        }
```

### 9.5 关键算法

#### 9.5.1 典型工艺相似度匹配算法

基于产品类型、材料、规格等属性计算相似度，推荐最匹配的典型工艺：

```php
function findSimilarTypicalProcess($pdo, $productType, $materialType, $spec, $limit = 5) {
    $sql = "SELECT * FROM typical_process WHERE status = 1";
    $stmt = $pdo->query($sql);
    $processes = $stmt->fetchAll(PDO::FETCH_ASSOC);
    
    $results = [];
    foreach ($processes as $tp) {
        $score = 0;
        
        // 1. 产品类型匹配（权重40%）
        if ($tp['product_type'] == $productType) {
            $score += 40;
        } elseif (strpos($tp['product_type'], $productType) !== false || 
                  strpos($productType, $tp['product_type']) !== false) {
            $score += 20;
        }
        
        // 2. 材料类型匹配（权重30%）
        if ($tp['material_type'] == $materialType) {
            $score += 30;
        } elseif (getMaterialFamily($tp['material_type']) == getMaterialFamily($materialType)) {
            $score += 15; // 同材料族（如不锈钢系列）
        }
        
        // 3. 规格范围匹配（权重20%）
        if ($tp['spec_range']) {
            $specScore = matchSpecRange($spec, $tp['spec_range']);
            $score += $specScore * 20;
        }
        
        // 4. 引用热度（权重10%）
        $hotScore = min($tp['usage_count'] / 100, 1); // 最多100次引用得满分
        $score += $hotScore * 10;
        
        // 5. 评分加成
        $ratingBonus = ($tp['rating'] - 3) * 2; // 高于3分加分，低于3分减分
        $score += $ratingBonus;
        
        $results[] = array_merge($tp, ['similarity_score' => round($score, 2)]);
    }
    
    // 按相似度排序
    usort($results, function($a, $b) {
        return $b['similarity_score'] <=> $a['similarity_score'];
    });
    
    return array_slice($results, 0, $limit);
}

// 规格匹配（如：Φ200 匹配 Φ100-300 得1.0，匹配 Φ150-250 得0.8）
function matchSpecRange($spec, $range) {
    // 提取数值
    preg_match('/[\d\.]+/', $spec, $m);
    $val = (float)($m[0] ?? 0);
    
    preg_match_all('/[\d\.]+/', $range, $m);
    $min = (float)($m[0][0] ?? 0);
    $max = (float)($m[0][1] ?? PHP_FLOAT_MAX);
    
    if ($val >= $min && $val <= $max) {
        // 在范围内，越靠近中心匹配度越高
        $center = ($min + $max) / 2;
        $deviation = abs($val - $center) / (($max - $min) / 2);
        return max(0.5, 1 - $deviation * 0.5);
    }
    
    // 不在范围内，计算距离
    $distance = $val < $min ? $min - $val : $val - $max;
    $rangeSize = $max - $min;
    return max(0, 1 - ($distance / $rangeSize));
}

// 获取材料族（简化示例）
function getMaterialFamily($materialType) {
    $families = [
        '0Cr18Ni9' => 'stainless_steel',
        '0Cr18Ni10Ti' => 'stainless_steel',
        '316L' => 'stainless_steel',
        'Q345R' => 'low_alloy_steel',
        'Q245R' => 'carbon_steel',
        '16Mn' => 'low_alloy_steel',
    ];
    return $families[$materialType] ?? 'other';
}
```

```php
    $sql = "SELECT * FROM process_param_lib 
            WHERE operation_id = ? AND material_type = ? AND equipment_type = ?
            AND reliability >= 2 ORDER BY source ASC, reliability DESC";
    $stmt = $pdo->prepare($sql);
    $stmt->execute([$operationId, getMaterialType($materialId), getEquipmentType($equipmentId)]);
    $exact = $stmt->fetchAll(PDO::FETCH_ASSOC);
    
    if (!empty($exact)) return $exact;
    
    // 2. 模糊匹配：同材料族
    $family = getMaterialFamily(getMaterialType($materialId));
    $sql = "SELECT ppl.*, m.material_type as actual_material 
            FROM process_param_lib ppl
            JOIN material m ON m.material_type LIKE CONCAT('%', ?, '%')
            WHERE ppl.operation_id = ? AND ppl.reliability >= 2
            LIMIT 10";
    $stmt = $pdo->prepare($sql);
    $stmt->execute([$family, $operationId]);
    $fuzzy = $stmt->fetchAll(PDO::FETCH_ASSOC);
    
    // 标记为推荐值（需人工确认）
    foreach ($fuzzy as &$item) {
        $item['is_recommended'] = true;
        $item['confidence'] = 'medium';
    }
    
    return $fuzzy;
}
```

## 附录：公共设计规范

### A.1 数据库设计规范

1. **命名规范**：表名使用小写下划线命名（如 `process_route`），字段名同理
2. **字符集**：统一使用 `utf8mb4`，支持中文及特殊符号
3. **主键**：所有表必须包含自增主键 `id` 或 `xxx_id`
4. **时间字段**：必须包含 `create_time` 和 `update_time`
5. **软删除**：使用 `status` 字段控制（0-停用/作废），避免物理删除
6. **索引策略**：外键字段、查询条件字段、排序字段必须建立索引
7. **注释**：所有表和字段必须添加中文注释

### A.2 PHP接口设计规范

1. **统一响应格式**：
```json
{
  "code": 200,
  "message": "success",
  "data": { },
  "timestamp": 1717776000
}
```

2. **错误码定义**：
   - 200：成功
   - 400：请求参数错误
   - 401：未登录
   - 403：无权限
   - 404：资源不存在
   - 500：服务器内部错误

3. **安全要求**：
   - 所有接口必须经过身份认证（Session/Token）
   - 敏感操作记录操作日志
   - SQL必须使用预处理语句防止注入
   - 文件上传限制类型、大小，存储路径不可预测
