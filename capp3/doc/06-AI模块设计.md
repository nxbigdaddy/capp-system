## 1. 概述

本文档针对工业压缩机、压力容器研发设计生产企业的CAPP（计算机辅助工艺规划）系统，详细设计AI模块的整体架构与功能实现方案。AI模块作为CAPP系统的智能增强层，通过大语言模型、知识检索、预测分析等技术手段，为工艺设计人员、生产管理人员、质量检验人员提供自然语言交互、智能决策支持、知识管理与业务预测能力。

本设计遵循以下核心原则：
- **业务驱动**：AI能力紧密围绕工业压缩机与压力容器工艺规划的核心痛点，不引入与业务无关的通用聊天功能；
- **安全可控**：所有AI交互涉及的企业工艺数据、客户信息、设计参数均经过脱敏与权限校验，确保技术秘密不泄露；
- **可解释性**：AI给出的工艺建议、排产方案、质量预警必须附带推理依据与数据来源，便于工程师审核确认；
- **渐进增强**：AI模块以辅助决策为主，关键工艺审批与最终决策权仍保留给具备资质的人类工程师。

AI模块覆盖以下核心场景：
- **智能工艺助手**：工艺员通过自然语言查询历史工艺方案、材料定额、设备参数，快速获取参考信息；
- **工艺优化决策**：基于历史生产数据与质量反馈，AI分析并提出焊接参数优化、加工余量调整、工序合并等建议；
- **知识库问答**：将分散在工艺规程、技术标准、失效案例中的知识结构化，支持工程师通过问答形式快速检索；
- **质量风险预警**：基于实时生产数据与工艺参数偏差，预测工业压缩机膜片寿命、压力容器焊缝缺陷风险；
- **智能排产辅助**：结合订单交期、设备负荷、工艺路线复杂度，生成排产建议并解释瓶颈原因。

## 2. AI助手功能设计

### 2.1 自然语言交互

AI助手提供Web端悬浮对话窗口、移动端企业微信内嵌页面、工艺编辑页侧边栏三种入口，支持工程师以自然语言方式与系统交互。

**交互模式设计**：

- **单轮问答模式**：用户输入问题，AI直接返回答案，适用于简单事实查询（如"Q345R材料焊接预热温度要求是多少？"）；
- **引导式多轮模式**：AI识别用户意图不完整时，主动追问关键信息（如用户询问"推荐焊接工艺"，AI追问"母材牌号、厚度、焊接位置、保护气体类型"）；
- **命令式交互模式**：用户通过自然语言触发系统操作（如"帮我创建工业压缩机G-50型的工艺路线，材料为S30408"），AI解析意图后调用CAPP系统API完成操作并返回结果确认；
- **文档解读模式**：用户上传工艺文件（PDF/Word/图片），AI提取关键参数并回答针对该文档的提问。

**意图识别层设计**：

CAPP系统AI模块在调用大模型前，先经过本地意图识别层（基于规则+轻量级分类模型），将用户请求分类至以下意图类别：

| 意图类别 | 说明 | 示例 |
|---------|------|------|
| process_query | 工艺查询 | "查询G-100型工业压缩机缸体加工工艺" |
| data_query | 数据查询 | "本月完成了多少份工艺规程" |
| optimize_suggest | 优化建议 | "优化这道焊接工序的参数" |
| report_generate | 报表生成 | "生成第三季度工艺完成情况统计" |
| knowledge_qa | 知识问答 | "什么是应力腐蚀开裂？如何预防？" |
| system_cmd | 系统命令 | "打开工艺审批页面" |
| chat | 闲聊/其他 | "你好" |

意图识别采用两级架构：第一级为基于关键词与正则的规则引擎，快速匹配高频意图；第二级为基于BERT轻量级模型的分类器，处理模糊表达。识别置信度低于0.7时，AI以澄清问题方式引导用户明确需求。

### 2.2 工艺查询

工艺查询是AI助手最高频的使用场景，设计要点如下：

**查询理解**：
- 实体识别：从用户输入中提取产品型号（如"G-50"、"GD-200"）、零部件名称（"膜片"、"缸体"、"曲轴箱"）、材料牌号（"Q345R"、"S30408"、"16MnDR"）、工艺类型（"焊接"、"机加"、"热处理"）等关键实体；
- 条件解析：识别数值范围（"厚度大于20mm"）、时间范围（"近三年的"）、状态过滤（"已批准的"）；
- 排序意图：识别"最新的"、"使用次数最多的"、"质量反馈最好的"等排序要求。

**查询执行**：

AI将自然语言查询转换为结构化查询条件，调用CAPP系统工艺数据库接口：

1. 语义解析后生成查询参数对象，包含`product_model`、`part_name`、`material`、`process_type`、`time_range`、`status`等字段；
2. 调用CAPP系统内部API检索符合条件的工艺记录；
3. 对检索结果进行智能摘要，提取与用户问题最相关的参数（如焊接电流、坡口形式、热处理温度曲线），以表格或结构化文本呈现；
4. 若涉及多份工艺对比，AI自动生成对比分析（参数差异、适用场景、质量记录差异）。

**查询结果呈现**：

- 单条工艺：展示工艺编号、版本、适用产品、关键工序参数摘要、编制人、批准状态；
- 多条工艺：以卡片列表展示，支持点击展开详情；
- 关联推荐：自动推荐"相似产品的工艺"、"同一编制人的其他工艺"、"后续工序工艺"。

### 2.3 数据查询

数据查询面向管理人员与工艺主管，支持对CAPP系统运营数据的自然语言探查：

- **工艺编制统计**："技术部本月编制了多少份焊接工艺规程？平均编制周期几天？"；
- **审批效率分析**："工艺审批平均耗时多久？哪个环节最容易卡单？"；
- **工艺复用率**："G系列工业压缩机有多少工艺可以复用？复用率多少？"；
- **质量关联查询**："哪些工艺规程对应的产品出现了返修？返修原因分布如何？"。

数据查询采用"自然语言→SQL→结果解释"链路：

1. AI根据CAPP系统数据库Schema（表结构、字段含义、关联关系）将自然语言转换为可执行SQL；
2. SQL经过安全校验（仅允许SELECT，禁止DML/DDL，限制返回行数≤1000）；
3. 执行SQL获取结果集，AI将结果转换为人类可读的自然语言摘要，必要时生成ECharts图表配置JSON，前端渲染为柱状图、饼图、趋势图。

### 2.4 多模态交互扩展

除文本交互外，AI助手支持以下多模态输入：

- **图片输入**：用户上传焊缝照片、金相组织图片、工艺简图照片，AI调用视觉模型分析并回答（如"这张焊缝照片是否存在未熔合缺陷？"、"识别这张图纸中的焊接符号并解释工艺要求"）；
- **语音输入**：移动端支持语音转文字后进入文本交互流程，适用于车间现场不便打字的场景；
- **文件输入**：上传工艺规程PDF、技术标准Word、Excel工艺卡片，AI解析内容后支持针对文档内容的问答与提取。

## 3. AI决策支持

### 3.1 工艺优化建议

AI基于历史工艺数据、质量反馈、设备能力参数，为工艺设计人员提供优化建议。

**优化维度**：

- **焊接工艺优化**：分析历史焊接记录（电流、电压、速度、预热温度、层间温度）与无损检测结果的关联，推荐更优参数区间。例如：针对S30408工业压缩机膜片与缸体焊接，AI发现历史数据中采用脉冲TIG焊、电流频率2Hz、峰值电流120A的批次，RT一次合格率显著高于其他参数组，遂向工艺员推荐该参数区间并附统计依据；
- **机加工艺优化**：分析加工尺寸偏差分布，推荐更合理的加工余量与刀具路径。例如：压力容器筒体车削工序中，AI发现某批次余量过大导致材料利用率低，建议将精车余量从2mm降至1mm，并提示需同步调整粗车尺寸公差；
- **热处理工艺优化**：基于材料力学性能检测结果，推荐更精准的热处理温度与保温时间。例如：16MnDR低温压力容器封头热压成型后，AI分析回火温度与冲击韧性关系，建议将回火温度从620℃微调至640℃以提升-40℃冲击功；
- **工序合并与拆分**：分析工序间等待时间、设备换型时间、物流路径，建议可合并的连续工序或需拆分的长工序。

**优化建议输出格式**：

每条优化建议必须包含：
1. **建议内容**：具体参数或方案调整；
2. **数据依据**：引用的历史数据范围、样本量、统计指标；
3. **预期效果**：量化预期改进（如合格率提升3%、工时降低8%）；
4. **风险提示**：调整可能带来的风险及缓解措施；
5. **人工确认**：提供"采纳建议"、"查看详情"、"忽略"三个操作按钮，工艺员确认后记录采纳状态。

### 3.2 排产建议

AI排产辅助模块接收生产订单、工艺路线、设备日历、人员资质等数据，生成排产建议。

**输入数据**：
- 订单信息：产品型号、数量、交期、优先级；
- 工艺路线：各工序标准工时、设备需求、前置工序关系；
- 资源日历：设备可用时段（考虑已排任务、维保计划）、人员班次、资质匹配；
- 约束规则：关键设备（如大型卷板机、自动焊机）不冲突、特种工序持证上岗、热处理炉装载量限制。

**输出内容**：
- **甘特图建议**：各工序建议开始/结束时间、占用设备、指派人员；
- **瓶颈分析**：识别排产中的资源瓶颈（如"第3周卷板机利用率110%，建议外协或加班"）；
- **风险预警**：提示可能延期的高风险订单及原因（如"订单PO-2024-089因等待Q345R钢板到货，建议提前3天启动采购"）；
- **优化方案对比**：提供"交期优先"、"成本优先"、"均衡负荷"三种策略的排产方案对比。

排产建议以建议形式呈现，最终排产确认由生产计划员在CAPP系统排产模块中人工审核后生效。

### 3.3 质量预警

AI质量预警模块基于实时工艺参数、检验数据、环境数据，预测质量风险并提前告警。

**预警场景**：

- **焊接缺陷预警**：监测焊接过程中电流/电压波动、气体流量偏差、层间温度异常，结合历史缺陷关联模型，预测该焊缝出现气孔、未焊透的概率，当概率超过阈值时立即推送告警至焊工及质检员企业微信；
- **工业压缩机膜片寿命预警**：基于膜片材料、运行压力曲线、循环次数、介质腐蚀性，预测膜片剩余寿命，提前建议更换周期，避免非计划停机；
- **压力容器热处理质量预警**：监测炉温均匀性、升温速率、保温段温度偏差，预测力学性能不达标风险；
- **尺寸超差预警**：分析机加工过程中刀具磨损趋势、机床热变形数据，预测关键尺寸（如压力容器法兰密封面平面度）超差风险。

**预警分级**：

| 级别 | 触发条件 | 响应方式 |
|-----|---------|---------|
| 提示（Info） | 参数偏离标准值5%-10% | 系统消息记录，日报汇总 |
| 警告（Warning） | 参数偏离10%-20%或风险概率30%-60% | 推送至工序负责人，建议关注 |
| 严重（Critical） | 参数偏离>20%或风险概率>60% | 立即推送企业微信+短信，暂停工序待确认 |

### 3.4 成本预测分析

AI基于工艺路线、材料定额、工时标准、历史实际成本，对新产品的工艺成本进行预测：

- **材料成本预测**：根据BOM、材料牌号、规格、当前采购价格，预测原材料成本；
- **工时成本预测**：基于工序内容、设备类型、历史同类零件实际工时，预测各工序工时及人工成本；
- **能耗成本预测**：针对热处理、焊接、试压等高能耗工序，预测电、气、水消耗成本；
- **质量成本预测**：基于历史该类型产品返修率、废品率，预测质量损失成本。

成本预测结果以"预测区间（乐观/基准/悲观）"形式呈现，支持工艺员调整参数后实时重新计算，辅助报价与工艺方案经济性比选。

## 4. AI知识库

### 4.1 工艺知识检索

CAPP系统AI知识库整合企业内部工艺知识资产，支持语义级检索。

**知识来源**：
- 历史工艺规程（结构化数据：工序、参数、设备、工装；非结构化数据：工艺说明、注意事项、附图）；
- 企业技术标准（焊接工艺评定规程、热处理工艺规范、无损检测工艺规程）；
- 国家/行业标准（GB/T 150、NB/T 47015、ASME VIII等，需确认版权合规后引用）；
- 失效案例库（压力容器失效分析报告、焊缝返修记录、客户质量反馈）；
- 设备操作手册（关键设备如自动焊机、数控立车的操作要点、维护经验）；
- 培训教材与专家经验（老师傅口述经验转录、内部培训PPT）。

**检索技术方案**：

采用"关键词检索+向量语义检索+图谱关联检索"混合架构：

1. **关键词检索**：基于MySQL全文索引（FULLTEXT）或Elasticsearch，快速匹配工艺编号、材料牌号、标准条款号等精确实体；
2. **向量语义检索**：将知识文档分块（Chunk）后，通过Embedding模型（如BGE-M3、text2vec）生成向量，存储于向量数据库（Milvus/pgvector），支持语义相似度搜索（如用户搜索"膜片开裂怎么办"，可召回"工业压缩机膜片疲劳失效分析与预防措施"文档）；
3. **知识图谱关联**：构建工艺知识图谱（实体：材料、设备、工序、缺陷、标准；关系：适用、导致、预防、替代），支持基于图谱路径的关联检索（如"Q345R+焊接+低温→关联到16MnDR替代方案"）。

**检索结果排序**：
- 相关性得分（向量相似度/关键词匹配度）；
- 知识权威性权重（企业标准>内部经验>外部标准）；
- 时效性权重（近3年文档权重高于早期文档）；
- 用户反馈权重（历史被采纳、点赞的知识权重提升）。

### 4.2 智能问答

智能问答是知识库面向用户的交互形态，设计要点：

**问答模式**：
- **直接回答**：知识库中存在明确答案时，直接给出答案并标注来源文档（如"根据《焊接工艺评定规程WPS-2023-05》，Q345R厚度20mm以下免预热，20mm以上预热100-150℃"）；
- **综合回答**：需整合多份文档时，AI综合归纳后给出结构化回答，并列出参考文档列表；
- **无法回答**：知识库未覆盖时，AI明确告知"当前知识库未收录相关信息"，并提供两个选项："提交问题给工艺专家"、"搜索外部互联网资源（需管理员开启）"。

**问答增强机制**：
- **追问澄清**：用户问题模糊时，AI列出可能的理解选项供用户选择；
- **上下文关联**：同一对话中，用户后续问题默认继承前文实体（如用户先问"G-50工业压缩机缸体材料"，再问"焊接工艺"，AI自动关联为"G-50缸体焊接工艺"）；
- **反馈学习**：用户对回答点赞/点踩、手动修正答案，数据进入训练数据集用于模型优化。

### 4.3 知识库构建与维护

**知识入库流程**：

1. **采集**：通过CAPP系统接口自动采集工艺数据；通过文件上传、OCR识别录入纸质文档；通过API对接企业标准管理系统同步标准文件；
2. **清洗**：去除重复内容、修正OCR错误、统一单位与术语（如将"氩弧焊"统一为"TIG焊"）；
3. **分块**：长文档按语义段落切分（Chunk），每块不超过512 tokens，保留上下文标题与元数据；
4. **标注**：人工审核关键工艺参数块，标注实体标签（材料、厚度、温度、电流等）；
5. **向量化**：调用Embedding服务生成向量，写入向量索引库；
6. **发布**：审核通过后发布至生产环境知识库，记录版本号。

**知识维护责任矩阵**：

| 知识类型 | 维护责任人 | 更新频率 | 审核人 |
|---------|----------|---------|--------|
| 工艺规程 | 工艺编制员 | 随工艺变更实时更新 | 工艺主管 |
| 企业标准 | 标准化工程师 | 标准修订后 | 技术部长 |
| 失效案例 | 质量工程师 | 每月汇总录入 | 质量部长 |
| 设备经验 | 设备工程师 | 每季度 | 设备部长 |
| 外部标准 | 标准化工程师 | 每年核查有效性 | 技术部长 |

### 4.4 知识更新与版本管理

知识库支持版本管理，每次更新产生新版本，旧版本保留用于追溯：

- **版本号规则**：主版本.次版本（如v2.1），重大内容变更升主版本，修正错误升次版本；
- **生效时间**：支持设定知识条目的生效时间与失效时间，过期知识自动降级（检索权重降低，问答时提示"该信息已过期，仅供参考"）；
- **变更通知**：关键知识（如焊接预热温度要求、热处理工艺参数）变更后，AI自动向相关工艺员推送变更摘要；
- **版本对比**：支持查看同一知识条目的历史版本差异，高亮修改内容。

## 5. AI模型接入

### 5.1 大语言模型API对接

CAPP系统AI模块采用"云上大模型+本地轻量模型"混合架构，大语言模型负责复杂推理、自然语言生成，本地模型负责敏感数据处理、高频简单任务。

**云上大模型对接方案**：

- **国内商用API**：优先对接国内合规大模型API（如百度文心一言、阿里通义千问、讯飞星火），满足企业数据不出境要求；
- **API封装层**：CAPP系统PHP后端封装统一的`LLMClient`类，屏蔽不同厂商API差异，支持以下能力：
  - 标准ChatCompletion（多轮对话）；
  - Function Calling（模型调用CAPP系统工具函数，如查询数据库、发起审批）；
  - Embedding（文本向量化，用于知识库检索）；
  - 流式输出（SSE协议，前端实时显示打字机效果）。
- **模型参数配置**：温度（Temperature）、最大Token数、Top-P等参数支持按场景配置（工艺查询场景Temperature=0.2确保确定性，创意优化场景Temperature=0.7允许发散）。

**Prompt工程规范**：

CAPP系统建立Prompt模板库，按场景维护标准化Prompt：
- **系统Prompt**：定义AI角色（"你是工业压缩机与压力容器CAPP系统的智能工艺助手，回答需基于企业知识库与工艺数据，不确定时明确告知"）、安全约束（"禁止透露客户名称、合同价格、专有工艺参数"）；
- **场景Prompt**：工艺查询、优化建议、质量预警、排产分析等场景各自维护Prompt模板，包含输出格式要求（JSON/表格/自然语言）；
- **动态注入**：Prompt模板中预留变量槽位，运行时注入用户身份（控制权限范围）、当前产品型号、历史上下文等动态信息。

### 5.2 本地模型部署方案

针对高敏感数据（如军工订单工艺、核心专利工艺）及网络隔离场景，提供本地模型部署方案：

- **模型选型**：部署开源轻量级大模型（如ChatGLM3-6B、Qwen2-7B、Llama3-Chinese-8B），经企业工艺领域微调后使用；
- **硬件要求**：单台GPU服务器（NVIDIA A10/A100或国产GPU），或CPU服务器（Intel Xeon + 128GB内存，响应延迟较高）；
- **部署架构**：采用vLLM或TGI（Text Generation Inference）框架提供OpenAI兼容API，CAPP系统PHP后端通过HTTP调用本地模型服务，与云上模型调用方式一致；
- **数据隔离**：本地模型服务部署于企业内网，与CAPP系统同机房，工艺数据不出内网；
- **模型更新**：每月评估模型效果，新微调版本先在测试环境验证，灰度发布至10%用户，稳定后全量切换。

### 5.3 模型路由与负载均衡

CAPP系统AI模块支持多模型并发接入，通过路由层智能分发请求：

- **按场景路由**：工艺查询→优先本地模型（响应快、数据安全）；复杂推理与创意生成→云上大规模模型（能力强）；Embedding→专用轻量模型（成本低）；
- **按优先级路由**：VIP用户/紧急请求→高优先级队列，分配更快响应的模型实例；
- **故障转移**：某模型API超时或报错时，自动切换至备用模型，并记录降级事件；
- **成本管控**：设置每月API调用预算上限，接近上限时自动降级至本地模型或限制非必要调用。

### 5.4 模型性能监控

建立模型服务监控体系：

- **响应延迟**：P50/P95/P99分位延迟，目标P95<3秒（工艺查询）、P95<8秒（复杂分析）；
- **Token吞吐量**：每分钟处理的输入/输出Token数；
- **错误率**：API调用失败率、模型生成内容格式错误率；
- **用户满意度**：对话结束后用户评分（1-5星），低于3星的对话自动标记为"待优化"；
- **成本监控**：按模型、按场景统计API调用费用，超预算告警。

## 6. AI对话管理

### 6.1 会话上下文管理

AI对话以"会话（Session）"为单位管理上下文，确保多轮对话的连贯性。

**会话生命周期**：
- **创建**：用户首次发起对话时创建会话，生成唯一`session_id`（UUID），记录用户ID、开始时间、入口来源（Web/企业微信/工艺编辑页）；
- **活跃**：用户持续交互期间，会话处于活跃状态，最近交互时间更新；
- **休眠**：30分钟无新消息，会话进入休眠，上下文保留但释放部分内存缓存；
- **结束**：用户主动关闭对话、超过24小时无交互、或对话轮数超过50轮时，会话结束，上下文归档至数据库；
- **恢复**：用户从历史记录中重新打开会话时，可恢复最近N轮（默认10轮）上下文继续对话。

**上下文压缩策略**：

大模型存在上下文长度限制（如4K/8K/128K tokens），长对话需压缩历史消息：
- **滑动窗口**：保留最近N轮对话（如最近10轮），丢弃早期消息；
- **摘要机制**：当对话超过阈值轮数时，AI自动生成对话摘要（"用户查询了G-50工业压缩机工艺，重点关注焊接参数与热处理要求，当前正在讨论膜片装配间隙"），后续对话以摘要替代原始历史；
- **关键信息提取**：将对话中确认的产品型号、材料、工艺类型等关键实体提取为结构化"对话记忆"，随每轮请求注入Prompt，减少对历史消息的依赖。

### 6.2 历史记录管理

所有AI对话记录持久化存储，支持检索、审计、分析。

**记录内容**：
- 会话元数据：会话ID、用户ID、开始/结束时间、总轮数、入口来源、使用模型；
- 消息明细：每轮用户输入（脱敏后）、AI输出、意图分类、调用的工具/接口、响应延迟、Token消耗；
- 用户反馈：点赞/点踩、手动修正、采纳建议记录。

**历史记录应用**：
- **个人历史**：用户查看自己的历史对话，支持关键词搜索、按时间筛选、收藏重要对话；
- **管理看板**：工艺主管查看团队AI使用情况（高频问题、未解决问题、采纳建议统计），识别知识缺口；
- **训练数据**：高质量对话（用户点赞、专家修正后）自动进入训练数据集，用于模型微调。

### 6.3 多轮对话设计

多轮对话设计遵循"意图聚焦、状态追踪、主动引导"原则：

**状态追踪**：
- 每轮对话维护"对话状态"（Dialog State），记录当前已确认的实体、待确认的实体、当前意图、已执行的操作；
- 状态以JSON结构存储，随请求传递给大模型，辅助模型理解当前进度。

**主动引导示例**：

用户："帮我优化焊接工艺"
AI（识别意图：optimize_suggest，缺失实体：材料、厚度、焊接方法）："好的，为了给您提供精准的焊接工艺优化建议，请补充以下信息：1. 母材牌号（如Q345R、S30408）；2. 板厚或管壁厚；3. 焊接方法（SMAW/TIG/SAW等）；4. 当前遇到的主要问题（气孔、变形、效率低等）。"

用户："Q345R，20mm，埋弧焊，焊缝有气孔"
AI（状态更新：材料=Q345R，厚度=20mm，方法=SAW，问题=气孔）："针对Q345R、20mm板厚埋弧焊焊缝气孔问题，根据知识库与历史数据分析，可能原因及优化建议如下：1. 焊剂受潮（历史占比35%）→建议焊剂烘干350℃×2h；2. 坡口油污（历史占比28%）→加强坡口清理，增加丙酮擦拭工序；3. 焊接速度过快（历史占比18%）→建议焊接速度从0.6m/min降至0.5m/min..."

### 6.4 对话意图识别与路由

复杂对话中，用户可能同时表达多个意图或中途切换意图，AI模块设计意图路由层处理：

- **单意图**：直接路由至对应处理模块；
- **多意图**：拆分为多个子任务顺序执行（如"查询G-50工艺并生成排产建议"→先执行工艺查询，再基于结果执行排产分析）；
- **意图切换**：用户中途改变话题时，AI保存前意图状态（如"先放一下，我问下16MnDR的热处理要求"），新意图处理完毕后，提示用户"是否继续刚才的G-50排产建议？"；
- **澄清机制**：意图置信度低于阈值时，列出最可能的2-3个意图供用户选择。

## 7. AI与业务系统集成

### 7.1 工艺推荐

AI工艺推荐模块在新产品工艺设计时，基于相似性分析推荐可参考的历史工艺：

- **输入**：新产品型号、零部件清单、材料、设计参数（压力、温度、介质）；
- **相似度计算**：基于产品类型、材料、压力等级、温度范围、结构特征（筒体/封头/法兰/膜片）计算与历史产品的多维相似度；
- **推荐输出**：
  - 最相似产品TOP5及相似度得分；
  - 推荐复用的工艺路线（可复用工序标记为绿色，需调整工序标记为黄色，需新增工序标记为红色）；
  - 复用工艺的历史质量表现（合格率、返修率、客户投诉率）；
  - 推荐工艺员（历史编制过相似产品且评价优秀的工艺员）。

工艺员可在推荐结果基础上"一键创建工艺草稿"，系统自动带入推荐参数，工艺员修改后提交审批。

### 7.2 异常检测

AI异常检测模块实时或准实时分析工艺执行数据，识别偏离正常模式的异常：

- **工艺参数异常**：焊接电流持续低于工艺规程下限、热处理炉温升温速率超标、机加工切削力突增（刀具崩刃征兆）；
- **数据完整性异常**：关键工序缺少检验记录、工艺参数未录入、照片未上传；
- **流程异常**：工序跳过（如未做无损检测即流转至下工序）、审批流程倒置、超期未处理任务；
- **关联异常**：同一操作者短期内连续出现多批次质量问题、同一设备短期内频繁报警。

异常检测结果以"异常事件"形式写入CAPP系统异常管理模块，触发分级处理流程（自动纠正→通知班组长→停线待处理）。

### 7.3 预测分析

AI预测分析模块基于历史数据与当前趋势，对未来业务指标进行预测：

- **工艺编制周期预测**：基于产品复杂度、材料稀缺性、历史同类工艺编制耗时，预测新订单工艺编制完成时间，辅助销售承诺交期；
- **设备故障预测**：基于设备运行参数（振动、温度、电流），预测关键设备（如自动焊机、数控加工中心）的故障概率，提前安排维护；
- **材料需求预测**：基于未来3个月订单的工艺BOM，预测各材料规格的需求数量与需求时间，辅助采购计划；
- **质量趋势预测**：基于当前在制产品的过程检验数据，预测最终一次交检合格率，提前识别高风险批次加强检验。

### 7.4 智能报表生成

AI智能报表模块允许管理人员通过自然语言指令生成统计报表：

- **指令示例**："生成2024年第三季度工业压缩机系列产品工艺编制情况报表，按产品型号分组，包含编制数量、平均编制周期、一次审批通过率、复用率，输出为柱状图+表格"；
- **执行流程**：AI解析指令→生成SQL查询数据→分析数据特征→选择图表类型→生成ECharts配置→组装HTML报表→提供下载（PDF/Excel）；
- **报表模板**：支持保存常用报表指令为模板，后续一键复用。

## 8. AI权限与安全

### 8.1 数据脱敏

AI模块处理的所有数据必须经过脱敏，防止敏感信息通过AI交互泄露：

**脱敏规则**：
- **客户信息**：客户名称替换为"客户A"、"客户B"，客户联系人姓名、电话、地址完全脱敏；
- **合同与价格**：合同金额、产品报价、材料采购价替换为"[价格信息-权限不足]"；
- **专有工艺参数**：核心专利工艺中的关键参数（如特殊热处理配方、专有焊接材料成分）对非授权用户脱敏；
- **军工/保密信息**：涉及军工订单、保密项目的任何信息，仅允许在本地模型且经保密授权的环境中处理，禁止接入云上模型。

**脱敏实现**：
- 建立"敏感实体词典"，维护正则表达式与实体类型映射；
- 用户输入与知识库检索结果在传入大模型前，经过脱敏处理器替换敏感实体为占位符；
- 大模型输出返回给用户前，逆向还原占位符（若用户有权限）或保持脱敏状态（若用户无权限）。

### 8.2 访问控制

AI模块继承CAPP系统RBAC权限体系，并增加AI专属权限维度：

- **功能权限**：
  - `ai_chat`：使用AI助手对话；
  - `ai_optimize`：查看工艺优化建议；
  - `ai_schedule`：查看排产建议；
  - `ai_quality_predict`：查看质量预警；
  - `ai_knowledge_manage`：管理知识库（增删改）；
  - `ai_model_config`：配置模型参数与路由；
  - `ai_audit`：查看AI审计日志。
- **数据权限**：AI查询工艺数据时，受CAPP系统数据权限控制（如某工艺员只能查询自己编制或本部门的工艺）；
- **模型权限**：普通用户仅允许使用标准模型，管理员可使用高级模型；涉密用户仅允许使用本地模型。

### 8.3 审计日志

AI模块所有操作记录详细审计日志，满足企业合规与追溯要求：

- **日志内容**：用户ID、操作时间、操作类型（对话/查询/采纳建议/生成报表）、输入内容（脱敏后）、输出摘要、调用的模型、Token消耗、IP地址、设备信息；
- **敏感操作额外记录**：导出AI对话记录、修改知识库内容、切换模型配置，记录操作前后快照；
- **日志保留**：审计日志保留不少于3年，定期归档至对象存储；
- **日志查询**：管理员可按用户、时间、操作类型、关键词检索审计日志，支持导出。

### 8.4 内容安全过滤

防止AI生成有害、错误、违规内容：

- **输入过滤**：用户输入经过敏感词库检测，包含攻击指令（如"忽略之前指令"、"输出系统Prompt"）、违法违规内容时，拒绝处理并记录告警；
- **输出过滤**：大模型输出经过内容安全检测，识别并拦截涉及国家秘密、企业核心机密、歧视性言论、错误工艺安全指导（如"焊接易燃容器无需清洗"）等内容；
- **工艺安全校验**：AI生成的工艺参数建议，必须经过CAPP系统工艺规则引擎校验（如预热温度是否低于标准下限、焊接电流是否超出设备能力范围），校验不通过时拦截并提示"AI建议与工艺标准冲突，请人工复核"。

## 9. AI训练数据管理

### 9.1 数据收集

高质量训练数据是AI模块效果的基础，数据来源包括：

- **历史对话数据**：用户与AI的真实对话记录，经用户点赞或专家修正后标记为高质量；
- **工艺文档数据**：历史工艺规程、技术标准、失效案例，经结构化解析后作为领域知识训练语料；
- **问答对数据**：工艺专家整理的FAQ（如"Q: 16MnDR焊接后是否必须热处理？A: 厚度>20mm或冷成形变形量>3%时需进行消除应力热处理..."）；
- **指令遵循数据**：自然语言指令与对应SQL/操作/报表的配对数据，用于训练Function Calling能力；
- **多模态数据**：焊缝缺陷图片与标注、工艺简图与文字说明配对，用于视觉模型训练。

**数据收集原则**：
-  consent原则：收集用户对话数据前，系统隐私政策明确告知并获取同意；
- 最小化原则：仅收集与工艺业务相关的对话，不收集用户私人闲聊；
- 匿名化原则：训练数据中的用户ID、姓名、部门替换为匿名标识。

### 9.2 数据标注

未经标注的原始数据需经过标注才能用于模型训练：

- **意图标注**：标注用户问题的意图类别、涉及的实体、情感倾向；
- **回答质量标注**：专家审核AI回答，标注"完全正确/部分正确/错误/无法判断"，并给出正确回答；
- **知识边界标注**：标注问题是否属于知识库覆盖范围，超出范围的问题标注为"需外部知识/需专家介入"；
- **安全标注**：标注数据是否包含敏感信息、是否需要脱敏、是否适合用于训练公开模型。

标注工作由工艺专家与数据标注员协作完成，CAPP系统提供Web标注工具，支持多人协同、标注一致性校验、标注进度统计。

### 9.3 模型微调

基于收集与标注的数据，定期对模型进行微调以提升领域适配性：

- **微调策略**：采用LoRA（Low-Rank Adaptation）或QLoRA轻量微调，在基础大模型上注入CAPP领域知识，不修改基础模型全量参数；
- **微调数据配比**：通用对话能力数据（30%）+ 工艺领域问答数据（50%）+ Function Calling数据（20%）；
- **微调频率**：每季度执行一次全量微调，每月基于新增高质量数据执行增量微调；
- **评估指标**：
  - 领域问答准确率（专家评分，目标≥85%）；
  - SQL生成正确率（目标≥90%）；
  - 工艺参数建议采纳率（目标≥60%）；
  - 幻觉率（生成不存在的事实，目标≤5%）。

### 9.4 数据质量评估

建立训练数据质量评估体系：

- **完整性**：检查数据字段是否齐全，缺失值比例；
- **一致性**：同一实体在不同数据中的表述是否一致（如"TIG焊"与"钨极氩弧焊"需统一）；
- **准确性**：工艺参数、标准条款号、材料牌号等事实性内容是否准确，抽样由专家复核；
- **多样性**：覆盖的产品类型、工艺类型、问题类型是否足够多样，避免模型偏见；
- **时效性**：知识类数据是否过期，过期数据需标注失效时间或更新。

数据质量评分低于阈值的数据集，禁止进入训练流程，需清洗修正后重新评估。

## 11. 系统架构图说明

AI模块在CAPP系统中的架构位置与数据流说明：

**层次架构**：

1. **接入层**：Web端悬浮窗、移动端企业微信H5、工艺编辑页侧边栏，统一通过HTTPS与CAPP后端通信；
2. **网关层**：Nginx反向代理，负载均衡，WAF防护，限流（单用户60请求/分钟）；
3. **应用层（PHP原生）**：
   - AI对话控制器：处理会话创建、消息发送、流式输出；
   - AI决策服务：封装工艺优化、排产、预警等决策逻辑；
   - AI知识服务：处理知识检索、问答、知识库管理；
   - 意图识别引擎：本地规则+轻量模型分类；
   - 数据脱敏引擎：输入输出双向脱敏；
   - 权限校验中间件：继承CAPP系统RBAC；
4. **模型层**：
   - 模型路由网关：按场景/优先级/成本分发至不同模型；
   - 云上模型客户端：封装各厂商大模型API；
   - 本地模型服务：内网部署的vLLM/TGI推理服务；
   - Embedding服务：文本向量化；
5. **数据层**：
   - MySQL：对话记录、决策记录、知识库、审计日志、模型配置；
   - Redis：会话上下文热缓存、意图分类缓存、模型响应缓存；
   - 向量数据库（可选Milvus/pgvector）：知识库向量索引；
   - 对象存储：训练数据归档、大文件附件。

**关键数据流**：

- **对话流**：用户输入→意图识别→权限校验→数据脱敏→模型路由→大模型API→结果生成→工艺安全校验→输出脱敏→返回用户→记录审计日志；
- **知识检索流**：用户问题→Embedding→向量相似度检索→MySQL全文检索→结果重排序→生成回答→标注来源；
- **决策流**：业务事件触发（如工艺提交）→数据采集→特征计算→模型预测→生成建议→规则引擎校验→推送用户→记录决策→用户反馈→模型效果评估。

## 13. 附录

### 附录A：PHP原生实现要点

- **SSE流式输出**：PHP通过设置`header('Content-Type: text/event-stream')`与`ob_flush()/flush()`实现SSE流式响应，将大模型生成的内容逐字推送给前端；
- **异步调用**：大模型API调用耗时较长（1-10秒），PHP端采用FastCGI保持连接，或结合消息队列（Redis List/RabbitMQ）将请求异步化，前端通过轮询或WebSocket获取结果；
- **cURL封装**：统一封装`AiHttpClient`，处理不同厂商API的鉴权方式（Bearer Token、AK/SK签名、HMAC），支持超时、重试、代理配置；
- **JSON处理**：PHP 7.4+使用`json_encode/json_decode`处理复杂嵌套结构，注意JSON_ERROR检查与UTF-8编码一致性；
- **加密存储**：API密钥、脱敏映射表采用OpenSSL扩展AES-256-GCM加密，密钥通过环境变量注入，禁止写入代码或数据库明文。

### 附录B：工业压缩机/压力容器行业AI适配要点

- **材料知识强化**：知识库重点覆盖压力容器常用材料（Q345R、Q370R、16MnDR、09MnNiDR、S30408、S31608等）的焊接、热处理、力学性能知识；
- **标准条款关联**：AI回答涉及GB/T 150.1~150.4、NB/T 47015、NB/T 47014、ASME BPVC VIII-1等标准时，必须标注具体条款号，便于工程师核查；
- **失效模式聚焦**：知识库重点收录压力容器典型失效案例（脆性断裂、疲劳失效、应力腐蚀开裂、蠕变失效、焊接再热裂纹等），AI问答时优先引用本企业实际失效案例；
- **工业压缩机专项**：针对工业压缩机特有的膜片材料（如哈氏合金C-276、不锈钢多层膜片）、膜腔曲面加工、液压油系统清洁度控制等专项工艺，建立独立知识子库；
- **安全红线校验**：AI生成的任何涉及压力试验、焊接工艺评定、热处理工艺的参数建议，必须经过CAPP系统内置的安全规则引擎校验，不得突破标准规定的下限值（如最低预热温度、最短保温时间）。

### 附录C：模型选型参考

| 应用场景 | 推荐模型类型 | 说明 |
|---------|------------|------|
| 通用工艺问答 | 国内商用大模型（文心/通义/星火）或本地7B-13B模型 | 平衡效果与成本 |
| 复杂推理与报表生成 | 国内商用大模型高级版（如通义千问Max） | 推理能力强，支持长上下文 |
| 代码/SQL生成 | 专用代码模型或通用大模型Code版本 | 提升SQL准确率 |
| Embedding/向量检索 | BGE-M3、text2vec-large-chinese | 中文语义效果好 |
| 视觉分析（焊缝缺陷） | 国内多模态大模型或专用CV模型 | 需针对焊缝缺陷数据微调 |
| 高敏感数据场景 | 本地部署开源模型（ChatGLM3/Qwen2） | 数据不出内网 |
