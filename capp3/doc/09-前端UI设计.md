## 1. 设计原则与风格

### 1.1 工业风设计理念

CAPP系统服务于工业压缩机、压力容器等重型装备制造行业，前端UI设计采用"工业风"设计理念，体现制造业的严谨、精密与可靠特质。工业风设计并非简单的视觉风格，而是将制造业的工程美学融入界面设计，使工艺人员在使用系统时产生专业认同感和操作信任感。

工业风设计的核心表现要素包括：

**（1）结构化的视觉秩序**

界面元素遵循严格的网格对齐系统，如同机械制图中的坐标网格。所有组件的间距、边距、圆角均遵循8px基准网格（8px Grid System），确保视觉上的整齐划一。表格、表单、卡片等容器组件采用1px实线边框，边框颜色使用中性灰（#D9D9D9），营造工程图纸般的清晰边界感。

**（2）克制的装饰元素**

摒弃过度圆角、阴影渐变、悬浮动效等互联网消费级产品的常见设计手法。按钮圆角统一为2px（仅作工艺卡片预览等特定场景可使用4px），卡片不使用投影阴影而采用实线边框区分层次，色彩过渡不使用渐变而使用纯色块拼接。整体视觉呈现如同精密机械的表面处理——平整、哑光、无多余装饰。

**（3）信息密度的合理控制**

工艺编制工作涉及大量数据录入和查阅，界面需在有限屏幕空间内呈现足够的信息密度。标准内容区域采用紧凑模式：表格行高40px（标准模式48px）、表单标签右对齐、列表页默认展示20条/页。同时提供"舒适模式"切换功能，允许用户根据个人习惯调整信息密度。

### 1.2 简洁高效原则

CAPP系统的核心用户为工艺工程师、工艺审核人员、生产管理人员，其工作场景具有以下特征：长时间连续操作、高频次数据录入、多任务并行处理、对操作效率极度敏感。因此，UI设计将"简洁高效"作为最高优先级原则。

**（1）三步可达原则**

任何核心功能必须在三次点击（或一次点击加两次选择）内可达。系统通过全局搜索框、快捷操作栏、最近访问记录等功能，缩短用户的操作路径。首页仪表盘提供"我的工作台"区域，聚合当前用户的待办审批、最近编辑工艺、常用功能入口，实现一键直达。

**（2）减少视觉干扰**

页面中仅保留与当前任务直接相关的信息和控件。次级功能、帮助提示、系统公告等通过折叠面板、悬浮提示、消息中心等方式收纳，避免常驻展示占用注意力。表单页面采用分步向导或标签页分组，每次仅展示当前步骤的字段，降低认知负荷。

**（3）键盘优先的交互支持**

针对工艺编制中大量数据录入的场景，系统全面支持键盘操作。表格内支持方向键导航、Tab键切换单元格、Enter键确认并下移；表单支持Tab顺序自定义配置；弹窗支持ESC关闭、Enter确认快捷键。所有快捷键操作均可在"个人设置"中自定义绑定。

### 1.3 响应式设计策略

系统采用自适应响应式设计策略，针对不同设备类型提供差异化的布局适配方案：

| 设备类型 | 分辨率范围 | 布局策略 | 主要使用场景 |
|---------|----------|---------|------------|
| 桌面大屏 | ≥1920px | 全功能展开，多列布局，固定侧边栏 | 工艺编制、BOM维护、报表分析 |
| 桌面标准 | 1366px-1919px | 标准布局，侧边栏可折叠，双列表单 | 日常办公、审批处理、数据查询 |
| 桌面小屏 | 1024px-1365px | 紧凑布局，侧边栏自动折叠，单列表单 | 车间终端、仓库盘点 |
| 平板横屏 | 768px-1023px | 简化导航，手势支持，触摸优化控件 | 现场巡检、移动审批 |
| 手机竖屏 | <768px | 单栏堆叠，底部导航，核心功能优先 | 企业微信H5、消息通知、简单查询 |

响应式断点（Breakpoint）设置：

```css
/* 移动端优先的断点定义 */
$breakpoint-sm: 768px;   /* 平板/小屏桌面 */
$breakpoint-md: 1024px;  /* 标准桌面 */
$breakpoint-lg: 1440px;  /* 大屏桌面 */
$breakpoint-xl: 1920px;  /* 超宽屏 */
```

## 2. 页面布局规范

### 2.1 整体布局框架

系统采用经典的"侧边栏+顶部导航+内容区"三栏布局框架，该布局在制造业信息化系统中经过长期验证，具有导航清晰、空间利用率高、扩展性强的特点。

整体布局结构如下：

```
┌─────────────────────────────────────────────────────────────┐
│  顶部导航栏 (Header)                                         │
│  ┌────────┐ ┌────────────────────────┐ ┌──────────────────┐  │
│  │ Logo   │ │ 全局搜索 / 快捷入口    │ │ 消息 / 用户 / 设置 │  │
│  └────────┘ └────────────────────────┘ └──────────────────┘  │
├────────┬────────────────────────────────────────────────────┤
│        │                                                    │
│ 侧边栏 │              内容区域 (Main Content)               │
│ (可折叠)│                                                    │
│        │  ┌──────────────────────────────────────────────┐  │
│        │  │ 面包屑导航 + 页面标题 + 操作按钮栏            │  │
│        │  ├──────────────────────────────────────────────┤  │
│        │  │                                              │  │
│        │  │              页面主体内容                     │  │
│        │  │                                              │  │
│        │  └──────────────────────────────────────────────┘  │
│        │                                                    │
├────────┴────────────────────────────────────────────────────┤
│  页脚 (Footer) - 版权信息 / 系统版本 / 技术支持热线          │
└─────────────────────────────────────────────────────────────┘
```

布局尺寸规范：

| 元素 | 尺寸 | 说明 |
|------|------|------|
| 顶部导航栏高度 | 56px | 固定定位，z-index: 1000 |
| 侧边栏展开宽度 | 220px | 固定定位，可折叠为64px图标模式 |
| 侧边栏折叠宽度 | 64px | 仅显示图标，悬浮显示菜单文字 |
| 内容区最小宽度 | 1024px | 小于此宽度出现横向滚动 |
| 内容区内边距 | 24px | 上/右/下/左均为24px |
| 页脚高度 | 40px | 非固定，随内容滚动 |

### 2.2 导航栏设计

顶部导航栏承载系统级功能和全局入口，分为三个功能区域：

**左侧区域：品牌标识与系统切换**

- 系统Logo：企业标识+CAPP系统名称，宽度160px，高度36px，垂直居中
- 系统切换器：当用户拥有多个系统（如PDM、ERP）权限时，提供下拉切换入口

**中间区域：全局搜索与快捷功能**

- 全局搜索框：宽度400px（大屏扩展至560px），支持工艺编号、产品型号、工序名称、人员姓名的模糊搜索，搜索结果按类别分组展示（工艺/产品/人员/知识库）
- 快捷功能入口：收藏夹、最近访问、常用功能三个图标按钮，点击展开下拉面板

**右侧区域：个人中心与系统工具**

- 消息通知：铃铛图标，红点提示未读数量，点击展开消息中心抽屉
- 全屏切换：支持F11快捷键，工艺卡片编制时尤为实用
- 用户头像与下拉菜单：包含个人资料、修改密码、我的待办、系统设置、退出登录

### 2.3 侧边栏设计

侧边栏采用两级菜单结构，一级菜单为功能模块分组，二级菜单为具体功能页面。菜单项根据当前用户的权限动态渲染，无权限的菜单项自动隐藏。

侧边栏菜单结构：

```
┌─────────────────────────┐
│  📊 首页仪表盘           │
├─────────────────────────┤
│  🔧 工艺管理    ▼        │
│    ├─ 工艺路线管理       │
│    ├─ 工序库管理         │
│    ├─ 工艺卡片编制       │
│    ├─ 工艺BOM管理        │
│    ├─ 工艺定额管理       │
│    └─ 工艺文件管理       │
├─────────────────────────┤
│  📋 审批流程    ▼        │
│    ├─ 我的待办           │
│    ├─ 我已审批           │
│    ├─ 流程监控           │
│    └─ 流程配置           │
├─────────────────────────┤
│  📚 知识库      ▼        │
│    ├─ 典型工艺模板       │
│    ├─ 工艺标准规范       │
│    ├─ 设备参数库         │
│    └─ 工装夹具库         │
├─────────────────────────┤
│  🤖 AI助手               │
├─────────────────────────┤
│  📈 报表统计    ▼        │
│    ├─ 工艺编制统计       │

│    ├─ 角色权限           │
│    ├─ 组织架构           │
│    ├─ 系统日志           │
│    └─ 基础数据           │
└─────────────────────────┘
```

侧边栏交互规范：

- 当前选中菜单项：左侧4px宽主色竖线指示器，背景色#E6F7FF，文字主色加粗
- 菜单分组展开/收起：点击一级菜单标题切换，仅允许一个分组同时展开（手风琴模式）
- 悬浮提示：折叠状态下，鼠标悬浮菜单图标显示Tooltip，延迟300ms出现
- 底部折叠按钮：位于侧边栏底部，点击切换展开/折叠状态，状态持久化存储至localStorage

### 2.4 面包屑导航

面包屑导航位于内容区域顶部，用于标识当前页面在系统功能树中的位置，并提供快速返回上级页面的入口。

面包屑规范：

- 格式：`首页 > 功能模块 > 功能分组 > 当前页面`
- 分隔符：右尖括号 `>`，颜色#8C8C8C，两侧各留4px间距
- 可点击项：除当前页面外，其他层级均可点击跳转；鼠标悬浮显示下划线
- 当前页面：文字加粗，颜色#262626，不可点击
- 附加功能：面包屑右侧可配置"收藏当前页面"星标按钮和"返回上一页"按钮

### 2.5 内容区域规范

内容区域是页面信息的主体承载空间，其内部布局根据页面类型采用不同的结构模式：

## 3. 色彩规范

### 3.1 主色调体系

主色调采用"工业蓝"（Industrial Blue），灵感来源于工程制图中的蓝色线条和工业设备的金属质感。蓝色在制造业环境中具有专业、冷静、可信赖的心理暗示，且对长时间屏幕工作的视觉疲劳影响较小。

| 色阶 | 色值 | 使用场景 |
|------|------|---------|
| 主色-深 | #003A8C | 顶部导航栏背景、重要按钮悬浮态 |
| 主色-中 | #0958D9 | 主按钮、链接文字、选中状态、图标高亮 |
| 主色-基 | #1890FF | 品牌色、主操作按钮、进度条、开关开启态 |
| 主色-浅 | #40A9FF | 按钮悬浮态、链接悬浮态、图表主色 |
| 主色-淡 | #BAE7FF | 标签背景、轻量提示背景、表格行悬浮 |
| 主色-极淡 | #E6F7FF | 菜单选中背景、信息提示背景、卡片轻量边框 |

### 3.2 辅助色体系

辅助色用于功能区分、数据可视化和状态标识，采用高饱和度的功能色，确保在工业环境下的显示辨识度。

| 色彩 | 色值 | 功能定位 | 典型应用场景 |
|------|------|---------|------------|
| 成功绿 | #52C41A | 正向操作、通过状态 | 保存成功、审批通过、设备正常、合格标识 |
| 警示橙 | #FAAD14 | 警告提示、待处理 | 待审核、即将超期、注意提示、中等风险 |
| 错误红 | #F5222D | 错误状态、禁止操作 | 删除确认、审批驳回、不合格、高风险 |
| 信息青 | #13C2C2 | 辅助信息、中性状态 | 提示消息、信息卡片、次要按钮、工艺备注 |
| 品质紫 | #722ED1 | 特殊标识、质量相关 | 质量特性、关键工序、特种工艺、保密标识 |

### 3.3 状态色体系

状态色用于标识工艺文件、审批流程、生产任务等业务对象的生命周期状态，确保用户一眼即可识别对象当前所处阶段。

| 状态类型 | 色值 | 背景色 | 使用对象 |
|---------|------|--------|---------|
| 草稿/新建 | #8C8C8C | #F5F5F5 | 工艺路线草稿、未提交审批 |
| 审核中 | #FAAD14 | #FFF7E6 | 已提交待审核、流程进行中 |
| 已发布/生效 | #52C41A | #F6FFED | 审批通过、正式版本、正在执行 |
| 已驳回 | #F5222D | #FFF1F0 | 审核不通过、需修改 |
| 已作废 | #BFBFBF | #FAFAFA | 历史版本、作废文件、停用状态 |
| 变更中 | #1890FF | #E6F7FF | 正在走变更流程、临时版本 |
| 已归档 | #722ED1 | #F9F0FF | 完成历史归档、仅可查阅 |

状态标签（Tag）的视觉规范：

## 4. 字体与图标规范

### 4.1 字体规范

系统采用无衬线字体（Sans-serif）家族，确保在Windows、macOS、Linux及移动设备上均有一致的显示效果。

字体栈定义：

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Helvetica Neue", Helvetica, Arial, sans-serif;
```

字体选择说明：

- **西文字体**：优先使用系统默认无衬线字体（Segoe UI/San Francisco），确保英文、数字、符号的显示清晰
- **中文字体**：优先使用PingFang SC（macOS/iOS）和Microsoft YaHei（Windows），作为系统预装字体无需额外加载
- **等宽字体**：代码片段、工艺编号、版本号等需对齐场景使用 `Consolas, Monaco, "Courier New", monospace`
- **数字字体**：金额、定额、工时等数值字段使用 `"Helvetica Neue", Helvetica, Arial` 以获得更紧凑的数字显示

| H3 | 16px | 600 | 1.5 | 分组标题、表格标题、步骤标题 |
| H4 | 14px | 600 | 1.5 | 小标题、列表项标题、标签页标题 |

### 4.3 图标规范

## 5. 组件规范

### 5.1 按钮组件

按钮是系统中最核心的交互元素，根据操作的重要性和后果严重程度分为四个层级。

| 类型 | 视觉样式 | 使用场景 | 尺寸规范 |
|------|---------|---------|---------|
| 主按钮（Primary） | 背景#1890FF，文字白色，无边框 | 新建、保存、提交、确认等正向主操作 | 高度32px，内边距8px 16px |
| 次按钮（Default） | 背景白色，边框#D9D9D9，文字#595959 | 返回、取消、重置、次要操作 | 高度32px，内边距8px 16px |
| 虚线按钮（Dashed） | 背景白色，虚线边框#D9D9D9 | 添加项、新增行、上传等可扩展操作 | 高度32px，内边距8px 16px |
| 文字按钮（Text） | 无背景无边框，文字#1890FF | 表格内操作、链接跳转、轻量操作 | 高度auto，内边距4px |
| 危险按钮（Danger） | 背景#FF4D4F，文字白色 | 删除、作废、驳回等破坏性操作 | 高度32px，内边距8px 16px |

按钮状态规范：

- 默认态：标准样式
- 悬浮态（Hover）：背景色加深10%，出现1px投影 `box-shadow: 0 2px 0 rgba(0,0,0,0.015)`
- 点击态（Active）：背景色加深20%，无投影，向下偏移1px
- 禁用态（Disabled）：透明度0.5，鼠标变为not-allowed，不响应点击
- 加载态（Loading）：显示旋转动画图标，禁用点击，保持按钮尺寸不变

### 5.2 表单组件

表单是工艺数据录入的核心载体，系统提供丰富的表单组件以满足不同数据类型的录入需求。

**输入框（Input）**

- 高度：32px（标准）/ 24px（紧凑）/ 40px（舒适）
- 边框：1px solid #D9D9D9，圆角2px
- 聚焦态：边框色#1890FF，外发光 `box-shadow: 0 0 0 2px rgba(24,144,255,0.2)`
- 错误态：边框色#FF4D4F，背景#FFF1F0，下方显示错误提示文字
- 前缀/后缀：支持单位符号（mm、MPa、min）、图标、下拉选择器

**下拉选择框（Select）**

- 支持单选、多选、可搜索、可清空、远程加载
- 选项高度：32px，悬浮背景#E6F7FF
- 分组选项：支持按设备类型、工序类型等分组展示
- 级联选择：用于工艺路线中的多级分类（如：工序大类→工序小类→具体工序）

**数字输入框（Number Input）**

- 支持步进按钮（+/-）、精度控制、范围限制
- 工艺参数录入专用：支持科学计数法、公差范围输入（如：50±0.5）
- 单位切换：支持在同一输入框内切换计量单位（mm/inch、MPa/psi、℃/℉）

**日期时间选择器（DatePicker）**

- 支持日期、日期时间、日期范围、月份、年份多种模式
- 工艺日期录入：支持快速选择"今天""明天""一周后""一个月后"
- 禁用日期：可配置不可选择的日期范围（如：节假日、设备检修日）

**文本域（Textarea）**

- 用于工艺要求、技术条件、备注说明等长文本录入
- 支持自动高度（根据内容自动扩展）
- 支持字数统计和限制提示
- 支持简单的富文本格式（加粗、斜体、下划线、项目符号）

### 5.3 表格组件

表格是工艺数据展示和编辑的核心组件，系统表格设计兼顾信息密度、操作效率和视觉清晰度。

**表格基础规范**

- 表头高度：40px，背景#FAFAFA，文字#262626，字重600，底部边框2px #F0F0F0
- 数据行高度：40px（标准）/ 32px（紧凑）/ 48px（舒适）
- 行交替背景：偶数行#FFFFFF，奇数行#FAFAFA（可选关闭）
- 行悬浮背景：#E6F7FF

- 单元格内边距：12px 16px
- 文字对齐：文本左对齐，数值右对齐，状态居中，操作按钮居中

**表格功能扩展**

- 列宽调整：拖拽列边框调整宽度，宽度持久化保存
- 列排序：拖拽表头调整列顺序，配置持久化保存
- 列显示/隐藏：通过表头右侧齿轮图标配置显示列
- 固定列：左侧固定选择列和操作列，右侧固定状态列，中间内容横向滚动
- 行内编辑：双击单元格进入编辑模式，支持输入框、下拉框、日期选择器
- 分页：默认20条/页，可选10/20/50/100条/页，支持跳页输入
- 汇总行：表格底部显示数值列的合计、平均值、最大值、最小值

### 5.4 弹窗组件

弹窗用于在当前页面之上承载次级任务，避免页面跳转导致上下文丢失。

| 弹窗类型 | 宽度 | 使用场景 | 关闭方式 |
|---------|------|---------|---------|
| 确认对话框 | 400px | 删除确认、提交确认、作废确认 | 确定/取消按钮、ESC、点击遮罩 |

| 全屏弹窗 | 100vw | 工艺卡片预览、复杂表单、报表打印预览 | 关闭按钮、ESC |

弹窗动画规范：

- 关闭动画：反向缩放 + 透明度渐变，时长150ms
- 遮罩层：背景rgba(0,0,0,0.45)，与弹窗同步淡入淡出

### 5.5 树形控件

树形控件用于展示层级结构数据，如产品BOM、工艺路线工序、组织架构、文件目录等。

**树形控件规范**

- 节点高度：32px，内边距4px 8px
- 展开/折叠图标：位于节点左侧，16px，点击切换展开状态
- 节点选中：背景#E6F7FF，文字#1890FF加粗

- 异步加载：支持点击展开时异步加载子节点，显示加载动画

**BOM树专用扩展**

- 节点前缀图标：根据物料类型显示不同图标（原材料、半成品、成品、外购件、标准件）

- 路径高亮：选中节点时高亮显示从根节点到当前节点的完整路径

  - 工序基本信息卡片：工序号、工序名称、工序类型、工作中心、设备、工装
  - 工艺参数表格：参数名称、参数值、单位、公差范围、检测方法
  - 工序要求文本域：技术要求、质量要求、安全要求
  - 附图区域：支持上传工序简图、示意图，支持图片预览和标注
- 右侧辅助信息栏：可折叠，显示工序知识库推荐、历史版本对比、相关标准规范

**沉浸式模式**

提供全屏编辑按钮，点击后隐藏顶部导航和侧边栏，仅保留顶部操作栏和编辑区域，适用于长时间工艺编制场景。按ESC键退出沉浸式模式。

### 6.6 工艺卡片页

工艺卡片页用于展示和打印标准化的工艺卡片，是工艺文件的标准输出形式。

**页面结构**

- 顶部工具栏：打印按钮、导出PDF按钮、页面设置（纸张A4/A3、方向纵向/横向、缩放比例）
- 卡片预览区：按实际打印尺寸渲染工艺卡片，支持多页连续预览
- 卡片内容：
  - 表头区：企业名称、工艺卡片标题、产品型号、产品名称、图号、材料牌号、卡片编号、版本号
  - 表体区：工序号、工序名称、工序内容、设备/工装/夹具/刀具、工艺参数、工时定额、检验要求
  - 表尾区：编制人/审核人/批准人签名栏、日期栏、更改记录栏

**打印预览模式**

- 背景模拟纸张颜色（#FDFDFD），四周显示纸张边界虚线
- 分页符处显示虚线分割，标注"第N页/共M页"
- 支持缩放预览：50%、75%、100%、125%、150%、适应宽度

### 6.7 审批流程页

审批流程页用于工艺文件的审核、会签、批准，以及流程进度的跟踪监控。

**页面结构**

**我的待办页**

- 顶部统计卡片：待审核（12）、待会签（5）、待批准（3）、已超时（2）
- 待办列表：表格展示待办事项，列包括：紧急程度、工艺编号、产品型号、流程类型、当前环节、提交人、提交时间、剩余时间、操作（立即处理）
- 紧急程度标识：红色"急"标签表示距截止时间不足24小时，橙色"紧"标签表示不足72小时

**审批处理弹窗**

- 左侧：工艺文件预览（只读模式），支持查看工艺卡片、BOM、工序明细
- 右侧：审批操作面板
  - 流程进度图：可视化展示当前流程所处节点（编制→审核→会签→批准→发布）
  - 审批意见输入框：文本域，支持常用意见快捷选择（"同意""退回修改""建议补充..."）
  - 操作按钮：通过（绿色主按钮）、驳回（红色危险按钮）、转办（次按钮）、加签（次按钮）
  - 历史审批记录：下方折叠面板展示此前环节的审批意见

### 6.8 系统管理页

系统管理页面向系统管理员，提供用户、权限、组织架构、基础数据、系统日志等管理功能。

**用户管理页**

- 搜索区：姓名/工号/部门筛选
- 用户表格：头像、姓名、工号、部门、角色、状态、最近登录、操作（编辑/禁用/重置密码/分配角色）
- 批量操作：批量导入（Excel模板下载）、批量导出、批量禁用/启用

**角色权限页**

- 左侧角色列表：系统预置角色（系统管理员、工艺总工程师、工艺组长、工艺员、审核员、质检员、生产调度员、访客）+ 自定义角色
- 右侧权限配置树：按功能模块→功能页面→操作按钮三级树形结构，支持勾选分配权限
- 数据权限配置：按组织架构范围配置数据可见性（全部/本部门/本部门及下级/仅本人）

### 6.9 AI助手页

AI助手页集成智能工艺辅助功能，提供自然语言交互界面。

**页面结构**

- 左侧会话列表：历史会话记录，支持新建会话、删除会话、搜索会话
- 右侧聊天区域：
  - 顶部：当前会话标题 + 清空会话按钮
  - 中部：消息气泡列表，用户消息右对齐（蓝色背景），AI消息左对齐（白色背景带边框）
  - AI消息内容：支持Markdown渲染、代码块高亮、表格展示、工艺卡片模板插入
  - 底部：输入框 + 发送按钮 + 快捷功能（"生成工艺路线""查询标准规范""分析工艺问题""优化工序参数"）

**AI消息特殊组件**

- 工艺卡片模板：AI生成的工艺卡片以特殊卡片样式展示，包含"一键导入"按钮
- 标准规范引用：引用企业标准或国标时，显示来源标注和原文链接
- 置信度标识：AI回答旁显示置信度标签（高/中/低），低置信度时提示"建议人工复核"

## 7. 交互设计

### 7.1 拖拽排序

拖拽排序功能应用于工艺路线工序调整、BOM物料层级调整、审批流程节点配置等场景。

**拖拽交互规范**

- 拖拽触发：鼠标左键按住可拖拽元素超过200ms或移动超过5px时触发拖拽状态
- 拖拽中样式：元素半透明（opacity: 0.8），宽度收缩为原宽度的90%，跟随鼠标移动
- 放置指示器：目标位置显示2px蓝色虚线，标注插入位置（前/后/子级）
- 放置成功：元素平滑动画移动至新位置，时长300ms，其他元素自动补位
- 放置失败：元素弹性动画返回原位置，提示"无法放置至该区域"

**工序拖拽排序**

在工序编辑页的左侧工序列表中，支持：

- 同级排序：拖拽调整同一层级工序的先后顺序，自动重新生成工序号
- 跨级移动：将子工序拖拽为独立工序，或将独立工序拖拽为某工序的子工序（插入/合并）
- 批量拖拽：按住Ctrl键多选工序后批量拖拽

### 7.2 右键菜单

右键菜单（Context Menu）为高级用户提供快捷操作入口，减少鼠标移动距离。

**右键菜单规范**

- 触发方式：鼠标右键点击目标元素
- 菜单位置：鼠标指针右下方，超出屏幕边界时自动调整至左上方
- 菜单宽度：最小160px，最大240px，根据内容自适应
- 菜单项高度：32px，内边距8px 12px，文字14px
- 分隔线：1px #F0F0F0，用于分组菜单项
- 快捷键提示：右侧显示对应键盘快捷键，颜色#8C8C8C

**典型右键菜单场景**

| 目标区域 | 菜单项 |
|---------|--------|
| 工艺表格行 | 查看详情、编辑、复制、删除、提交审核、查看历史版本、收藏 |
| BOM树节点 | 查看物料、添加子项、插入同级、删除、替换物料、复制子树、展开/折叠全部 |
| 工序列表项 | 编辑工序、复制工序、删除工序、插入前/后、设为关键工序、查看知识库推荐 |
| 审批记录 | 查看详情、催办、转办、加签、撤回（仅提交人） |

### 7.3 批量操作

批量操作提升数据管理效率，适用于工艺文件、BOM物料、用户账号等批量处理场景。

**批量操作流程**

1. **选择阶段**：表格左侧复选框选择目标行，表头复选框全选当前页或跨页全选
2. **校验阶段**：点击批量操作按钮后，系统校验选中项的状态是否允许该操作（如仅"草稿"状态可批量删除）
3. **确认阶段**：弹窗展示操作影响范围（"即将删除12项工艺，其中3项有关联BOM"），要求二次确认
4. **执行阶段**：显示进度条，支持后台执行和取消操作
5. **结果阶段**：操作完成后显示结果摘要（成功12项/失败0项），失败项提供错误原因和单独重试

**批量操作按钮状态**

- 未选择任何项时：批量操作按钮禁用，Tooltip提示"请先选择数据项"
- 选择部分项时：按钮启用，显示操作数量徽章
- 选择项包含不可操作数据时：按钮启用但点击后弹窗提示冲突项，要求用户取消选择或仅对合法项执行

### 7.4 搜索筛选

搜索筛选功能帮助用户从大量工艺数据中快速定位目标信息。

**全局搜索**

- 位置：顶部导航栏中央，快捷键Ctrl+K聚焦
- 搜索范围：工艺编号、产品型号、产品名称、工序名称、物料编码、人员姓名
- 搜索结果：分类展示（工艺/产品/人员/知识库），每类最多显示5条，底部"查看全部结果"链接
- 搜索历史：记录最近10条搜索关键词，点击快速复用
- 搜索建议：输入时实时显示匹配建议，支持方向键选择、Enter确认

**高级筛选**

- 触发：列表页搜索区"高级筛选"按钮或筛选图标
- 筛选条件：支持多条件组合，条件之间可选"且"/"或"关系
- 条件类型：等于、不等于、包含、不包含、大于、小于、范围、为空、不为空
- 筛选模板：支持保存当前筛选条件为个人模板，下次快速应用
- 筛选标签：已应用的筛选条件以标签形式展示在搜索区下方，点击标签上的"×"移除单个条件，点击"清除全部"移除所有条件

## 8. 打印设计

### 8.1 工艺卡片打印

工艺卡片是生产现场使用的核心工艺文件，其打印输出必须符合国家机械行业标准（JB/T 9165.2-1998）和企业内部格式规范。

**打印页面设置**

| 参数 | 设置值 | 说明 |
|------|--------|------|
| 纸张规格 | A4（210mm×297mm）或A3（297mm×420mm） | 根据工艺内容多少自动推荐 |
| 打印方向 | 纵向（Portrait） | 标准工艺卡片采用纵向 |
| 页边距 | 上20mm、下15mm、左20mm、右15mm | 预留装订边 |
| 打印缩放 | 100%（实际尺寸） | 确保表格尺寸与实物一致 |
| 页眉页脚 | 页眉：企业名称+系统名称；页脚：第X页/共Y页+打印时间 | 每页重复 |

**工艺卡片样式**

- 表格外边框：1.5px实线黑色
- 表格内边框：0.75px实线黑色
- 表头行背景：浅灰色（#F5F5F5），用于区分表头与数据区
- 字体：正文10.5pt（五号字），表头9pt（小五号字），标题14pt（四号字）
- 行高：根据内容自适应，最小8mm
- 签名栏：预留手写签名空白区域，高度15mm

**打印预览功能**

- 浏览器端使用CSS `@media print` 媒体查询定义打印样式
- 打印前弹窗预览，支持分页预览、缩放调整、页码显示
- 提供"打印设置"选项：是否打印页眉页脚、是否打印背景色、是否连续打印多份

### 8.2 报表打印

报表打印用于统计分析结果的输出，包括工艺编制统计、工时定额汇总、材料消耗分析等。

**报表打印规范**

- 报表标题：居中，16pt加粗，下方显示统计时间范围和生成时间
- 数据表格：表头背景#E8E8E8，数据行交替白色/#F9F9F9，合计行加粗
- 图表打印：彩色打印时保留图表颜色，黑白打印时自动转换为图案填充区分
- 分页控制：表格跨页时表头重复显示，长表格支持横向A3打印

## 9. 移动端适配

### 9.1 企业微信H5适配

系统通过企业微信自建应用方式提供移动端访问入口，主要覆盖审批处理、消息通知、简单查询、现场数据录入等轻量场景。

**企业微信集成规范**

- 应用入口：企业微信工作台"CAPP工艺系统"图标
- 单点登录：通过企业微信OAuth2授权，免密自动登录
- 页面标题：动态设置页面标题，显示当前功能名称
- 分享限制：禁止随意分享内部页面，仅允许分享至企业内部群聊
- JS-SDK调用：调用企业微信扫码、拍照、定位、获取网络状态等原生能力

**移动端页面适配**

- 布局方式：单栏垂直堆叠，侧边栏变为底部Tab导航或顶部下拉菜单
- 触摸优化：按钮最小点击区域44px×44px，表单输入框高度40px，增大字体至16px防止iOS缩放
- 页面切换：使用滑动转场动画，左滑进入下一页，右滑返回上一页
- 下拉刷新：列表页支持下拉刷新，上拉加载更多
- 底部安全区：适配iPhone刘海屏和底部手势条，预留34px安全边距

**核心移动端页面**

| 页面 | 功能描述 |
|------|---------|
| 待办列表 | 展示当前用户的待审核/待会签/待批准事项，支持左滑快速通过/驳回 |
| 审批详情 | 查看工艺文件摘要信息，填写审批意见，选择通过/驳回/转办 |
| 消息中心 | 接收系统通知、审批提醒、变更提醒，支持点击跳转对应页面 |
| 工艺查询 | 通过产品型号或工艺编号查询工艺状态，查看工艺卡片（只读） |
| 现场录入 | 车间现场录入实际工时、材料消耗、检验结果，支持拍照上传 |
| 个人中心 | 查看个人信息、修改密码、设置消息推送偏好、查看操作记录 |

### 9.2 移动端交互优化

针对移动设备的触摸操作和有限屏幕空间，进行以下交互优化：

**手势操作**

- 左滑/右滑：列表项左滑显示快捷操作按钮（审核/驳回/收藏），右滑返回上一页
- 长按：长按列表项进入多选模式，支持批量操作
- 双指缩放：工艺卡片预览、图纸查看时支持双指缩放
- 摇一摇：现场录入页面摇一摇快速唤起扫码功能

**输入优化**

- 数字键盘：数量、工时、金额等字段自动唤起数字键盘
- 扫码输入：物料编码、设备编号、工艺编号字段支持点击扫码图标唤起摄像头扫码
- 语音输入：审批意见、备注说明字段支持语音转文字输入
- 拍照上传：工序附图、检验记录支持现场拍照并自动压缩上传

**离线支持**

- 数据缓存：最近访问的10条工艺数据本地缓存，无网络时可离线查看
- 离线队列：现场录入数据在无网络时保存至本地队列，网络恢复后自动同步
- 同步提示：离线数据同步成功后显示Toast提示，同步失败时保留队列待重试

**性能优化**

- 首屏加载：首屏内容控制在1秒内呈现，非首屏内容懒加载
- 图片压缩：移动端上传图片自动压缩至宽度1280px，质量80%，单张不超过500KB
- 虚拟滚动：长列表使用虚拟滚动技术，仅渲染可视区域DOM节点
- 骨架屏：页面加载时显示骨架屏占位，减少白屏等待焦虑
