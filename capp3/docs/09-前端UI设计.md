## 1. 设计原则与风格

### 1.1 工业风设计理念

CAPP系统服务于工业压缩机、压力容器等重型装备制造行业，前端UI设计应体现工业制造的严谨性、专业性与可靠性。工业风设计并非简单的视觉风格，而是对制造行业用户心智模型的深度契合。

**设计特征：**
- **结构化网格**：采用严谨的网格系统，所有元素对齐遵循8px基准网格，体现工程制图般的精确感
- **硬朗线条**：减少圆角使用，卡片和面板采用2-4px微圆角或直角，传递工业设备的机械感
- **信息密度适中**：工艺数据本身具有高密度特征，UI在保证可读性的前提下，合理压缩留白，单屏展示更多信息
- **专业术语可视化**：对工艺参数、设备型号、材料牌号等专业数据采用等宽字体或标签化展示，增强辨识度

### 1.2 简洁高效原则

工艺规划人员的核心诉求是"快速录入、准确查询、高效审批"，UI设计必须围绕效率展开。

**效率导向设计：**
- **减少点击层级**：核心功能（工艺创建、工序编辑、BOM维护）入口控制在3次点击以内
- **键盘优先**：表单支持Tab键顺序跳转、Enter键提交、ESC键关闭弹窗，支持快捷键（如Ctrl+S保存、Ctrl+F搜索）
- **智能默认值**：根据产品类型、材料、设备自动填充工艺参数的默认值，减少重复输入
- **批量操作显性化**：将批量导入、批量修改、批量删除等操作以工具栏形式常驻，而非隐藏在下拉菜单中
- **即时反馈**：操作结果通过Toast消息在2秒内反馈，复杂操作（如工艺计算、AI生成）提供进度指示

### 1.3 响应式设计策略

系统需同时支持PC端（工艺规划主战场）和企业微信H5端（移动审批、现场查看），采用自适应与响应式结合的策略。

**断点定义：**
| 断点名称 | 宽度范围 | 适用场景 |
|---------|---------|---------|
| 大屏 | ≥1920px | 工艺设计工作站、大屏展示 |
| 桌面 | 1366px-1919px | 主流办公电脑 |
| 笔记本 | 1024px-1365px | 小型笔记本、分屏操作 |
| 平板 | 768px-1023px | 平板设备、车间现场 |
| 手机 | <768px | 企业微信H5、移动审批 |

**响应式策略：**
- PC端（≥1024px）：完整布局，侧边栏常驻，表格全功能展示
- 平板端（768px-1023px）：侧边栏可折叠，表格横向滚动，简化部分次要操作
- 手机端（<768px）：侧边栏变为底部Tab或抽屉式导航，卡片式布局替代表格，核心功能优先展示

## 2. 页面布局规范

### 2.1 整体布局架构

系统采用经典的"顶部导航+左侧边栏+主内容区"三栏布局，这是企业级管理系统经过验证的高效布局模式。

**布局结构：**
```
+------------------------------------------+
|  顶部导航栏 (Height: 56px)                |
+----------+-------------------------------+
| 侧边栏    |  面包屑导航 (Height: 44px)   |
| (Width:  |  +---------------------------+ |
|  220px)   |  |                           | |
|  可折叠   |  |      主内容区域            | |
|           |  |                           | |
|           |  +---------------------------+ |
+----------+-------------------------------+
```

**布局规则：**
- 顶部导航栏固定定位，始终可见，承载系统Logo、全局搜索、消息通知、用户头像
- 侧边栏固定定位，宽度220px，可折叠为60px图标模式，折叠状态通过悬停展开二级菜单
- 主内容区域自适应宽度，最小宽度1000px，超出时横向滚动
- 整体页面最小高度100vh，内容不足时底部留白，内容超出时侧边栏与内容区同步滚动

### 2.2 导航栏设计

**顶部导航栏（Header）：**
- **高度**：56px，背景色使用主色（#1a5f9e）
- **左侧**：系统Logo（工业压缩机图标+"CAPP工艺系统"文字），点击返回首页
- **中间**：全局搜索框（宽度400px，placeholder："搜索工艺编号、产品名称、图号..."），支持快捷键Ctrl+K聚焦
- **右侧**：
  - 消息通知图标（带未读红点计数）
  - 待办审批图标（带数字角标）
  - 全屏切换按钮
  - 用户头像下拉菜单（个人设置、修改密码、退出登录）

**用户头像下拉菜单项：**
- 用户信息（只读展示：姓名、部门、角色）
- 分隔线
- 个人设置
- 修改密码
- 系统帮助
- 分隔线
- 退出登录

### 2.3 侧边栏设计

**侧边栏（Sidebar）：**
- **宽度**：展开220px，折叠60px
- **背景色**：#f0f2f5（浅灰蓝），与白色内容区形成层次区分
- **菜单分组**：按功能模块分组，组间有分隔线和分组标题

**菜单结构：**
```
📊 首页仪表盘
🔧 工艺管理
   ├─ 工艺路线管理
   ├─ 工序库管理
   ├─ 工艺卡片管理
   └─ 工艺版本管理
📋 BOM管理
   ├─ BOM清单
   ├─ 物料主数据
   └─ BOM对比
✅ 审批流程
   ├─ 我的待办
   ├─ 我的已办
   ├─ 我发起的
   └─ 流程监控
🤖 AI助手
📚 知识库
⚙️ 系统管理
   ├─ 用户管理
   ├─ 角色权限
   ├─ 组织架构
   ├─ 日志审计
   └─ 系统配置
```

**菜单交互：**
- 一级菜单点击展开/收起二级菜单，展开时图标旋转90度
- 当前选中菜单项高亮显示（背景色#e6f7ff，左侧4px主色竖线）
- 鼠标悬停菜单项背景色变为#e8e8e8
- 折叠状态下，鼠标悬停一级菜单在右侧浮现二级菜单面板

### 2.4 面包屑导航

**面包屑（Breadcrumb）：**
- **位置**：主内容区顶部，高度44px，下边1px边框#e8e8e8
- **结构**：首页 > 一级模块 > 二级模块 > 当前页面（当前页面文字加粗，不可点击）
- **功能**：
  - 点击上级面包屑可快速返回
  - 面包屑右侧预留页面级操作按钮区域（如"新建工艺"、"导出Excel"）
  - 支持面包屑下拉快速切换同级页面（如在"工艺路线管理"下拉可切换到"工序库管理"）

### 2.5 内容区域规范

**主内容区（Main Content）：**
- **内边距**：24px，保证内容呼吸感
- **页面标题**：24px加粗，位于面包屑下方，描述当前页面核心功能
- **页面副标题/说明**：14px灰色文字，位于标题下方，解释页面用途或操作提示
- **内容卡片**：白色背景，1px边框#e8e8e8，4px圆角，16px内边距，16px下边距
- **筛选区**：位于表格上方，折叠/展开设计，默认收起，点击"展开筛选"显示全部条件
- **表格区**：占据主要内容，支持分页、排序、列宽调整
- **表单区**：两列或三列布局，标签右对齐或顶对齐，根据表单复杂度选择

## 3. 色彩规范

### 3.1 主色调体系

主色选取工业蓝，象征科技、专业、可靠，与装备制造行业的工业气质契合。

| 色阶 | 色值 | 用途 |
|-----|------|------|
| 主色-深 | #0d3a5c | 悬停状态、强调背景 |
| 主色-默认 | #1a5f9e | 导航栏、主按钮、链接、选中状态 |
| 主色-浅 | #4a90d9 | 悬停高亮、次要强调 |
| 主色-淡 | #e6f7ff | 选中背景、轻提示背景 |

**主色使用规则：**
- 顶部导航栏背景：主色-默认（#1a5f9e）
- 主要按钮（新建、保存、提交）：主色-默认，文字白色
- 链接文字：主色-默认，悬停时主色-浅
- 当前选中菜单项：左侧4px主色-默认竖线，背景主色-淡
- 单选/复选框选中：主色-默认填充

### 3.2 辅助色系

辅助色用于功能区分、图表配色、标签分类，保持整体色调协调。

| 颜色名称 | 色值 | 用途 |
|---------|------|------|
| 工业橙 | #e67e22 | 警告按钮、待办提醒、重要标记 |
| 机械灰 | #5d6d7e | 次要文字、禁用状态、说明文字 |
| 钢铁银 | #95a5a6 | 边框、分割线、占位符 |
| 深蓝灰 | #2c3e50 | 页面标题、正文强调 |
| 青绿色 | #16a085 | 成功状态、正向指标、完成标记 |

**辅助色使用规则：**
- 工业橙：仅用于需要用户注意但非紧急的场景，如"待审批"标签、"修改"按钮
- 机械灰：表单标签、表格列头、说明文字
- 钢铁银：全局边框、分割线、表格边框、输入框边框
- 深蓝灰：页面标题、卡片标题、正文内容
- 青绿色：成功提示、已完成状态、正向数据指标

### 3.3 状态色彩

状态色用于反馈操作结果、标识数据状态，必须直观易懂。

| 状态 | 色值 | 使用场景 |
|-----|------|---------|
| 成功 | #27ae60 | 保存成功、审批通过、工艺发布、在线状态 |
| 警告 | #f39c12 | 参数异常、即将超期、部分完成、离线状态 |
| 错误 | #e74c3c | 保存失败、审批驳回、系统错误、删除确认 |
| 信息 | #3498db | 提示消息、帮助说明、进行中状态 |
| 中性 | #95a5a6 | 草稿状态、未开始、禁用、已作废 |

**状态色应用规范：**
- **Tag标签**：状态文字+浅色背景组合，如"已发布"（青绿文字+#e8f8f5背景）
- **Badge角标**：纯色圆点或数字，用于消息、待办计数
- **Toast通知**：左侧带4px状态色竖线，图标与状态色一致
- **表单校验**：错误状态边框变红，下方显示红色错误提示文字
- **进度条**：进行中用信息蓝，完成用成功绿，异常用错误红

### 3.4 背景与边框色

| 用途 | 色值 |
|-----|------|
| 页面背景 | #f0f2f5 |
| 卡片/面板背景 | #ffffff |
| 侧边栏背景 | #f0f2f5 |
| 表格表头背景 | #fafafa |
| 表格斑马纹 | #fafafa（隔行） |
| 悬停背景 | #f5f5f5 |
| 主边框 | #e8e8e8 |
| 次边框 | #d9d9d9 |
| 分割线 | #f0f0f0 |

## 4. 字体与图标规范

### 4.1 字体规范

**字体栈：**
```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Helvetica Neue", Helvetica, Arial, sans-serif;
```

**字号规范：**

| 层级 | 字号 | 字重 | 行高 | 用途 |
|-----|------|------|------|------|
| 页面标题 | 24px | 600 | 1.4 | 页面顶部主标题 |
| 卡片标题 | 18px | 600 | 1.4 | 内容卡片标题、弹窗标题 |
| 小标题 | 16px | 600 | 1.5 | 表单分组标题、模块标题 |
| 正文 | 14px | 400 | 1.6 | 表格内容、表单文字、菜单文字 |
| 辅助文字 | 13px | 400 | 1.5 | 按钮文字、标签文字、面包屑 |
| 说明文字 | 12px | 400 | 1.5 | 提示信息、时间戳、备注说明 |
| 数据展示 | 14px | 500 | 1.4 | 工艺参数、数值（等宽字体） |

**等宽字体（用于工艺编号、图号、数值）：**
```css
font-family: "SFMono-Regular", Consolas, "Liberation Mono", Menlo, Courier, monospace;
```

**字体使用规则：**
- 中文内容优先使用"Microsoft YaHei"，保证Windows环境下的清晰度
- 所有文字颜色至少满足WCAG 2.0 AA级对比度要求
- 正文文字颜色#333333，辅助文字#666666，禁用/占位文字#999999
- 重要数据（如工艺版本号、物料编码）使用等宽字体，增强对齐感和辨识度

### 4.2 图标规范

**图标体系：**
系统采用Iconfont图标库（阿里巴巴矢量图标库），统一使用线性风格（outline），保持视觉一致性。

**图标尺寸：**

| 场景 | 尺寸 | 说明 |
|-----|------|------|
| 导航菜单图标 | 18px | 侧边栏一级菜单 |
| 按钮图标 | 14px | 按钮内前缀图标 |
| 表格操作图标 | 16px | 编辑、删除、查看等行内操作 |
| 状态图标 | 16px | 成功、警告、错误提示 |
| 页面空状态 | 64px | 无数据、搜索无结果 |

**常用图标映射：**

| 功能 | 图标名称 | 备注 |
|-----|---------|------|
| 首页 | icon-dashboard | 仪表盘样式 |
| 工艺管理 | icon-setting | 齿轮或工具 |
| BOM管理 | icon-list-tree | 树形列表 |
| 审批流程 | icon-check-circle | 对勾圆圈 |
| AI助手 | icon-robot | 机器人 |
| 知识库 | icon-book | 书本 |
| 系统管理 | icon-system | 系统/网格 |
| 新建 | icon-plus | 加号 |
| 编辑 | icon-edit | 铅笔 |
| 删除 | icon-delete | 垃圾桶 |
| 保存 | icon-save | 软盘 |
| 导出 | icon-export | 向上箭头 |
| 导入 | icon-import | 向下箭头 |
| 搜索 | icon-search | 放大镜 |
| 刷新 | icon-reload | 循环箭头 |
| 打印 | icon-printer | 打印机 |
| 预览 | icon-eye | 眼睛 |
| 更多 | icon-more | 三个点 |
| 折叠 | icon-menu-fold | 左箭头 |
| 展开 | icon-menu-unfold | 右箭头 |

**图标交互：**
- 图标按钮悬停时颜色变为主色，有0.2s过渡动画
- 危险操作图标（删除）悬停时变为错误红色
- 图标与文字组合时，图标右侧留4px间距

## 5. 组件规范

### 5.1 按钮组件

**按钮类型：**

| 类型 | 样式 | 用途 | 高度 |
|-----|------|------|------|
| 主按钮 | 主色背景，白色文字 | 主要操作：新建、保存、提交、确认 | 36px |
| 次按钮 | 白色背景，主色边框，主色文字 | 次要操作：取消、返回、重置 | 36px |
| 文字按钮 | 无背景，主色文字 | 表格行内操作：编辑、查看、详情 | 继承行高 |
| 危险按钮 | 错误色背景，白色文字 | 删除、作废、驳回等不可逆操作 | 36px |
| 警告按钮 | 警告色背景，白色文字 | 特殊注意操作：强制发布、跳过校验 | 36px |
| 图标按钮 | 仅图标，无文字 | 工具栏常用：刷新、导出、设置 | 32px |
| 幽灵按钮 | 透明背景，白色边框文字 | 深色背景上使用，如导航栏 | 32px |

**按钮状态：**
- **默认**：标准样式
- **悬停**：亮度降低10%，0.2s过渡
- **按下**：亮度降低20%，轻微下移1px
- **加载中**：显示旋转Loading图标，文字保留，禁用点击
- **禁用**：透明度0.5，cursor:not-allowed，无悬停效果

**按钮间距：**
- 多个按钮并排时，间距12px
- 按钮组内按钮间距0px，仅中间分隔线
- 页面级操作按钮位于面包屑右侧或卡片右上角

### 5.2 表单组件

**表单布局：**
- **单列布局**：复杂表单、审批意见、长文本输入，标签顶对齐
- **双列布局**：常规信息录入，标签右对齐，宽度比例Label:Input = 1:3
- **三列布局**：简单查询条件、参数配置，标签顶对齐，节省纵向空间

**输入框规范：**
- **高度**：36px（与按钮同高，保证对齐）
- **边框**：1px #d9d9d9，圆角4px
- **聚焦**：边框变为主色，外显2px主色-淡阴影
- **禁用**：背景#f5f5f5，文字#999999
- **错误**：边框#e74c3c，下方显示错误提示

**下拉选择框：**
- 支持搜索过滤（选项超过15个时自动开启）
- 支持多选，多选时以Tag形式展示已选项
- 分组下拉：选项按类别分组显示（如设备选择按车间分组）

**日期时间选择：**
- 日期选择：年月日选择器，支持范围选择
- 时间选择：工序时间、工时录入使用时分选择器
- 日期格式统一：YYYY-MM-DD
- 日期时间格式：YYYY-MM-DD HH:mm

**数字输入：**
- 工艺参数（工时、尺寸、压力值）使用数字输入框
- 支持步进按钮（+/-）
- 支持单位后缀（如"mm"、"MPa"、"min"）
- 支持精度控制（小数位限制）

**文本域：**
- 工序内容、工艺要求、备注说明使用多行文本域
- 最小高度80px，可拖拽调整高度
- 显示当前字数/最大字数（如"120/500"）

### 5.3 表格组件

**表格基础样式：**
- 表头：背景#fafafa，文字#333333，14px，加粗，高度40px
- 行高：48px，保证数据可读性
- 边框：1px #e8e8e8，纵向边框可选（默认无纵向边框，仅行分割线）
- 斑马纹：隔行背景#fafafa，提升横向阅读体验
- 悬停：行悬停背景#f5f5f5

**表格功能：**
- **排序**：表头点击排序，支持单字段排序，三角箭头指示方向
- **筛选**：表头下拉筛选，支持文本搜索、多选、日期范围
- **分页**：底部分页器，默认每页20条，可选10/20/50/100条
- **列宽调整**：拖拽表头边框调整列宽，记忆用户设置
- **列显隐**：自定义显示/隐藏列，记忆用户设置
- **固定列**：左侧固定序号/操作列，右侧固定状态列，横向滚动时保持可见
- **行选择**：首列复选框，支持全选、跨页全选、Shift连选
- **行展开**：点击展开图标展开子表格（如工艺行展开显示工序列表）

**表格操作列：**
- 操作按钮默认显示前2个（查看、编辑），更多操作收拢在"更多"下拉菜单
- 危险操作（删除）始终放在下拉菜单末位，与常规操作分隔
- 行内操作使用文字按钮样式，减小视觉干扰

**表格空状态：**
- 无数据时显示空状态插图+文字"暂无数据"+操作引导（如"立即新建工艺"）
- 搜索无结果时显示"未找到匹配结果，请调整筛选条件"

**树形控件用于：**

## 7. 交互设计

### 7.1 拖拽排序

**应用场景：**
- 工艺路线中工序顺序调整
- BOM层级中子项顺序调整
- 工艺卡片列顺序调整
- 仪表盘统计卡片排序

**拖拽交互规范：**
- **拖拽触发**：鼠标按住拖拽手柄（六点点阵图标）或整行（按住0.3秒后触发拖拽，防止误触）
- **拖拽中**：被拖拽元素半透明（opacity:0.8），跟随鼠标移动，宽度保持与原元素一致
- **放置位置**：目标位置显示2px主色虚线指示器，明确放置位置
- **放置结果**：元素插入新位置，其他元素平滑动画重排（0.3s过渡）
- **层级拖拽**：BOM树支持拖拽改变父节点，拖拽到目标节点上方/下方为平级排序，拖拽到节点右侧为成为子节点
- **撤销支持**：复杂排序操作后，提供"撤销"Toast提示（5秒内可撤销）

**拖拽权限：**
- 已发布工艺不允许拖拽排序（需先创建变更版本）
- 审批中的工艺仅编制人可拖拽
- 系统管理员可拖拽所有未发布工艺

### 7.2 右键菜单

**应用场景：**
- 工艺表格行右键
- BOM树节点右键
- 工序列表项右键
- 工艺卡片页面右键

**右键菜单规范：**
- **触发**：右键点击目标元素，0.1s内显示菜单
- **位置**：鼠标指针右下方，超出屏幕边界时自动调整
- **样式**：白色背景，1px阴影，4px圆角，最小宽度160px
- **菜单项**：16px高度，14px文字，左侧图标+文字，悬停背景#f5f5f5
- **分组**：相关操作分组，组间1px分割线
- **禁用项**：灰色文字，不可点击
- **快捷键提示**：右侧显示快捷键（如"Ctrl+C"）

**工艺表格右键菜单项：**
```
├─ 查看详情
├─ 编辑工艺
├─ 复制工艺
├─ ─────────
├─ 提交审批
├─ 发布工艺
├─ 创建变更版本
├─ ─────────
├─ 导出工艺卡
├─ 打印工艺卡
├─ ─────────
├─ 删除工艺（红色文字）
```

### 7.3 批量操作

**批量操作入口：**
- 表格首列复选框，表头复选框控制全选/全不选
- 选中行后，底部浮现批量操作工具条（或顶部操作栏高亮）
- 显示已选中数量（如"已选择 12 项"）

**批量操作规范：**
- **批量删除**：二次确认弹窗，列出前3项名称+"等共N项"，危险按钮
- **批量导出**：直接下载ZIP包，内含各工艺Excel文件
- **批量提交审批**：确认后批量提交，失败项在结果弹窗中列出
- **批量修改状态**：下拉选择目标状态，确认后执行
- **批量打印**：打开新标签页，每工艺一页，调用浏览器打印

**跨页全选：**
- 表格上方显示"已选择本页N项，跨页全选M项"
- 点击"跨页全选"选中所有符合条件的记录（受当前筛选条件限制）
- 批量操作受权限控制，无权限的操作按钮禁用并Tooltip提示原因

### 7.4 搜索筛选

**全局搜索：**
- **位置**：顶部导航栏中央
- **触发**：点击搜索框或按Ctrl+K
- **下拉面板**：输入时实时搜索，分类展示结果（工艺、BOM、文档、用户）
- **结果项**：显示标题、类型标签、匹配高亮片段
- **快捷键**：↑↓选择，Enter跳转，Esc关闭

**页面级筛选：**
- **简单筛选**：表格上方1-3个常用条件（状态、时间范围、关键词），常驻显示
- **高级筛选**：点击"展开筛选"显示全部条件，支持：
  - 文本模糊搜索
  - 下拉精确匹配/多选
  - 数字范围（最小-最大）
  - 日期范围（开始-结束）
  - 级联选择（车间→班组→设备）
- **筛选标签**：已选条件以Tag形式展示在筛选区下方，可单独关闭，有"清空全部"按钮
- **筛选记忆**：用户筛选条件保存在localStorage，下次进入页面自动恢复
- **筛选联动**：选择产品型号后，下游筛选条件（图号、版本）自动过滤可选范围

**表格列头筛选：**
- 文本列：输入框实时过滤
- 枚举列：多选下拉（如状态：草稿、待审批、已发布）
- 日期列：日期范围选择器
- 数字列：数字范围输入

## 8. 打印设计

### 8.1 工艺卡片打印

**打印样式规范：**
- 使用专门的打印CSS（@media print），隐藏导航栏、侧边栏、操作按钮
- 页面设置为A4纵向，边距15mm
- 内容区域宽度100%，自适应纸张

**工艺卡片打印模板：**
- **页眉**：企业Logo（左侧）、"工艺卡片"标题（居中）、卡片编号（右侧）
- **产品信息栏**：产品型号、产品名称、图号、材料、编制日期（表格形式，无边框或细边框）
- **主体表格**：工序列表
  - 表头：序号、工序号、工序名称、工序内容、设备/工装、工时定额、技术要求、检验标准
  - 行高：根据内容自适应，最小60px
  - 边框：1px黑色实线，符合工程图纸规范
  - 技术要求列：允许自动换行，最小宽度200px
  - 跨页时表头在每页重复显示
- **页脚**：编制、审核、批准、会签签字栏（预留手写空间），页码

**打印控制：**
- 打印预览页：全屏弹窗，1:1显示打印效果
- 打印设置：纸张大小（A4/A3）、方向（纵向/横向）、边距、缩放（适应页面/实际大小）
- 分页控制：用户可手动插入分页符，调整每页显示工序数
- 打印按钮调用window.print()，同时提供PDF导出（通过html2pdf.js或后端生成）

**特殊打印需求：**
- 工序简图打印：支持将上传的工序图打印在卡片右侧或独立页
- 汇总表打印：工时汇总、材料汇总单独成页
- 封面打印：工艺规程封面，含产品信息、版本历史、分发单位

### 8.2 报表打印

**报表类型：**
- 工艺统计报表（按产品、车间、月份汇总）
- 工时汇总报表
- 材料定额报表
- 工艺变更记录报表
- 审批效率报表

**报表打印规范：**
- 报表标题：18px加粗，居中，下方报表生成时间
- 报表表格：表头背景灰色，数据行交替白色/浅灰，合计行加粗
- 页眉页脚：页眉显示报表标题，页脚显示页码和生成时间
- 大数据量报表：支持分Sheet导出Excel，或分页打印

**报表导出格式：**
- Excel导出：.xlsx格式，保留公式、筛选、样式
- PDF导出：适合存档和打印，固定版式
- Word导出：适合编辑和汇报，可调整样式

## 9. 移动端适配

### 9.1 企业微信H5适配策略

**运行环境：**
- 企业微信内置浏览器（基于Chromium内核）
- 主要使用场景：移动审批、现场查看工艺、接收消息通知、简单数据查询
- 屏幕尺寸：以手机为主（375px-414px宽度），部分使用平板

**适配策略：**
- **独立H5页面**：非响应式改造，为移动端单独开发精简页面，通过User-Agent判断跳转
- **企业微信JS-SDK**：集成扫码、拍照、定位、分享、获取用户信息等能力
- **单点登录**：通过企业微信OAuth2授权，免密登录
- **消息推送**：审批待办通过企业微信消息推送，点击消息直达审批页面

**性能优化：**
- 资源懒加载，首屏资源<500KB
- 图片压缩、CDN加速
- 接口响应时间<1s，超时友好提示
- 离线缓存：已查看的工艺数据本地缓存，弱网环境可查看

### 9.2 移动端页面规范

**布局规范：**
- **导航**：底部Tab导航（首页、待办、工艺查询、我的），高度50px
- **页面标题**：顶部固定，高度44px，左侧返回箭头，右侧操作按钮
- **内容区**：上下留白适配安全区域（iPhone刘海屏、底部横条）
- **列表页**：卡片式列表，每卡片垂直布局，信息精简
- **详情页**：分段展示，每段可折叠，默认展开前3段
- **表单页**：单列布局，标签顶对齐，输入框高度44px（适合手指点击）

**移动端专属交互：**
- **下拉刷新**：列表页支持下拉刷新
- **上拉加载**：分页数据上拉加载更多
- **左滑操作**：列表项左滑显示快捷操作（同意、驳回、查看）
- **长按菜单**：长按列表项弹出操作菜单
- **扫码查询**：首页提供扫码入口，扫描工艺卡片二维码或产品条码快速查询
- **拍照上传**：工序现场拍照上传，自动关联当前工序
- **语音输入**：审批意见支持语音转文字输入

**移动端页面清单：**

| 页面 | 功能 | 优先级 |
|-----|------|--------|
| 登录页 | 企业微信免登/账号密码登录 | 高 |
| 首页 | 待办统计、快捷入口、消息通知 | 高 |
| 待办列表 | 审批任务卡片列表 | 高 |

| 工艺详情 | 工艺卡片查看（简化版） | 中 |

| 消息中心 | 系统通知、审批提醒 | 高 |
| 个人中心 | 个人信息、密码修改、设置 | 低 |

**移动端工艺卡片展示：**
- 不直接复刻PC端表格，改为卡片流：每道工序一张卡片
- 卡片内容：工序号、工序名称、设备、工时、技术要求（折叠展开）

## 附录：前端技术实现要点

**技术选型说明：**
- 本系统采用PHP原生开发，前端不使用Vue/React等现代框架，以原生HTML/CSS/JS+jQuery为主
- UI组件库：基于Layui或自研组件库，保证轻量化和一致性
- 图表库：ECharts 5.x，满足仪表盘和报表图表需求
- 表格库：DataTables或自研表格组件，支持分页、排序、筛选
- 树形组件：zTree或自研树组件
- 富文本编辑器：wangEditor或UEditor（工序内容编辑）
- 打印方案：浏览器原生打印+html2canvas/html2pdf.js
- 移动端：独立H5页面，rem布局适配多屏

**文件组织：**
```
/assets
  /css
    /base          # 基础样式、变量、重置
    /components    # 组件样式（按钮、表单、表格、弹窗）
    /pages         # 页面级样式
    /print         # 打印专用样式
    /mobile        # 移动端样式
  /js
    /components    # 组件JS（表格、树、弹窗封装）
    /utils         # 工具函数（日期、校验、请求封装）
    /pages         # 页面逻辑
    /mobile        # 移动端JS
  /images          # 图片、图标、Logo
  /fonts           # 字体文件、Iconfont
```

**兼容性要求：**
- PC端：Chrome 90+、Edge 90+、Firefox 88+、360安全浏览器（极速模式）
- 不支持IE11及以下版本（系统提示升级浏览器）
- 移动端：iOS 12+、Android 8.0+
