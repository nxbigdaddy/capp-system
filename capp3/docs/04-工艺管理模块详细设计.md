## 1. 概述

工艺管理模块是CAPP系统的核心，面向工业压缩机、压力容器等重型装备制造企业，覆盖从产品设计到生产制造的全工艺生命周期。本模块采用PHP原生架构与MySQL数据库，通过模块化设计实现工艺路线、工序、工艺卡片、BOM、材料定额、工时定额、工艺文件、工艺变更及工艺知识库的统一管理。

本模块的设计原则包括：
- **标准化**：遵循GB/T 24737-2009《工艺管理导则》及行业工艺规范；
- **可追溯性**：所有工艺数据支持版本控制与变更历史追溯；
- **协同性**：支持多部门工艺会签与并行审批；
- **复用性**：通过工艺知识库实现典型工艺的快速复用。

## 2. 工艺路线管理

### 2.1 功能描述

工艺路线管理是工艺规划的首要环节，定义产品从原材料到成品的全部加工路径。针对工业压缩机（如膜片、缸体、油路系统）和压力容器（如筒体、封头、接管）的多品种、小批量、定制化特点，本模块支持以下核心功能：

1. **工艺路线创建与编辑**：基于产品型号或订单创建工艺路线，支持图形化编辑工序节点；
2. **审核与发布流程**：实现编制→校对→审核→批准→发布的五级工艺审签流程；
3. **版本管理**：支持主版本（V1.0、V2.0）与修订版本（V1.1、V1.2）的自动递增，保留历史版本供追溯；
4. **产品关联**：建立工艺路线与产品主数据（物料编码）的一对多关联，支持按产品族分类管理；
5. **复制与引用**：支持跨产品复制工艺路线，或引用典型工艺库中的标准路线，减少重复编制工作。

### 2.2 业务流程图（文字描述）

### 2.5 关键算法

**版本号生成算法**

```php
function generateVersion($route_id, $change_type = 'major') {
    $lastVersion = getLastVersion($route_id); // 查询最新版本，如 "V1.3"
    preg_match('/V(\d+)\.(\d+)/', $lastVersion, $matches);
    $major = intval($matches[1]);
    $minor = intval($matches[2]);
    
    if ($change_type == 'major') {
        // 重大变更：主版本+1，修订版本归零
        return 'V' . ($major + 1) . '.0';
    } else {
        // 一般变更：修订版本+1
        return 'V' . $major . '.' . ($minor + 1);
    }
}
```

**工艺路线复制算法**

```php
function copyRoute($source_route_id, $target_product_id, $copy_mode) {
    // copy_mode: 1=全复制（深拷贝，独立新路线）
    //            2=引用复制（关联源路线，源路线变更时同步更新）
    //            3=继承复制（复制后建立继承关系，允许局部覆盖）
    
    $source = getRouteDetail($source_route_id);
    $newRoute = createNewRoute($target_product_id, $source['route_name'] . '_副本');
    
    if ($copy_mode == 1) {
        deepCopyOperations($source['route_id'], $newRoute['route_id']);
    } else if ($copy_mode == 2) {
        setReferenceRelation($newRoute['route_id'], $source_route_id);
    } else if ($copy_mode == 3) {
        deepCopyOperations($source['route_id'], $newRoute['route_id']);
        setInheritRelation($newRoute['route_id'], $source_route_id);
    }
    
    return $newRoute;
}
```

## 3. 工序管理

### 3.1 功能描述

工序管理定义工艺路线中的具体加工单元。针对工业压缩机和压力容器的制造特点，工序类型涵盖：

1. **工序定义**：支持加工（车、铣、钻、磨）、装配（部件装配、总装）、检验（尺寸检验、压力试验、无损检测）、热处理（正火、调质、固溶）、特种工艺（焊接、表面处理）等类型；
2. **工序参数管理**：定义每道工序的技术参数，如焊接工序的电流、电压、速度；热处理工序的温度、时间、冷却方式；
3. **工序资源分配**：关联设备（如数控车床CK6150、焊接机器人）、工装夹具、模具及技能等级要求的人员；
4. **工序顺序与并行关系**：通过前驱后继关系定义工序串行顺序，通过并行组标识支持多工序并行执行（如筒体纵缝焊接与封头成型可并行）。

```
[工序关系设定] → [设定前驱工序] → [设定并行组（可选）] → [保存工序]
```

### 3.5 关键算法

**工序拓扑排序算法（检测循环依赖并生成执行顺序）**

```php
function topologicalSort($route_id) {
    $operations = getOperationsByRoute($route_id);
    $inDegree = []; // 入度表
    $adjList = [];  // 邻接表
    
    foreach ($operations as $op) {
        $inDegree[$op['operation_id']] = 0;
        $adjList[$op['operation_id']] = [];
    }
    
    // 构建图
    $sequences = getSequencesByRoute($route_id);
    foreach ($sequences as $seq) {
        if ($seq['relation_type'] == 1 || $seq['relation_type'] == 2) {
            $adjList[$seq['prev_operation_id']][] = $seq['operation_id'];
            $inDegree[$seq['operation_id']]++;
        }
    }
    
    // Kahn算法
    $queue = [];
    foreach ($inDegree as $id => $degree) {
        if ($degree == 0) $queue[] = $id;
    }
    
    $result = [];
    while (!empty($queue)) {
        $current = array_shift($queue);
        $result[] = $current;
        foreach ($adjList[$current] as $next) {
            $inDegree[$next]--;
            if ($inDegree[$next] == 0) $queue[] = $next;
        }
    }
    
    if (count($result) != count($operations)) {
        throw new Exception("存在循环依赖，请检查工序顺序设置");
    }
    
    return $result;
}
```

**资源冲突检测算法**

```php
function checkResourceConflict($route_id, $planned_date) {
    $operations = getOperationsByRoute($route_id);
    $conflicts = [];
    
    foreach ($operations as $op) {
        $resources = getOperationResources($op['operation_id']);
        foreach ($resources as $res) {
            if ($res['resource_type'] == 1) { // 设备
                $occupied = queryDeviceOccupancy(
                    $res['resource_id'], 
                    $planned_date, 
                    $op['standard_hour']
                );
                if ($occupied) {
                    $conflicts[] = [
                        'operation' => $op['operation_name'],
                        'resource' => $res['resource_name'],
                        'conflict_with' => $occupied
                    ];
                }
            }
        }
    }
    return $conflicts;
}
```

工艺卡片是指导车间现场生产的核心文件。本模块支持：

1. **工艺卡片模板设计**：提供可视化模板设计器，支持表格式、自由格式及混合布局；预置机械加工卡片、装配工艺卡片、焊接工艺卡片、热处理工艺卡片等标准模板；

### 4.5 关键算法

**模板渲染算法（动态填充数据到模板布局）**

```php
function renderCard($template_id, $route_id, $operation_id = null) {
    $template = getTemplate($template_id);
    $layout = json_decode($template['layout_config'], true);
    
    // 获取数据源
    $data = [];
    $data['header'] = getRouteHeaderData($route_id);
    $data['body'] = $operation_id ? getOperationDetail($operation_id) : getAllOperations($route_id);
    $data['footer'] = getRouteFooterData($route_id);
    
    // 渲染HTML
    $html = '<div class="card-container">';
    foreach ($layout['sections'] as $section) {
        $html .= '<div class="section section-' . $section['type'] . '">';
        foreach ($section['fields'] as $field) {
            $value = extractFieldValue($data, $field['data_path']);
            $html .= '<div class="field">';
            $html .= '<label>' . $field['label'] . '</label>';
            $html .= '<span>' . formatValue($value, $field['format']) . '</span>';
            $html .= '</div>';
        }
        $html .= '</div>';
    }
    $html .= '</div>';
    
    return $html;
}

function extractFieldValue($data, $path) {
    // 支持路径如 "header.product_name" 或 "body.0.operation_name"
    $keys = explode('.', $path);
    $current = $data;
    foreach ($keys as $key) {
        if (is_array($current) && isset($current[$key])) {
            $current = $current[$key];
        } else {
            return '';
        }
    }
    return $current;
}
```

## 5. BOM管理

### 5.1 功能描述

BOM（物料清单）管理是连接设计与制造的桥梁。针对工业压缩机和压力容器的多级装配结构，本模块支持：

1. **BOM结构管理**：支持多级BOM树形维护，无限层级展开；支持父件与子件的用量、损耗率、替代料关系维护；
2. **BOM与工艺路线关联**：每个BOM节点可关联对应的工艺路线，实现"物料-工艺"一体化管理；
3. **BOM变更管理**：支持工程变更（ECO）驱动的BOM变更，自动触发工艺路线、定额、工时的联动更新提示；
4. **BOM版本控制**：支持按时间戳、版本号双维度管理BOM版本，支持版本对比（高亮差异项）。

```php
function explodeBOM($bom_id, $parent_qty = 1, $level = 1, &$result = []) {
    $items = getBOMItems($bom_id, 0); // 获取直接子项
    
    foreach ($items as $item) {
        $actual_qty = $item['quantity'] * $parent_qty * (1 + $item['loss_rate']);
        
        $result[] = [
            'material_code' => $item['material_code'],
            'material_name' => $item['material_name'],
            'level' => $level,
            'quantity' => $actual_qty,
            'unit' => $item['unit'],
            'route_id' => $item['route_id']
        ];
        
        // 递归展开子BOM
        $child_bom = getBOMByProductCode($item['material_code']);
        if ($child_bom) {
            explodeBOM($child_bom['bom_id'], $actual_qty, $level + 1, $result);
        }
    }
    
    return $result;
}
```

```php
function compareBOMVersions($bom_id, $ver1, $ver2) {
    $snapshot1 = json_decode(getVersionSnapshot($bom_id, $ver1), true);
    $snapshot2 = json_decode(getVersionSnapshot($bom_id, $ver2), true);
    
    $diff = [];
    $map1 = array_column($snapshot1, null, 'material_code');
    $map2 = array_column($snapshot2, null, 'material_code');
    
    // 检测新增和修改
    foreach ($map2 as $code => $item) {
        if (!isset($map1[$code])) {
            $diff[] = ['type' => '新增', 'material_code' => $code, 'data' => $item];
        } else if ($map1[$code]['quantity'] != $item['quantity'] || 
                   $map1[$code]['loss_rate'] != $item['loss_rate']) {
            $diff[] = [
                'type' => '修改', 
                'material_code' => $code, 
                'old' => $map1[$code], 
                'new' => $item
            ];
        }
    }
    
    // 检测删除
    foreach ($map1 as $code => $item) {
        if (!isset($map2[$code])) {
            $diff[] = ['type' => '删除', 'material_code' => $code, 'data' => $item];
        }
    }
    
    return $diff;
}
```

```php
function calculateMaterialQuota($product_id, $bom_id, $cutting_params) {
    $bom_items = explodeBOM($bom_id); // 调用BOM展开算法
    $quotas = [];
    
    foreach ($bom_items as $item) {
        $material = getMaterialInfo($item['material_code']);
        $quota_type = classifyMaterial($material['category']);
        
        // 基础用量 = BOM净用量 × (1 + 损耗率)
        $base_qty = $item['quantity'] * (1 + $item['loss_rate']);
        
        // 根据材料类型应用下料利用率
        $utilization = 1.0;
        if ($quota_type == 1) { // 板材
            $utilization = calculatePlateUtilization(
                $material['specification'], 
                $item['quantity'], 
                $cutting_params
            );
        } else if ($quota_type == 3) { // 管材
            $utilization = calculatePipeUtilization(
                $material['specification'], 
                $item['quantity']
            );
        }
        
        $quota_qty = $base_qty / $utilization;
        
        $quotas[] = [
            'product_id' => $product_id,
            'material_code' => $item['material_code'],
            'bom_qty' => $item['quantity'],
            'loss_rate' => $item['loss_rate'],
            'cutting_utilization' => $utilization,
            'quota_qty' => round($quota_qty, 4),
            'final_qty' => round($quota_qty, 4),
            'quota_type' => $quota_type
        ];
    }
    
    return $quotas;
}

function calculatePlateUtilization($spec, $qty, $params) {
    // 板材利用率计算：基于排样算法或经验系数
    $plate_size = parsePlateSpec($spec); // 解析板材规格
    $part_size = $params['part_size'] ?? null;
    
    if ($part_size) {
        // 简单矩形排样估算
        $parts_per_sheet = floor($plate_size['width'] / $part_size['width']) * 
                           floor($plate_size['length'] / $part_size['length']);
        $total_sheets = ceil($qty / $parts_per_sheet);
        $actual_area = $total_sheets * $plate_size['width'] * $plate_size['length'];
        $needed_area = $qty * $part_size['width'] * $part_size['length'];
        return min(0.95, $needed_area / $actual_area); // 上限95%
    }
    
    return 0.85; // 默认经验系数
}
```

```php
function getSubstitutePriority($original_code, $requirement) {
    $substitutes = getSubstitutesByOriginal($original_code);
    $scored = [];
    
    foreach ($substitutes as $sub) {
        $score = 0;
        $material = getMaterialInfo($sub['substitute_code']);
        
        // 价格权重30%
        $price_ratio = $material['price'] / getMaterialInfo($original_code)['price'];
        $score += (1 / max($price_ratio, 0.1)) * 30;
        
        // 库存权重25%
        $stock = getMaterialStock($sub['substitute_code']);
        $score += min($stock / 100, 1) * 25;
        
        // 性能匹配权重35%
        $performance_match = calculatePerformanceMatch($original_code, $sub['substitute_code'], $requirement);
        $score += $performance_match * 35;
        
        // 审批状态权重10%
        if ($sub['approval_status'] == 1) $score += 10;
        
        $scored[] = array_merge($sub, ['priority_score' => round($score, 2)]);
    }
    
    usort($scored, function($a, $b) {
        return $b['priority_score'] <=> $a['priority_score'];
    });
    
    return $scored;
}
```

### 7.5 关键算法

**技术测定法工时计算（剔除异常值，计算平均工时）**

```php
function calculateMeasuredHour($sample_data, $method = 'technical') {
    $samples = json_decode($sample_data, true);
    $times = array_column($samples, 'duration'); // 单位：分钟
    
    if ($method == 'technical') {
        // 1. 剔除异常值（3σ原则）
        $mean = array_sum($times) / count($times);
        $variance = 0;
        foreach ($times as $t) {
            $variance += pow($t - $mean, 2);
        }
        $std_dev = sqrt($variance / count($times));
        
        $filtered = [];
        foreach ($times as $t) {
            if (abs($t - $mean) <= 3 * $std_dev) {
                $filtered[] = $t;
            }
        }
        
        // 2. 计算平均实测工时
        $avg_measured = array_sum($filtered) / count($filtered);
        
        // 3. 评定系数（根据操作者熟练度、努力程度等）
        $rating_factor = 1.0; // 正常状态为1.0
        $normal_time = $avg_measured * $rating_factor;
        
        // 4. 加入宽放时间（通常10%-20%）
        $allowance_rate = 0.15;
        $std_hour = $normal_time * (1 + $allowance_rate);
        
        return round($std_hour, 2);
    } else if ($method == 'statistical') {
        // 统计分析法：加权平均历史数据
        $weights = [];
        foreach ($samples as $i => $s) {
            $weights[$i] = $s['batch_size'] ?? 1; // 批量越大权重越高
        }
        $weighted_sum = 0;
        $weight_total = 0;
        foreach ($times as $i => $t) {
            $weighted_sum += $t * $weights[$i];
            $weight_total += $weights[$i];
        }
        return round($weighted_sum / $weight_total, 2);
    }
    
    return round(array_sum($times) / count($times), 2);
}
```

**学习曲线工时修正算法**

```php
function applyLearningCurve($base_hour, $batch_number, $learning_rate = 0.85) {
    // 学习曲线模型：第N批次的工时 = 首件工时 × N^(log(学习率)/log(2))
    // 学习率通常为80%-90%，即产量翻倍时工时为原来的80%-90%
    
    if ($batch_number <= 1) return $base_hour;
    
    $exponent = log($learning_rate) / log(2);
    $adjusted_hour = $base_hour * pow($batch_number, $exponent);
    
    // 学习曲线在达到一定批量后趋于平稳（经验系数下限）
    $floor_factor = 0.7; // 最低可降至定额的70%
    $adjusted_hour = max($adjusted_hour, $base_hour * $floor_factor);
    
    return round($adjusted_hour, 2);
}
```

```php
function checkFilePermission($file_id, $user_id, $action) {
    $user = getUserInfo($user_id);
    $permissions = getFilePermissions($file_id);
    
    $effective_perm = [
        'can_read' => 0,
        'can_write' => 0,
        'can_download' => 0,
        'can_print' => 0
    ];
    
    foreach ($permissions as $perm) {
        $match = false;
        if ($perm['target_type'] == 1 && $perm['target_id'] == $user['role_id']) {
            $match = true; // 角色匹配
        } else if ($perm['target_type'] == 2 && $perm['target_id'] == $user['dept_id']) {
            $match = true; // 部门匹配
        } else if ($perm['target_type'] == 3 && $perm['target_id'] == $user_id) {
            $match = true; // 用户匹配
        } else if ($perm['target_type'] == 4 && $perm['target_id'] == $user['project_id']) {
            $match = true; // 项目匹配
        }
        
        if ($match) {
            $effective_perm['can_read'] |= $perm['can_read'];
            $effective_perm['can_write'] |= $perm['can_write'];
            $effective_perm['can_download'] |= $perm['can_download'];
            $effective_perm['can_print'] |= $perm['can_print'];
        }
    }
    
    // 系统管理员拥有所有权限
    if ($user['is_admin']) {
        return true;
    }
    
    $action_map = ['read' => 'can_read', 'write' => 'can_write', 
                   'download' => 'can_download', 'print' => 'can_print'];
    return $effective_perm[$action_map[$action]] ?? false;
}
```

```php
function addWatermark($source_path, $user_name, $download_time) {
    $watermark_text = "{$user_name} {$download_time} 机密文件";
    $ext = pathinfo($source_path, PATHINFO_EXTENSION);
    
    if (strtolower($ext) == 'pdf') {
        // 使用PDF库（如FPDF或TCPDF）添加水印
        $output_path = generateTempPath($source_path, '_wm');
        // 调用PDF处理工具添加文字水印
        exec("pdftk {$source_path} multistamp watermark.pdf output {$output_path}");
        return $output_path;
    } else if (in_array(strtolower($ext), ['jpg', 'jpeg', 'png', 'tiff'])) {
        // 图片水印
        $image = imagecreatefromstring(file_get_contents($source_path));
        $color = imagecolorallocatealpha($image, 128, 128, 128, 60);
        imagettftext($image, 20, 45, 100, 100, $color, 'arial.ttf', $watermark_text);
        $output_path = generateTempPath($source_path, '_wm');
        imagepng($image, $output_path);
        imagedestroy($image);
        return $output_path;
    }
    
    return $source_path; // 不支持的格式直接返回原文件
}
```

**变更传播路径追溯算法**

```php
function traceChangePropagation($ecr_id, &$path = [], $visited = []) {
    if (in_array($ecr_id, $visited)) return $path; // 防止循环
    $visited[] = $ecr_id;
    
    $ecr = getChangeRequest($ecr_id);
    $path[] = [
        'ecr_id' => $ecr_id,
        'ecr_no' => $ecr['ecr_no'],
        'status' => $ecr['status'],
        'time' => $ecr['propose_time']
    ];
    
    // 查找由本变更触发的后续变更
    $triggered = getTriggeredChanges($ecr_id);
    foreach ($triggered as $t) {
        traceChangePropagation($t['ecr_id'], $path, $visited);
    }
    
    // 查找本变更的前置触发变更
    $triggered_by = getTriggeredBy($ecr_id);
    if ($triggered_by && !in_array($triggered_by['ecr_id'], $visited)) {
        // 前置变更插入到当前节点之前
        array_splice($path, count($path) - 1, 0, [
            [
                'ecr_id' => $triggered_by['ecr_id'],
                'ecr_no' => $triggered_by['ecr_no'],
                'status' => $triggered_by['status'],
                'time' => $triggered_by['propose_time'],
                'relation' => '前置触发'
            ]
        ]);
    }
    
    return $path;
}
```

### 10.5 关键算法

**典型工艺相似度匹配算法**

```php
function matchTypicalProcess($product_features, $limit = 5) {
    $typical_processes = getAllTypicalProcesses();
    $scored = [];
    
    foreach ($typical_processes as $tp) {
        $score = 0;
        $tp_features = json_decode($tp['feature_vector'] ?? '{}', true);
        
        // 1. 产品类型匹配（权重40%）
        if ($tp['category'] == $product_features['category']) {
            $score += 40;
            if ($tp['sub_category'] == $product_features['sub_category']) {
                $score += 20; // 子分类额外加分
            }
        }
        
        // 2. 材料相似度（权重25%）
        if (isset($tp_features['material']) && isset($product_features['material'])) {
            $material_sim = calculateMaterialSimilarity(
                $tp_features['material'], 
                $product_features['material']
            );
            $score += $material_sim * 25;
        }
        
        // 3. 尺寸范围匹配（权重20%）
        if (isset($tp_features['size_range']) && isset($product_features['size_range'])) {
            $size_sim = calculateSizeRangeOverlap(
                $tp_features['size_range'], 
                $product_features['size_range']
            );
            $score += $size_sim * 20;
        }
        
        // 4. 质量等级权重（权重15%）
        $quality_weight = [1 => 0.6, 2 => 0.8, 3 => 1.0];
        $score += ($quality_weight[$tp['quality_level']] ?? 0.5) * 15;
        
        // 5. 引用次数加成（经验系数）
        $usage_bonus = min($tp['usage_count'] / 100, 0.1) * 100;
        $score += $usage_bonus;
        
        $scored[] = array_merge($tp, ['match_score' => round($score, 2)]);
    }
    
    usort($scored, function($a, $b) {
        return $b['match_score'] <=> $a['match_score'];
    });
    
    return array_slice($scored, 0, $limit);
}

function calculateMaterialSimilarity($mat1, $mat2) {
    // 材料相似度：同牌号=1.0，同系列=0.8，同大类=0.5
    if ($mat1 == $mat2) return 1.0;
    if (getMaterialSeries($mat1) == getMaterialSeries($mat2)) return 0.8;
    if (getMaterialCategory($mat1) == getMaterialCategory($mat2)) return 0.5;
    return 0.0;
}
```

**工艺参数推荐算法（基于条件匹配与验证状态）**

```php
function recommendProcessParams($param_category, $material, $device, $requirement) {
    $params = getParamsByCategory($param_category);
    $candidates = [];
    
    foreach ($params as $param) {
        $match_score = 0;
        
        // 材料匹配
        $materials = explode(',', $param['material_scope']);
        if (in_array($material, $materials) || in_array('通用', $materials)) {
            $match_score += 40;
        } else if (in_array(getMaterialSeries($material), $materials)) {
            $match_score += 25;
        }
        
        // 设备匹配
        $devices = explode(',', $param['device_scope']);
        if (in_array($device, $devices) || in_array('通用', $devices)) {
            $match_score += 30;
        }
        
        // 条件匹配（关键词模糊匹配）
        if ($requirement) {
            $condition_sim = textSimilarity($param['condition_desc'], $requirement);
            $match_score += $condition_sim * 20;
        }
        
        // 验证状态加成
        if ($param['verified'] == 1) {
            $match_score += 10;
        }
        
        if ($match_score >= 30) { // 最低匹配阈值
            $candidates[] = array_merge($param, ['recommend_score' => round($match_score, 2)]);
        }
    }
    
    usort($candidates, function($a, $b) {
        return $b['recommend_score'] <=> $a['recommend_score'];
    });
    
    return $candidates;
}
```

### 11.2 接口通用规范

1. **请求格式**：所有POST请求采用`application/x-www-form-urlencoded`或`application/json`格式；
2. **响应格式**：统一返回JSON，结构为`{"code": 0, "message": "success", "data": {}}`，`code=0`表示成功，非0表示错误；
3. **认证方式**：基于PHP Session或Token（JWT）认证，请求头携带`Authorization: Bearer {token}`；
4. **分页规范**：列表接口支持`page`（页码，从1开始）和`size`（每页条数，默认20，最大100）参数，返回数据包含`total`、`page`、`size`、`list`；
5. **权限控制**：接口层通过中间件（PHP原生实现为前置拦截函数）校验用户权限，未授权返回`code: 403`。

### 11.4 系统性能考虑

1. **BOM展开优化**：对于深度超过5级的复杂BOM，采用数据库递归CTE（Common Table Expression）或预计算扁平化BOM表，避免PHP层递归带来的性能损耗；
2. **文件存储**：工艺图纸等大文件采用对象存储（如MinIO）或NAS存储，数据库仅保存元数据和路径；
3. **版本快照**：工艺路线、BOM的版本快照采用JSON压缩存储，减少存储空间占用；
4. **知识库检索**：典型工艺和经验库支持全文检索，可通过MySQL FULLTEXT索引或集成Elasticsearch实现；
5. **并发控制**：工艺审签、变更审批等流程采用乐观锁（version字段）或数据库行锁防止并发冲突。
