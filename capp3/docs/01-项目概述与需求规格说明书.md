## 1. 项目背景与目标

### 1.1 项目背景

随着我国装备制造业的快速发展，工业压缩机及压力容器作为能源、化工、航天、核电等关键领域的核心装备，其制造质量与工艺水平直接关系到国家重大工程的安全运行。本企业作为专业从事工业压缩机、压力容器研发设计与生产制造的国家级高新技术企业，拥有A1/A2级压力容器设计制造许可证、GC1级工业管道安装改造维修许可证等多项资质，产品广泛应用于氢能加注、特种气体压缩、超高压技术等领域。

在当前数字化转型的大背景下，企业原有的工艺管理模式已难以满足日益复杂的生产需求。目前，企业的工艺规划工作主要依赖人工编制Excel表格、AutoCAD图纸及纸质工艺卡片，存在数据分散、版本混乱、检索困难、协同效率低等问题。随着产品种类不断增加、客户定制化需求日益增多、特种设备监管要求日趋严格，建立一套覆盖全生命周期的计算机辅助工艺规划（CAPP）系统已成为企业提升核心竞争力的迫切需求。

本项目旨在通过信息化手段，将企业多年积累的工艺知识、制造经验进行系统化沉淀，实现工艺数据的结构化存储、工艺路线的智能化设计、工艺资源的精细化管理，从而缩短工艺准备周期、提高工艺设计质量、降低生产成本、确保产品制造过程的可追溯性，最终支撑企业实现智能制造的战略目标。

### 1.2 项目目标

本项目的核心目标是建设一套面向工业压缩机与压力容器行业的计算机辅助工艺规划系统（CAPP），具体目标包括：

**（1）工艺数据集中化管理**
建立统一的工艺数据库，将分散在个人电脑、纸质档案中的工艺文件、工艺参数、工艺资源进行集中管理，实现工艺数据的唯一性、准确性和实时性，消除信息孤岛。

**（2）工艺设计流程标准化**
基于工业压缩机和压力容器的行业特点，建立标准化的工艺设计流程与工艺模板库，规范工艺路线编制、工艺卡片填写、工艺定额计算等工作，减少人为差错，提高工艺设计效率30%以上。

**（3）工艺与生产深度集成**
实现CAPP系统与ERP、MES、PDM等系统的数据贯通，确保工艺数据能够准确、及时地传递至生产执行层，支持生产计划排程、物料需求计算、车间作业指导等核心业务。

**（4）工艺知识积累与复用**
构建企业级工艺知识库，支持典型工艺路线的快速复用、工艺参数的自动推荐、历史工艺版本的对比分析，促进工艺技术的持续优化与传承。

**（5）质量追溯与合规管理**
满足TSG 21-2016《固定式压力容器安全技术监察规程》、GB/T 150《压力容器》等法规标准对工艺文件、焊接工艺评定、无损检测工艺、热处理工艺等的记录与追溯要求，确保工艺数据的完整性和不可篡改性。

### 1.3 项目范围

本项目的实施范围涵盖企业总部研发中心、工艺部门、生产车间及相关职能部门，具体包括：

- **业务范围**：覆盖工业压缩机整机、压力容器（储气罐、分离器、换热器、反应釜等）及其零部件的工艺规划全过程，包括工艺方案设计、工艺路线编制、工艺定额计算、工艺文件审批、工艺变更管理、工艺现场服务等环节。
- **系统范围**：建设CAPP核心应用系统，包括工艺文件管理、工艺路线设计、工艺BOM管理、工艺定额管理、工艺资源管理、工艺变更管理、质量工艺控制、生产任务管理、报表统计分析、系统管理等十大功能模块，并提供与外部系统的标准数据接口。
- **组织范围**：涉及工艺部、研发部、生产部、质量部、物资部、设备部、信息中心等部门，预计系统用户规模约150人。
- **数据范围**：涵盖企业现有全部在产产品的工艺数据迁移，以及未来新增产品的工艺数据管理，预计初期导入工艺数据约5万条，工艺文件约1万份。

## 2. 企业业务描述

### 2.1 企业概况

本企业成立于二十世纪九十年代，经过三十余年的发展，已成为国内工业压缩机及压力容器领域的领先企业。企业占地面积约8万平方米，拥有现代化生产车间4座，配备数控加工中心、自动焊接设备、热处理炉、无损检测设备等先进制造装备200余台套。企业现有员工600余人，其中工程技术人员120余人，高级技师及技师80余人。

企业通过了ISO 9001质量管理体系认证、ISO 14001环境管理体系认证、ISO 45001职业健康安全管理体系认证，以及欧盟PED认证、美国ASME U/U2钢印认证等国际资质。产品远销欧美、东南亚、中东等30多个国家和地区，在氢能、航天、军工、石油化工等高端市场占据重要地位。

### 2.2 主要产品类型

企业主要产品分为两大类：

**（1）工业压缩机系列产品**
- 结构形式：单缸单作用、单缸双作用、多缸多级、对称平衡型等
- 排气压力范围：0.1MPa至100MPa（超高压型可达300MPa）
- 应用领域：氢气充装、氦气回收、特种气体压缩、加注站等
- 关键零部件：曲轴箱、缸体、缸盖、膜片、配油盘、进出口阀组、冷却器等

**（2）压力容器系列产品**
- 储气罐、缓冲罐、分离器、过滤器、换热器、反应釜、塔器等
- 设计压力：常压至35MPa
- 设计温度：-196℃至650℃
- 材质：碳钢、低合金钢、不锈钢、双相钢、镍基合金、钛合金等
- 制造工艺涉及：下料、成型、焊接、热处理、无损检测、压力试验、表面处理等

### 2.3 研发设计流程

企业的研发设计流程遵循APQP（产品质量先期策划）方法论，主要分为以下阶段：

**（1）需求分析与方案设计**
销售部门获取客户需求后，组织技术评审会议，由研发工程师进行可行性分析，确定技术方案。对于压力容器产品，需进行强度计算、疲劳分析、稳定性校核；对于工业压缩机，需进行热力计算、动力计算、气流脉动分析等。

**（2）详细设计与图纸输出**
采用AutoCAD、SolidWorks、ANSYS等工具进行三维建模、工程制图和有限元分析。设计输出包括总装图、部件图、零件图、管路布置图、电气原理图等。所有图纸需经过校对、审核、工艺审查、标准化审查、批准五级审签。

**（3）设计验证与确认**
关键产品需进行样机试制、型式试验、性能测试、寿命试验等验证活动。压力容器产品需进行应力测试、爆破试验等验证设计裕量。

**（4）设计变更控制**
设计变更需发起ECR（工程变更请求），经过影响分析、审批流程后，更新相关图纸、工艺文件和BOM，确保变更的可追溯性。

### 2.4 生产制造流程

工业压缩机及压力容器的生产制造流程具有多品种、小批量、工艺复杂、质量要求高的特点，主要制造流程如下：

**（1）原材料采购与复验**
压力容器用钢板、锻件、管材等关键材料需按NB/T 47013进行复验，包括化学成分分析、力学性能试验、无损检测等。材料需具备可追溯的炉批号、质保书。

**（2）下料与成型**
采用数控火焰切割、等离子切割、激光切割、水刀切割等方式进行板材下料；采用卷板机、压力机、旋压机等设备进行筒体卷制、封头成型、弯管等工序。

**（3）焊接**
焊接是压力容器制造的核心工序，涉及焊条电弧焊（SMAW）、埋弧焊（SAW）、气体保护焊（GMAW/FCAW）、钨极氩弧焊（GTAW）、等离子弧焊（PAW）等多种方法。所有焊接工艺需经过焊接工艺评定（WPS/PQR），焊工需持相应项目的特种设备作业人员证书。

**（4）热处理**
根据材料特性和工艺要求，进行焊后热处理（PWHT）、正火、淬火+回火、固溶处理、稳定化处理等。热处理工艺需严格控制升温速度、保温温度、保温时间、冷却速度等参数。

**（5）无损检测**
按设计图纸和标准要求进行射线检测（RT）、超声检测（UT）、磁粉检测（MT）、渗透检测（PT）、衍射时差法超声检测（TOFD）等。检测比例分为全部（100%）和局部（≥20%）两种。

**（6）压力试验与气密性试验**
压力容器需进行耐压试验（液压试验或气压试验）和泄漏试验（气密性试验、氨检漏、氦检漏等）。试验压力、保压时间、合格标准需严格按规范执行。

**（7）装配与调试**
工业压缩机需进行部件装配、总装、跑合试验、性能试验、无负荷试验、负荷试验等。调试过程中需记录排气量、排气压力、温度、振动、噪声等参数。

**（8）表面处理与涂装**
进行除锈、喷砂、喷漆、喷锌、电镀等表面处理，满足防腐和外观质量要求。

**（9）包装与发运**
按运输要求进行防护包装，编制竣工资料（含产品合格证、质量证明书、竣工图等），办理发运手续。

### 2.5 工艺管理现状与痛点

目前企业的工艺管理存在以下突出问题：

**（1）工艺数据分散，检索困难**
工艺文件分散存储在个人电脑、共享文件夹、纸质档案中，缺乏统一的编码体系和分类标准。查找一份历史工艺文件往往需要数小时，严重影响工艺复用和知识传承。

**（2）工艺编制效率低，重复劳动多**
工艺人员编制工艺卡片时，大量时间花费在重复填写设备名称、型号、参数等基础信息上。相似产品的工艺路线无法快速复制和修改，工艺准备周期占生产周期的比例过高。

**（3）工艺版本管理混乱**
工艺变更频繁，但缺乏有效的版本控制机制。车间现场经常出现使用过期工艺文件的情况，导致加工错误、返工返修，甚至质量事故。

**（4）工艺与生产脱节**
工艺数据无法直接传递至ERP和MES系统，需要人工二次录入，数据一致性差。生产计划变更时，工艺部门无法及时获取反馈，工艺优化滞后。

**（5）工艺定额不准确**
工时定额、材料定额主要依靠经验估算，缺乏科学的计算模型和统计分析。定额数据更新不及时，导致成本核算偏差大，报价缺乏竞争力。

**（6）工艺资源管理粗放**
设备台账、工装模具、刀具量具、焊接材料等工艺资源信息不完整，状态更新不及时。工艺编制时无法准确判断资源可用性，导致工艺可行性差。

**（7）合规性管理压力大**
特种设备制造许可换证、监督检验、客户审核时，需要大量人工整理工艺记录。工艺文件的签署、发放、回收、归档缺乏系统支撑，存在合规风险。

## 3. 系统总体目标

### 3.1 总体建设目标

本CAPP系统的总体建设目标是：构建一套覆盖工业压缩机与压力容器全生命周期、集成化、智能化、标准化的计算机辅助工艺规划平台，实现工艺数据的集中管理、工艺设计的协同高效、工艺知识的持续积累、工艺与生产的深度融合，为企业智能制造奠定坚实的工艺信息化基础。

具体目标分解如下：

**（1）建立企业级工艺数据中心**
构建统一的工艺数据库，实现工艺路线、工艺卡片、工艺定额、工艺资源、工艺标准等数据的结构化存储和关联管理。建立完整的数据编码体系，确保数据的唯一性、准确性和一致性。

**（2）实现工艺设计全过程信息化**
覆盖从工艺方案设计、工艺路线编制、工艺卡片生成、工艺文件审批、工艺变更管理到工艺现场服务的全业务流程。支持在线编制、在线审批、电子签章、自动归档，实现工艺设计无纸化。

**（3）构建工艺知识管理与复用体系**
建立典型工艺库、标准工序库、工艺参数库、工艺问题库等知识资产库。支持基于产品特征的智能工艺推荐、相似工艺检索、工艺版本对比分析，提升工艺设计效率和水平。

**（4）打通工艺与上下游系统数据流**
通过标准接口与PDM/PLM系统对接，获取设计BOM、图纸、技术规范；与ERP系统对接，传递工艺BOM、工艺定额、工艺路线；与MES系统对接，下发工艺指令、采集工艺执行数据；与质量管理系统对接，传递检验工艺、接收质量反馈。

**（5）支撑工艺优化与决策分析**
提供工艺数据统计分析、工艺成本分析、工艺效率分析、工艺质量分析等多维度报表。支持工艺瓶颈识别、工艺改进建议、工艺趋势预测，为工艺管理和技术决策提供数据支撑。

### 3.2 分期实施计划

本项目采用总体规划、分步实施的建设策略，分为三个阶段：

**第一阶段（基础平台建设期，6个月）**
- 完成系统需求分析、架构设计、数据库设计
- 搭建开发测试环境，完成基础框架开发
- 实现系统管理、工艺资源管理、工艺文件管理、基础报表功能
- 完成历史工艺数据梳理与批量导入
- 完成系统部署、用户培训、试运行

**第二阶段（核心业务完善期，6个月）**
- 实现工艺路线设计、工艺BOM管理、工艺定额管理
- 实现工艺变更管理、质量工艺控制、生产任务管理
- 实现与PDM、ERP系统的数据集成
- 建立典型工艺库、标准工序库等知识库
- 完善报表与统计分析功能
- 系统正式上线运行

**第三阶段（深化应用与优化期，6个月）**
- 实现与MES系统的深度集成
- 开发工艺智能推荐、工艺参数优化等高级功能
- 建立工艺大数据分析平台
- 持续优化系统性能、用户体验
- 开展系统全面评估与验收

### 3.3 预期效益分析

**（1）经济效益**
- 工艺设计效率提升30%以上，工艺准备周期缩短20%
- 工艺文件差错率降低50%以上，减少返工返修成本
- 材料定额准确率提升至95%以上，降低材料浪费
- 工时定额准确率提升至90%以上，优化人力资源配置
- 预计年节约工艺管理成本约200万元

**（2）管理效益**

## 4. 功能需求总览

### 4.1 工艺文件管理模块

工艺文件管理是CAPP系统的基础模块，负责工艺文件的创建、编辑、审批、发布、归档、检索全生命周期管理。

**核心功能需求：**

- **工艺文件分类管理**：支持按产品类型、工艺类别、文件性质等多维度分类。工艺文件类型包括：工艺路线卡、工艺过程卡、工序卡、检验卡、焊接工艺卡、热处理工艺卡、无损检测工艺卡、装配工艺卡、调试工艺卡、涂装工艺卡、包装工艺卡等。

- **工艺文件模板管理**：提供各类工艺文件的标准模板，支持模板自定义。模板中可预定义固定字段、下拉选项、计算公式、自动填充规则等，规范工艺文件格式，减少重复录入。

- **工艺文件在线编制**：支持在Web页面中在线编制工艺文件，提供富文本编辑、表格编辑、公式插入、图片插入、CAD图纸引用等功能。支持从典型工艺库、历史工艺中复制内容，快速生成新工艺文件。

- **工艺文件审批流程**：支持自定义审批流程，可配置多级审批节点、会签、转办、退回等操作。审批过程中支持批注、痕迹保留、版本对比。审批通过后自动赋予文件正式版本号并发布。

- **工艺文件版本管理**：采用大版本（V1.0、V2.0）+小版本（V1.1、V1.2）的管理模式。支持版本历史查看、版本对比、版本回滚。文件变更时自动触发版本升级，旧版本自动归档但可查阅。

- **工艺文件检索与浏览**：支持按产品型号、零部件图号、工艺名称、编制人、编制日期、审批状态等多条件组合检索。支持全文检索、模糊检索、高级检索。支持在线浏览、打印、导出PDF/Excel。

- **工艺文件发放与回收**：支持按车间、班组、工序等维度进行工艺文件的发放管理。记录发放对象、发放时间、发放份数。工艺变更时自动通知相关使用方回收旧版文件。

### 4.2 工艺路线设计模块

工艺路线设计模块是CAPP系统的核心，负责确定产品从原材料到成品的全部加工工序及其顺序。

**核心功能需求：**

- **工艺路线创建**：支持基于设计BOM自动创建工艺路线框架，或从典型工艺库中复制相似工艺路线。支持多工艺路线管理（如正常工艺路线、返修工艺路线、试制工艺路线）。

- **工序定义与排序**：支持工序的增删改查、拖拽排序、并行工序设置。工序属性包括：工序号、工序名称、工序内容、工作中心、设备/工装、工艺参数、工时定额、检验要求等。

- **工序资源分配**：为每道工序分配所需的设备、工装模具、刀具量具、操作人员资质等。系统自动校验资源可用性，提示资源冲突或不足。

- **工艺路线审批**：工艺路线编制完成后提交审批，审批流程可配置。审批通过后锁定工艺路线，作为生产排程和车间作业的依据。

- **工艺路线变更**：支持工艺路线的在线变更申请，变更内容高亮显示。变更需经过审批流程，审批通过后自动更新相关工艺文件和生产任务。

- **工艺路线可视化**：以甘特图、流程图等形式直观展示工艺路线，支持工序详情查看、关键路径分析、瓶颈工序识别。

### 4.3 工艺BOM管理模块

工艺BOM管理模块负责管理制造过程中所需的物料清单，包括原材料、半成品、辅料、耗材等。

**核心功能需求：**

- **设计BOM导入**：从PDM/PLM系统导入设计BOM，或手工创建设计BOM。支持BOM结构展开、多级BOM浏览、BOM差异对比。

- **工艺BOM转换**：基于设计BOM，结合工艺路线，自动生成工艺BOM。工艺BOM需体现制造过程中的物料流转关系，如原材料→毛坯→半成品→成品。

- **材料定额计算**：根据零件尺寸、材料牌号、加工余量、下料排版方案等，自动计算材料消耗定额。支持板材、型材、管材、锻件、铸件等不同类型材料的定额计算。

- **辅料与耗材管理**：管理焊接材料（焊条、焊丝、焊剂）、切削液、润滑油、砂轮片、气体等辅料和耗材的消耗定额。

- **BOM版本管理**：支持工艺BOM的版本管理，与设计BOM版本、工艺路线版本关联，确保数据一致性。

- **BOM查询与报表**：提供单级BOM、多级BOM、反查BOM（Where-Used）等查询功能。提供材料汇总表、外购件清单、标准件清单等报表输出。

### 4.4 工艺定额管理模块

工艺定额管理模块负责工时定额、材料定额、能源定额等的制定、维护与统计分析。

**核心功能需求：**

- **工时定额制定**：支持多种工时定额制定方法，包括经验估工法、统计分析法、类推比较法、技术测定法（MTM、MODAPTS等）。提供工时定额计算模型和公式库。

- **工时定额维护**：支持工序工时、准备终结时间、休息与生理需要时间、辅助时间等的分项维护。支持批量修改、批量导入、批量导出。

- **材料定额维护**：支持材料定额的制定、审核、发布。材料定额需关联材料编码、规格型号、计量单位、单价等信息。

- **定额版本管理**：支持定额数据的版本管理，记录定额变更历史、变更原因、变更审批信息。

- **定额统计分析**：提供定额完成率分析、定额偏差分析、工时利用率分析、材料利用率分析等统计报表。支持按产品、车间、工序、时间段等多维度分析。

- **定额优化建议**：基于历史生产数据，运用统计分析方法，识别定额不合理之处，提供定额调整建议。

### 4.5 工艺资源管理模块

工艺资源管理模块负责管理工艺设计所需的各类资源数据，为工艺编制提供基础数据支撑。

**核心功能需求：**

- **设备资源管理**：管理企业全部生产设备台账，包括设备编码、设备名称、型号规格、技术参数、所属车间、能力范围、精度等级、当前状态（在用/闲置/维修/报废）等。支持设备能力查询、设备负荷分析。

- **工装模具管理**：管理工装、模具、夹具、胎具等工艺装备台账，包括编号、名称、适用产品、存放位置、使用次数、检定状态、寿命管理等。支持工装需求计划编制。

- **刀具量具管理**：管理刀具、量具、检具台账，包括规格型号、材质、适用工序、库存数量、检定周期、检定状态等。支持检定到期预警。

- **焊接材料管理**：管理焊条、焊丝、焊剂、保护气体等焊接材料的牌号、标准、化学成分、力学性能、适用范围、库存信息等。支持焊材与焊接工艺评定的关联。

- **工艺参数库**：管理各类加工工艺的标准参数范围，如切削速度、进给量、切削深度、焊接电流、焊接电压、热处理温度等。支持按材料、设备、加工方法等条件检索。

- **人员资质管理**：管理工艺人员、操作人员、检验人员、焊工、无损检测人员等的资质信息，包括证书编号、证书项目、有效期、发证机构等。支持资质到期预警。

### 4.6 工艺变更管理模块

工艺变更管理模块负责工艺变更的申请、评估、审批、实施、验证全过程管理，确保变更受控。

**核心功能需求：**

- **变更申请**：支持在线发起工艺变更申请（ECR），填写变更原因、变更内容、影响范围、预计实施时间等。支持上传附件、关联相关工艺文件。

- **变更评估**：系统自动分析变更影响范围，包括受影响的产品、零部件、工艺文件、BOM、生产任务、库存物料等。支持多部门会签评估。

- **变更审批**：配置变更审批流程，根据变更类型、影响程度自动选择审批路径。重大变更需经技术委员会评审。

- **变更实施**：审批通过后，自动更新相关工艺文件、BOM、定额等数据。支持变更实施计划编制、任务分派、进度跟踪。

- **变更验证**：变更实施后，需进行验证确认，记录验证结果。支持变更前后数据对比、效果评估。

- **变更追溯**：完整记录变更全过程信息，包括申请、评估、审批、实施、验证各环节的人员、时间、意见、结果。支持变更历史查询、变更统计分析。

### 4.7 质量工艺控制模块

质量工艺控制模块负责管理产品制造过程中的质量控制工艺，确保产品质量符合设计要求和标准规范。

**核心功能需求：**

- **检验工艺管理**：编制进货检验、过程检验、最终检验的检验工艺卡，定义检验项目、检验方法、检验设备、抽样方案、判定标准、记录表单等。

- **焊接工艺管理**：编制焊接工艺规程（WPS），关联焊接工艺评定报告（PQR）。管理焊工资质、焊接材料、焊接参数、预热后热要求、焊后热处理要求等。支持焊接工艺评定到期预警。

- **热处理工艺管理**：编制热处理工艺卡，定义热处理类型、设备、装炉方式、升温速度、保温温度、保温时间、冷却方式、冷却介质等。支持热处理工艺曲线绘制。

- **无损检测工艺管理**：编制射线检测、超声检测、磁粉检测、渗透检测等无损检测工艺卡，定义检测比例、检测部位、检测方法、验收标准、检测设备等。支持检测工艺与焊接工艺的关联。

- **压力试验工艺管理**：编制耐压试验、气密性试验工艺卡，定义试验介质、试验压力、保压时间、合格标准、安全措施等。

- **不合格品处理**：记录制造过程中的不合格品信息，支持不合格品评审、返工/返修工艺编制、让步接收申请、报废处理等流程。

- **质量记录管理**：管理制造过程中的各类质量记录，包括材料复验报告、焊接记录、热处理记录、无损检测报告、压力试验报告、外观检查记录等。支持记录与工艺文件的关联、归档、检索。

### 4.8 生产任务管理模块

生产任务管理模块负责接收生产计划，进行工艺分解，生成车间作业指令，跟踪任务执行情况。

**核心功能需求：**

- **生产任务接收**：从ERP系统接收生产订单、生产计划，或手工创建生产任务。任务信息包括产品型号、数量、交货期、优先级等。

- **工艺分解**：根据工艺路线，将生产任务分解为各工序的作业任务，生成工序作业计划。支持正向排程、逆向排程、有限能力排程。

- **工艺指令下发**：将工序作业任务、工艺卡片、图纸、NC程序等工艺指令下发至车间终端或MES系统。支持按设备、班组、人员分派任务。

- **任务进度跟踪**：实时跟踪各工序任务的开工、完工、报工情况。支持进度看板、甘特图展示。异常任务自动预警。

- **工艺现场服务**：支持工艺人员现场处理技术问题，记录现场工艺变更、工艺问题、改进建议。支持移动端拍照上传、语音录入。

- **任务完工确认**：工序完成后，进行完工确认，记录实际工时、实际材料消耗、质量检验结果等。支持与定额数据的对比分析。

### 4.9 报表与统计分析模块

报表与统计分析模块提供多维度、多层次的工艺数据统计分析功能，支撑管理决策。

**核心功能需求：**

- **工艺文件统计**：统计工艺文件编制数量、审批通过率、编制周期、变更频次等。支持按编制人、产品类型、时间段分析。

- **工艺定额统计**：统计工时定额、材料定额的制定情况、执行情况、偏差情况。支持定额趋势分析、定额对比分析。

- **工艺资源统计**：统计设备利用率、工装使用频次、焊材消耗量、刀具损耗率等。支持资源负荷分析、资源优化建议。

- **工艺质量统计**：统计一次交检合格率、返工返修率、废品率、质量事故次数等。支持按产品、车间、工序、时间段分析。

- **工艺效率统计**：统计工艺准备周期、工艺编制效率、工艺变更响应时间等。支持工艺效率趋势分析、标杆对比。

- **自定义报表**：提供报表设计器，支持用户自定义报表格式、数据源、筛选条件、统计维度、图表类型。支持报表定时生成、自动推送、导出打印。

### 4.10 系统管理模块

系统管理模块负责CAPP系统的基础配置、用户权限、日志审计、数据维护等管理工作。

**核心功能需求：**

- **组织架构管理**：管理企业的部门、车间、班组、岗位等组织架构信息。支持多级组织架构、组织调整历史记录。

- **用户账号管理**：管理系统用户账号，包括账号创建、启用/禁用、密码重置、密码策略配置、登录日志查询等。支持LDAP/AD域集成。

- **角色权限管理**：定义系统角色，配置角色功能权限和数据权限。支持角色继承、权限批量配置、权限审计。

- **数据字典管理**：管理系统使用的各类数据字典，包括产品类型、材料牌号、设备类型、工序类型、检验类型、计量单位等。支持字典项的增删改查、排序、启用/禁用。

- **编码规则管理**：配置工艺文件编号、工艺路线编号、BOM编号、变更单号等的编码规则。支持自动编码、编码唯一性校验。

- **流程配置管理**：配置工艺文件审批流程、变更审批流程、不合格品处理流程等。支持图形化流程设计、流程版本管理。

- **系统参数配置**：配置系统运行参数，如文件上传大小限制、会话超时时间、数据备份策略、邮件通知配置、企业微信集成配置等。

- **日志审计管理**：记录系统操作日志、登录日志、数据修改日志。支持日志查询、日志导出、日志归档。敏感操作实时告警。

- **数据备份与恢复**：支持数据库全量备份、增量备份、定时自动备份。支持数据恢复、数据迁移、历史数据归档。

### 4.11 外部系统集成接口

外部系统集成接口负责实现CAPP系统与周边系统的数据交换和业务协同。

**核心功能需求：**

- **PDM/PLM集成**：接收设计BOM、图纸、技术规范、设计变更通知。支持设计数据与工艺数据的关联映射。

- **ERP集成**：向ERP系统传递工艺BOM、工艺定额、工艺路线、物料需求计划。从ERP系统接收生产订单、库存信息、采购信息。

- **MES集成**：向MES系统下发工艺指令、作业计划、NC程序。从MES系统接收生产执行数据、设备状态数据、质量检测数据。

- **质量管理系统集成**：传递检验工艺、无损检测工艺、质量记录。接收不合格品信息、质量改进要求。

- **企业微信集成**：通过企业微信推送审批待办、任务通知、预警信息。支持企业微信单点登录、移动端审批。

- **数据交换平台**：提供标准WebService/REST API接口，支持JSON/XML数据格式。提供接口调用日志、接口异常告警、接口性能监控。

## 5. 非功能需求

### 5.1 性能需求

**（1）响应时间**
- 普通页面查询响应时间不超过2秒
- 复杂报表统计响应时间不超过10秒
- 工艺文件在线编辑保存响应时间不超过3秒
- 系统登录响应时间不超过1秒
- 批量数据导入（1万条记录）处理时间不超过5分钟

**（2）并发能力**
- 系统支持同时在线用户数不少于200人
- 支持并发操作用户数不少于100人
- 支持高峰期（月初/月末）并发访问量激增50%而不影响系统正常运行

**（3）数据处理能力**
- 支持单表数据量达到1000万条时查询性能不显著下降
- 支持日新增工艺数据记录不少于5000条
- 支持历史数据归档机制，确保在线数据库数据量可控

**（4）资源占用**
- 服务器CPU平均利用率不超过70%
- 服务器内存平均利用率不超过80%
- 数据库连接池配置合理，避免连接泄漏

### 5.2 安全需求

**（1）身份认证**
- 采用用户名+密码+验证码的多因素认证方式
- 支持强密码策略（长度≥8位，包含大小写字母、数字、特殊字符）
- 支持密码定期更换（默认90天）
- 支持登录失败锁定（连续5次失败锁定30分钟）
- 支持单点登录（SSO）与企业微信集成

**（2）访问控制**
- 基于RBAC（基于角色的访问控制）模型，实现功能权限和数据权限的双重控制
- 支持菜单级、按钮级、字段级的细粒度权限控制
- 支持数据行级权限控制（如只能查看本部门数据）
- 支持数据列级权限控制（如敏感字段脱敏显示）

**（3）数据安全**
- 敏感数据（密码、证书信息等）采用AES-256加密存储
- 数据传输采用HTTPS/TLS 1.2以上加密协议
- 数据库连接采用加密传输
- 重要操作（删除、修改）需二次确认
- 支持数据操作痕迹保留，确保数据可追溯

**（4）系统安全**
- 防范SQL注入攻击，所有数据库操作采用参数化查询
- 防范XSS跨站脚本攻击，对用户输入进行过滤和转义
- 防范CSRF跨站请求伪造，采用Token验证机制
- 防范文件上传漏洞，限制上传文件类型、大小，进行病毒扫描
- 定期进行安全漏洞扫描和渗透测试

### 6.2 权限模型设计

系统采用RBAC（Role-Based Access Control，基于角色的访问控制）模型，结合ACL（Access Control List，访问控制列表）实现细粒度权限管理。权限模型包含四个核心要素：

**（1）用户（User）**
系统的实际使用者，每个用户对应企业的一名员工。用户属性包括：用户ID、姓名、工号、部门、岗位、联系方式、账号状态等。

**（2）角色（Role）**
一组权限的集合，代表用户在组织中的职责身份。角色可以继承（如"工艺主管"继承"工艺工程师"的全部权限），减少权限配置工作量。

**（3）权限（Permission）**
系统功能操作和数据访问的许可。权限分为两类：
- **功能权限**：控制用户能否访问某个菜单、按钮、页面。如"工艺文件编制"、"工艺文件审批"、"工艺数据删除"等。
- **数据权限**：控制用户能查看和操作哪些数据。如"只能查看本部门工艺文件"、"只能修改自己编制的工艺文件"等。

**（4）资源（Resource）**
系统中需要被保护的对象，包括菜单、页面、按钮、数据记录、文件等。

权限分配流程：为角色分配权限 → 为用户分配角色 → 用户登录时加载权限 → 系统根据权限控制访问。

### 6.3 数据权限控制

数据权限控制确保用户只能访问其职责范围内的数据，防止数据越权访问和泄露。系统支持以下数据权限控制策略：

**（1）组织范围控制**
- 全部数据：可查看全公司数据（适用于公司领导、系统管理员）
- 本部门数据：只能查看本部门及下属部门数据（适用于部门管理人员）
- 本人数据：只能查看自己创建或负责的数据（适用于普通业务人员）

**（2）业务类型控制**
- 按产品类型控制：如某用户只能查看工业压缩机类产品的工艺数据
- 按工艺类别控制：如某用户只能查看焊接工艺相关数据
- 按项目控制：如某用户只能查看指定项目的工艺数据

**（3）字段级控制**
- 对敏感字段（如材料单价、工时定额、供应商信息）进行脱敏或隐藏处理
- 支持按角色配置字段可见性

**（4）特殊授权**
- 支持临时授权，如项目协作期间临时授予跨部门数据访问权限
- 支持数据共享，如将特定工艺文件共享给指定用户或角色

### 6.4 审批流程配置

系统支持图形化审批流程配置，主要审批流程包括：

**（1）工艺文件审批流程**
- 标准流程：编制 → 校对 → 审核 → 批准 → 发布
- 简化流程（简单工艺文件）：编制 → 审核 → 批准 → 发布
- 复杂流程（关键工艺文件）：编制 → 校对 → 审核 → 工艺会签 → 标准化审查 → 批准 → 发布

**（2）工艺变更审批流程**
- 一般变更：申请 → 部门审核 → 批准 → 实施
- 重大变更：申请 → 技术评审 → 部门审核 → 总工程师批准 → 实施 → 验证

**（3）工艺定额审批流程**
- 编制 → 审核 → 批准 → 发布

**（4）不合格品处理流程**
- 发现 → 隔离 → 评审 → 处置（返工/返修/让步接收/报废） → 验证

审批流程支持以下配置项：
- 审批节点：可配置多个审批节点，每个节点指定审批人（固定人员、角色、部门负责人、上级领导等）
- 审批方式：支持或签（一人通过即可）、会签（全部通过才算通过）、依次审批
- 审批条件：支持根据业务数据设置审批路径分支（如金额大于10万需总经理审批）
- 审批操作：支持通过、驳回、转办、加签、退回上一步、退回发起人
- 审批通知：支持邮件通知、企业微信通知、系统消息通知
- 审批时限：支持设置审批时限，超期自动提醒或升级
