## 1. 部署概述

### 1.1 部署架构原则

| 原则 | 说明 | 具体措施 |
|:---|:---|:---|
| **高可用** | 消除单点故障，确保系统7x24小时可用 | 主从复制、负载均衡、故障自动切换 |
| **可扩展** | 支持业务增长时的水平扩展 | 微服务拆分、容器化部署、弹性伸缩 |
| **易维护** | 降低运维复杂度，提升故障处理效率 | 自动化运维、标准化部署、完善的监控告警 |
| **安全性** | 保障数据和应用安全 | 网络隔离、加密传输、访问控制 |
| **可恢复** | 确保灾难发生时快速恢复 | 多层级备份、灾难恢复演练 |

### 3.2 Web服务器：Nginx 1.24

**安装要点**：

```bash
# 添加Nginx官方源
cat > /etc/yum.repos.d/nginx.repo << 'EOF'
[nginx-stable]
name=nginx stable repo
baseurl=http://nginx.org/packages/centos/$releasever/$basearch/
gpgcheck=1
enabled=1
gpgkey=https://nginx.org/keys/nginx_signing.key
EOF

# 安装Nginx
yum install -y nginx-1.24.0

# 验证安装
nginx -v
```

**核心配置**：

```nginx
# /etc/nginx/nginx.conf
user nginx;
worker_processes auto;
worker_rlimit_nofile 65535;
error_log /var/log/nginx/error.log warn;
pid /var/run/nginx.pid;

events {
    worker_connections 65535;
    use epoll;
    multi_accept on;
}

http {
    include /etc/nginx/mime.types;
    default_type application/octet-stream;

    log_format main '$remote_addr - $remote_user [$time_local] "$request" '
                    '$status $body_bytes_sent "$http_referer" '
                    '"$http_user_agent" "$http_x_forwarded_for" '
                    '$request_time $upstream_response_time';

    access_log /var/log/nginx/access.log main;

    sendfile on;
    tcp_nopush on;
    tcp_nodelay on;
    keepalive_timeout 65;
    types_hash_max_size 2048;

    # Gzip压缩
    gzip on;
    gzip_vary on;
    gzip_proxied any;
    gzip_comp_level 6;
    gzip_types text/plain text/css text/xml application/json application/javascript application/xml+rss application/rss+xml font/truetype font/opentype application/vnd.ms-fontobject image/svg+xml;

    # 负载均衡配置
    upstream capp_backend {
        least_conn;
        server 203.0.113.10:9000 weight=5;
        server 203.0.113.10:9000 weight=5;
        server 203.0.113.10:9000 weight=5;
        keepalive 300;
    }

    # 限流配置
    limit_req_zone $binary_remote_addr zone=api_limit:10m rate=10r/s;
    limit_req_zone $binary_remote_addr zone=login_limit:10m rate=5r/m;

    include /etc/nginx/conf.d/*.conf;
}
```

    --quick \

    --master-data=2 \

    echo "全量备份成功: $BACKUP_FILE"

else
    echo "全量备份失败"

### 9.4 证书管理

```bash
#!/bin/bash
# /opt/scripts/check-ssl.sh
# SSL证书检查脚本

DOMAINS=("capp.company.com" "api.capp.company.com" "maxkb.capp.company.com")
ALERT_DAYS=30

for domain in "${DOMAINS[@]}"; do
    expiry_date=$(echo | openssl s_client -servername $domain -connect $domain:443 2>/dev/null | openssl x509 -noout -enddate | cut -d= -f2)
    expiry_epoch=$(date -d "$expiry_date" +%s)
    current_epoch=$(date +%s)
    days_left=$(( (expiry_epoch - current_epoch) / 86400 ))

    if [ $days_left -le $ALERT_DAYS ]; then
        echo "WARNING: $domain SSL证书将在 $days_left 天后过期"
        # 发送告警通知
    fi
done
```

**证书续期流程**：
1. 监控脚本检测到证书即将过期（<30天）
2. 发送告警通知运维人员
3. 使用Let's Encrypt或商业CA续期
4. 更新Nginx证书配置
5. 重载Nginx服务
6. 验证证书有效性
