## 1. 工艺路线管理模块

### 1.1 模块概述

工艺路线管理模块是CAPP系统的核心模块，用于定义和管理产品从原材料到成品的完整加工路径。针对工业压缩机（膜片、缸体、曲轴、阀组等关键部件）和压力容器（筒体、封头、法兰、接管等）的多品种、小批量、高精度制造特点，提供灵活的工艺路线编制、版本控制和审批管理功能。

### 1.2 功能清单

| 功能编号 | 功能名称 | 功能说明 | 优先级 |
|---------|---------|---------|--------|
| PR-001 | 工艺路线创建 | 基于产品/零部件新建工艺路线 | 高 |
| PR-002 | 工艺路线编辑 | 修改已有工艺路线的工序内容 | 高 |
| PR-003 | 工艺路线查看 | 查看工艺路线详情及历史版本 | 高 |
| PR-004 | 版本管理 | 工艺路线版本创建、切换、对比 | 高 |
| PR-005 | 工序定义 | 定义工序基本信息及加工要求 | 高 |
| PR-006 | 工序编排 | 调整工序顺序、设置并行/分支 | 高 |
| PR-007 | 工艺路线模板 | 标准工艺路线库及复用 | 中 |
| PR-008 | 审批流程 | 工艺路线编制→校对→审核→批准 | 高 |

### 1.5 关键逻辑说明

#### 1.5.1 工序编号规则

```
格式：{工艺路线编号}-{工序序号}
示例：PR-2024-001-010（第10道工序）

序号间隔：10，便于中间插入新工序
并行工序：010A、010B、010C
分支工序：020-1（分支1）、020-2（分支2）
```

#### 1.5.2 版本号规则

```
格式：V{主版本号}.{次版本号}.{修订号}
初始版本：V1.0.0
重大变更：主版本号+1（V2.0.0）
一般变更：次版本号+1（V1.1.0）
修订错误：修订号+1（V1.0.1）
```

#### 1.5.3 状态流转

```
草稿 → 校对中 → 审核中 → 批准中 → 已发布 → 已归档
  ↑      ↓         ↓         ↓
  └────退回────退回────退回
```

#### 1.5.4 并行工序处理逻辑

- 并行工序组内所有工序完成后，才能进入下一道工序
- 系统记录每道工序的计划开始/结束时间和实际开始/结束时间
- 并行工序组的计划周期 = MAX(组内各工序计划周期)

## 2. 工艺卡片管理模块

### 2.1 模块概述

工艺卡片管理模块用于创建、管理和输出各类工艺卡片，包括加工工序卡、检验工序卡和辅助工序卡。针对工业压缩机和压力容器的特殊工艺要求（如膜片的热处理、缸体的精密加工、压力容器的焊接工艺等），提供标准化的卡片模板和灵活的自定义能力。

### 2.2 功能清单

| 功能编号 | 功能名称 | 功能说明 | 优先级 |
|---------|---------|---------|--------|
| PC-001 | 加工工序卡 | 机械加工工序的详细工艺卡片 | 高 |
| PC-002 | 检验工序卡 | 质量检验工序的检测卡片 | 高 |
| PC-003 | 辅助工序卡 | 热处理、清洗、包装等辅助工序卡片 | 中 |
| PC-004 | 工步卡片 | 工序内各工步的详细参数卡片 | 高 |
| PC-005 | 模板管理 | 工艺卡片模板的设计与管理 | 中 |
| PC-006 | 打印输出 | 工艺卡片的打印和PDF导出 | 高 |

### 2.5 关键逻辑说明

#### 2.5.1 卡片类型与适用场景

| 卡片类型 | 适用工序 | 特殊要求 |
|---------|---------|---------|

- **A4纵向**：适用于简单工序（工步数<=5）

## 3. BOM管理模块

### 3.1 模块概述

BOM管理模块实现从设计BOM（EBOM）到工艺BOM（PBOM）再到制造BOM（MBOM）的转换管理。针对工业压缩机和压力容器的特点，支持从CAXA PLM系统同步EBOM数据，按工艺路线重构生成PBOM，并按生产单元拆分生成MBOM，同时提供BOM对比和版本管理功能。

### 3.2 功能清单

| 功能编号 | 功能名称 | 功能说明 | 优先级 |
|---------|---------|---------|--------|
| BM-001 | EBOM接收 | 从CAXA PLM同步设计BOM | 高 |
| BM-002 | PBOM转换 | 按工艺路线重构BOM结构 | 高 |
| BM-003 | MBOM生成 | 按生产单元拆分制造BOM | 高 |
| BM-004 | BOM对比 | 不同版本BOM的差异分析 | 中 |
| BM-005 | BOM版本 | BOM版本管理与追溯 | 高 |
| BM-006 | BOM可视化 | 树形/层级结构展示 | 中 |

#### 3.5.3 BOM差异对比算法

```php
function compareBOM($bom_a, $bom_b, $path = '') {
    $diff = [];
    
    // 对比当前层级节点
    foreach ($bom_a as $node_a) {
        $node_b = findNodeById($bom_b, $node_a['material_id']);
        if (!$node_b) {
            $diff[] = ['type' => 'deleted', 'path' => $path, 'node' => $node_a];
        } else {
            // 对比属性
            $attr_diff = compareAttributes($node_a, $node_b);
            if (!empty($attr_diff)) {
                $diff[] = ['type' => 'modified', 'path' => $path, 'diff' => $attr_diff];
            }
            // 递归对比子节点
            if (!empty($node_a['children']) || !empty($node_b['children'])) {
                $child_diff = compareBOM(
                    $node_a['children'] ?? [], 
                    $node_b['children'] ?? [], 
                    $path . '/' . $node_a['material_id']
                );
                $diff = array_merge($diff, $child_diff);
            }
        }
    }
    
    // 检查新增节点
    foreach ($bom_b as $node_b) {
        if (!findNodeById($bom_a, $node_b['material_id'])) {
            $diff[] = ['type' => 'added', 'path' => $path, 'node' => $node_b];
        }
    }
    
    return $diff;
}
```

```php
    ];
}
```

```php
// 单件工时定额计算
function calculateUnitTime($elements) {
    $prepare_time = $elements['prepare_time']; // 准备终结时间
    $process_time = $elements['process_time']; // 作业时间
    $aux_time = $elements['aux_time'];         // 辅助时间
    $allowance_rate = $elements['allowance_rate']; // 宽放率(%)
    
    // 作业时间 = 基本时间 + 辅助时间
    $operation_time = $process_time + $aux_time;
    
    // 宽放时间 = 作业时间 × 宽放率
    $allowance_time = $operation_time * ($allowance_rate / 100);
    
    // 单件时间 = 作业时间 + 宽放时间
    $unit_time = $operation_time + $allowance_time;
    
    // 批量工时 = 准备时间 + (单件时间 × 批量数)
    $batch_size = $elements['batch_size'];
    $batch_time = $prepare_time + ($unit_time * $batch_size);
    
    return [
        'unit_time' => round($unit_time, 2),
        'batch_time' => round($batch_time, 2),
        'prepare_time' => $prepare_time,
        'operation_time' => $operation_time,
        'allowance_time' => round($allowance_time, 2)
    ];
}
```

```php
function judgeInspection($record) {
    $standard = $record['standard'];
    $value = $record['measured_value'];
    $method = $standard['judgment_method']; // 'range', 'max', 'min', 'boolean'
    
    $result = 'pass';
    $detail = '';
    
    switch ($method) {
        case 'range':
            if ($value < $standard['min_value'] || $value > $standard['max_value']) {
                $result = 'fail';
                $detail = "实测值 {$value} 超出范围 [{$standard['min_value']}, {$standard['max_value']}]";
            }
            break;
        case 'max':
            if ($value > $standard['max_value']) {
                $result = 'fail';
                $detail = "实测值 {$value} 超过最大值 {$standard['max_value']}";
            }
            break;
        case 'min':
            if ($value < $standard['min_value']) {
                $result = 'fail';
                $detail = "实测值 {$value} 低于最小值 {$standard['min_value']}";
            }
            break;
        case 'boolean':
            if ($value != $standard['expected_value']) {
                $result = 'fail';
                $detail = "判定结果不符合要求";
            }
            break;
    }
    
    return ['result' => $result, 'detail' => $detail];
}
```

#### 10.5.3 流程引擎核心逻辑

```php
class WorkflowEngine {
    // 启动流程实例
    public function startInstance($definition_id, $business_data) {
        $instance = $this->createInstance($definition_id, $business_data);
        $start_node = $this->getStartNode($definition_id);
        $this->enterNode($instance, $start_node);
        return $instance;
    }
    
    // 处理审批任务
    public function handleTask($task_id, $action, $comment, $user_id) {
        $task = $this->getTask($task_id);
        $instance = $this->getInstance($task['instance_id']);
        
        // 记录审批历史
        $this->recordHistory($task, $action, $comment, $user_id);
        
        if ($action == 'approve') {
            // 检查是否满足节点通过条件
            if ($this->checkNodeComplete($task['node_id'])) {
                $next_nodes = $this->getNextNodes($task['node_id'], 'approve');
                foreach ($next_nodes as $node) {
                    $this->enterNode($instance, $node);
                }
            }
        } elseif ($action == 'reject') {
            // 退回处理
            $back_node = $this->getBackNode($task['node_id']);
            $this->enterNode($instance, $back_node);
        }
        
        // 更新任务状态
        $this->updateTaskStatus($task_id, $action);
    }
    
    // 进入节点
    private function enterNode($instance, $node) {
        if ($node['type'] == 'approval') {
            // 创建审批任务
            $assignees = $this->resolveAssignees($node);
            foreach ($assignees as $assignee) {
                $this->createTask($instance, $node, $assignee);
            }
        } elseif ($node['type'] == 'auto') {
            // 执行自动节点
            $this->executeAutoNode($node);
            $next_nodes = $this->getNextNodes($node['id']);
            foreach ($next_nodes as $next) {
                $this->enterNode($instance, $next);
            }
        } elseif ($node['type'] == 'end') {
            // 结束流程
            $this->completeInstance($instance);
        }
    }
}
```

```php
                'similarity' => $ref['similarity'],
                'source_url' => generateSourceUrl($ref['document_id'])
            ];
        }
    }
    
    // 计算置信度
    if (!empty($result['references'])) {
        $similarities = array_column($result['references'], 'similarity');
        $result['confidence'] = round(array_sum($similarities) / count($similarities) * 100, 2);
    }
    
    return $result;
}

// 生成引用来源链接
function generateSourceUrl($doc_id) {
    // 查询文档在CAPP中的对应记录
    $mapping = getMaxKBMappping($doc_id);
    if ($mapping) {
        return '/document/preview.php?id=' . $mapping['capp_doc_id'];
    }
    return null;
}
```
