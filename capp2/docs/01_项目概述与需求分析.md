## 1. 项目概述

### 1.1 项目背景

工业压缩机与压力容器属于特种设备制造领域，产品具有多品种、小批量、定制化程度高的特点。工艺设计作为连接产品设计与生产制造的核心环节，直接决定了产品质量、生产效率和制造成本。当前企业工艺管理仍以传统手工方式为主，工艺数据分散、版本控制困难、知识沉淀不足，已无法满足企业数字化转型和智能制造的发展需求。

为提升工艺设计效率、规范工艺数据管理、实现工艺知识积累与复用，企业决定建设一套覆盖工艺全生命周期的计算机辅助工艺规划（CAPP）系统，并与企业现有信息系统（CAXA PLM、U8 ERP、MES）及MaxKB专业版知识库/智能体系统进行深度集成，构建完整的数字化工艺管理体系。

### 1.2 项目目标

#### 1.2.1 总体目标

建设一套面向工业压缩机与压力容器制造行业的CAPP系统，实现工艺设计的标准化、数字化、智能化，提升工艺设计效率30%以上，工艺数据准确率达到99%以上，形成可复用的企业工艺知识资产。

#### 1.2.2 具体目标

| 目标维度 | 具体指标 | 目标值 |
|----------|----------|--------|
| 效率提升 | 工艺设计周期缩短 | >= 30% |
| 数据质量 | 工艺数据准确率 | >= 99% |
| 知识复用 | 标准工艺覆盖率 | >= 60% |
| 系统集成 | 与PLM/ERP/MES数据互通 | 100% |
| 知识管理 | 工艺知识库文档覆盖率 | >= 80% |
| 智能化 | AI辅助工艺设计覆盖率 | >= 40% |

## 2. 企业现状分析

### 2.1 企业产品特点

#### 2.1.1 工业压缩机产品特点

工业压缩机是一种借助膜片在液压油的推动下往复运动，使气体在膜片与缸盖之间形成的腔体内被压缩的特殊容积式压缩机。主要应用于高纯度、易燃易爆、有毒有害、稀有贵重气体的压缩输送。

| 特点维度 | 具体描述 |
|----------|----------|
| 结构复杂 | 由曲轴箱、液压系统、膜头组、冷却系统、控制系统等组成，零部件数量多 |
| 精度要求高 | 膜片厚度公差、缸盖型线精度、配合间隙要求严格 |
| 材料特殊 | 膜片采用特殊合金材料，缸体采用高强度不锈钢或合金钢 |
| 定制化程度高 | 根据介质特性、压力参数、流量需求进行定制化设计 |
| 安全等级高 | 属于特种设备，需符合《特种设备安全法》及相关标准 |

#### 2.1.2 压力容器产品特点

企业生产的压力容器涵盖I类、II类、III类压力容器，包括储罐、换热器、反应釜、分离器等。

| 特点维度 | 具体描述 |
|----------|----------|
| 法规约束强 | 设计、制造需符合GB/T 150、ASME VIII等标准及《固定式压力容器安全技术监察规程》 |
| 焊接工艺复杂 | 涉及多种焊接方法（SMAW、GTAW、GMAW、SAW等），焊工需持证上岗 |
| 检测要求严格 | 需进行RT（射线检测）、UT（超声检测）、MT（磁粉检测）、PT（渗透检测）等无损检测 |
| 热处理工艺关键 | 焊后热处理（PWHT）对消除焊接残余应力、恢复材料性能至关重要 |
| 质量追溯要求高 | 需建立完整的质量追溯档案，实现材料、焊接、检测全过程追溯 |

### 2.2 工艺特点分析

#### 2.2.1 焊接工艺

焊接是工业压缩机和压力容器制造的核心工艺，直接决定产品的密封性能和结构强度。

| 工艺要素 | 具体内容 |
|----------|----------|
| 焊接方法 | 手工电弧焊（SMAW）、钨极氩弧焊（GTAW）、熔化极气体保护焊（GMAW）、埋弧焊（SAW）、等离子弧焊（PAW） |
| 焊接材料 | 焊条、焊丝、焊剂、保护气体（氩气、二氧化碳、混合气体） |
| 焊接参数 | 电流、电压、焊接速度、热输入、层间温度、预热温度 |
| 工艺评定 | 按NB/T 47014进行焊接工艺评定（WPS/PQR） |
| 焊工资质 | 按TSG Z6002进行焊工考试，持证项目需覆盖产品焊接方法 |
| 特殊要求 | 工业压缩机膜片焊接需采用特殊工艺，控制热影响区 |

#### 2.2.2 机加工工艺

机加工是保证零部件尺寸精度和形位公差的关键工艺。

| 工艺要素 | 具体内容 |
|----------|----------|
| 加工设备 | 数控车床、数控铣床、加工中心、磨床、线切割、电火花 |
| 关键工序 | 缸体镗孔、曲轴磨削、膜片型线加工、密封面研磨 |
| 精度要求 | 关键配合尺寸公差等级IT6-IT7，表面粗糙度Ra0.8-Ra1.6 |
| 工艺装备 | 专用夹具、精密量具、在线检测装置 |
| 材料特性 | 不锈钢、合金钢加工需考虑切削参数优化、刀具选择 |

#### 2.2.3 装配工艺

装配是将零部件组装成完整产品的过程，对工业压缩机尤为关键。

| 工艺要素 | 具体内容 |
|----------|----------|
| 装配顺序 | 部件预装（曲轴箱组件、膜头组件）→总装→调试 |
| 关键控制点 | 膜片安装预紧力、缸盖与膜腔同轴度、液压系统密封性 |
| 装配工具 | 扭矩扳手、液压拉伸器、专用装配工装 |
| 清洁度要求 | 气体接触表面需达到特定清洁度等级 |
| 试运行 | 空载试运行、负载试运行、性能测试 |

#### 2.2.4 检测工艺

检测工艺贯穿产品制造全过程，确保产品符合设计要求和标准规范。

| 检测类型 | 检测内容 | 适用标准 |
|----------|----------|----------|
| 原材料检验 | 化学成分、力学性能、金相组织、超声波探伤 | GB/T 150、材料标准 |
| 焊接检验 | 外观检查、尺寸检查、无损检测（RT/UT/MT/PT） | NB/T 47013 |
| 热处理检验 | 硬度测试、金相检验、力学性能复验 | 工艺文件 |
| 压力试验 | 液压试验、气压试验、气密性试验 | GB/T 150、设计文件 |
| 最终检验 | 外观、尺寸、性能、清洁度、包装 | 产品标准 |
| 型式试验 | 排气量、排气压力、轴功率、振动、噪声 | JB/T 6905 |

## 3. 业务需求分析

### 3.1 工艺路线管理

#### 3.1.1 业务流程

```
产品设计完成 → 接收EBOM → 工艺路线规划 → 工序编排 → 工艺路线审核 → 工艺路线发布 → 下发MES
```

#### 3.1.2 功能需求

| 功能编号 | 功能名称 | 功能描述 |
|----------|----------|----------|
| R-001 | 工艺路线创建 | 基于产品型号创建工艺路线，支持复制已有工艺路线进行修改 |
| R-002 | 工序编排 | 定义工序顺序、工序内容、工序属性（关键工序/一般工序） |
| R-003 | 工艺路线版本管理 | 支持工艺路线版本创建、版本对比、版本回滚 |
| R-004 | 工艺路线审核 | 工艺路线提交审核，支持多级审批流程 |
| R-005 | 工艺路线发布 | 审核通过后发布，发布后锁定，变更需走变更流程 |
| R-006 | 工艺路线查询 | 按产品型号、状态、版本等条件查询工艺路线 |
| R-007 | 工艺路线模板 | 建立标准工艺路线模板，支持相似产品快速引用 |

#### 3.1.3 业务规则

- 工艺路线必须包含至少一道工序
- 关键工序必须关联质量控制点
- 已发布的工艺路线变更必须走变更审批流程
- 工艺路线版本号采用V1.0、V1.1、V2.0格式

### 3.2 工艺卡片管理

#### 3.2.1 业务流程

```
工艺路线确定 → 工序卡片编制 → 工步卡片编制 → 工艺参数填写 → 工艺卡片审核 → 工艺卡片发布
```

#### 3.2.2 功能需求

| 功能编号 | 功能名称 | 功能描述 |
|----------|----------|----------|
| R-008 | 工序卡片编制 | 按工序编制工序卡片，包含工序名称、设备、工装、工时等 |
| R-009 | 工步卡片编制 | 在工序卡片下编制工步，定义工步内容、加工参数、技术要求 |
| R-010 | 工艺参数管理 | 管理焊接参数、机加工参数、装配参数等，支持参数推荐 |
| R-011 | 工艺卡片模板 | 建立各类工艺卡片模板（焊接工艺卡、机加工工艺卡、装配工艺卡等） |
| R-012 | 工艺卡片打印 | 支持按标准格式打印工艺卡片，输出PDF |
| R-013 | 工艺卡片版本管理 | 工艺卡片与工艺路线版本联动管理 |

#### 3.2.3 工艺卡片类型

| 卡片类型 | 适用工序 | 主要内容 |
|----------|----------|----------|
| 焊接工艺卡 | 焊接工序 | 焊接方法、焊接材料、焊接参数、预热/层间温度、焊后热处理 |
| 机加工工艺卡 | 机加工工序 | 设备型号、刀具/夹具、切削参数、加工尺寸、公差要求 |
| 装配工艺卡 | 装配工序 | 装配顺序、装配工具、预紧力矩、间隙要求、检测要求 |
| 检测工艺卡 | 检测工序 | 检测项目、检测方法、检测标准、判定准则、记录要求 |
| 热处理工艺卡 | 热处理工序 | 热处理工艺、加热/保温/冷却参数、硬度要求 |

### 3.3 BOM管理

#### 3.3.1 业务流程

```
接收EBOM（PLM） → EBOM校验 → PBOM转换（工艺视角） → MBOM转换（制造视角） → BOM发布 → 同步ERP/MES
```

#### 3.3.2 功能需求

| 功能编号 | 功能名称 | 功能描述 |
|----------|----------|----------|
| R-014 | EBOM接收 | 从CAXA PLM系统接收EBOM数据，支持手动导入和自动同步 |
| R-015 | EBOM校验 | 校验EBOM完整性，检查物料编码、数量、单位等 |
| R-016 | PBOM转换 | 将EBOM转换为工艺BOM，增加工艺路线信息、工序物料分配 |
| R-017 | MBOM转换 | 将PBOM转换为制造BOM，增加工艺辅料、工装夹具、虚拟件处理 |
| R-018 | BOM对比 | 支持EBOM/PBOM/MBOM三态对比，高亮差异项 |
| R-019 | BOM版本管理 | BOM版本与工艺路线版本关联管理 |
| R-020 | BOM变更管理 | BOM变更与工艺变更联动，自动触发相关流程 |
| R-021 | BOM同步 | 将MBOM同步至U8 ERP和MES系统 |

#### 3.3.3 BOM转换规则

| 转换类型 | 转换内容 | 处理规则 |
|----------|----------|----------|
| EBOM→PBOM | 增加工艺信息 | 按工艺路线分配物料到工序，增加工艺辅料 |
| EBOM→PBOM | 虚拟件处理 | 虚拟件展开为子件，不保留虚拟件层级 |
| PBOM→MBOM | 增加制造信息 | 增加工装夹具、刀具、量具等制造资源 |
| PBOM→MBOM | 工艺合件处理 | 工艺合件拆分为单个零件，或保留合件作为整体 |
| PBOM→MBOM | 外协件标识 | 标识外协加工件，关联外协供应商信息 |

#### 3.4.1 功能需求

#### 3.5.2 定额计算规则

| 材料类型 | 定额组成 | 计算公式 |
|----------|----------|----------|
| 板材 | 净重 + 切割损耗 + 加工余量 | 定额 = 净重 / (1 - 切割损耗率) + 加工余量 |
| 管材 | 净重 + 切割损耗 + 焊接坡口损耗 | 定额 = 净重 / (1 - 切割损耗率) + 坡口损耗 |
| 棒材 | 净重 + 下料损耗 + 加工余量 | 定额 = 净重 / (1 - 下料损耗率) + 加工余量 |
| 焊材 | 焊缝金属量 + 飞溅损耗 + 焊条头损耗 | 定额 = 焊缝金属量 / (1 - 损耗率) |
