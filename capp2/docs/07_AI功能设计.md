## 1. AI功能概述

### 1.1 AI在CAPP系统中的定位与价值

在工业压缩机与压力容器制造企业中，工艺规划（CAPP）是连接产品设计与生产制造的核心环节。传统CAPP系统依赖工艺人员的经验和知识积累，存在知识传承困难、决策效率低、工艺质量波动大等问题。AI技术的引入旨在解决以下核心痛点：

| 痛点 | AI解决方案 | 预期价值 |
|------|-----------|---------|
| 工艺专家经验难以沉淀 | 知识图谱+知识库 | 实现工艺知识的结构化存储与复用 |
| 工艺参数选择依赖个人经验 | AI决策引擎 | 基于数据智能推荐最优参数，减少人为偏差 |
| 工艺编制效率低 | AI助手辅助编制 | 自动生成工艺路线草稿，效率提升60%+ |
| 质量问题追溯困难 | 异常诊断助手 | 基于知识库快速定位问题根因 |
| 标准规范查询繁琐 | 智能问答 | 自然语言查询标准，秒级响应 |
| 新员工培训周期长 | 知识库+AI助手 | 降低知识获取门槛，缩短培养周期 |

**AI在CAPP系统中的三层定位**：

- **决策层（AI决策引擎）**：面向工艺规划的核心决策场景，提供参数推荐、方案优选、材料选择、设备匹配等智能决策能力
- **交互层（AI助手）**：面向工艺人员的日常辅助，提供问答、编制辅助、标准查询、异常诊断等交互式服务
- **知识层（知识库+MaxKB）**：面向全系统的知识支撑，提供结构化工艺知识、标准规范、历史数据的统一管理与检索

### 1.3 技术选型

#### 1.3.1 大语言模型（LLM）

| 模型类型 | 推荐方案 | 适用场景 | 部署方式 |
|---------|---------|---------|---------|
| 主模型 | Qwen2.5-72B / DeepSeek-V3 | 复杂工艺决策、多轮对话 | 本地私有化部署 |
| 轻量模型 | Qwen2.5-14B / ChatGLM3-6B | 简单问答、意图识别 | 本地部署 |
| Embedding模型 | BGE-M3 / bge-large-zh-v1.5 | 文本向量化、语义检索 | 本地部署 |
| 代码/结构化 | DeepSeek-Coder | 工艺参数结构化输出 | 本地部署 |

**选型原则**：
- 优先支持私有化部署，确保工艺数据不出域
- 中文工艺领域理解能力强
- 支持长上下文（工艺文档通常较长）
- 支持Function Calling，便于与系统功能集成

## 2. AI决策引擎

### 2.1 功能概述

AI决策引擎是CAPP系统的核心智能组件，基于产品特征、工艺约束和历史数据，为工艺人员提供智能化的工艺决策支持。引擎采用"知识驱动+数据驱动"的双轮驱动模式，结合知识图谱的结构化知识和RAG的检索增强能力，实现可解释、可信赖的工艺决策。

```python
    def evaluate(self, decision_result, context):
        scores = {
            # 知识支撑度：检索到的相关知识与决策的匹配程度
            'knowledge_support': self.eval_knowledge_support(),
            # 历史案例相似度：与历史成功案例的相似程度
            'case_similarity': self.eval_case_similarity(),
            # 参数合理性：参数是否在标准允许范围内
            'parameter_validity': self.eval_parameter_validity(),
            # 约束满足度：是否满足所有工艺约束
            'constraint_satisfaction': self.eval_constraint_satisfaction(),
            # 模型确定性：LLM输出的概率分布集中度
            'model_certainty': self.eval_model_certainty()
        }
        
        # 加权综合
        final_score = weighted_sum(scores)
        
        # 分级
        if final_score >= 0.85:
            level = 'HIGH'      # 可直接采用
        elif final_score >= 0.65:
            level = 'MEDIUM'    # 建议复核
        else:
            level = 'LOW'       # 必须人工审核
            
        return {'score': final_score, 'level': level, 'details': scores}
```

```python
        )
        
        # 4. LLM推理
        raw_response = self.llm.generate(prompt)
        
        # 5. 结果解析
        structured_result = self._parse_json_response(raw_response)
        
        # 6. 置信度评估
        confidence = self._evaluate_confidence(
            structured_result,

        )
        
        # 7. 组装响应
        return {
            'recommended_parameters': structured_result['parameters'],

        }

        """多路检索"""
        # 向量检索
        vector_results = self.vector_store.search(
            embedding=self.embedding_model.encode(query_features['query_text']),

            cypher=self._build_kg_query(query_features)
        )
        # 结构化数据查询
        sql_results = self._query_structured_data(query_features)
        
        # 融合重排序
        return self._fusion_rerank(vector_results, kg_results, sql_results)
```

```python
    def get_context_window(self, max_tokens: int = 4000):
        """获取上下文窗口（控制token数）"""

            if total_tokens + msg_tokens > max_tokens:
                break
            context.insert(0, msg)
            total_tokens += msg_tokens
        return context
```

#### 3.4.3 知识检索与生成（RAG流程）

```python
class RAGPipeline:
    def __init__(self):
        self.retriever = KnowledgeRetriever()
        self.reranker = CrossEncoderReranker()
        self.generator = LLMGenerator()
    
    def process(self, query: str, intent: str, context: dict) -> str:
        # 1. 查询改写（根据意图优化查询）
        rewritten_query = self._rewrite_query(query, intent)
        
        # 2. 多路检索
        candidates = self.retriever.retrieve(
            query=rewritten_query,
            intent=intent,
            filters=self._build_filters(context)
        )
        
        # 3. 重排序
        ranked = self.reranker.rerank(query, candidates)
        
        # 4. 上下文组装
        context_text = self._build_context(ranked[:5])
        
        # 5. 生成回答
        answer = self.generator.generate(
            query=query,
            context=context_text,
            intent=intent,
            conversation_history=context.get('messages', [])
        )
        
        return answer
```

```php
<?php
// lib/MaxKBClient.php

class MaxKBClient {
    private $baseUrl;
    private $apiKey;
    private $timeout;
    
    public function __construct() {
        $this->baseUrl = Config::get('maxkb.url');
        $this->apiKey = YOUR_SECRET'maxkb.api_key');
        $this->timeout = Config::get('maxkb.timeout', 30);
    }
    
    /**
     * 知识检索
     */
    public function searchKnowledge(string $query, array $options = []): array {
        $datasetId = $options['dataset_id'] ?? null;
        $topK = $options['top_k'] ?? 5;
        $threshold = $options['similarity_threshold'] ?? 0.7;
        
        $response = $this->request('POST', "/api/dataset/{$datasetId}/hit_test", [
            'query_text' => $query,
            'top_number' => $topK,
            'similarity' => $threshold,
            'search_mode' => $options['search_mode'] ?? 'embedding'
        ]);
        
        return $response['data'] ?? [];
    }
    
    /**
     * 创建文档
     */
    public function createDocument(string $datasetId, string $title, 
                                    string $content, array $meta = []): array {
        return $this->request('POST', '/api/document', [
            'dataset_id' => $datasetId,
            'title' => $title,
            'content' => $content,
            'meta' => $meta
        ]);
    }
    
    /**
     * 更新文档
     */
    public function updateDocument(string $docId, array $data): array {
        return $this->request('PUT', "/api/document/{$docId}", $data);
    }
    
    /**
     * 删除文档
     */
    public function deleteDocument(string $docId): bool {
        $response = $this->request('DELETE', "/api/document/{$docId}");
        return $response['success'] ?? false;
    }
    
    /**
     * 获取知识库列表
     */
    public function listDatasets(): array {
        $response = $this->request('GET', '/api/dataset');
        return $response['data'] ?? [];
    }
    
    private function request(string $method, string $endpoint, array $data = []): array {
        $url = rtrim($this->baseUrl, '/') . $endpoint;
        
        $ch = curl_init();
        curl_setopt($ch, CURLOPT_URL, $url);
        curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
        curl_setopt($ch, CURLOPT_TIMEOUT, $this->timeout);
        curl_setopt($ch, CURLOPT_HTTPHEADER, [
            'Content-Type: application/json',
            'Authorization: Bearer ' . $this->apiKey
        ]);
        
        if ($method === 'POST') {
            curl_setopt($ch, CURLOPT_POST, true);
            curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data));
        } elseif ($method === 'PUT') {
            curl_setopt($ch, CURLOPT_CUSTOMREQUEST, 'PUT');
            curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data));
        } elseif ($method === 'DELETE') {
            curl_setopt($ch, CURLOPT_CUSTOMREQUEST, 'DELETE');
        }
        
        $response = curl_exec($ch);
        $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
        curl_close($ch);
        
        if ($httpCode >= 200 && $httpCode < 300) {
            return json_decode($response, true);
        }
        
        throw new MaxKBException("MaxKB请求失败: HTTP {$httpCode}, 响应: {$response}");
    }
}
```

#### 4.5.2 文档同步服务

```php
<?php
// services/MaxKBSyncService.php

class MaxKBSyncService {
    private $maxkb;
    private $db;
    
    public function __construct() {
        $this->maxkb = new MaxKBClient();
        $this->db = DB::getInstance();
    }
    
    /**
     * 执行全量同步
     */
    public function fullSync(): array {
        $stats = ['created' => 0, 'updated' => 0, 'failed' => 0];
        
        // 获取所有待同步文档
        $docs = $this->db->query("SELECT * FROM documents WHERE status = 1");
        
        foreach ($docs as $doc) {
            try {
                $result = $this->syncDocument($doc);
                if ($result['action'] === 'create') {
                    $stats['created']++;
                } else {
                    $stats['updated']++;
                }
            } catch (Exception $e) {
                $stats['failed']++;
                Logger::error("同步文档失败: {$doc['id']}, 错误: {$e->getMessage()}");
            }
        }
        
        return $stats;
    }
    
    /**
     * 同步单个文档
     */
    public function syncDocument(array $doc): array {
        // 格式转换
        $content = $this->convertDocument($doc);
        
        // 查询同步状态
        $syncStatus = $this->db->queryOne(
            "SELECT * FROM maxkb_sync_status WHERE doc_id = ?",
            [$doc['id']]
        );
        
        if (!$syncStatus) {
            // 新增同步
            $datasetId = $this->getDatasetId($doc['category']);
            $result = $this->maxkb->createDocument($datasetId, $doc['title'], 
                                                     $content, [
                    'doc_id' => $doc['id'],
                    'doc_type' => $doc['type'],
                    'version' => $doc['version']
                ]);
            
            $this->saveSyncStatus($doc, $result['id'], 'create');
            return ['action' => 'create', 'maxkb_id' => $result['id']];
            
        } elseif ($doc['version'] > $syncStatus['local_version']) {
            // 更新同步
            $result = $this->maxkb->updateDocument($syncStatus['maxkb_doc_id'], [
                'title' => $doc['title'],
                'content' => $content,
                'meta' => [
                    'doc_id' => $doc['id'],
                    'version' => $doc['version']
                ]
            ]);
            
            $this->saveSyncStatus($doc, $syncStatus['maxkb_doc_id'], 'update');
            return ['action' => 'update', 'maxkb_id' => $syncStatus['maxkb_doc_id']];
        }
        
        return ['action' => 'none'];
    }
    
    /**
     * 文档格式转换
     */
    private function convertDocument(array $doc): string {
        $converter = DocumentConverterFactory::getConverter($doc['file_type']);
        return $converter->convert($doc['file_path']);
    }
    
    /**
     * 获取MaxKB知识库ID
     */
    private function getDatasetId(string $category): string {
        $mapping = Config::get('maxkb.category_mapping');
        return $mapping[$category] ?? $mapping['default'];
    }
}
```

```php
        $allResults = [];

                'content' => $this->highlightKeywords($item['content']),

                'source' => $item['meta']['doc_type'] ?? '未知',
                'document_id' => $item['document_id']
            ];
```

```php
// 智能体对话接口
class MaxKBAgentService {
    private $client;
    
    public function chat(string $sessionId, string $message, array $context): Generator {
        // 1. 获取或创建MaxKB会话
        $maxkbSession = $this->getOrCreateSession($sessionId);
        
        // 2. 构建消息（注入上下文）

            'chat_id' => $maxkbSession['chat_id'],
            'message' => $enrichedMessage
        ]);
        
        // 4. 流式转发
        foreach ($stream as $chunk) {
            yield $this->transformChunk($chunk);
        }

        if (!empty($context['process_id'])) {
            $process = $this->getProcessInfo($context['process_id']);
            $contextStr .= "【当前工艺：{$process['name']}】\n";
        }
        
        if ($contextStr) {
            return $contextStr . "\n用户问题：" . $message;
        }
        
        return $message;
    }
}
```

```php
<?php
// services/MaxKBSessionManager.php

class MaxKBSessionManager {
    private $db;
    private $maxkb;
    
    /**
     * 获取或创建会话
     */
    public function getOrCreateSession(string $cappSessionId, array $userInfo): array {
        // 查询已有映射
        $mapping = $this->db->queryOne(
            "SELECT * FROM maxkb_session_mapping WHERE capp_session_id = ?",
            [$cappSessionId]
        );
        
        if ($mapping && $this->isSessionValid($mapping['maxkb_chat_id'])) {
            return [
                'chat_id' => $mapping['maxkb_chat_id'],
                'is_new' => false
            ];
        }
        
        // 创建新MaxKB会话
        $chat = $this->maxkb->createChat([
            'application_id' => Config::get('maxkb.agent_application_id'),
            'client_id' => $userInfo['user_id'],
            'client_type' => 'CAPP'
        ]);
        
        // 保存映射
        $this->db->execute(
            "INSERT INTO maxkb_session_mapping 
             (capp_session_id, maxkb_chat_id, user_id, created_at)
             VALUES (?, ?, ?, NOW())
             ON DUPLICATE KEY UPDATE
             maxkb_chat_id = VALUES(maxkb_chat_id),
             updated_at = NOW()",
            [$cappSessionId, $chat['id'], $userInfo['user_id']]
        );
        
        return [
            'chat_id' => $chat['id'],
            'is_new' => true
        ];
    }
    
    /**
     * 检查会话是否有效
     */
    private function isSessionValid(string $chatId): bool {
        try {
            $chat = $this->maxkb->getChat($chatId);
            return $chat['is_active'] ?? false;
        } catch (Exception $e) {
            return false;
        }
    }
}
```

#### 5.6.2 会话管理服务

```php
<?php
// services/AgentSessionService.php

class AgentSessionService {
    private $agentClient;
    private $sessionManager;
    
    public function __construct() {
        $this->agentClient = new MaxKBAgentClient();
        $this->sessionManager = new MaxKBSessionManager();
    }
    
    /**
     * 发起对话（带上下文）
     */
    public function converse(array $request): array {
        $sessionId = $request['session_id'];
        $message = $request['message'];
        $userId = $request['user_id'];
        $context = $request['context'] ?? [];
        
        // 1. 获取/创建会话
        $session = $this->sessionManager->getOrCreateSession($sessionId, [
            'user_id' => $userId
        ]);
        
        // 2. 注入业务上下文
        $enrichedMessage = $this->buildContextualMessage($message, $context);
        
        // 3. 调用智能体
        $response = [];
        foreach ($this->agentClient->chatStream($session['chat_id'], $enrichedMessage) as $chunk) {
            $response[] = $this->parseSSEChunk($chunk);
        }
        
        // 4. 记录对话日志
        $this->logConversation($sessionId, $message, $response);
        
        return [
            'session_id' => $sessionId,
            'chat_id' => $session['chat_id'],
            'response' => $response
        ];
    }
    
    /**
     * 构建带上下文的用户消息
     */
    private function buildContextualMessage(string $message, array $context): string {
        $parts = [];
        
        if (!empty($context['product_model'])) {
            $parts[] = "当前产品：{$context['product_model']}";
        }
```

```php
<?php
// services/SensitiveFilter.php

class SensitiveFilter {
    private $patterns;
    
    public function __construct() {
        $this->patterns = Config::get('sensitive.patterns');
    }
    
    /**
     * 过滤用户输入
     */
    public function filterInput(string $text): string {
        // 1. 检测Prompt注入攻击
        if ($this->detectPromptInjection($text)) {
            throw new SecurityException('检测到潜在的Prompt注入攻击');
        }
        
        // 2. 脱敏处理
        $text = $this->desensitize($text);
        
        return $text;
    }
    
    /**
     * 过滤AI输出
     */
    public function filterOutput(string $text): string {
        // 1. 检测敏感内容泄露
        $text = $this->removeSensitivePatterns($text);
        
        // 2. 添加免责声明（如需要）
        if ($this->needsDisclaimer($text)) {
            $text .= "\n\n【免责声明】以上内容由AI生成，仅供参考，正式工艺决策请以审核为准。";
        }
        
        return $text;
    }
    
    /**
     * 检测Prompt注入
     */
    private function detectPromptInjection(string $text): bool {
        $injectionPatterns = [
            '/ignore previous instructions/i',
            '/system prompt/i',
            '/you are now/i',
            '/DAN mode/i',
            '/jailbreak/i'
        ];
        
        foreach ($injectionPatterns as $pattern) {
            if (preg_match($pattern, $text)) {
                return true;
            }
        }
        
        return false;
    }
    
    /**
     * 脱敏处理
     */
    private function desensitize(string $text): string {
        // 客户名称脱敏
        $text = preg_replace('/客户[：:]\s*(\S+)/', '客户：***', $text);
        // 价格信息脱敏
        $text = preg_replace('/(报价|价格|金额)[：:]\s*[\d,]+/', '$1：***', $text);
        
        return $text;
    }
```

```php
<?php
// middleware/RateLimitMiddleware.php

class RateLimitMiddleware {
    private $redis;
    
    public function handle($request, $next) {
        $userId = $request->user_id;
        $role = $request->user_role;
        
        $limits = Config::get("rate_limits.{$role}");
        
        // 检查分钟限流
        $minuteKey = "rate_limit:minute:{$userId}";
        $minuteCount = $this->redis->incr($minuteKey);
        if ($minuteCount === 1) {
            $this->redis->expire($minuteKey, 60);
        }
        if ($minuteCount > $limits['per_minute']) {
            return response()->json(['error' => '请求过于频繁，请稍后再试'], 429);
        }
        
        // 检查小时限流
        $hourKey = "rate_limit:hour:{$userId}";
        $hourCount = $this->redis->incr($hourKey);
        if ($hourCount === 1) {
            $this->redis->expire($hourKey, 3600);
        }
        if ($hourCount > $limits['per_hour']) {
            return response()->json(['error' => '本小时请求次数已达上限'], 429);
        }
        
        return $next($request);
    }
}
```

```python
# services/model_manager.py

class ModelManager:
    def __init__(self):
        self.models = {}
        self.version_file = '/models/current_version.json'
        self._load_models()
        self._start_watchdog()
    
    def _start_watchdog(self):
        """启动模型版本监控"""
        def watch():
            while True:
                time.sleep(60)
                self._check_version_update()
        
        threading.Thread(target=watch, daemon=True).start()
    
    def _check_version_update(self):
        """检查版本更新"""
        try:
            with open(self.version_file, 'r') as f:
                new_config = json.load(f)
            
            for model_name, config in new_config.items():
                current = self.models.get(model_name)
                if current and current['version'] != config['version']:
                    self._hot_reload(model_name, config)
        except Exception as e:
            logger.error(f"版本检查失败: {e}")
    
    def _hot_reload(self, model_name, config):
        """热重载模型"""
        logger.info(f"开始热重载模型: {model_name} -> {config['version']}")
        
        # 1. 加载新模型
        new_model = load_model(config['path'])
        
        # 2. 原子切换
        old_model = self.models[model_name]['instance']
        self.models[model_name] = {
            'instance': new_model,
            'version': config['version'],
            'loaded_at': datetime.now()
        }
        
        # 3. 延迟卸载旧模型
        time.sleep(30)
        del old_model
        gc.collect()
        
        logger.info(f"模型热重载完成: {model_name}")
```

```python
# 批处理推理示例
class BatchInference:
    def __init__(self, batch_size=8, max_wait_ms=100):
        self.batch_size = batch_size
        self.max_wait_ms = max_wait_ms
        self.queue = []
        self.lock = threading.Lock()
    
    async def infer(self, request):
        """添加请求到批处理队列"""
        future = asyncio.Future()
        
        with self.lock:
            self.queue.append((request, future))
            
            if len(self.queue) >= self.batch_size:
                self._process_batch()
        
        # 设置超时处理
        asyncio.create_task(self._timeout_check())
        
        return await future
    
    def _process_batch(self):
        """处理批次"""
        with self.lock:
            batch = self.queue[:self.batch_size]
            self.queue = self.queue[self.batch_size:]
        
        # 批量推理
        inputs = [item[0] for item in batch]
        results = model.batch_predict(inputs)
        
        # 分发结果
        for (request, future), result in zip(batch, results):
            future.set_result(result)
```

```python
    """检测模型幻觉"""
    # 1. 事实一致性检查
    fact_score = check_factual_consistency(response, retrieved_knowledge)
    
    # 2. 来源可追溯性检查
    source_score = check_source_traceability(response)
    
    # 3. 参数合理性检查
    param_score = check_parameter_validity(response)
    
    # 综合评分
    hallucination_score = 1 - (0.4 * fact_score + 0.3 * source_score + 0.3 * param_score)
    
    return {
        'hallucination_score': hallucination_score,
        'is_hallucination': hallucination_score > 0.7,
        'details': {
            'fact_score': fact_score,
            'source_score': source_score,
            'param_score': param_score
        }
    }
```
