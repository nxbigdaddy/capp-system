## 1. 安全设计概述

### 1.1 安全设计目标

本CAPP系统安全设计围绕以下核心目标展开：

| 目标 | 说明 | 实现方式 |
|------|------|----------|
| **机密性** | 确保工艺数据、技术参数等核心资产不被未授权访问 | 传输加密、存储加密、访问控制 |
| **完整性** | 确保工艺路线、BOM等关键数据不被篡改 | 数据签名、审计日志、操作校验 |
| **可用性** | 确保系统在遭受攻击或故障时仍能正常提供服务 | 高可用架构、DDoS防护、容灾备份 |
| **可追溯性** | 确保所有操作可追溯到具体操作人和时间 | 完整审计日志、操作记录、变更追踪 |

### 1.2 安全设计原则

| 原则 | 说明 | 应用场景 |
|------|------|----------|
| **最小权限原则** | 用户和系统组件仅被授予完成任务所需的最小权限 | 数据库账号权限、文件系统权限、API接口权限 |
| **纵深防御原则** | 通过多层安全控制措施，形成纵深防御体系 | 网络层+应用层+数据层多层防护 |
| **安全默认原则** | 系统默认配置为最安全状态，需要时再开放 | 关闭不必要端口、默认拒绝访问、参数化查询 |
| **职责分离原则** | 关键操作需要多个角色参与，防止权限滥用 | 工艺审批流程、数据导出审批、系统配置变更 |
| **失败安全原则** | 系统在出现异常时应倾向于更安全的处理方式 | 认证失败拒绝访问、接口超时返回错误而非默认值 |

### 1.3 安全合规要求

本系统按照**等保2.0（GB/T 22239-2019）**基本要求进行安全设计，主要覆盖以下控制点：

| 等保要求类别 | 对应系统设计 |
|-------------|-------------|
| **安全物理环境** | 机房环境、设备防盗、电力保障（基础设施层面） |
| **安全通信网络** | 网络架构、通信传输加密、网络边界防护 |
| **安全区域边界** | 访问控制、入侵防范、安全审计 |
| **安全计算环境** | 身份鉴别、访问控制、安全审计、数据完整性、数据保密性 |
| **安全管理中心** | 集中系统管理、集中安全管理、集中审计管理 |
| **安全管理制度** | 安全策略、管理制度、操作规程 |

## 2. 身份认证安全

### 2.1 认证方案（JWT Token认证机制）

系统采用 **JWT（JSON Web Token）** 作为核心认证机制，实现无状态的分布式认证。

**JWT Token结构**：

```
Header（头部）     .  Payload（载荷）     .  Signature（签名）
eyJhbGciOiJIUzI1  .  eyJzdWIiOiIxMjM0  .  SflKxwRJSMeKKF2QT4
NiIsInR5cCI6IkpX   .  NTY3ODkwIiwibmFt   .  fwpMeJf36POk6yJV_
VCJ9                 .  ZSI6IkphbWVzIiwi  .  adQssw5c
                      cm9sZSI6ImFkbWluI  .
                      n0iLCJleHAiOjE3M  .
                      jAwMDAwMDAwfQ
```

**JWT实现方案**：

```php
<?php
// app/common/JWT.php

class JWT {
    private static $secretKey = 'YOUR_SECRET';
    private static $algorithm = 'HS256';
    private static $accessTokenExpiry = 7200;      // 访问Token有效期：2小时
    private static $refreshTokenExpiry = 604800;    // 刷新Token有效期：7天

    /**
     * 生成访问Token
     */
    public static function generateAccessToken(array $payload): string {
        $now = time();
        $payload['iat'] = $now;           // 签发时间
        $payload['exp'] = $now + self::$accessTokenExpiry;  // 过期时间
        $payload['jti'] = self::generateJTI();  // Token唯一标识
        $payload['type'] = 'access';

        $header = self::base64UrlEncode(json_encode([
            'alg' => self::$algorithm,
            'typ' => 'JWT'
        ]));

        $payloadStr = self::base64UrlEncode(json_encode($payload));
        $signature = self::base64UrlEncode(
            hash_hmac('sha256', $header . '.' . $payloadStr, self::$secretKey, true)
        );

        return $header . '.' . $payloadStr . '.' . $signature;
    }

    /**
     * 生成刷新Token
     */
    public static function generateRefreshToken(array $payload): string {
        $now = time();
        $payload['iat'] = $now;
        $payload['exp'] = $now + self::$refreshTokenExpiry;
        $payload['jti'] = self::generateJTI();
        $payload['type'] = 'refresh';

        $header = self::base64UrlEncode(json_encode([
            'alg' => self::$algorithm,
            'typ' => 'JWT'
        ]));

        $payloadStr = self::base64UrlEncode(json_encode($payload));
        $signature = self::base64UrlEncode(
            hash_hmac('sha256', $header . '.' . $payloadStr, self::$secretKey, true)
        );

        return $header . '.' . $payloadStr . '.' . $signature;
    }

    /**
     * 验证Token
     */
    public static function verifyToken(string $token): ?array {
        $parts = explode('.', $token);
        if (count($parts) !== 3) {
            return null;
        }

        list($header, $payload, $signature) = $parts;

        // 验证签名
        $expectedSignature = self::base64UrlEncode(
            hash_hmac('sha256', $header . '.' . $payload, self::$secretKey, true)
        );

        if (!hash_equals($expectedSignature, $signature)) {
            return null;
        }

        // 解析载荷
        $data = json_decode(self::base64UrlDecode($payload), true);
        if ($data === null) {
            return null;
        }

        // 验证过期时间
        if (isset($data['exp']) && $data['exp'] < time()) {
            return null;
        }

        return $data;
    }

    /**
     * 生成Token唯一标识
     */
    private static function generateJTI(): string {
        return bin2hex(random_bytes(16));
    }

    private static function base64UrlEncode(string $data): string {
        return rtrim(strtr(base64_encode($data), '+/', '-_'), '=');
    }

    private static function base64UrlDecode(string $data): string {
        $remainder = strlen($data) % 4;
        if ($remainder) {
            $data .= str_repeat('=', 4 - $remainder);
        }
        return base64_decode(strtr($data, '-_', '+/'));
    }
}
```

### 2.2 登录安全

#### 2.2.1 密码策略

| 策略项 | 要求 | 说明 |
|--------|------|------|
| **密码长度** | 最少8位 | 建议至少12位 |
| **复杂度** | 必须包含大写字母、小写字母、数字、特殊字符 | 四类字符至少包含三类 |
| **密码历史** | 不能使用最近5次使用过的密码 | 防止密码循环使用 |
| **密码有效期** | 90天 | 到期前15天提醒修改 |
| **初始密码** | 首次登录强制修改 | 管理员创建的初始密码必须修改 |
| **密码存储** | bcrypt哈希（cost=12） | 永不明文存储密码 |

**密码验证实现**：

```php
<?php
// app/services/AuthService.php

class AuthService {
    const PASSWORD_MIN_LENGTH = 8;
    const PASSWORD_MAX_LENGTH = 128;
    const BCRYPT_COST = 12;

    /**
     * 验证密码复杂度
     */
    public static function validatePasswordStrength(string $password): array {
        $errors = [];

        if (strlen($password) < self::PASSWORD_MIN_LENGTH) {
            $errors[] = '密码长度不能少于' . self::PASSWORD_MIN_LENGTH . '位';
        }
        if (strlen($password) > self::PASSWORD_MAX_LENGTH) {
            $errors[] = '密码长度不能超过' . self::PASSWORD_MAX_LENGTH . '位';
        }
        if (!preg_match('/[a-z]/', $password)) {
            $errors[] = '密码必须包含小写字母';
        }
        if (!preg_match('/[A-Z]/', $password)) {
            $errors[] = '密码必须包含大写字母';
        }
        if (!preg_match('/[0-9]/', $password)) {
            $errors[] = '密码必须包含数字';
        }
        if (!preg_match('/[!@#$%^&*()_+\-=\[\]{}|;:,.<>?]/', $password)) {
            $errors[] = '密码必须包含特殊字符';
        }

        // 检查常见弱密码
        $commonPasswords = ['Password1!', 'Qwerty123!', 'Admin123!', '12345678aA!'];
        if (in_array($password, $commonPasswords)) {
            $errors[] = '密码过于常见，请使用更复杂的密码';
        }

        return $errors;
    }

    /**
     * 密码哈希
     */
    public static function hashPassword(string $password): string {
        return password_hash($password, PASSWORD_BCRYPT, [
            'cost' => self::BCRYPT_COST
        ]);
    }

    /**
     * 验证密码
     */
    public static function verifyPassword(string $password, string $hash): bool {
        return password_verify($password, $hash);
    }

    /**
     * 检查密码是否需要重新哈希（算法升级时使用）
     */
    public static function needsRehash(string $hash): bool {
        return password_needs_rehash($hash, PASSWORD_BCRYPT, [
            'cost' => self::BCRYPT_COST
        ]);
    }
}
```

#### 2.2.2 登录失败锁定

| 策略项 | 配置值 | 说明 |
|--------|--------|------|
| **最大失败次数** | 5次 | 连续5次登录失败后锁定 |
| **锁定时长** | 30分钟 | 锁定30分钟后自动解锁 |
| **累计失败阈值** | 10次/天 | 一天内累计10次失败锁定24小时 |
| **锁定通知** | 企业微信消息 | 锁定时通知用户和管理员 |

**登录失败锁定实现**：

```php
<?php
// app/services/LoginSecurityService.php

class LoginSecurityService {
    const MAX_FAILED_ATTEMPTS = 5;
    const LOCK_DURATION = 1800;          // 30分钟
    const DAILY_FAILED_LIMIT = 10;
    const DAILY_LOCK_DURATION = 86400;    // 24小时

    private $redis;

    public function __construct() {
        $this->redis = RedisClient::getConnection();
    }

    /**
     * 检查账户是否被锁定
     */
    public function isAccountLocked(int $userId): array {
        // 检查连续失败锁定
        $lockKey = "login:lock:user:{$userId}";
        $lockEnd = $this->redis->get($lockKey);
        if ($lockEnd) {
            $remaining = $lockEnd - time();
            if ($remaining > 0) {
                return [
                    'locked' => true,
                    'reason' => 'continuous_fail',
                    'remaining_seconds' => $remaining
                ];
            }
            $this->redis->del($lockKey);
        }

        // 检查每日累计失败锁定
        $dailyLockKey = "login:daily_lock:user:{$userId}:" . date('Ymd');
        $dailyLockEnd = $this->redis->get($dailyLockKey);
        if ($dailyLockEnd) {
            $remaining = $dailyLockEnd - time();
            if ($remaining > 0) {
                return [
                    'locked' => true,
                    'reason' => 'daily_limit',
                    'remaining_seconds' => $remaining
                ];
            }
        }

        return ['locked' => false];
    }

    /**
     * 记录登录失败
     */
    public function recordFailedAttempt(int $userId, string $ip): array {
        $failKey = "login:fail:user:{$userId}";
        $failCount = $this->redis->incr($failKey);
        $this->redis->expire($failKey, self::LOCK_DURATION);

        // 记录失败IP
        $ipKey = "login:fail_ip:{$ip}";
        $this->redis->incr($ipKey);
        $this->redis->expire($ipKey, 3600);

        // 检查是否达到连续失败阈值
        if ($failCount >= self::MAX_FAILED_ATTEMPTS) {
            $lockKey = "login:lock:user:{$userId}";
            $this->redis->setex($lockKey, self::LOCK_DURATION, time() + self::LOCK_DURATION);

            // 通知用户和管理员
            $this->sendLockNotification($userId, 'continuous', self::LOCK_DURATION);

            return [
                'locked' => true,
                'reason' => 'continuous_fail',
                'remaining_seconds' => self::LOCK_DURATION,
                'failed_attempts' => $failCount
            ];
        }

        // 检查每日累计失败
        $dailyKey = "login:daily_fail:user:{$userId}:" . date('Ymd');
        $dailyCount = $this->redis->incr($dailyKey);
        $this->redis->expire($dailyKey, 86400);

        if ($dailyCount >= self::DAILY_FAILED_LIMIT) {
            $dailyLockKey = "login:daily_lock:user:{$userId}:" . date('Ymd');
            $this->redis->setex($dailyLockKey, self::DAILY_LOCK_DURATION, time() + self::DAILY_LOCK_DURATION);

            $this->sendLockNotification($userId, 'daily', self::DAILY_LOCK_DURATION);

            return [
                'locked' => true,
                'reason' => 'daily_limit',
                'remaining_seconds' => self::DAILY_LOCK_DURATION,
                'failed_attempts' => $dailyCount
            ];
        }

        return [
            'locked' => false,
            'failed_attempts' => $failCount,
            'remaining_attempts' => self::MAX_FAILED_ATTEMPTS - $failCount
        ];
    }

    /**
     * 登录成功，清除失败记录
     */
    public function clearFailedAttempts(int $userId): void {
        $this->redis->del("login:fail:user:{$userId}");
    }

    private function sendLockNotification(int $userId, string $reason, int $duration): void {
        // 通过企业微信发送通知
        $message = sprintf(
            "账户安全告警：用户ID %d 因连续登录失败被锁定%s。请确认是否为本人操作。",
            $userId,
            $reason === 'continuous' ? '30分钟' : '24小时'
        );
        WeChatNotifier::sendSecurityAlert($userId, $message);
    }
}
```

#### 2.2.3 验证码机制

| 场景 | 验证码类型 | 说明 |
|------|-----------|------|
| **登录验证** | 滑动验证码 | 连续3次失败后触发 |
| **敏感操作** | 短信验证码 | 删除工艺路线、导出数据等 |
| **密码修改** | 短信验证码 + 旧密码验证 | 双重验证 |
| **密码重置** | 短信验证码 | 通过手机号重置密码 |
| **API接口** | 图形验证码 | 防止暴力破解 |

**验证码实现要点**：

```php
<?php
// app/services/CaptchaService.php

class CaptchaService {
    const CAPTCHA_EXPIRY = 300;       // 验证码有效期5分钟
    const SMS_INTERVAL = 60;          // 短信发送间隔60秒
    const SMS_DAILY_LIMIT = 10;       // 每日短信上限10条
    const CAPTCHA_LENGTH = 6;         // 验证码长度

    /**
     * 生成并发送短信验证码
     */
    public function sendSmsCaptcha(string $phone, string $scene): array {
        // 检查发送频率
        $intervalKey = "sms:interval:{$phone}:{$scene}";
        $lastSend = RedisClient::get($intervalKey);
        if ($lastSend) {
            return ['success' => false, 'message' => '请勿频繁发送验证码'];
        }

        // 检查每日发送上限
        $dailyKey = "sms:daily:{$phone}:" . date('Ymd');
        $dailyCount = RedisClient::incr($dailyKey);
        if ($dailyCount > self::SMS_DAILY_LIMIT) {
            return ['success' => false, 'message' => '今日验证码发送次数已达上限'];
        }
        RedisClient::expire($dailyKey, 86400);

        // 生成验证码
        $code = str_pad((string)random_int(0, 999999), self::CAPTCHA_LENGTH, '0', STR_PAD_LEFT);

        // 存储验证码（使用Redis，设置过期时间）
        $codeKey = "sms:captcha:{$phone}:{$scene}";
        RedisClient::setex($codeKey, self::CAPTCHA_EXPIRY, $code);

        // 记录发送间隔
        RedisClient::setex($intervalKey, self::SMS_INTERVAL, time());

        // 发送短信
        SmsSender::send($phone, "您的验证码是{$code}，5分钟内有效。如非本人操作请忽略。");

        return ['success' => true, 'message' => '验证码已发送'];
    }

    /**
     * 验证短信验证码
     */
    public function verifySmsCaptcha(string $phone, string $scene, string $code): bool {
        $codeKey = "sms:captcha:{$phone}:{$scene}";
```

### 3.4 API接口鉴权

**Token验证 + 权限校验中间件**：

```php
<?php
// app/middleware/AuthMiddleware.php

class AuthMiddleware {
    /**
     * API接口鉴权中间件
     */
    public function handle(array $request, Closure $next): array {
        // 1. 获取Token
        $authHeader = $request['headers']['Authorization'] ?? '';
        if (empty($authHeader) || !str_starts_with($authHeader, 'Bearer ')) {
            return $this->unauthorized('缺少认证Token');
        }

        $token = YOUR_SECRET, 7);

        // 2. 验证Token
        $payload = JWT::verifyToken($token);
        if (!$payload) {
            return $this->unauthorized('Token无效或已过期');
        }

        // 3. 检查Token是否在黑名单中
        if (TokenService::isTokenBlacklisted($payload['jti'])) {
            return $this->unauthorized('Token已被撤销');
        }

        // 4. 检查用户状态
        $user = UserModel::findById($payload['user_id']);
        if (!$user || $user['status'] != 1) {
            return $this->unauthorized('用户已被禁用');
        }

        // 5. 将用户信息注入请求上下文
        $request['user'] = $user;
        $request['user_id'] = $payload['user_id'];

        // 6. 执行后续处理
        return $next($request);
    }

    /**
     * 权限检查中间件
     */
    public function requirePermission(string $permissionCode): callable {
        return function(array $request, Closure $next) use ($permissionCode) {
            $user = $request['user'];

            // 检查用户是否拥有指定权限
            if (!$this->hasPermission($user['id'], $permissionCode)) {
                return $this->forbidden('无权执行此操作');
            }

            return $next($request);
        };
    }

    /**
     * 检查用户权限
     */
    private function hasPermission(int $userId, string $permissionCode): bool {
        // 超级管理员拥有所有权限
        if ($this->isSuperAdmin($userId)) {
            return true;
        }

        // 从缓存获取用户权限列表
        $cacheKey = "user:permissions:{$userId}";
        $permissions = RedisClient::get($cacheKey);

        if ($permissions === false) {
            $permissions = UserModel::getPermissionCodes($userId);
            RedisClient::setex($cacheKey, 3600, json_encode($permissions));
            $permissions = $permissions;
        } else {
            $permissions = json_decode($permissions, true);
        }

        return in_array($permissionCode, $permissions);
    }

    private function isSuperAdmin(int $userId): bool {
        return UserModel::hasRole($userId, 'super_admin');
    }

    private function unauthorized(string $message): array {
        http_response_code(401);
        return ['code' => 401, 'message' => $message, 'data' => null];
    }

    private function forbidden(string $message): array {
        http_response_code(403);
        return ['code' => 403, 'message' => $message, 'data' => null];
    }
}
```

### 3.5 PHP中间件实现示例

**中间件链实现**：

```php
<?php
// app/core/MiddlewareChain.php

class MiddlewareChain {
    private $middlewares = [];
    private $request;

    public function __construct(array $request) {
        $this->request = $request;
    }

    /**
     * 注册中间件
     */
    public function add(callable $middleware): self {
        $this->middlewares[] = $middleware;
        return $this;
    }

    /**
     * 执行中间件链
     */
    public function run(callable $handler): array {
        $pipeline = array_reduce(
            array_reverse($this->middlewares),
            function ($next, $middleware) {
                return function ($request) use ($next, $middleware) {
                    return $middleware($request, $next);
                };
            },
            $handler
        );

        return $pipeline($this->request);
    }
}

        ->middleware([
            [AuthMiddleware::class, 'handle'],
            [AuthMiddleware::class, 'requirePermission', ['process:create']]
        ]);

    $router->delete('/{id}', 'ProcessRouteController@delete')
        ->middleware([
```

### 4.3 存储加密

**AES-256加密实现**：

```php
<?php
// app/common/Cryptor.php

class Cryptor {
    // AES-256-CBC加密
    const CIPHER = 'aes-256-cbc';
    const KEY_LENGTH = 32;  // 256位

    /**
     * 加密敏感字段
     */
    public static function encrypt(string $plaintext, string $key): string {
        $iv = random_bytes(openssl_cipher_iv_length(self::CIPHER));
        $ciphertext = openssl_encrypt(
            $plaintext,
            self::CIPHER,
            hash('sha256', $key, true),  // 派生256位密钥
            OPENSSL_RAW_DATA,
            $iv
        );

        // 格式：IV(16字节) + 密文
        return base64_encode($iv . $ciphertext);
    }

    /**
     * 解密敏感字段
     */
    public static function decrypt(string $ciphertext, string $key): ?string {
        $data = base64_decode($ciphertext);
        if ($data === false || strlen($data) < 16) {
            return null;
        }

        $iv = substr($data, 0, 16);
        $encrypted = substr($data, 16);

        $plaintext = openssl_decrypt(
            $encrypted,
            self::CIPHER,
            hash('sha256', $key, true),
            OPENSSL_RAW_DATA,
            $iv
        );

        return $plaintext !== false ? $plaintext : null;
    }
}
```

```php
<?php
// app/common/DataMasker.php

class DataMasker {
    /**
     * 手机号脱敏
     */
    public static function maskPhone(string $phone): string {
        if (strlen($phone) !== 11) {
            return $phone;
        }
        return substr($phone, 0, 3) . '****' . substr($phone, 7);
    }

    /**
     * 身份证号脱敏
     */
    public static function maskIdCard(string $idCard): string {
        $len = strlen($idCard);
        if ($len < 8) {
            return $idCard;
        }
        return substr($idCard, 0, 4) . str_repeat('*', $len - 8) . substr($idCard, -4);
    }

    /**
     * 邮箱脱敏
     */
    public static function maskEmail(string $email): string {
        $parts = explode('@', $email);
        if (count($parts) !== 2) {
            return $email;
        }
        $name = $parts[0];
        $masked = mb_substr($name, 0, 3) . '***';
        return $masked . '@' . $parts[1];
    }

    /**
     * 姓名脱敏
     */
    public static function maskName(string $name): string {
        $len = mb_strlen($name);
        if ($len <= 1) {
            return '*';
        }
        return mb_substr($name, 0, 1) . str_repeat('*', $len - 1);
    }

    /**
     * 通用脱敏方法
     */
    public static function mask(string $value, int $prefixLen = 0, int $suffixLen = 0): string {
        $len = strlen($value);
        $maskLen = $len - $prefixLen - $suffixLen;
        if ($maskLen <= 0) {
            return $value;
        }
        return substr($value, 0, $prefixLen) . str_repeat('*', $maskLen) . substr($value, -$suffixLen);
    }
}
```

### 5.3 CSRF防护

**Token验证方案**：

```php
<?php
// app/middleware/CsrfMiddleware.php

class CsrfMiddleware {
    /**
     * 生成CSRF Token
     */
    public static function generateToken(): string {
        $token = YOUR_SECRET));
        $_SESSION['csrf_token'] = $token;
        $_SESSION['csrf_token_time'] = time();
        return $token;
    }

    /**
     * 验证CSRF Token
     */
    public static function validateToken(string $token): bool {
        // 检查session中是否存在Token
        if (empty($_SESSION['csrf_token'])) {
            return false;
        }

        // 检查Token是否过期（默认2小时）
        if (time() - $_SESSION['csrf_token_time'] > 7200) {
            unset($_SESSION['csrf_token']);
            return false;
        }

        // 使用时间安全比较
        if (!hash_equals($_SESSION['csrf_token'], $token)) {
            return false;
        }

        // 验证通过后删除Token（一次性使用）
        unset($_SESSION['csrf_token']);
        return true;
    }

    /**
     * API请求CSRF验证
     */
    public function handle(array $request, Closure $next): array {
        // GET/HEAD/OPTIONS请求不需要CSRF验证
        if (in_array($request['method'], ['GET', 'HEAD', 'OPTIONS'])) {
            return $next($request);
        }

        // JWT认证的API不需要CSRF Token（通过Authorization头认证）
        if (!empty($request['headers']['Authorization'])) {
            return $next($request);
        }

        // 从Header或Body获取CSRF Token
        $token = YOUR_SECRET'headers']['X-CSRF-Token']
            ?? $request['post']['_csrf_token']
            ?? '';

        if (!self::validateToken($token)) {
            return [
                'code' => 403,
                'message' => 'CSRF验证失败，请刷新页面后重试',
                'data' => null
            ];
        }

        return $next($request);
    }
}
```

### 5.4 文件上传安全

**文件上传安全检查**：

```php
<?php
// app/services/FileUploadService.php

class FileUploadService {
    // 允许的文件类型白名单
    const ALLOWED_MIME_TYPES = [
        // 图纸文件
        'application/pdf' => ['pdf'],
        'application/dxf' => ['dxf'],
        'application/dwg' => ['dwg'],

        // Office文档
        'application/vnd.openxmlformats-officedocument.wordprocessingml.document' => ['docx'],
        'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet' => ['xlsx'],
        'application/vnd.openxmlformats-officedocument.presentationml.presentation' => ['pptx'],

        // 图片
        'image/jpeg' => ['jpg', 'jpeg'],
        'image/png' => ['png'],
        'image/gif' => ['gif'],
        'image/webp' => ['webp'],

        // 压缩文件
        'application/zip' => ['zip'],
        'application/x-rar-compressed' => ['rar'],
        'application/x-7z-compressed' => ['7z'],
    ];

    // 文件大小限制（字节）
    const MAX_FILE_SIZE = 209715200;  // 200MB

    /**
     * 安全文件上传
     */
    public function upload(array $file, string $bucket, string $category): array {
        // 1. 检查上传错误
        if ($file['error'] !== UPLOAD_ERR_OK) {
            throw new UploadException($this->getUploadErrorMessage($file['error']));
        }

        // 2. 检查文件大小
        if ($file['size'] > self::MAX_FILE_SIZE) {
            throw new UploadException('文件大小超过限制（最大200MB）');
        }
        if ($file['size'] === 0) {
            throw new UploadException('文件为空');
        }

        // 3. 检查文件扩展名
        $extension = strtolower(pathinfo($file['name'], PATHINFO_EXTENSION));
        $allowedExtensions = array_merge(...array_values(self::ALLOWED_MIME_TYPES));
        if (!in_array($extension, $allowedExtensions)) {
            throw new UploadException('不支持的文件类型');
        }

        // 4. 检查MIME类型（使用finfo，不依赖客户端Content-Type）
        $finfo = new finfo(FILEINFO_MIME_TYPE);
        $mimeType = $finfo->file($file['tmp_name']);

        if (!isset(self::ALLOWED_MIME_TYPES[$mimeType])
            || !in_array($extension, self::ALLOWED_MIME_TYPES[$mimeType])) {
            throw new UploadException('文件类型与扩展名不匹配');
        }

        // 5. 检查文件内容（防止伪装文件）
        if ($this->isFileSuspicious($file['tmp_name'], $extension)) {
            throw new UploadException('文件内容异常，上传被拒绝');
        }

        // 6. 病毒扫描（调用ClamAV）
        if (!$this->virusScan($file['tmp_name'])) {
            throw new UploadException('文件包含病毒，上传被拒绝');
        }

        // 7. 生成安全的存储路径
        $storagePath = $this->generateStoragePath($category, $extension);

        // 8. 上传到MinIO
        $minioClient = MinIOClient::getInstance();
        $result = $minioClient->uploadFile(
            $bucket,
            $storagePath,
            $file['tmp_name'],
            $mimeType
        );

        // 9. 记录文件上传日志
        AuditLogger::log('file.upload', [
            'file_name' => $file['name'],
            'file_size' => $file['size'],
            'file_type' => $mimeType,
            'storage_path' => $storagePath,
            'bucket' => $bucket
        ]);

        return [
            'file_id' => $result['file_id'],

        // 检查文件头（Magic Number）
        $handle = fopen($filePath, 'rb');
        $header = fread($handle, 8);
        fclose($handle);

        $magicNumbers = [
            'jpg' => ["\xFF\xD8\xFF"],
            'png' => ["\x89\x50\x4E\x47"],
            'gif' => ["\x47\x49\x46\x38"],

            'xlsx' => ["\x50\x4B\x03\x04"],
        ];

        if (isset($magicNumbers[$extension])) {
            $valid = false;
            foreach ($magicNumbers[$extension] as $magic) {
                if (strpos($header, $magic) === 0) {
                    $valid = true;
                    break;
                }
            }
            if (!$valid) {
                return true;  // 文件头不匹配，可疑
            }
        }

        // 检查是否包含PHP标签（防止上传PHP文件伪装）
        $content = file_get_contents($filePath);
        if (preg_match('/<\?php/i', $content)) {
            return true;
        }

        return false;
    }
```

### 6.3 接口限流

**令牌桶算法实现**：

```php
<?php
// app/middleware/RateLimitMiddleware.php

class RateLimitMiddleware {
    const DEFAULT_RATE = 100;      // 每秒100次请求
    const DEFAULT_BURST = 200;     // 突发200次
    const PENALTY_DURATION = 60;    // 超限后惩罚60秒

    /**
     * 令牌桶限流
     */
    public function rateLimitByUser(int $userId, int $rate = self::DEFAULT_RATE, int $burst = self::DEFAULT_BURST): bool {
        return $this->tokenBucket("rate_limit:user:{$userId}", $rate, $burst);
    }

    /**
     * 按IP限流
     */
    public function rateLimitByIp(string $ip, int $rate = 60, int $burst = 120): bool {
        return $this->tokenBucket("rate_limit:ip:{$ip}", $rate, $burst);
    }

    /**
     * 按接口限流
     */
    public function rateLimitByApi(string $api, int $rate = 200, int $burst = 500): bool {
        return $this->tokenBucket("rate_limit:api:{$api}", $rate, $burst);
    }

    /**
     * 令牌桶算法实现
     */
    private function tokenBucket(string $key, int $rate, int $burst): bool {
        $redis = RedisClient::getConnection();

        // 检查是否在惩罚期
        $penaltyKey = "{$key}:penalty";
        if ($redis->exists($penaltyKey)) {
            return false;
        }

        $luaScript = <<<'LUA'
            local key = KEYS[1]
            local rate = tonumber(ARGV[1])
            local burst = tonumber(ARGV[2])
            local now = tonumber(ARGV[3])
            local interval = 1000000 / rate

            local tokens = redis.call('HMGET', key, 'tokens', 'last_time')
            local currentTokens = tonumber(tokens[1]) or burst
            local lastTime = tonumber(tokens[2]) or now

            -- 计算新增令牌
            local elapsed = now - lastTime
            local newTokens = math.floor(elapsed / interval)
            currentTokens = math.min(burst, currentTokens + newTokens)
            lastTime = now - (elapsed % interval)

            if currentTokens > 0 then
                currentTokens = currentTokens - 1
                redis.call('HMSET', key, 'tokens', currentTokens, 'last_time', lastTime)
                redis.call('EXPIRE', key, math.ceil(burst / rate) + 10)
                return 1
            else
                -- 超限，设置惩罚
                redis.call('HMSET', key, 'tokens', 0, 'last_time', lastTime)
                redis.call('SET', key .. ':penalty', '1', 'EX', ARGV[4])
                return 0
            end
LUA;

        $result = $redis->eval($luaScript, [$key, $rate, $burst, (int)(microtime(true) * 1000000), self::PENALTY_DURATION], 1);

        return $result == 1;
    }
}
```

### 6.4 接口签名

**请求签名验证**：

```php
<?php
// app/common/ApiSignature.php

class ApiSignature {
    /**
     * 生成请求签名
     * 签名规则：将所有非空参数按key升序排列，拼接成key=value&key=value格式，
     * 末尾追加timestamp和api_key，使用HMAC-SHA256计算签名
     */
    public static function generateSignature(array $params, string $apiKey, string $secretKey): string {
        // 移除签名字段
        unset($params['sign']);

        // 按key升序排列
        ksort($params);

        // 过滤空值
        $params = array_filter($params, function($value) {
            return $value !== '' && $value !== null;
        });

        // 拼接字符串
        $signStr = http_build_query($params);
        $signStr .= "&timestamp={$params['timestamp']}&api_key=YOUR_SECRET}";

        // HMAC-SHA256签名
        return hash_hmac('sha256', $signStr, $secretKey);
    }

    /**
     * 验证请求签名
     */
    public static function verifySignature(array $request): bool {
        $apiKey = YOUR_SECRET'headers']['X-API-Key'] ?? '';
        $timestamp = $request['headers']['X-Timestamp'] ?? '';
        $sign = $request['headers']['X-Signature'] ?? '';

        // 获取API客户端信息
        $client = ApiClientModel::findByKey($apiKey);
        if (!$client) {
            return false;
        }

        // 重新计算签名
        $params = array_merge(
            $request['get'] ?? [],
            $request['post'] ?? []
        );
        $params['timestamp'] = $timestamp;
        $params['api_key'] = $apiKey;

        $expectedSign = self::generateSignature($params, $apiKey, $client['secret_key']);

        return hash_equals($expectedSign, $sign);
    }
}
```

### 9.1 AccessToken安全管理

```php
<?php
// app/services/WeChatTokenService.php

    private $corpId;

     * 获取AccessToken（带缓存和自动刷新）
     */
    public function getAccessToken(): string {
        $cacheKey = "wechat:access_token:YOUR_SECRET}";

        // 从Redis缓存获取
        $token = YOUR_SECRET);
        if ($token) {
            return $token;

        // 缓存未命中，请求企业微信API

        $data = json_decode($response, true);

        $token = YOUR_SECRET'access_token'];
        $expiresIn = $data['expiresin'] - 300;  // 提前5分钟过期

        // 加密存储到Redis
        $this->redis->setex($cacheKey, $expiresIn, $token);

    }

    }
```

### 9.2 回调事件安全

```php
<?php
// app/controllers/WeChatCallbackController.php

class WeChatCallbackController {
    /**
     * 处理企业微信回调事件
     */
    public function handleCallback(): void {
        $msgSignature = $_GET['msg_signature'] ?? '';
        $timestamp = $_GET['timestamp'] ?? '';
        $nonce = $_GET['nonce'] ?? '';
        $echoStr = $_GET['echostr'] ?? '';
        $postData = file_get_contents('php://input');

        // 1. 验证URL（首次配置时）
        if (!empty($echoStr)) {
            $this->verifyUrl($msgSignature, $timestamp, $nonce, $echoStr);
            return;
        }

        // 2. 验证消息签名
        if (!$this->verifySignature($msgSignature, $timestamp, $nonce, $postData)) {
            http_response_code(403);
            echo '签名验证失败';
            return;
        }

        // 3. 解密消息
        $decryptedXml = $this->decryptMessage($postData);
        $event = simplexml_load_string($decryptedXml);

        // 4. 处理事件
        $eventType = $event->Event;
        switch ($eventType) {
            case 'change_contact':
                $this->handleContactChange($event);
                break;
            case 'subscribe':
                $this->handleSubscribe($event);
                break;
            default:
                Logger::info('wechat.callback', "未处理的事件类型：{$eventType}");
        }

        echo 'success';
    }

    /**
     * 验证回调签名
     */
    private function verifySignature(string $msgSignature, string $timestamp, string $nonce, string $postData): bool {
        $token = YOUR_SECRET'wechat.callback_token');
        $encodingAesKey = Config::get('wechat.encoding_aes_key');
        $corpId = Config::get('wechat.corp_id');

        $signArr = [$token, $timestamp, $nonce, $postData];
        sort($signArr, SORT_STRING);
        $signStr = implode($signArr);
        $expectedSignature = sha1($signStr);

        return hash_equals($expectedSignature, $msgSignature);
    }

    /**
     * AES解密消息
     */
    private function decryptMessage(string $encryptedXml): string {
        $xml = simplexml_load_string($encryptedXml);
        $encryptedMsg = (string)$xml->Encrypt;

        $encodingAesKey = Config::get('wechat.encoding_aes_key');
        $corpId = Config::get('wechat.corp_id');
        $aesKey = base64_decode($encodingAesKey . '=');

        // AES-256-CBC解密
        $iv = substr($aesKey, 0, 16);
        $decrypted = openssl_decrypt($encryptedMsg, 'AES-256-CBC', $aesKey, OPENSSL_RAW_DATA, $iv);

        // 去除PKCS7填充
        $pad = ord($decrypted[strlen($decrypted) - 1]);
        $decrypted = substr($decrypted, 0, -$pad);

        // 提取消息内容（格式：16字节随机串 + 4字节消息长度 + 消息 + CorpID）
        $msgLen = unpack('N', substr($decrypted, 16, 4))[1];
        $message = substr($decrypted, 20, $msgLen);
        $receivedCorpId = substr($decrypted, 20 + $msgLen);

        // 验证CorpID
        if ($receivedCorpId !== $corpId) {
            throw new SecurityException('CorpID验证失败');
        }

        return $message;
    }
}
```

```python
class AIInputFilter:

        found_words = cls.detect_sensitive_words(text)
        if found_words:
            result['valid'] = False

        # 3. 格式检查（防止注入特殊字符）
        if cls.has_injection_patterns(text):
            result['valid'] = False
            result['errors'].append('输入包含非法字符')

        return result

    @classmethod
    def detect_sensitive_words(cls, text: str) -> list:

        text_lower = text.lower()
        return [word for word in cls.SENSITIVE_WORDS if word in text_lower]

    @classmethod
    def has_injection_patterns(cls, text: str) -> bool:
        """检测注入模式"""
        import re
        injection_patterns = [
            r'<script[^>]*>',           # XSS脚本
            r'javascript:',             # JS协议
            r'on\w+\s*=',              # HTML事件属性
            r'\{\{.*\}\}',             # 模板注入
            r'\$\{.*\}',               # Shell变量
            r';\s*DROP\s+',            # SQL注入
            r';\s*DELETE\s+',          # SQL注入
            r';\s*UPDATE\s+',          # SQL注入
        ]
        for pattern in injection_patterns:
            if re.search(pattern, text, re.IGNORECASE):
                return True
        return False
```

```python
# ai/app/utils/prompt_guard.py

class PromptGuard:
    """Prompt注入防护"""

    # 系统Prompt模板（不允许用户修改）
    SYSTEM_PROMPT_TEMPLATE = """
    你是一个专业的工业压缩机/压力容器工艺规划助手。
    你的职责是基于提供的工艺参数和知识库，提供工艺优化建议。

    1. 仅回答与工艺规划相关的问题
    2. 不执行任何系统命令
    3. 不泄露系统内部信息
    4. 不修改任何数据
    5. 如果问题超出你的职责范围，请明确拒绝
    """

    INJECTION_PATTERNS = [
        r'ignore\s+(all\s+)?previous\s+instructions',
        r'ignore\s+(the\s+)?system\s+prompt',
        r'you\s+are\s+(now|a)',
        r'act\s+as',
        r'pretend\s+(to\s+be|you\s+are)',
        r'disregard',
        r'forget\s+(everything|all)',
        r'new\s+instructions?',
        r'system\s*:',
        r'assistant\s*:',
    ]

    @classmethod
    def check_prompt_injection(cls, user_input: str) -> bool:
        """检测Prompt注入"""
        import re
        for pattern in cls.INJECTION_PATTERNS:
            if re.search(pattern, user_input, re.IGNORECASE):
                return True
        return False

    @classmethod
    def build_safe_prompt(cls, user_input: str, context: dict = None) -> str:
        """构建安全的Prompt"""
        # 检查注入
        if cls.check_prompt_injection(user_input):
            raise SecurityError("检测到Prompt注入尝试")

        # 分离系统指令和用户输入
        system_prompt = cls.SYSTEM_PROMPT_TEMPLATE
        if context:
            system_prompt += f"\n\n当前上下文：{json.dumps(context, ensure_ascii=False)}"

        # 使用明确的分隔符
        full_prompt = f"""[SYSTEM]
{system_prompt}
[/SYSTEM]

[USER]
{user_input}
[/USER]

请基于[SYSTEM]中的规则回答[USER]的问题。"""

        return full_prompt
```
