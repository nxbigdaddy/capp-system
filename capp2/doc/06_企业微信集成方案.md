## 1. 企业微信集成概述

### 1.1 集成目标

本方案旨在将CAPP系统与企业微信平台深度集成，实现以下核心目标：

| 目标 | 说明 | 业务价值 |
|------|------|----------|
| **统一身份认证** | 通过企业微信扫码登录CAPP系统，实现单点登录 | 简化登录流程，提升用户体验，减少密码管理成本 |
| **消息通知推送** | 将工艺审批、变更通知、任务提醒等消息通过企业微信推送给相关人员 | 确保关键信息及时触达，避免审批延误 |
| **组织架构同步** | 将企业微信通讯录中的部门和人员信息同步到CAPP系统 | 保持组织架构一致性，减少人工维护工作量 |

### 1.2 企业微信应用架构

系统在企业微信中创建一个自建应用（CAPP工艺管理），作为CAPP系统与企业微信之间的桥梁。

## 2. 企业微信应用配置

### 2.1 创建自建应用步骤

在企业微信管理后台创建CAPP工艺管理应用的完整步骤：

**步骤1：登录企业微信管理后台**

访问 `https://work.weixin.qq.com/wework_admin/frame` ，使用管理员账号登录。

**步骤2：进入应用管理**

导航至 `应用管理` > `自建`，点击 `创建应用`。

**步骤3：填写应用基本信息**

| 配置项 | 值 | 说明 |
|--------|---|------|
| 应用名称 | CAPP工艺管理 | 显示在企业微信工作台中的应用名称 |
| 应用logo | 上传CAPP系统Logo | 建议尺寸144x144px |
| 应用介绍 | 计算机辅助工艺规划系统，用于工艺路线编制、审批与变更管理 | 应用功能简介 |
| 可见范围 | 全员或指定部门 | 设置哪些成员可以看到和使用此应用 |

**步骤4：获取应用凭证**

创建完成后，在应用详情页获取以下关键信息：

| 参数 | 示例值 | 说明 |
|------|--------|------|
| `AgentId` | `1000002` | 应用AgentId |
| `Secret` | `YOUR_WECOM_SECRET` | 应用Secret（需保密） |
| `CorpID` | `ww1234567890abcdef` | 企业ID |

**步骤5：配置应用主页**

| 配置项 | 值 |
|--------|---|
| 应用主页 | `https://capp.company.com/wechat/entry` |
| 企业微信授权登录 | 开启 |

1. 在企业微信管理后台 > 应用管理 > CAPP工艺管理 > 权限管理中申请

### 2.3 可信域名配置

在企业微信管理后台中配置可信域名，用于OAuth2.0授权回调：

| 配置项 | 值 |
|--------|---|
| 可信域名 | `capp.company.com` |

**注意事项：**

- 域名必须已完成ICP备案
- 域名必须支持HTTPS访问
- 不需要添加协议前缀（http://或https://）
- 配置后企业微信会向该域名发送验证请求，需确保服务器可正常响应

### 2.4 回调URL配置

在企业微信管理后台 > 应用管理 > CAPP工艺管理 > 接收消息 > 设置API接收 中配置回调URL：

| 配置项 | 值 |
|--------|---|
| URL | `https://capp.company.com/api/v1/wechat/callback` |
| Token | `capp_callback_token_2026` |
| EncodingAESKey | `YOUR_ENCODING_AES_KEY` |

**回调URL验证：** 配置时企业微信会发送GET请求进行验证，服务端需返回解密后的echostr。

## 3. 扫码登录方案

### 3.1 OAuth2.0授权流程

CAPP系统通过企业微信OAuth2.0协议实现扫码登录，用户使用企业微信App扫描二维码即可登录系统。

```mermaid
sequenceDiagram
    participant User as 用户
    participant Browser as 浏览器
    participant CAPP as CAPP系统
    participant WeChat as 企业微信服务器

    User->>Browser: 访问CAPP登录页
    Browser->>CAPP: GET /login
    CAPP-->>Browser: 返回登录页（含企业微信登录按钮）

    User->>Browser: 点击企业微信登录
    Browser->>WeChat: 重定向到企业微信OAuth2.0授权页<br/>GET https://open.work.weixin.qq.com/wwopen/sso/qrConnect?appid={CorpID}&redirect_uri={callback_url}&state={state}&usertype=member

    WeChat-->>User: 显示企业微信登录二维码
    User->>WeChat: 使用企业微信App扫码确认

    WeChat->>Browser: 302重定向到回调URL<br/>https://capp.company.com/api/v1/wechat/callback?code={auth_code}&state={state}

    Browser->>CAPP: GET /api/v1/wechat/callback?code={auth_code}&state={state}

    CAPP->>WeChat: POST https://qyapi.weixin.qq.com/cgi-bin/user/getuserinfo?access_token=YOUR_SECRET}&code={auth_code}

    WeChat-->>CAPP: 返回用户信息<br/>{UserId: "zhangsan", DeviceId: "..."}

    CAPP->>CAPP: 查询系统用户表<br/>根据wechat_userid关联系统用户

    alt 用户已绑定
        CAPP->>CAPP: 生成JWT Token
        CAPP-->>Browser: 302重定向到首页（携带Token）
        Browser->>CAPP: 后续请求携带Authorization头
    else 用户未绑定
        CAPP-->>Browser: 返回绑定提示页<br/>引导用户绑定系统账号
    end
```

### 3.2 PHP实现方案

#### 3.2.1 获取授权码（构造扫码登录URL）

```php
<?php
// src/Service/WeChat/WeChatOAuthService.php

class WeChatOAuthService
{
    // 企业微信配置
    private $corpId = 'ww1234567890abcdef';
    private $agentId = 1000002;
    private $secret = 'YOUR_WECOM_SECRET';
    private $callbackUrl = 'https://capp.company.com/api/v1/wechat/oauth/callback';

    /**
     * 构造企业微信扫码登录URL
     *
     * @param string $state 用于防止CSRF攻击的随机字符串
     * @return string 扫码登录页面URL
     */
    public function buildAuthUrl($state = '')
    {
        if (empty($state)) {
            $state = $this->generateState();
        }

        // 将state存入session，用于回调验证
        $_SESSION['wechat_oauth_state'] = $state;

        $params = [
            'appid'         => $this->corpId,
            'redirect_uri'  => urlencode($this->callbackUrl),
            'response_type' => 'code',
            'scope'         => 'snsapi_base',
            'state'         => $state,
            'agentid'       => $this->agentId,
            'usertype'      => 'member'
        ];

        $url = 'https://open.work.weixin.qq.com/wwopen/sso/qrConnect?' . http_build_query($params);

        return $url;
    }

    /**
     * 生成随机state字符串（防CSRF）
     *
     * @param int $length 字符串长度
     * @return string
     */
    private function generateState($length = 32)
    {
        $chars = 'abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789';
        $state = '';
        for ($i = 0; $i < $length; $i++) {
            $state .= $chars[random_int(0, strlen($chars) - 1)];
        }
        return $state;
    }
}
```

#### 3.2.2 获取用户身份（通过code换取userid）

```php
<?php
// src/Service/WeChat/WeChatOAuthService.php（续）

class WeChatOAuthService
{
    // ...（前面的属性和方法）

    /**
     * 通过授权码获取企业微信用户身份
     *
     * @param string $code OAuth2.0授权码
     * @return array|false 用户信息数组或false
     */
    public function getUserInfoByCode($code)
    {
        // 1. 获取AccessToken
        $accessToken = YOUR_SECRET);
        if (!$accessToken) {
            return false;
        }

        // 2. 通过code换取用户身份
        $url = "https://qyapi.weixin.qq.com/cgi-bin/user/getuserinfo?access_token=YOUR_SECRET}&code={$code}";

        $response = $this->httpGet($url);
        $result = json_decode($response, true);

        if (!$result || $result['errcode'] !== 0) {
            $this->logError('get_user_info_failed', $result);
            return false;
        }

        // 3. 如果用户不是企业成员（外部联系人），需要特殊处理
        if (empty($result['UserId'])) {
            $this->logError('user_not_member', $result);
            return false;
        }

        // 4. 获取用户详细信息
        $userInfo = $this->getUserDetail($accessToken, $result['UserId']);

        return $userInfo;
    }

    /**
     * 获取企业微信AccessToken
     *
     * @return string|false AccessToken或false
     */
    public function getAccessToken()
    {
        // 优先从缓存读取
        $cache = new CacheService();
        $token = YOUR_SECRET'wechat_access_token');

        if ($token) {
            return $token;
        }

        // 缓存未命中，请求企业微信API获取
        $url = "https://qyapi.weixin.qq.com/cgi-bin/gettoken?corpid={$this->corpId}&corpsecret={$this->secret}";

        $response = $this->httpGet($url);
        $result = json_decode($response, true);

        if (!$result || $result['errcode'] !== 0) {
            $this->logError('get_access_token_failed', $result);
            return false;
        }

        // 缓存AccessToken（提前5分钟过期，预留刷新时间）
        $expiresIn = $result['expires_in'] - 300;
        $cache->set('wechat_access_token', $result['access_token'], $expiresIn);

        return $result['access_token'];
    }

    /**
     * 获取企业微信用户详细信息
     *
     * @param string $accessToken
     * @param string $userId 企业微信用户ID
     * @return array|false
     */
    private function getUserDetail($accessToken, $userId)
    {
        $url = "https://qyapi.weixin.qq.com/cgi-bin/user/get?access_token=YOUR_SECRET}&userid={$userId}";

        $response = $this->httpGet($url);
        $result = json_decode($response, true);

        if (!$result || $result['errcode'] !== 0) {
            $this->logError('get_user_detail_failed', $result);
            return false;
        }

        return [
            'wechat_userid'   => $result['userid'],
            'wechat_name'     => $result['name'],
            'wechat_mobile'   => $result['mobile'] ?? '',
            'wechat_email'     => $result['email'] ?? '',
            'wechat_department' => $result['department'] ?? [],
            'wechat_position' => $result['position'] ?? '',
            'wechat_avatar'   => $result['avatar'] ?? '',
            'wechat_status'   => $result['status'] ?? 1
        ];
    }

    /**
     * HTTP GET请求封装
     *
     * @param string $url
     * @param int $timeout 超时时间（秒）
     * @return string|false
     */
    private function httpGet($url, $timeout = 10)
    {
        $ch = curl_init();
        curl_setopt_array($ch, [
            CURLOPT_URL            => $url,
            CURLOPT_RETURNTRANSFER => true,
            CURLOPT_TIMEOUT        => $timeout,
            CURLOPT_SSL_VERIFYPEER => true,
            CURLOPT_SSL_VERIFYHOST => 2,
            CURLOPT_FOLLOWLOCATION => true,
            CURLOPT_MAXREDIRS      => 3
        ]);

        $response = curl_exec($ch);
        $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
        $error = curl_error($ch);
        curl_close($ch);

        if ($error || $httpCode !== 200) {
            $this->logError('http_get_failed', [
                'url' => $url,
```

### 3.3 登录状态管理（JWT Token生成与验证）

```php
<?php
// src/Service/Auth/JwtService.php

class JwtService
{
    private $secretKey = 'YOUR_SECRET';
    private $accessTokenExpire = 86400;      // 24小时
    private $refreshTokenExpire = 604800;     // 7天

    /**
     * 生成JWT Token
     *
     * @param array $user 用户信息
     * @return array 包含access_token和refresh_token
     */
    public function generateToken($user)
    {
        $now = time();

        // Access Token Payload
        $accessPayload = [
            'iss'          => 'capp-system',
            'iat'          => $now,
            'exp'          => $now + $this->accessTokenExpire,
            'type'         => 'access',
            'user_id'      => $user['user_id'],
            'username'     => $user['username'],
            'real_name'    => $user['real_name'],
            'role_id'      => $user['role_id'],
            'department_id'=> $user['department_id']
        ];

        $accessToken = YOUR_SECRET);

        // Refresh Token Payload
        $refreshPayload = [
            'iss'     => 'capp-system',
            'iat'     => $now,
            'exp'     => $now + $this->refreshTokenExpire,
            'type'    => 'refresh',
            'user_id' => $user['user_id']
        ];

        $refreshToken = $this->encode($refreshPayload);

        return [
            'access_token'  => $accessToken,
            'refresh_token' => $refreshToken,
            'expires_in'    => $this->accessTokenExpire
        ];
    }

    /**
     * 验证JWT Token
     *
     * @param string $token
     * @return array|false
     */
    public function verifyToken($token)
    {
        try {
            $payload = $this->decode($token);

            if (!$payload) {
                return false;
            }

            // 检查是否过期
            if ($payload['exp'] < time()) {
                return false;
            }

            return $payload;
        } catch (Exception $e) {
            return false;
        }
    }

    /**
     * JWT编码（简化实现，生产环境建议使用firebase/php-jwt库）
     */
    private function encode($payload)
    {
        $header = ['alg' => 'HS256', 'typ' => 'JWT'];
        $headerEncoded = $this->base64UrlEncode(json_encode($header));
        $payloadEncoded = $this->base64UrlEncode(json_encode($payload));
        $signature = hash_hmac('sha256', $headerEncoded . '.' . $payloadEncoded, $this->secretKey, true);
        $signatureEncoded = $this->base64UrlEncode($signature);

        return $headerEncoded . '.' . $payloadEncoded . '.' . $signatureEncoded;
    }

    /**
     * JWT解码
     */
    private function decode($token)
    {
        $parts = explode('.', $token);
        if (count($parts) !== 3) {
            return false;
        }

        $headerEncoded = $parts[0];
        $payloadEncoded = $parts[1];
        $signatureEncoded = $parts[2];

        // 验证签名
        $expectedSignature = hash_hmac('sha256', $headerEncoded . '.' . $payloadEncoded, $this->secretKey, true);
        $expectedSignatureEncoded = $this->base64UrlEncode($expectedSignature);

        if (!hash_equals($expectedSignatureEncoded, $signatureEncoded)) {
            return false;
        }

        return json_decode($this->base64UrlDecode($payloadEncoded), true);
    }

    private function base64UrlEncode($data)
    {
        return rtrim(strtr(base64_encode($data), '+/', '-_'), '=');
    }

    private function base64UrlDecode($data)
    {
        $remainder = strlen($data) % 4;
        if ($remainder) {
            $data .= str_repeat('=', 4 - $remainder);
        }
        return base64_decode(strtr($data, '-_', '+/'));
    }
}
```

### 4.1 通讯录同步策略

采用**全量同步 + 增量同步**相结合的策略：

| 同步类型 | 频率 | 说明 |
|---------|------|------|
| **全量同步** | 每天凌晨2:00执行一次 | 完整同步所有部门和成员，确保数据一致性 |
| **增量同步** | 通过回调事件实时触发 | 监听通讯录变更回调，实时同步变更数据 |
| **手动同步** | 管理员在后台手动触发 | 用于紧急修复数据不一致问题 |

**同步规则：**

| 场景 | 处理规则 |
|------|---------|
| 企业微信新增成员 | 系统自动创建对应用户（状态为未激活） |
| 企业微信删除成员 | 系统用户标记为已离职（软删除，保留历史数据） |
| 企业微信更新成员信息 | 系统同步更新用户姓名、手机、邮箱等信息 |
| 企业微信新增部门 | 系统自动创建对应部门 |
| 企业微信删除部门 | 系统部门标记为已停用 |
| 企业微信调整部门层级 | 系统同步更新部门层级关系 |

```php
// src/Service/WeChat/WeChatUserSyncService.php

class WeChatUserSyncService
{
    private $db;

    public function __construct()
    {
        $this->db = Database::getInstance()->getConnection();
    }

    /**
     * 同步企业微信成员列表到系统
     *
     * @return array 同步结果统计
     */
    public function syncUsers()
    {
        $oauthService = new WeChatOAuthService();
        $accessToken = YOUR_SECRET);

        if (!$accessToken) {
            throw new Exception('获取AccessToken失败');
        }

        // 先同步部门（确保部门数据是最新的）
        $deptSync = new WeChatDeptSyncService();
        $deptSync->syncDepartments();

        // 获取全部部门列表
        $deptList = $this->getAllDepartments();
        $stats = ['created' => 0, 'updated' => 0, 'disabled' => 0];

        $this->db->beginTransaction();
        try {
            // 遍历每个部门获取成员
            foreach ($deptList as $dept) {
                $wechatDeptId = $dept['wechat_dept_id'];
                $localDeptId = $dept['department_id'];

                // 获取部门下的成员列表（分页获取）
                $fetchChild = 1; // 递归获取子部门成员
                $url = "https://qyapi.weixin.qq.com/cgi-bin/user/list?access_token=YOUR_SECRET}&department_id={$wechatDeptId}&fetch_child={$fetchChild}";

                $response = $this->httpGet($url);
                $result = json_decode($response, true);

                if (!$result || $result['errcode'] !== 0) {
                    $this->logError('sync_users_failed', [
                        'department_id' => $wechatDeptId,
                        'error' => $result['errmsg'] ?? '未知错误'
                    ]);
                    continue;
                }

                if (empty($result['userlist'])) {
                    continue;
                }

                foreach ($result['userlist'] as $member) {
                    $existingUser = $this->findUserByWechatId($member['userid']);

                    if ($existingUser) {
                        // 更新已有用户
                        $this->updateUser($existingUser['user_id'], $member, $localDeptId);
                        $stats['updated']++;
                    } else {
                        // 创建新用户
                        $this->createUser($member, $localDeptId);
                        $stats['created']++;
                    }
                }
            }

            $this->db->commit();
        } catch (Exception $e) {
            $this->db->rollBack();
            throw $e;
        }

        // 记录同步日志
        $this->logSync('user', 'full', $stats);

        return $stats;
    }

    /**
     * 创建用户
     */
    private function createUser($member, $departmentId)
    {
        // 生成系统用户名（企业微信userid作为用户名）
        $username = $member['userid'];

        // 生成随机初始密码（用户首次登录时需修改）
        $defaultPassword = md5('Capp@2026' . $username);

        $stmt = $this->db->prepare(
            "INSERT INTO sys_users (
                username, password, real_name, email, phone,
                wechat_userid, department_id, position, avatar,
                status, created_at, updated_at
            ) VALUES (
                :username, :password, :real_name, :email, :phone,
                :wechat_userid, :department_id, :position, :avatar,
                :status, NOW(), NOW()
            )"
        );

        // 状态映射：企业微信 1=已激活 2=已禁用 4=未激活 5=已退出
        $statusMap = [1 => 1, 2 => 0, 4 => 1, 5 => 0];
        $status = $statusMap[$member['status']] ?? 1;

        $stmt->execute([
            ':username'      => $username,
            ':password'      => $defaultPassword,
            ':real_name'     => $member['name'],
            ':email'         => $member['email'] ?? '',
            ':phone'         => $member['mobile'] ?? '',
            ':wechat_userid' => $member['userid'],
            ':department_id' => $departmentId,
            ':position'      => $member['position'] ?? '',
            ':avatar'        => $member['avatar'] ?? '',
            ':status'        => $status
        ]);
    }

    /**
     * 更新用户
     */
    private function updateUser($userId, $member, $departmentId)
    {
        $statusMap = [1 => 1, 2 => 0, 4 => 1, 5 => 0];
        $status = $statusMap[$member['status']] ?? 1;

        $stmt = $this->db->prepare(
            "UPDATE sys_users SET
                real_name = :real_name,
                email = :email,
                phone = :phone,
                department_id = :department_id,
                position = :position,
                avatar = :avatar,
                status = :status,
                updated_at = NOW()
            WHERE user_id = :user_id"
        );

        $stmt->execute([
            ':real_name'     => $member['name'],
            ':email'         => $member['email'] ?? '',
            ':phone'         => $member['mobile'] ?? '',
            ':department_id' => $departmentId,
            ':position'      => $member['position'] ?? '',
            ':avatar'        => $member['avatar'] ?? '',
            ':status'        => $status,
            ':user_id'       => $userId
        ]);
    }
}
```

### 4.6 定时任务设计（Cron定时同步）

```php
<?php
// src/Command/SyncCommand.php

class SyncCommand
{
    /**
     * 执行全量同步
     * 用法: php console.php sync:full
     */
    public function fullSync()
    {
        $startTime = microtime(true);
        echo "[" . date('Y-m-d H:i:s') . "] 开始全量通讯录同步...\n";

        try {
            $deptSync = new WeChatDeptSyncService();
            $deptStats = $deptSync->syncDepartments();
            echo "  部门同步完成: 新增{$deptStats['created']}, 更新{$deptStats['updated']}, 删除{$deptStats['deleted']}\n";

            $userSync = new WeChatUserSyncService();
            $userStats = $userSync->syncUsers();
            echo "  用户同步完成: 新增{$userStats['created']}, 更新{$userStats['updated']}, 禁用{$userStats['disabled']}\n";

            $elapsed = round(microtime(true) - $startTime, 2);
            echo "[" . date('Y-m-d H:i:s') . "] 全量同步完成，耗时{$elapsed}秒\n";

            // 同步成功后发送通知给管理员
            $this->notifyAdmin('full_sync_success', [
                'dept_stats' => $deptStats,
                'user_stats' => $userStats,
                'elapsed'    => $elapsed
            ]);

            return 0;
        } catch (Exception $e) {
            echo "[" . date('Y-m-d H:i:s') . "] 同步失败: " . $e->getMessage() . "\n";

            // 发送告警通知
            $this->notifyAdmin('full_sync_failed', [
                'error' => $e->getMessage()
            ]);

            return 1;
        }
    }

    /**
     * 通知管理员同步结果
     */
    private function notifyAdmin($type, $data)
    {
        $messageService = new WeChatMessageService();
        $adminUserId = 'admin'; // 管理员的企业微信UserID

        if ($type === 'full_sync_success') {
            $content = sprintf(
                "【通讯录同步完成】\n" .
                "同步时间: %s\n" .
                "部门: 新增%d, 更新%d, 删除%d\n" .
                "用户: 新增%d, 更新%d, 禁用%d\n" .
                "耗时: %.2f秒",
                date('Y-m-d H:i:s'),
                $data['dept_stats']['created'],
                $data['dept_stats']['updated'],
                $data['dept_stats']['deleted'],
                $data['user_stats']['created'],
                $data['user_stats']['updated'],
                $data['user_stats']['disabled'],
                $data['elapsed']
            );
        } else {
            $content = sprintf(
                "【通讯录同步失败】\n" .
                "时间: %s\n" .
                "错误: %s\n" .
                "请及时检查处理！",
                date('Y-m-d H:i:s'),
                $data['error']
            );
        }

        $messageService->sendText($adminUserId, $content);
    }
}
```

## 5. 消息推送方案

### 5.1 消息类型

CAPP系统通过企业微信应用向用户推送以下类型的消息：

| 消息类型 | 企业微信消息类型 | 适用场景 |
|---------|----------------|---------|
| **文本消息** | `text` | 简短通知、审批提醒、告警信息 |
| **图文消息** | `news` | 带有详情链接的通知，如工艺变更详情 |
| **Markdown卡片消息** | `markdown` | 格式化信息展示，如审批任务卡片 |
| **文件消息** | `file` | 工艺文档、检验报告等文件推送 |

### 5.2 应用消息推送（通过应用发送消息给指定用户）

```php
<?php
// src/Service/WeChat/WeChatMessageService.php

class WeChatMessageService
{
    private $corpId  = 'ww1234567890abcdef';
    private $agentId = 1000002;
    private $secret  = 'YOUR_WECOM_SECRET';

    /**
     * 发送文本消息
     *
     * @param string|array $userList 接收者（单个userid或数组）
     * @param string $content 消息内容
     * @param bool $safe 是否为保密消息
     * @return bool
     */
    public function sendText($userList, $content, $safe = false)
    {
        $userList = is_array($userList) ? implode('|', $userList) : $userList;

        $data = [
            'touser'  => $userList,
            'msgtype' => 'text',
            'agentid' => $this->agentId,
            'text'    => [
                'content' => $content
            ],
            'safe'    => $safe ? 1 : 0
        ];

        return $this->sendMessage($data);
    }

    /**
     * 发送Markdown消息
     *
     * @param string|array $userList 接收者
     * @param string $content Markdown内容
     * @return bool
     */
    public function sendMarkdown($userList, $content)
    {
        $userList = is_array($userList) ? implode('|', $userList) : $userList;

        $data = [
            'touser'  => $userList,
            'msgtype' => 'markdown',
            'agentid' => $this->agentId,
            'markdown'=> [
                'content' => $content
            ]
        ];

        return $this->sendMessage($data);
    }

    /**
     * 发送图文消息
     *
     * @param string|array $userList 接收者
     * @param array $articles 文章列表
     * @return bool
     */
    public function sendNews($userList, $articles)
    {
        $userList = is_array($userList) ? implode('|', $userList) : $userList;

        $data = [
            'touser'  => $userList,
            'msgtype' => 'news',
            'agentid' => $this->agentId,
            'news'    => [
                'articles' => $articles
            ]
        ];

        return $this->sendMessage($data);
    }

    /**
     * 发送文件消息
     *
     * @param string|array $userList 接收者
     * @param string $mediaId 文件媒体ID（需先上传临时素材）
     * @return bool
     */
    public function sendFile($userList, $mediaId)
    {
        $userList = is_array($userList) ? implode('|', $userList) : $userList;

        $data = [
            'touser'  => $userList,
            'msgtype' => 'file',
            'agentid' => $this->agentId,
            'file'    => [
                'media_id' => $mediaId
            ]
        ];

        return $this->sendMessage($data);
    }

    /**
     * 调用企业微信消息发送API
     *
     * @param array $data 消息数据
     * @return bool
     */
    private function sendMessage($data)
    {
        $oauthService = new WeChatOAuthService();
        $accessToken = YOUR_SECRET);

        if (!$accessToken) {
            throw new Exception('获取AccessToken失败');
        }

        $url = "https://qyapi.weixin.qq.com/cgi-bin/message/send?access_token=YOUR_SECRET}";
        $json = json_encode($data, JSON_UNESCAPED_UNICODE);

        $response = $this->httpPost($url, $json);
        $result = json_decode($response, true);

        if (!$result || $result['errcode'] !== 0) {
            $this->logError('send_message_failed', $result);
            return false;
        }

        // 记录消息发送日志
        $this->logMessageSent($data, $result);

        return true;
    }

    /**
     * HTTP POST请求
     */
    private function httpPost($url, $data, $timeout = 10)
    {
        $ch = curl_init();
        curl_setopt_array($ch, [
            CURLOPT_URL            => $url,
            CURLOPT_POST           => true,
            CURLOPT_POSTFIELDS     => $data,
            CURLOPT_RETURNTRANSFER => true,
            CURLOPT_TIMEOUT        => $timeout,
            CURLOPT_SSL_VERIFYPEER => true,
            CURLOPT_HTTPHEADER     => ['Content-Type: application/json']
        ]);

        $response = curl_exec($ch);
        curl_close($ch);

        return $response;
    }
```

### 5.4 PHP实现方案

#### 5.4.1 消息队列（RabbitMQ）异步推送

采用RabbitMQ实现消息异步推送，避免企业微信API调用阻塞业务流程。

```php
<?php
// src/Service/Queue/MessageQueueService.php

class MessageQueueService
{
    private $connection;
    private $channel;
    private $queueName = 'capp_wechat_message';

    public function __construct()
    {
        $config = [
            'host'     => '127.0.0.1',
            'port'     => 5672,
            'user'     => 'capp',
            'password' => 'capp_password',
            'vhost'    => '/capp'
        ];

        $this->connection = new AMQPConnection(
            $config['host'],
            $config['port'],
            $config['user'],
            $config['password'],
            $config['vhost']
        );
        $this->channel = $this->connection->channel();

        // 声明队列（持久化）
        $this->channel->queue_declare(
            $this->queueName,
            false,  // passive
            true,   // durable - 队列持久化
            false,  // exclusive
            false   // auto_delete
        );
    }

    /**
     * 推送消息到队列
     *
     * @param array $messageData 消息数据
     * @return bool
     */
    public function publish($messageData)
    {
        $message = new AMQPMessage(
            json_encode($messageData, JSON_UNESCAPED_UNICODE),
            ['delivery_mode' => AMQPMessage::DELIVERY_MODE_PERSISTENT]
        );

        $this->channel->basic_publish(
            $message,
            '',                    // exchange（使用默认exchange）
            $this->queueName       // routing_key
        );

        return true;
    }

    /**
     * 消费队列消息
     *
     * @param callable $callback 消息处理回调
     */
    public function consume($callback)
    {
        $this->channel->basic_qos(null, 1, null);

        $this->channel->basic_consume(
            $this->queueName,
            '',
            false,  // no_local
            false,  // no_ack
            false,  // exclusive
            false,  // no_wait
            function ($message) use ($callback) {
                try {
                    $data = json_decode($message->body, true);
                    $result = $callback($data);

                    if ($result) {
                        $message->ack();     // 处理成功，确认消息
                    } else {
                        $message->nack(true); // 处理失败，重新入队
                    }
                } catch (Exception $e) {
                    // 异常处理，记录日志后重新入队
                    $this->logError('queue_consume_error', $e->getMessage());
                    $message->nack(true);
                }
            }
        );

        while (count($this->channel->callbacks)) {
            $this->channel->wait();
        }
    }

    public function close()
    {
        $this->channel->close();
        $this->connection->close();
    }
}
```

## 6. 回调事件处理

### 6.1 通讯录变更回调（成员变更、部门变更）

企业微信在通讯录发生变更时，会向配置的回调URL发送POST请求。CAPP系统需要处理以下事件：

| 事件类型 | Event | 说明 | 处理动作 |
|---------|-------|------|---------|
| 成员新增 | `change_contact` + `ChangeType=create_user` | 新增成员 | 创建系统用户 |
| 成员更新 | `change_contact` + `ChangeType=update_user` | 更新成员信息 | 更新系统用户信息 |
| 成员删除 | `change_contact` + `ChangeType=delete_user` | 删除成员 | 标记用户为已离职 |
| 部门新增 | `change_contact` + `ChangeType=create_party` | 新增部门 | 创建系统部门 |
| 部门更新 | `change_contact` + `ChangeType=update_party` | 更新部门 | 更新系统部门信息 |
| 部门删除 | `change_contact` + `ChangeType=delete_party` | 删除部门 | 标记部门为已停用 |
| 成员离职 | `change_contact` + `ChangeType=leave_user` | 成员离职 | 标记用户为已离职 |

### 6.2 回调数据验证（签名验证、解密）

企业微信回调数据采用AES加密传输，服务端需进行签名验证和解密。

```php
<?php

class WeChatCallbackService

    /**
     * 验证回调URL（企业微信配置回调时的GET请求验证）
     *
     * @param string $msg_signature 签名
     * @param string $timestamp 时间戳
     * @param string $nonce 随机数
     * @param string $echostr 加密的随机字符串
     * @return string|false 解密后的echostr
     */
    public function verifyUrl($msgSignature, $timestamp, $nonce, $echostr)
    {
        // 1. 验证签名
        $signature = $this->generateSignature($token, $timestamp, $nonce, $echostr);

        if ($signature !== $msgSignature) {
            $this->logError('callback_verify_failed', [
                'expected' => $signature,
                'received' => $msgSignature
            ]);
            return false;
        }

        // 2. 解密echostr
        $decrypted = $this->decrypt($echostr);
        return $decrypted;
    }

    /**
     * 处理回调事件
     *
     * @param string $msgSignature 签名
     * @param string $timestamp 时间戳
     * @param string $nonce 随机数
     * @param string $postData 加密的XML数据
     * @return string 响应内容（"success"或加密的响应）
     */
    public function handleCallback($msgSignature, $timestamp, $nonce, $postData)
    {
        // 1. 验证签名
        $signature = $this->generateSignature($this->token, $timestamp, $nonce, $postData);

        if ($signature !== $msgSignature) {
            $this->logError('callback_signature_invalid', [
                'expected' => $signature,
                'received' => $msgSignature
            ]);
            return 'signature verification failed';
        }

        // 2. 解密数据
        $decryptedXml = $this->decrypt($postData);
        if (!$decryptedXml) {
            return 'decryption failed';
        }

        // 3. 解析XML
        $xml = simplexml_load_string($decryptedXml, 'SimpleXMLElement', LIBXML_NOCDATA);
        $data = json_decode(json_encode($xml), true);

        // 4. 根据事件类型分发处理
        $event = $data['Event'] ?? '';
        $changeType = $data['ChangeType'] ?? '';

        try {
            switch ($changeType) {
                case 'create_user':
                    $this->handleUserCreate($data);
                    break;
                case 'update_user':
                    $this->handleUserUpdate($data);
                    break;
                case 'delete_user':
                case 'leave_user':
                    $this->handleUserDelete($data);
                    break;
                case 'create_party':
                    $this->handleDeptCreate($data);
                    break;
                case 'update_party':
                    $this->handleDeptUpdate($data);
                    break;
                case 'delete_party':
                    $this->handleDeptDelete($data);
                    break;
                default:
                    $this->logError('unknown_callback_event', $data);
            }
        } catch (Exception $e) {
            $this->logError('callback_handle_error', [
                'event' => $changeType,
                'error' => $e->getMessage()
            ]);
        }

        // 5. 返回成功响应
        return 'success';
    }

    /**
     * 生成签名
     */
    private function generateSignature($token, $timestamp, $nonce, $encrypt)
    {
        $parts = [$token, $timestamp, $nonce, $encrypt];
        sort($parts, SORT_STRING);
        return sha1(implode($parts));
    }

    /**
     * AES解密
     */
    private function decrypt($encrypted)
    {
        $aesKey = base64_decode($this->encodingAesKey . '=');

        $ciphertext = base64_decode($encrypted);
        $iv = substr($ciphertext, 0, 16);
        $decrypted = openssl_decrypt(
            substr($ciphertext, 16),
            'AES-256-CBC',
            $aesKey,
            OPENSSL_RAW_DATA,
            $iv
        );

        if ($decrypted === false) {
            return false;
        }

        // 去除PKCS7填充
        $pad = ord(substr($decrypted, -1));
        $decrypted = substr($decrypted, 0, -$pad);

        // 去除16位随机字符串 + 4位msg_len + corpId
        $content = substr($decrypted, 16);
        $msgLen = unpack('N', substr($content, 0, 4))[1];
        $xmlContent = substr($content, 4, $msgLen);

        return $xmlContent;
    }
```

### 6.3 PHP回调处理实现

**回调入口控制器：**

```php
<?php
// src/Controller/WeChatCallbackController.php

class WeChatCallbackController
{
    private $callbackService;

    public function __construct()
    {
        $this->callbackService = new WeChatCallbackService();
    }

    /**
     * 处理GET请求（URL验证）
     * URL: GET /api/v1/wechat/callback
     */
    public function verify()
    {
        $msgSignature = $_GET['msg_signature'] ?? '';
        $timestamp    = $_GET['timestamp'] ?? '';
        $nonce        = $_GET['nonce'] ?? '';
        $echostr      = $_GET['echostr'] ?? '';

        $result = $this->callbackService->verifyUrl(
            $msgSignature, $timestamp, $nonce, $echostr
        );

        if ($result !== false) {
            header('Content-Type: text/plain');
            echo $result;
        } else {
            http_response_code(403);
            echo 'verification failed';
        }
    }

    /**
     * 处理POST请求（事件回调）
     * URL: POST /api/v1/wechat/callback
     */
    public function handleEvent()
    {
        $msgSignature = $_GET['msg_signature'] ?? '';
        $timestamp    = $_GET['timestamp'] ?? '';
        $nonce        = $_GET['nonce'] ?? '';

        // 获取POST原始数据（XML格式）
        $postData = file_get_contents('php://input');

        if (empty($postData)) {
            http_response_code(400);
            echo 'empty request body';
            return;
        }

        $result = $this->callbackService->handleCallback(
            $msgSignature, $timestamp, $nonce, $postData
        );

        header('Content-Type: text/plain');
        echo $result;
    }
}
```

## 7. 安全设计

### 7.1 AccessToken安全管理

**缓存策略：**

| 策略 | 说明 |
|------|------|
| 缓存介质 | Redis（推荐）或文件缓存 |
| 缓存键 | `capp:wechat:access_token` |
| 缓存时间 | 企业微信返回的expires_in减去300秒（提前5分钟刷新） |
| 自动刷新 | 每次使用前检查缓存，过期自动重新获取 |
| 并发控制 | 使用Redis SETNX避免并发刷新 |

```php
<?php
// src/Service/WeChat/AccessTokenManager.php

class AccessTokenManager
{
    private $corpId  = 'ww1234567890abcdef';
    private $secret  = 'YOUR_WECOM_SECRET';
    private $cacheKey = 'capp:wechat:access_token';
    private $lockKey  = 'capp:wechat:access_token:lock';

    /**
     * 获取AccessToken（带并发控制）
     */
    public function getToken()
    {
        $redis = $this->getRedis();

        // 1. 尝试从缓存获取
        $token = YOUR_SECRET);
        if ($token) {
            return $token;
        }

        // 2. 获取分布式锁（防止并发刷新）
        $lockAcquired = $redis->set($this->lockKey, '1', ['NX', 'EX' => 10]);
        if (!$lockAcquired) {
            // 其他进程正在刷新，等待后重试
            sleep(1);
            $token = YOUR_SECRET);
            return $token ?: false;
        }

        try {
            // 3. 请求企业微信API获取新Token
            $url = "https://qyapi.weixin.qq.com/cgi-bin/gettoken?corpid={$this->corpId}&corpsecret={$this->secret}";
            $response = $this->httpGet($url);
            $result = json_decode($response, true);

            if (!$result || $result['errcode'] !== 0) {
                return false;
            }

            // 4. 缓存Token（提前5分钟过期）
            $expiresIn = $result['expires_in'] - 300;
            $redis->set($this->cacheKey, $result['access_token'], $expiresIn);

            return $result['access_token'];
        } finally {
            // 5. 释放锁
            $redis->del($this->lockKey);
        }
    }
}
```

### 7.3 回调事件签名验证

每次收到企业微信回调时，必须验证签名以确保请求来自企业微信服务器而非伪造。

**验证流程：**

1. 获取请求参数：`msg_signature`、`timestamp`、`nonce`、`echostr`（GET验证）或POST body（事件回调）
2. 将 `token`、`timestamp`、`nonce`、`encrypt` 按字典序排序后拼接
3. 对拼接字符串进行SHA1哈希，得到签名
4. 将计算得到的签名与请求中的 `msg_signature` 比较
5. 签名一致则验证通过，否则拒绝请求

（签名验证代码见6.2节 `generateSignature` 方法）

## 8. 错误处理与日志

### 8.1 企业微信API调用错误码处理

| 错误码 | 说明 | 处理方式 |
|--------|------|---------|
| 0 | 成功 | 正常处理 |
| -1 | 系统繁忙 | 重试（指数退避） |
| 40001 | 不合法的access_token | 清除缓存，重新获取Token后重试 |
| 40014 | 不合法的access_token | 同上 |
| 40029 | 不合法的code | 提示用户重新扫码 |
| 41001 | 缺少access_token | 重新获取Token |
| 42001 | access_token已超时 | 清除缓存，重新获取Token |
| 43004 | 需要接收者关注 | 记录日志，跳过发送 |
| 45009 | 接口调用超过限制 | 等待后重试 |
| 45047 | 客服接口下发消息被限制 | 等待后重试 |
| 60011 | 不合法的部门id | 记录日志，跳过同步 |
| 60123 | 部门个数超出限制 | 通知管理员 |
| 60131 | 用户个数超出限制 | 通知管理员 |
| 86000 | 消息已读 | 无需处理 |
| 86001 | 消息被拒收 | 记录日志 |

```php
<?php
// src/Service/WeChat/WeChatErrorHandler.php

class WeChatErrorHandler
{
    /**
     * 处理企业微信API错误
     *
     * @param int $errcode 错误码
     * @param string $errmsg 错误信息
     * @param string $apiName API名称
     * @return bool true=可重试 false=不可重试
     */
    public static function handle($errcode, $errmsg, $apiName)
    {
        switch ($errcode) {
            case 0:
                return false;

            case 40001:
            case 40014:
            case 42001:
                // Token相关错误，清除缓存
                $cache = new CacheService();
                $cache->delete('wechat_access_token');
                self::log('token_error', $apiName, $errcode, $errmsg);
                return true; // 可重试

            case 40029:
                self::log('invalid_code', $apiName, $errcode, $errmsg);
                return false; // 不可重试，需用户重新操作

            case -1:
            case 45009:
            case 45047:
                self::log('rate_limit', $apiName, $errcode, $errmsg);
                return true; // 可重试（需等待）

            default:
                self::log('api_error', $apiName, $errcode, $errmsg);
                return false;
        }
    }

    /**
     * 记录错误日志
     */
    private static function log($type, $apiName, $errcode, $errmsg)

        );

            ':type'     => $type,
            ':api_name' => $apiName,

        ]);
    }
}
```

### 8.2 重试机制设计

采用**指数退避重试策略**，避免频繁重试导致被限流。

```php
<?php
// src/Service/WeChat/WeChatRetryService.php

class WeChatRetryService
{
    private $maxRetries = 3;
    private $baseDelay  = 1000;  // 基础延迟1秒
    private $maxDelay   = 30000; // 最大延迟30秒

    /**
     * 带重试的API调用
     *
     * @param callable $apiCall API调用闭包
     * @param string $apiName API名称（用于日志）
     * @return array|false API响应数据
     */
    public function callWithRetry($apiCall, $apiName)
    {
        $lastError = null;

        for ($attempt = 1; $attempt <= $this->maxRetries; $attempt++) {
            try {
                $response = $apiCall();
                $result = json_decode($response, true);

                if ($result && $result['errcode'] === 0) {
                    return $result;
                }

                $errcode = $result['errcode'] ?? -1;
                $errmsg  = $result['errmsg'] ?? '未知错误';

                // 判断是否可重试
                $retryable = WeChatErrorHandler::handle($errcode, $errmsg, $apiName);

                if (!$retryable) {
                    return false;
                }

                $lastError = $errmsg;

                // 指数退避等待
                if ($attempt < $this->maxRetries) {
                    $delay = min($this->baseDelay * pow(2, $attempt - 1), $this->maxDelay);
                    $delay += random_int(0, 500); // 添加随机抖动
                    usleep($delay * 1000); // 微秒
                }
            } catch (Exception $e) {
                $lastError = $e->getMessage();

                if ($attempt < $this->maxRetries) {
                    $delay = min($this->baseDelay * pow(2, $attempt - 1), $this->maxDelay);
                    usleep($delay * 1000);
                }
            }
        }

        // 重试耗尽，记录最终错误
        WeChatErrorHandler::log('retry_exhausted', $apiName, -1, $lastError);
        return false;
    }
}
```

**重试策略参数：**

| 参数 | 值 | 说明 |
|------|---|------|
| 最大重试次数 | 3 | 超过3次不再重试 |
| 基础延迟 | 1秒 | 第一次重试等待1秒 |
| 退避因子 | 2 | 每次重试延迟翻倍 |
| 最大延迟 | 30秒 | 单次等待上限 |
| 随机抖动 | 0-500ms | 避免多个请求同时重试 |

**日志记录中间件：**

```php
<?php
// src/Service/WeChat/WeChatApiLogger.php

class WeChatApiLogger
{
    private $db;

    /**
     * 记录API调用日志
     *
     * @param string $apiName API名称
     * @param string $url 请求URL
     * @param array $requestData 请求数据
     * @param array $responseData 响应数据
     * @param int $duration 耗时（毫秒）
     * @param int $retryCount 重试次数
     */
    public function log($apiName, $url, $requestData, $responseData, $duration, $retryCount = 0)
    {
        $errcode = $responseData['errcode'] ?? 0;
        $errmsg  = $responseData['errmsg'] ?? '';

        // 脱敏处理
        $safeUrl = $this->maskSensitiveInfo($url);
        $safeRequest = $this->maskSensitiveData($requestData);
        $safeResponse = $this->maskSensitiveData($responseData);

        $stmt = $this->db->prepare(
            "INSERT INTO wechat_api_logs (
                log_type, api_name, request_url, request_data,
                response_data, errcode, errmsg, duration, retry_count, created_at
            ) VALUES (
                'api_call', :api_name, :request_url, :request_data,
                :response_data, :errcode, :errmsg, :duration, :retry_count, NOW()
            )"
        );

        $stmt->execute([
            ':api_name'      => $apiName,
            ':request_url'   => $safeUrl,
            ':request_data'  => json_encode($safeRequest, JSON_UNESCAPED_UNICODE),
            ':response_data' => json_encode($safeResponse, JSON_UNESCAPED_UNICODE),
            ':errcode'       => $errcode,
            ':errmsg'        => $errmsg,
            ':duration'      => $duration,
            ':retry_count'   => $retryCount
        ]);
    }

    /**
     * 脱敏处理URL中的敏感信息
     */
    private function maskSensitiveInfo($url)
    {
        return preg_replace('/access_token=[^&]+/', 'access_token=***', $url);
    }

    /**
     * 脱敏处理数据中的敏感字段
     */
    private function maskSensitiveData($data)
    {
        if (!is_array($data)) {
            return $data;
        }

        $sensitiveKeys = ['access_token', 'secret', 'password', 'mobile', 'phone'];

        foreach ($data as $key => $value) {
            if (in_array(strtolower($key), $sensitiveKeys)) {
                $data[$key] = '***';
            }
        }

        return $data;
    }
}
```
