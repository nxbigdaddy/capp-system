## 1. 项目概述

### 1.1 项目背景

随着制造业数字化转型的深入推进，计算机辅助工艺规划（Computer Aided Process Planning，CAPP）已成为制造企业实现工艺数字化、提升生产效率的关键环节。本公司作为工业压缩机和压力容器的研发、设计、生产企业，产品涉及精密机械加工、特种焊接、无损检测、压力试验等多类复杂工艺，工艺管理难度大、专业性强、质量要求高。

当前企业工艺管理主要依赖人工编制Excel/Word文档，存在工艺数据分散、版本控制困难、审批流程低效、与设计端（PLM）和生产端（MES/ERP）信息孤岛严重等问题。为解决上述问题，企业决定建设一套专业的CAPP系统，实现工艺规划的数字化、标准化和智能化，打通设计-工艺-制造的数据链路，提升企业整体运营效率。

### 1.2 项目目标

| 目标类别 | 具体目标 |
|---------|---------|
| **效率提升** | 工艺编制效率提升50%以上，工艺审批周期缩短60%以上 |
| **质量保障** | 工艺文件标准化率达到95%以上，工艺错误率降低80%以上 |
| **数据贯通** | 实现EBOM-PBOM-MBOM的数据贯通，打通PLM-ERP-MES数据链路 |
| **知识沉淀** | 建立企业标准工艺库，沉淀工艺知识，支撑新工艺快速复用 |
| **智能辅助** | 引入AI能力，实现工艺参数智能推荐和工艺方案优选 |
| **移动协同** | 通过企业微信实现移动审批、消息推送和扫码应用 |

### 1.3 项目范围

**纳入范围**：

- 工业压缩机全系列产品（含气缸体、曲轴箱、膜片组件、气阀组件等核心零部件）的工艺规划与管理
- 压力容器全系列产品（含筒体、封头、法兰、接管等核心部件）的工艺规划与管理
- 工艺路线设计、工艺卡片编制、BOM管理、资源管理、质量管理等核心业务
- 企业微信集成（扫码登录、用户同步、消息推送）
- AI辅助决策（工艺参数推荐、工艺方案优选、智能问答）
- 外部系统集成（CAXA PLM、用友U8、MES系统）

**不纳入范围**：

- CAD三维设计功能（由CAXA PLM承担）
- ERP财务模块（由用友U8承担）
- MES车间执行层功能（由MES系统承担）
- 硬件设备直接控制

## 2. 企业现状分析

### 2.1 工业压缩机工艺特点

工业压缩机是一种特殊结构的容积式压缩机，其核心特点是气体被金属膜片与液压油系统完全隔离，因此对零部件的加工精度、密封性能和可靠性要求极高。主要工艺特点如下：

#### 2.1.1 核心零部件及工艺

| 零部件 | 材料 | 关键工艺 | 工艺难点 |
|--------|------|---------|---------|
| **膜片** | 不锈钢（316L/301） | 冲压成型、热处理、表面处理 | 厚度公差控制（0.1-0.5mm）、疲劳寿命、表面粗糙度 |
| **缸体/缸盖** | 铸钢/锻钢 | 铸造/锻造、机加工、表面处理 | 腔体加工精度（形位公差IT6-IT7）、密封面加工 |
| **曲轴** | 合金钢（40Cr/42CrMo） | 锻造、调质处理、机加工、磨削 | 轴颈尺寸精度、表面硬度（HRC55-62）、动平衡 |
| **连杆** | 合金钢 | 锻造、调质处理、机加工 | 大小头孔精度、两孔平行度 |
| **油缸体** | 铸铁/铸钢 | 铸造、机加工、珩磨 | 缸体内孔精度、表面粗糙度（Ra0.4） |
| **气阀组件** | 不锈钢/合金钢 | 精密机加工、研磨 | 阀片平面度、密封面粗糙度 |
| **配管/管接头** | 不锈钢 | 弯管、焊接、探伤 | 焊接质量、壁厚减薄控制 |
| **密封件** | 聚四氟乙烯/橡胶 | 模压、机加工 | 尺寸精度、材料性能一致性 |

#### 2.1.2 典型工艺路线

```
原材料入库 → 材料检验 → 下料（锯切/激光切割） → 锻造/铸造 →
热处理（正火/退火/调质） → 粗加工 → 半精加工 → 热处理（淬火/渗碳） →
精加工 → 特种加工（磨削/珩磨/研磨） → 表面处理（电镀/喷涂） →
清洗/防锈 → 装配 → 试验 → 检验 → 入库
```

#### 2.1.3 工艺管理特殊要求

- **精度要求高**：关键零部件尺寸公差在微米级，需严格管控加工参数
- **工艺路线长**：单件产品加工工序多达30-50道，工序间衔接复杂
- **热处理穿插多**：粗加工-热处理-精加工的交替频繁，需精确控制热处理工艺参数
- **特殊检测要求**：需进行硬度检测、金相检测、尺寸检测（三坐标测量）、密封试验等
- **试制工艺多**：新产品开发阶段工艺变更频繁，需灵活支持工艺迭代

### 2.2 压力容器工艺特点

压力容器属于特种设备，其设计、制造、检验均需严格遵循国家相关法规和标准（GB 150、TSG 21等），工艺管理具有法规强制性和高度规范性。

#### 2.2.1 核心部件及工艺

| 部件 | 材料 | 关键工艺 | 法规/标准要求 |
|------|------|---------|--------------|
| **筒体** | Q345R/16MnR/不锈钢 | 卷板、纵缝焊接、校圆 | GB 150、NB/T 47014焊接评定 |
| **封头** | 同筒体材料 | 冲压/旋压成型、热处理 | GB/T 25198封头标准 |
| **法兰** | 锻钢 | 锻造、机加工、钻孔 | HG/T 20592-20635法兰标准 |
| **接管** | 同筒体材料 | 下料、机加工、焊接 | GB 150接管要求 |
| **人孔/手孔** | 锻钢+不锈钢 | 机加工、焊接 | GB 150 |
| **支座** | Q235B/Q345B | 下料、焊接、机加工 | JB/T 4712支座标准 |

#### 2.2.2 焊接工艺（核心工艺）

压力容器的焊接工艺是最核心、最复杂的工艺环节：

| 焊接方法 | 适用场景 | 坡口形式 | 焊接位置 | 检测要求 |
|---------|---------|---------|---------|---------|
| SAW（埋弧自动焊） | 筒体纵缝/环缝 | V型/U型/X型 | 平焊 | 100%RT或UT |
| GTAW（氩弧焊） | 管子-管板、接管焊接 | V型 | 全位置 | 100%RT+PT |
| SMAW（手工电弧焊） | 返修焊、附件焊接 | V型 | 全位置 | 按比例RT/UT |
| GMAW（气体保护焊） | 角焊缝、附件焊接 | 单V/角焊 | 全位置 | MT/PT |

**焊接工艺管理要求**：
- 必须依据焊接工艺评定（PQR）编制焊接工艺规程（WPS）
- 焊工必须持有相应项目的特种设备作业人员证
- 焊接材料（焊条、焊丝、焊剂）需烘焙、保温管理
- 焊缝需进行焊缝编号、焊工钢印标识
- 焊缝返修需编制返修方案并经审批

#### 2.2.3 无损检测工艺

| 检测方法 | 适用对象 | 执行标准 | 合格级别 |
|---------|---------|---------|---------|
| RT（射线检测） | A类/B类焊缝 | NB/T 47013.2 | AB级II级 |
| UT（超声波检测） | A类/B类焊缝、锻件 | NB/T 47013.3 | I级 |
| MT（磁粉检测） | 角焊缝、表面缺陷 | NB/T 47013.4 | I级 |
| PT（渗透检测） | 不锈钢焊缝、表面缺陷 | NB/T 47013.5 | I级 |

#### 2.2.4 典型工艺路线

```
材料入库 → 材料复验（理化检测） → 材料标记移植 → 下料（数控切割） →
坡口加工 → 卷板/冲压成型 → 焊前预热 → 组对定位焊 → 焊接（多层多道） →
焊后热处理（PWHT） → 无损检测（NDT） → 焊缝返修（如需要） →
总装 → 焊接 → 无损检测 → 压力试验（水压/气压试验） →
气密性试验 → 表面处理/涂装 → 包装 → 出厂检验
```

### 2.3 当前工艺管理痛点

#### 2.3.1 工艺编制效率低

- 工艺文件（工艺路线卡、工序卡、作业指导书等）主要使用Word/Excel手工编制，重复工作量大
- 相似零件的工艺无法快速复用，每次都需从零开始编制
- 工艺参数（切削参数、焊接参数等）依赖工程师个人经验，缺乏系统化积累
- 工艺卡片格式不统一，不同工程师编制风格差异大

#### 2.3.2 工艺数据孤岛严重

- 设计BOM（EBOM）在CAXA PLM中管理，工艺BOM（PBOM）和制造BOM（MBOM）需手工转换
- 工艺数据无法直接传递给U8 ERP（物料、采购）和MES（工单、报工），需反复手工录入
- 图纸在PLM中管理，工艺人员需反复切换系统查看，效率低下
- 物料编码、工艺路线编码等缺乏统一规范，各系统间数据对不上

#### 2.3.3 版本控制困难

- 工艺文件版本管理混乱，修改后无法追溯历史版本
- 同一零件存在多个版本的工艺文件，生产现场使用版本不明确
- 工艺变更后，相关联的BOM、定额、作业指导书无法同步更新
- ECN（工程变更通知）执行后，工艺变更的闭环管理缺失

#### 2.3.4 审批流程低效

- 工艺审批采用纸质签字或邮件流转，周期长、效率低
- 审批状态无法实时追踪，经常出现"卡在某个环节"的情况
- 工艺主管出差时无法及时审批，影响生产进度
- 审批意见缺乏结构化记录，不便于后续追溯

#### 2.3.5 质量管控薄弱

- 质量控制点（焊接参数、热处理参数、检测要求等）分散在多份文档中
- 特种设备法规要求的追溯性信息（焊工、材料、检测报告）缺乏系统化管理
- 工艺纪律检查缺乏信息化手段支撑
- 质量问题与工艺参数的关联分析能力不足

#### 2.3.6 知识沉淀不足

- 资深工艺工程师的经验知识以个人笔记或记忆形式存在，人员流动导致知识流失
- 缺乏标准工艺库和典型工艺路线库，无法支撑新工艺快速编制
- 工艺问题解决案例缺乏系统化记录和检索手段
- 新员工培训周期长，缺乏智能化的工艺知识辅助工具

## 3. 业务需求分析

### 3.1 工艺路线管理

#### 3.1.1 业务场景

工艺路线是描述零部件从毛坯到成品的全部加工过程的核心数据，是连接产品设计与生产制造的桥梁。对于工业压缩机和压力容器产品，工艺路线管理需要支持复杂的多工序编排和灵活的工序调整。

#### 3.1.2 功能需求

| 需求编号 | 需求名称 | 需求描述 | 优先级 |
|---------|---------|---------|--------|
| BR-RT-001 | 工艺路线创建 | 支持基于EBOM节点创建工艺路线，可手动添加或从标准工艺库导入工序 | P0 |
| BR-RT-002 | 工序编排 | 支持工序的增删改查、拖拽排序、工序合并/拆分，支持并行工序定义 | P0 |
| BR-RT-003 | 工序属性定义 | 每道工序可定义工序名称、工序编号、工作中心、标准工时、准备工时、工装夹具、质量控制点等属性 | P0 |
| BR-RT-004 | 工艺路线版本管理 | 支持工艺路线的版本创建、版本对比、版本回退，每次修改自动生成新版本 | P0 |
| BR-RT-005 | 工艺路线复制 | 支持从已有工艺路线复制创建新路线，支持选择性复制（全部工序或指定工序） | P1 |
| BR-RT-006 | 工艺路线审批 | 支持工艺路线的提交审批、审批流程配置、审批意见填写、审批撤回 | P0 |
| BR-RT-007 | 工艺路线查询 | 支持按产品、零部件、工艺路线编号、状态等多维度查询和检索 | P1 |
| BR-RT-008 | 工艺路线导入导出 | 支持工艺路线数据的Excel导入导出，支持批量操作 | P2 |
| BR-RT-009 | 替代工艺路线 | 支持为同一零部件定义多条替代工艺路线（如不同设备方案），并标记主/备选 | P1 |
| BR-RT-010 | 工艺路线BOM关联 | 工艺路线与PBOM节点关联，支持按工序展开物料需求 | P0 |

### 3.2 工艺卡片管理

#### 3.2.1 业务场景

工艺卡片是工艺规程的核心载体，用于指导车间生产操作。工业压缩机和压力容器企业需要管理多种类型的工艺卡片，包括工序卡片、工步卡片、检验卡片等。卡片格式需符合行业标准和企业规范。

#### 3.2.2 功能需求

| 需求编号 | 需求名称 | 需求描述 | 优先级 |
|---------|---------|---------|--------|
| BR-CD-001 | 工序卡片管理 | 支持按工序生成标准工序卡片，包含工序内容、加工设备、工装夹具、切削参数、工时定额等信息 | P0 |
| BR-CD-002 | 工步卡片管理 | 支持在工序卡片下细化工步，每个工步可定义具体操作内容、加工参数、辅助材料等 | P0 |

## 5. 非功能需求

### 5.1 性能要求

| 指标 | 要求 | 说明 |
|------|------|------|
| 页面响应时间 | <= 3秒（95%请求） | 普通页面加载和操作响应时间 |
| 复杂查询响应 | <= 5秒（95%请求） | BOM展开、工艺路线查询等复杂操作 |
| 并发用户数 | >= 100 | 系统同时在线用户数 |
| 峰值并发 | >= 200 | 考虑早晚高峰时段 |
| 数据库查询 | <= 1秒（单表） | 单表简单查询响应时间 |
| 文件上传 | 支持100MB单文件 | 工艺文件、图纸上传 |
| 文件下载 | >= 5MB/s | 局域网环境下文件下载速度 |
| API响应时间 | <= 500ms | 后端接口平均响应时间 |
| 系统可用性 | >= 99.5% | 月度系统可用时间比例 |

### 5.2 安全要求

| 类别 | 要求 | 说明 |
|------|------|------|
| 身份认证 | 企业微信OAuth2.0认证 | 基于企业微信的统一身份认证 |
| 会话管理 | Token + Redis会话管理 | JWT Token认证，Redis存储会话 |
| 密码策略 | 符合等保要求 | 密码复杂度、过期策略、登录失败锁定 |
| 权限控制 | RBAC权限模型 | 基于角色的访问控制，支持数据级权限 |
| 数据加密 | 传输层TLS加密 | 全站HTTPS，敏感数据加密存储 |
| SQL注入防护 | 参数化查询 | 所有数据库操作使用预处理语句 |
| XSS防护 | 输入过滤和输出转义 | 防止跨站脚本攻击 |
| CSRF防护 | Token验证 | 防止跨站请求伪造 |
| 操作审计 | 全量操作日志 | 记录用户所有关键操作，支持审计追溯 |
| 数据备份 | 每日全量+实时增量 | 数据库定时备份，支持快速恢复 |
| 文件安全 | 文件类型白名单 | 上传文件类型限制和病毒扫描 |

### 6.3 角色使用场景

#### 工艺工程师

- 接收PLM同步的EBOM数据，查看产品图纸
- 基于EBOM创建PBOM，调整BOM结构
- 编制工艺路线，编排工序，定义工序属性
- 编制各类工艺卡片（工序卡、焊接卡、热处理卡等）
- 编制材料定额和工时定额
- 定义工序质量控制点
- 从标准工艺库检索和引用标准工艺
- 使用AI助手获取工艺参数推荐和工艺知识问答
- 提交工艺文件审批，处理审批驳回意见
- 发起工艺变更申请

#### 工艺主管

- 审核工艺路线、工艺卡片、BOM等工艺文件
- 审批工艺变更申请
- 管理标准工艺库，审核入库申请
- 监控工艺编制进度和审批状态
- 分析工艺执行数据，优化工艺方案
- 管理工艺团队工作分配

#### 生产主管

- 查看已发布的工艺路线和作业指导书
- 反馈工艺执行中的问题和改进建议
- 参与工艺可制造性评审
- 查看生产进度与工艺计划的匹配情况

#### 质量工程师

- 审核工序质量控制点的合理性
- 录入和管理质量检测数据
- 进行质量追溯分析
- 处理不合格品，关联工艺参数分析原因

#### 车间操作员

- 在生产现场通过终端查看作业指导书
- 扫描二维码快速定位工艺文件
- 录入工序完工信息和质量数据
- 反馈工艺执行中的异常情况

#### 系统管理员

- 管理用户账号和角色权限
- 配置系统参数和数据字典
- 监控系统运行状态
- 管理外部系统集成配置
- 执行数据备份和恢复
- 查看系统操作日志
