## 1. 部署概述

### 1.1 部署架构原则

本CAPP系统部署遵循以下核心原则：

| 原则 | 说明 |
|------|------|
| **高可用** | 核心组件均采用主从/集群部署，单点故障不影响系统整体运行，可用性目标 >= 99.9% |
| **可扩展** | 应用层无状态设计，支持水平扩展；数据层支持读写分离和分库分表 |
| **易维护** | 标准化部署流程，自动化运维工具，完善的监控告警体系 |
| **安全性** | 网络分区隔离，最小权限原则，数据传输与存储加密 |
| **可追溯** | 完整的部署版本管理，操作审计日志，变更记录可追溯 |

### 1.2 部署架构总览

系统采用分层分布式部署架构，整体分为以下层次：

```
┌─────────────────────────────────────────────────────────────┐
│                        接入层                                │
│   Nginx负载均衡 + SSL终止 + WAF防护 + 静态资源缓存           │
├─────────────────────────────────────────────────────────────┤
│                        应用层                                │
│   PHP-FPM集群（无状态）  │  Vue前端静态资源  │  AI服务集群     │
├─────────────────────────────────────────────────────────────┤
│                       中间件层                               │
│   Redis缓存/会话  │  RabbitMQ消息队列  │  Elasticsearch搜索  │
├─────────────────────────────────────────────────────────────┤
│                        数据层                                │
│   MySQL主从集群  │  MinIO对象存储（文件/图纸/工艺文档）       │
├─────────────────────────────────────────────────────────────┤
│                       基础设施层                              │
│   CentOS/Ubuntu  │  Docker（可选容器化）  │  监控/日志采集    │
└─────────────────────────────────────────────────────────────┘
```

### 1.3 部署环境要求

| 环境 | 用途 | 规模 |
|------|------|------|
| **开发环境** | 开发人员日常开发与调试 | 单机部署，资源最小化配置 |
| **测试环境** | 功能测试、集成测试、性能测试 | 模拟生产环境架构，资源减半 |

## 2. 服务器规划

### 2.1 应用服务器配置

应用服务器承载PHP-FPM进程和Nginx服务，属于无状态服务，支持水平扩展。

| 配置项 | 最低配置 | 推荐配置 | 说明 |
|--------|----------|----------|------|
| CPU | 8核 | 16核 | PHP-FPM进程密集型，建议高频多核 |
| 内存 | 16GB | 32GB | PHP进程池 + OPcache缓存 |
| 系统盘 | 100GB SSD | 200GB SSD | 操作系统 + 应用代码 + 日志 |
| 数据盘 | 200GB SSD | 500GB SSD | 临时文件、会话文件、缓存 |
| 网络 | 千兆网卡 | 万兆网卡 | 内网通信带宽 |
| 数量 | 2台（最低） | 3台（推荐） | Nginx主备 + PHP-FPM集群 |

**PHP-FPM进程规划**：

```ini
; 根据内存计算进程数
; 公式：总内存 / (每个进程内存 × 1.2) = 最大进程数
; 32GB服务器，每进程约64MB，最大进程数 ≈ 400

pm = dynamic
pm.max_children = 400
pm.start_servers = 40
pm.min_spare_servers = 20
pm.max_spare_servers = 80
pm.max_requests = 1000
```

### 2.2 数据库服务器配置

MySQL数据库承载CAPP系统核心业务数据，包括工艺路线、BOM、物料、工序等关键数据。

| 配置项 | 主库配置 | 从库配置 | 说明 |
|--------|----------|----------|------|
| CPU | 16核 | 8核 | 主库承担写操作，需要更高计算能力 |
| 内存 | 64GB | 32GB | InnoDB缓冲池建议为物理内存的70%-80% |
| 系统盘 | 200GB SSD | 100GB SSD | 操作系统 + MySQL程序 |
| 数据盘 | 1TB NVMe SSD | 1TB SATA SSD | 数据文件 + InnoDB表空间 + Binlog |
| 网络 | 万兆网卡 | 万兆网卡 | 主从复制需要高带宽低延迟 |
| 数量 | 1台 | 2台 | 1主2从，从库可用于读操作和备份 |

**MySQL关键参数**：

```ini
[mysqld]
# InnoDB缓冲池
innodb_buffer_pool_size = 40G          # 主库：物理内存的70%
innodb_buffer_pool_instances = 8

# 连接数
max_connections = 1000
max_connect_errors = 1000

# 日志配置
binlog_format = ROW
expire_logs_days = 7
sync_binlog = 1
innodb_flush_log_at_trx_commit = 1

# 查询缓存（MySQL 8.0已移除，使用Redis替代）

# 临时表
tmp_table_size = 256M
max_heap_table_size = 256M

# 排序缓冲
sort_buffer_size = 4M
join_buffer_size = 4M
```

### 2.3 Redis服务器配置

Redis用于会话管理、数据缓存、分布式锁、消息发布订阅等场景。

| 配置项 | 配置 | 说明 |
|--------|------|------|
| CPU | 8核 | Redis单线程模型，多核用于Sentinel/Cluster |
| 内存 | 32GB | 缓存数据 + 会话数据 + 分布式锁 |
| 系统盘 | 100GB SSD | 操作系统 + Redis程序 |
| 数据盘 | 200GB SSD | RDB快照 + AOF日志 |
| 网络 | 万兆网卡 | 低延迟访问 |
| 数量 | 3台（哨兵模式）或 6台（集群模式） | 哨兵模式3节点（1主2从+3哨兵），集群模式6节点（3主3从） |

**Redis关键参数**：

```ini
# 内存配置
maxmemory 24gb
maxmemory-policy allkeys-lru

# 持久化配置
save 900 1
save 300 10
save 60 10000
appendonly yes
appendfsync everysec

# 网络配置
bind 0.0.0.0
port 6379
tcp-backlog 511
timeout 300

# 安全配置
requirepass <强密码>
rename-command FLUSHDB ""
rename-command FLUSHALL ""
```

|--------|------|------|

| 内存 | 32GB | 磁盘缓存 + 元数据缓存 |
| 系统盘 | 200GB SSD | 操作系统 + MinIO程序 |
| 数据盘 | 4×2TB SATA SSD | 纠删码模式，4块盘提供高可用 |
| 网络 | 万兆网卡 | 大文件上传下载需要高带宽 |
| 数量 | 4台（分布式集群） | 每台4块数据盘，共16块盘 |

| 存储桶 | 用途 | 生命周期策略 |

| `capp-process-files` | 工艺文件 | 永久保存，版本控制 |
| `capp-documents` | 技术文档 | 永久保存 |

## 3. 软件环境

### 3.1 操作系统

| 项目 | 说明 |
|------|------|
| **推荐系统** | CentOS 7.9（应用/数据库/中间件）、Ubuntu 20.04 LTS（AI服务器） |
| **内核版本** | CentOS 7.9：3.10.0-1160.el7.x86_64+；Ubuntu 20.04：5.4.0+ |
| **文件系统** | XFS（数据盘，支持大文件和高并发IO）、ext4（系统盘） |
| **时区配置** | Asia/Shanghai，统一使用NTP时间同步 |
| **字符集** | UTF-8（LANG=zh_CN.UTF-8） |

**系统初始化脚本**：

```bash
#!/bin/bash
# system_init.sh - 系统初始化脚本

# 设置时区
timedatectl set-timezone Asia/Shanghai

# 安装NTP同步
yum install -y chrony
systemctl enable chronyd
systemctl start chronyd

# 设置字符集
localectl set-locale LANG=zh_CN.UTF-8

# 内核参数调优
cat >> /etc/sysctl.conf << 'EOF'
# 网络优化
net.core.somaxconn = 65535
net.core.netdev_max_backlog = 65535
net.ipv4.tcp_max_syn_backlog = 65535
net.ipv4.tcp_tw_reuse = 1
net.ipv4.tcp_fin_timeout = 15
net.ipv4.tcp_keepalive_time = 300
net.ipv4.tcp_keepalive_intvl = 30
net.ipv4.tcp_keepalive_probes = 3
net.ipv4.tcp_max_tw_buckets = 60000
net.ipv4.ip_local_port_range = 1024 65535

# 文件句柄
fs.file-max = 1048576
fs.nr_open = 1048576

# 内存优化
vm.swappiness = 10
vm.dirty_ratio = 10
vm.dirty_background_ratio = 5
vm.overcommit_memory = 1

# 共享内存
kernel.shmmax = 68719476736
kernel.shmall = 4294967296
EOF

sysctl -p

# 文件句柄限制
cat >> /etc/security/limits.conf << 'EOF'
* soft nofile 65535
* hard nofile 65535
* soft nproc 65535
* hard nproc 65535
root soft nofile 65535
root hard nofile 65535
EOF

# 关闭不必要的服务
systemctl disable firewalld  # 使用外部防火墙
systemctl disable postfix
systemctl disable NetworkManager

# 安装基础工具
yum install -y vim wget curl git net-tools lrzsz unzip jq htop iotop
```

```php
        [
            'host'     => '203.0.113.10',
            'port'     => 3306,
            'database' => 'capp_db',
            'username' => 'capp_read',
            'password' => '<slave_password>',
            'charset'  => 'utf8mb4',

// DB类实现读写分离
class DB {
    private static $master = null;
    private static $slaves = [];
    private static $slaveIndex = 0;

    public static function getMaster() {
        if (self::$master === null) {
            $config = include __DIR__ . '/database.php';
            $dsn = "mysql:host={$config['master']['host']};port={$config['master']['port']};dbname={$config['master']['database']};charset={$config['master']['charset']}";
            self::$master = new PDO($dsn, $config['master']['username'], $config['master']['password'], [
                PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
                PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                PDO::ATTR_EMULATE_PREPARES => false,
            ]);
        }
        return self::$master;
    }

    public static function getSlave() {
        $config = include __DIR__ . '/database.php';
        if (empty(self::$slaves)) {
            foreach ($config['slaves'] as $slave) {
                $dsn = "mysql:host={$slave['host']};port={$slave['port']};dbname={$slave['database']};charset={$slave['charset']}";
                self::$slaves[] = new PDO($dsn, $slave['username'], $slave['password'], [
                    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
                    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                    PDO::ATTR_EMULATE_PREPARES => false,
                ]);
            }
        }
        // 轮询选择从库
        $index = self::$slaveIndex % count(self::$slaves);
        self::$slaveIndex++;
        return self::$slaves[$index];
    }

    // 写操作使用主库
    public static function query($sql, $params = []) {
        return self::getMaster()->prepare($sql)->execute($params);
    }

    // 读操作使用从库
    public static function fetchAll($sql, $params = []) {
        $stmt = self::getSlave()->prepare($sql);
        $stmt->execute($params);
        return $stmt->fetchAll();
    }
}
```

### 6.4 灰度发布策略

**灰度发布流程**：

1. **准备阶段**：新版本部署到所有应用服务器，但不切换流量
2. **灰度10%**：Nginx将10%流量路由到新版本（按用户ID哈希）
3. **观察期**（30分钟）：监控错误率、响应时间、业务指标
4. **灰度50%**：指标正常则扩大到50%流量
5. **观察期**（30分钟）：继续监控
6. **全量发布**：指标正常则切换100%流量到新版本

**Nginx灰度配置**：

```nginx
# 灰度发布 - 基于Cookie的流量分配
split_clients "${remote_addr}" $backend {
    10%   new_version;
    90%   old_version;
}

upstream old_version {
    server 203.0.113.10:9000;
    server 203.0.113.10:9000;
    server 203.0.113.10:9000;
}

upstream new_version {
    server 203.0.113.10:9001;  # 新版本PHP-FPM端口
    server 203.0.113.10:9001;
    server 203.0.113.10:9001;
}

server {
    location /api/ {
        fastcgi_pass $backend;
        # ...
    }
}
```

### 6.5 回滚方案

**回滚策略**：

| 回滚级别 | 触发条件 | 回滚方式 | 回滚时间 |
|----------|----------|----------|----------|
| **代码回滚** | 功能异常、严重Bug | Git回退到上一版本，重新部署 | 5-10分钟 |
| **配置回滚** | 配置错误导致异常 | 恢复备份配置文件 | 2-5分钟 |
| **数据库回滚** | 数据迁移错误 | 执行反向迁移脚本 | 10-30分钟 |
| **全量回滚** | 系统严重故障 | 切换到上一版本的完整备份 | 30-60分钟 |

**回滚脚本**：

```bash
#!/bin/bash
# rollback.sh - 回滚脚本

set -e

ENV=$1  # test / production
TARGET_VERSION=$2  # 目标版本号（可选，默认回退到上一版本）

DEPLOY_DIR="/opt/capp/app"
RELEASE_DIR="${DEPLOY_DIR}/releases"
CURRENT_LINK="${DEPLOY_DIR}/current"

if [ -z "$TARGET_VERSION" ]; then
    # 查找上一个版本
    CURRENT_RELEASE=$(readlink ${CURRENT_LINK} | xargs basename)
    TARGET_VERSION=$(ls -t ${RELEASE_DIR} | grep -v "${CURRENT_RELEASE}" | head -1)
fi

if [ -z "$TARGET_VERSION" ]; then
    echo "错误：找不到可回滚的版本"
    exit 1
fi

echo "回滚到版本: ${TARGET_VERSION}"

# 切换版本
ln -sfn "${RELEASE_DIR}/${TARGET_VERSION}" "${CURRENT_LINK}"

# 重启PHP-FPM
systemctl reload php81-php-fpm

# 验证
sleep 3
HTTP_CODE=$(curl -s -o /dev/null -w "%{http_code}" http://localhost:9000/health)
if [ "$HTTP_CODE" != "200" ]; then
    echo "回滚验证失败！"
    exit 1
fi

echo "回滚成功: ${TARGET_VERSION}"
```

**PHP日志类实现**：

```php
<?php
// app/common/Logger.php

class Logger {
    private static $logDir = '/opt/capp/app/logs';
    private static $logFile = 'app.log';
    private static $maxFileSize = 104857600; // 100MB
    private static $maxFiles = 30;

    const DEBUG = 'DEBUG';
    const INFO = 'INFO';
    const WARNING = 'WARNING';
    const ERROR = 'ERROR';
    const CRITICAL = 'CRITICAL';

    public static function log($level, $category, $message, array $context = []) {
        $timestamp = date('Y-m-d H:i:s.v');
        $contextStr = empty($context) ? '' : ' ' . json_encode($context, JSON_UNESCAPED_UNICODE);

        $logLine = sprintf(
            "[%s] %s %s - %s%s\n",
            $timestamp,
            $level,
            $category,
            $message,
            $contextStr
        );

        // 写入日志文件
        $logPath = self::$logDir . '/' . self::$logFile;
        file_put_contents($logPath, $logLine, FILE_APPEND | LOCK_EX);

        // 日志轮转
        self::rotateLog($logPath);

        // ERROR及以上级别同时写入错误日志
        if (in_array($level, [self::ERROR, self::CRITICAL])) {
            $errorPath = self::$logDir . '/error.log';
            file_put_contents($errorPath, $logLine, FILE_APPEND | LOCK_EX);
        }
    }

    public static function info($category, $message, array $context = []) {
        self::log(self::INFO, $category, $message, $context);
    }

    public static function error($category, $message, array $context = []) {
        self::log(self::ERROR, $category, $message, $context);
    }

    public static function warning($category, $message, array $context = []) {
        self::log(self::WARNING, $category, $message, $context);
    }

    public static function debug($category, $message, array $context = []) {
        if (defined('APP_DEBUG') && APP_DEBUG) {
            self::log(self::DEBUG, $category, $message, $context);
        }
    }

    public static function critical($category, $message, array $context = []) {
        self::log(self::CRITICAL, $category, $message, $context);
    }

    private static function rotateLog($logPath) {
        clearstatcache(true, $logPath);
        if (file_exists($logPath) && filesize($logPath) > self::$maxFileSize) {
            $timestamp = date('Ymd_His');
            $rotatedPath = $logPath . '.' . $timestamp;
            rename($logPath, $rotatedPath);

            // 清理旧日志
            $logs = glob($logPath . '.*');
            if (count($logs) > self::$maxFiles) {
                usort($logs, function($a, $b) {
                    return filemtime($a) - filemtime($b);
                });
                $toDelete = array_slice($logs, 0, count($logs) - self::$maxFiles);
                array_map('unlink', $toDelete);
            }
        }
    }
}
```

### 9.4 证书管理

**SSL证书管理流程**：

```bash
#!/bin/bash
# ssl_check.sh - SSL证书有效期检查

DOMAINS=(
    "capp.company.com:443"
    "api.capp.company.com:443"
)

for domain in "${DOMAINS[@]}"; do
    hostname=$(echo $domain | cut -d: -f1)
    port=$(echo $domain | cut -d: -f2)
    expiry_date=$(echo | openssl s_client -servername $hostname -connect $hostname:$port 2>/dev/null | openssl x509 -noout -enddate 2>/dev/null | cut -d= -f2)
    expiry_epoch=$(date -d "$expiry_date" +%s)
    current_epoch=$(date +%s)
    days_left=$(( ($expiry_epoch - $current_epoch) / 86400 ))

    echo "$hostname: 证书剩余 $days_left 天"

    if [ $days_left -lt 30 ]; then
        echo "警告：$hostname 证书即将过期！"
        # 发送告警
    fi
done
```
