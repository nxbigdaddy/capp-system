## 1. AI功能概述

### 1.1 AI在CAPP系统中的定位与价值

#### 1.1.1 定位

AI功能作为CAPP系统的智能化增强层，定位为"工艺专家辅助决策系统"，不替代工艺人员的专业判断，而是通过数据驱动和知识检索为工艺人员提供科学、高效的决策支持。AI功能独立部署为Python Flask微服务，通过HTTP API与PHP主系统松耦合集成。

#### 1.1.2 核心价值

| 价值维度 | 说明 | 预期效果 |
|---------|------|---------|
| **效率提升** | 自动推荐工艺参数和工艺方案，减少人工查阅标准和计算的工作量 | 工艺编制效率提升30%-50% |
| **质量保障** | 基于标准规范和历史经验推荐参数，降低人为疏漏和经验依赖 | 工艺参数合规率提升至98%以上 |
| **知识沉淀** | 将分散的工艺知识结构化、向量化，形成可检索的企业知识资产 | 新人上手时间缩短40% |
| **决策辅助** | 多方案对比评分，为工艺人员提供量化决策依据 | 工艺方案优选效率提升60% |
| **持续优化** | 通过实际生产数据反馈，持续优化推荐模型 | 推荐准确率随使用逐步提升 |

## 2. AI决策引擎

### 2.1 功能概述

AI决策引擎是面向业务场景的智能决策模块，基于产品特征（材料、尺寸、精度要求等）和工艺约束（标准规范、设备能力等），通过RAG（检索增强生成）技术从工艺知识库中检索相关知识，结合大语言模型的推理能力，智能推荐工艺参数和工艺方案。

**核心设计理念：**

- **知识驱动**：所有推荐结果基于企业工艺知识库、国家标准、行业标准等可靠知识来源
- **可解释性**：每个推荐结果附带知识来源引用和置信度评分，便于工艺人员判断
- **人机协同**：AI推荐作为辅助参考，最终决策权归工艺人员
- **持续学习**：通过工艺人员对推荐结果的采纳/修正反馈，持续优化推荐准确度

### 2.2 决策场景

#### 2.2.1 工艺参数推荐

**场景描述：** 根据产品特征（材料牌号、板厚/管径、接头形式等）和工艺要求，自动推荐关键工艺参数。

**焊接参数推荐：**

| 推荐参数 | 影响因素 | 典型范围 |
|---------|---------|---------|
| 焊接电流（A） | 材料厚度、焊接方法、接头形式 | 80A - 350A |
| 焊接电压（V） | 焊接方法、保护气体、熔深要求 | 20V - 45V |
| 焊接速度（mm/min） | 材料厚度、焊道层数、热输入控制 | 150 - 600 mm/min |
| 保护气体流量（L/min） | 焊接方法、喷嘴直径、环境条件 | 10 - 25 L/min |
| 预热温度（℃） | 材料牌号、板厚、环境温度 | 室温 - 200℃ |
| 层间温度（℃） | 材料牌号、热处理要求 | 100 - 350℃ |
| 热输入（kJ/mm） | 材料标准、接头性能要求 | 按标准限定范围 |

**热处理参数推荐：**

| 推荐参数 | 影响因素 | 典型范围 |
|---------|---------|---------|
| 加热温度（℃） | 材料牌号、热处理类型 | 500℃ - 1100℃ |
| 保温时间（min） | 壁厚、加热温度 | 按壁厚计算 |
| 升温速率（℃/h） | 材料类型、壁厚、形状复杂度 | 50 - 200℃/h |
| 冷却方式 | 材料牌号、性能要求 | 炉冷/空冷/水冷/油冷 |
| 冷却速率（℃/h） | 材料标准、硬度要求 | 按工艺规范限定 |

**机加工参数推荐：**

| 推荐参数 | 影响因素 | 典型范围 |
|---------|---------|---------|
| 切削速度（m/min） | 工件材料、刀具材料、加工方式 | 30 - 500 m/min |
| 进给量（mm/r） | 表面粗糙度要求、刀具强度、工件刚性 | 0.05 - 1.0 mm/r |
| 切削深度（mm） | 加工余量、机床功率、工件刚性 | 0.1 - 5.0 mm |
| 主轴转速（r/min） | 切削速度、工件/刀具直径 | 按切削速度计算 |

#### 2.2.2 工艺方案优选

**场景描述：** 针对同一加工对象，存在多种可行工艺方案时，AI从质量、成本、效率、设备利用率等维度进行多方案对比评分，推荐最优工艺路线。

**评分维度：**

| 评分维度 | 权重 | 评估指标 |
|---------|------|---------|
| **质量保障** | 35% | 标准符合度、历史合格率、检测难度 |
| **生产效率** | 25% | 预估工时、工序数量、并行度 |
| **成本控制** | 25% | 材料利用率、设备成本、人工成本 |
| **设备匹配** | 15% | 设备可用性、设备负荷、设备精度匹配 |

#### 2.2.3 材料选择建议

**场景描述：** 根据工况条件（介质、温度、压力、腐蚀性等）推荐合适的材料牌号。

**推荐依据：**

| 工况条件 | 知识来源 | 推荐逻辑 |
|---------|---------|---------|
| 工作介质 | GB/T 150、GB/T 151、材料手册 | 根据介质腐蚀性匹配耐蚀材料 |
| 设计压力 | GB 150.1~150.4 | 根据压力等级确定材料强度要求 |
| 设计温度 | GB/T 150、材料标准 | 根据温度范围确定材料适用性 |
| 腐蚀环境 | HG/T 20581、企业经验 | 根据腐蚀类型推荐材料及防腐措施 |
| 特殊要求 | 客户技术协议、行业标准 | 根据特殊工况补充材料要求 |

#### 2.2.4 设备选型匹配

**场景描述：** 根据加工要求（工件尺寸、精度等级、工艺类型等）从企业设备库中推荐最合适的加工设备。

**匹配逻辑：**

| 匹配维度 | 匹配规则 |
|---------|---------|
| **加工能力** | 设备最大加工尺寸 >= 工件尺寸要求 |
| **精度等级** | 设备精度等级 >= 工件精度要求 |
| **工艺类型** | 设备支持的工艺类型包含目标工艺 |
| **负荷状态** | 优先推荐当前空闲或低负荷设备 |
| **历史表现** | 参考设备在该类工艺上的历史合格率 |

#### 2.4.2 RAG（检索增强生成）方案设计

RAG是AI决策引擎的核心技术方案，通过"检索-增强-生成"三阶段流程，确保AI推荐结果基于可靠知识来源。

**RAG流程设计：**

```
┌─────────────────────────────────────────────────────────────┐
│                     RAG 流程架构                              │
│                                                             │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐             │
│  │  检索阶段 │───>│  增强阶段 │───>│  生成阶段 │             │
│  │ Retrieve  │    │ Augment   │    │ Generate  │             │
│  └──────────┘    └──────────┘    └──────────┘             │
│       │               │               │                     │
│  · Query构建     · 知识注入      · LLM推理                  │
│  · 向量检索       · Prompt组装    · 结果解析                 │
│  · 规则匹配       · 上下文窗口    · 结构化输出               │
│  · 结果排序       · 约束注入      · 置信度评估               │
└─────────────────────────────────────────────────────────────┘
```

**检索策略（混合检索）：**

| 检索方式 | 说明 | 适用场景 |
|---------|------|---------|
| **向量语义检索** | 通过Embedding模型将Query转为向量，在Milvus中检索语义最相似的文档片段 | 工艺知识问答、经验案例检索 |
| **关键词精确检索** | 基于材料牌号、标准编号等精确关键词进行匹配 | 标准条款查询、规则精确匹配 |
| **结构化规则检索** | 基于条件字段在知识规则表中进行条件匹配 | 工艺参数推荐、设备选型匹配 |

**检索结果融合与排序：**

```python
def hybrid_search(query: str, conditions: dict, top_k: int = 10) -> list:
    """
    混合检索：向量检索 + 关键词检索 + 规则检索
    """
    # 1. 向量语义检索
    query_vector = embedding_model.encode(query)
    vector_results = milvus_collection.search(
        data=[query_vector],
        anns_field="embedding",
        param={"metric_type": "IP", "params": {"nprobe": 16}},
        limit=top_k,
        output_fields=["content", "source", "category"]
    )

    # 2. 关键词精确检索（从向量结果中过滤）
    keyword_results = [r for r in vector_results[0]
                       if any(kw in r.entity.get("content", "")
                              for kw in conditions.get("keywords", []))]

    # 3. 结构化规则检索
    rule_results = knowledge_rule_dao.match_rules(conditions)

    # 4. 结果融合与去重（RRF - Reciprocal Rank Fusion）
    merged_results = reciprocal_rank_fusion(
        vector_results[0],
        keyword_results,
        rule_results,
        weights=[0.5, 0.2, 0.3]
    )

    return merged_results[:top_k]
```

#### 2.4.4 决策结果评估与置信度评分

**置信度评分模型：**

```
置信度 = W1 × 知识匹配度 + W2 × 规则覆盖度 + W3 × 历史验证度

其中：
- 知识匹配度：检索到的相关知识数量和质量（0-1）
- 规则覆盖度：匹配到的结构化规则数量与所需规则数量的比值（0-1）
- 历史验证度：该类推荐在历史使用中的采纳率（0-1）

权重：W1=0.4, W2=0.35, W3=0.25
```

**置信度等级与处理策略：**

| 置信度等级 | 分值范围 | 处理策略 |
|-----------|---------|---------|
| 高置信 | 0.80 - 1.00 | 直接推荐，标注"高置信"标签 |
| 中置信 | 0.50 - 0.79 | 推荐但标注"建议复核"，附注参考依据 |
| 低置信 | 0.20 - 0.49 | 标注"仅供参考"，明确列出信息缺口 |
| 无置信 | 0.00 - 0.19 | 不推荐，提示"信息不足，建议人工决策" |

#### 2.5.2 模型加载与推理

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM
from vllm import LLM, SamplingParams

class ModelManager:
    """LLM模型管理器"""

    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance._initialized = False
        return cls._instance

    def initialize(self, config):
        """初始化模型（单例模式，仅加载一次）"""
        if self._initialized:
            return

        self.llm = LLM(
            model=config['model_path'],       # Qwen2.5-72B模型路径
            tensor_parallel_size=config.get('tensor_parallel_size', 4),
            gpu_memory_utilization=0.90,
            max_model_len=8192,
            trust_remote_code=True
        )
        self.tokenizer = AutoTokenizer.from_pretrained(config['model_path'])
        self._initialized = True

    def generate(self, prompt: str, max_tokens: int = 2048,
                 temperature: float = 0.3) -> str:
        """模型推理"""
        sampling_params = SamplingParams(
            temperature=temperature,
            max_tokens=max_tokens,
            top_p=0.85,
            repetition_penalty=1.1
        )
        outputs = self.llm.generate([prompt], sampling_params)
        return outputs[0].outputs[0].text.strip()


class EmbeddingManager:
    """Embedding模型管理器"""

    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance._initialized = False
        return cls._instance

    def initialize(self, config):
        if self._initialized:
            return
        from FlagEmbedding import FlagModel
        self.model = FlagModel(
            config['model_path'],
            query_instruction_for_retrieval="为这个句子生成表示以用于检索相关文章："
        )
        self._initialized = True

    def encode(self, texts: list[str]) -> list[list[float]]:
        """文本向量化"""
        embeddings = self.model.encode(texts)
        return embeddings.tolist()
```

## 3. AI助手

### 3.1 功能概述

AI助手是一个面向工艺人员的交互式智能助手，以对话式界面提供工艺知识问答、工艺编制辅助、标准查询、异常诊断等能力。AI助手集成在CAPP系统的侧边栏中，工艺人员在编制工艺过程中可随时调用。

**设计理念：**

- **随时可用**：侧边栏常驻，不中断工艺编制主流程
- **上下文感知**：自动获取当前正在编辑的工艺信息作为对话上下文
- **多轮对话**：支持连续追问和逐步细化需求
- **流式输出**：SSE流式响应，提升交互体验

### 3.2 核心能力

#### 3.2.1 工艺知识问答

**能力描述：** 基于企业工艺知识库，回答工艺相关的专业问题。

**典型问答场景：**

| 问题类型 | 示例问题 | 回答方式 |
|---------|---------|---------|

| 工艺方法 | "不锈钢压力容器的焊接工艺要点有哪些？" | 结构化列举要点 |
| 参数范围 | "16MnDR低温钢的最低使用温度是多少？" | 直接回答 + 标准来源 |
| 对比分析 | "埋弧焊和手工电弧焊各有什么优缺点？" | 表格对比 |

#### 3.4.2 意图识别

采用基于Prompt的意图识别方案，无需单独训练分类模型：

```python
INTENT_PROMPT = """
根据用户的输入，判断其意图类别。

意图类别：
- knowledge_qa：工艺知识问答（询问工艺方法、参数、标准等知识）
- process_assist：工艺编制辅助（请求生成工艺路线、工序内容等）
- standard_query：标准查询（查询国标、行标、企标的具体条款）
- fault_diagnosis：异常诊断（描述质量问题，请求排查方向）

用户输入：{user_message}
当前上下文：{context}

请仅返回意图类别名称，不要返回其他内容。
"""

class IntentClassifier:
    def classify(self, message: str, context: str = '') -> str:
        """意图分类"""
        prompt = INTENT_PROMPT.format(
            user_message=message,
            context=context or "无"
        )
        # 使用轻量级模型快速分类（或基于关键词规则快速匹配）
        intent = self._rule_based_classify(message)
        if intent:
            return intent

        # 规则无法匹配时，使用LLM分类
        result = self.llm.generate(prompt, max_tokens=20, temperature=0.1)
        return result.strip()

    def _rule_based_classify(self, message: str) -> str:
        """基于关键词规则的快速意图识别"""
        rules = {
            'knowledge_qa': ['什么是', '为什么', '如何', '原理', '区别', '对比'],
            'process_assist': ['生成', '帮我写', '编制', '工艺路线', '工序'],
            'standard_query': ['标准', '国标', '行标', '企标', 'NB/T', 'GB'],
            'fault_diagnosis': ['缺陷', '裂纹', '气孔', '不合格', '返修', '问题']
        }
        for intent, keywords in rules.items():
            if any(kw in message for kw in keywords):
                return intent
        return ''
```

**文档解析处理方案：**

```python
class DocumentProcessor:
    """文档解析处理器"""

    def process_pdf(self, file_path: str) -> list[dict]:
        """PDF文档解析"""
        import fitz  # PyMuPDF

        doc = fitz.open(file_path)
        segments = []

        for page_num in range(len(doc)):
            page = doc[page_num]
            text = page.get_text()

            # 按段落/章节分段
            paragraphs = self._split_paragraphs(text)
            for para in paragraphs:
                if len(para.strip()) > 20:  # 过滤过短段落
                    segments.append({
                        'content': para.strip(),
                        'page': page_num + 1,
                        'source': os.path.basename(file_path),
                        'type': 'standard'
                    })

        return segments

    def _split_paragraphs(self, text: str) -> list[str]:
        """文本分段策略"""
        # 1. 按标题/章节分割
        sections = re.split(r'\n(?=\d+[\.\s]|第[一二三四五六七八九十]+章)', text)

        # 2. 长章节按段落二次分割（每段不超过500字）
        final_segments = []
        for section in sections:
            if len(section) > 500:
                chunks = self._split_by_length(section, max_length=500, overlap=50)
                final_segments.extend(chunks)
            else:
                final_segments.append(section)

        return final_segments

    def _split_by_length(self, text: str, max_length: int = 500,
                         overlap: int = 50) -> list[str]:
        """按长度分割，保留重叠区域"""
        chunks = []
        start = 0
        while start < len(text):
            end = start + max_length
            chunk = text[start:end]
            chunks.append(chunk)
            start = end - overlap
        return chunks
```

#### 4.4.3 相似度算法

采用余弦相似度（Cosine Similarity）作为相似度度量算法：

```
similarity(A, B) = (A · B) / (||A|| × ||B||)

其中：
- A、B为两个文本的Embedding向量
- A · B 为向量内积
- ||A||、||B|| 为向量模长
- 取值范围：[-1, 1]，值越大表示越相似
```

在Milvus中使用IP（内积）度量时，需先将向量归一化，此时IP等价于余弦相似度。

**AI生成内容审核机制：**

| 审核维度 | 审核规则 | 处理方式 |
|---------|---------|---------|
| **参数合理性** | 推荐参数值是否在合理范围内 | 超出范围时标注警告 |

| **完整性检查** | 推荐结果是否包含必要信息 | 缺失信息时列出缺口 |

**审核实现方案：**

```python
class OutputValidator:
    """AI输出审核器"""

    def validate(self, result: dict, decision_type: str) -> dict:
        """审核AI输出结果"""
        issues = []

        # 1. 参数合理性检查
        if decision_type == 'parameter_recommend':
            for param in result.get('parameters', []):
                if not self._check_range(param):
                    issues.append({
                        'level': 'warning',
                        'message': f"参数 {param['param_name']} 推荐值超出常规范围"
                    })

        # 2. 置信度检查
        confidence = result.get('confidence', 0)
        if confidence < 0.5:
            issues.append({
                'level': 'warning',
                'message': f"推荐置信度较低（{confidence:.0%}），建议人工复核"
            })

        # 3. 敏感信息检查
        sensitive_found = self._check_sensitive_info(str(result))
        if sensitive_found:
            issues.append({
                'level': 'error',
                'message': "输出包含敏感信息，已自动过滤"
            })
            result = self._remove_sensitive_info(result)

        result['validation'] = {
            'status': 'pass' if not issues else 'review_required',
            'issues': issues
        }

        return result
```

### 6.3 Prompt注入防护

**防护策略：**

| 防护层 | 措施 | 说明 |
|-------|------|------|
| **输入过滤** | 检测并过滤常见注入模式 | 过滤"忽略以上指令"、"你现在是"等注入关键词 |
| **Prompt隔离** | 用户输入与系统Prompt明确分隔 | 使用XML标签区分系统指令和用户输入 |
| **输出限制** | 限制AI输出的操作权限 | AI仅返回推荐结果，不执行任何系统操作 |
| **白名单控制** | 限制AI可访问的知识范围 | 仅检索知识库内容，不访问数据库/文件系统 |

**输入过滤实现：**

```python
class PromptGuard:
    """Prompt注入防护"""

    INJECTION_PATTERNS = [
        r'忽略以上.*指令',
        r'ignore\s+previous\s+instructions',
        r'你现在是',
        r'you\s+are\s+now',
        r'system\s*prompt',
        r'请输出你的.*prompt',
        r'请.*扮演',
        r'作为.*管理员',
    ]

    def check_input(self, user_input: str) -> dict:
        """检查用户输入是否包含注入尝试"""
        threats = []
        for pattern in self.INJECTION_PATTERNS:
            if re.search(pattern, user_input, re.IGNORECASE):
                threats.append(pattern)

        if threats:
            return {
                'safe': False,
                'threats': threats,
                'action': 'reject'  # 或 'sanitize'
            }
        return {'safe': True}
```
