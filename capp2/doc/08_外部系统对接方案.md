## 1. 对接概述

### 1.1 对接系统清单

CAPP系统作为连接设计端（PLM）和生产端（ERP/MES）的核心枢纽，需要与以下外部系统进行数据对接：

| 对接系统 | 系统厂商 | 对接方向 | 核心数据 | 对接方式 |
|---------|---------|---------|---------|---------|
| **CAXA PLM** | CAXA数码大方 | PLM → CAPP（主）<br/>CAPP → PLM（辅） | EBOM、图纸、设计变更 | API + 数据库视图 |
| **用友U8** | 用友网络 | 双向同步 | 物料主数据、MBOM、库存、工时 | U8 API + 数据库视图 |
| **MES** | 自研/第三方 | CAPP → MES（主）<br/>MES → CAPP（辅） | 工单、工艺参数、报工、质量 | REST API + 消息队列 |

### 1.4 对接原则

| 原则 | 说明 | 实现方式 |
|------|------|---------|
| **数据一致性** | 确保CAPP与外部系统的核心数据保持一致 | 分布式事务补偿、定期对账 |
| **幂等性** | 同一请求重复执行不产生副作用 | 请求唯一ID + 状态检查 |
| **异常处理** | 任何对接异常不影响系统正常运行 | 熔断降级、失败重试、异常隔离 |
| **日志追踪** | 每次数据同步可追踪、可审计 | 统一Request-ID、全链路日志 |
| **松耦合** | 对接模块独立于核心业务，可插拔 | 适配器模式、消息队列解耦 |
| **可配置** | 对接参数（地址、频率、映射规则）可配置 | 配置文件 + 数据库配置表 |

## 2. CAXA PLM对接方案

### 2.1 对接目标

| 目标 | 说明 | 业务价值 |
|------|------|---------|
| **图纸同步** | PLM中发布的CAD图纸自动同步到CAPP | 工艺人员无需手动下载图纸，直接在CAPP中查看 |
| **EBOM同步** | PLM中的工程BOM自动同步到CAPP，作为工艺编制的基础 | 避免手工重复录入BOM数据，确保数据源头一致 |
| **设计变更通知** | PLM中的设计变更（ECN）实时通知CAPP | 工艺变更及时响应，避免按旧图纸编制工艺 |

### 2.4 同步流程

```mermaid
sequenceDiagram
    participant PLM as CAXA PLM
    participant WH as Webhook处理器
    participant MQ as RabbitMQ

    participant CAPP as CAPP数据库
    participant NOTIFY as 通知服务

    Note over PLM,CAPP: 场景1：PLM设计变更触发同步

    PLM->>WH: POST Webhook回调<br/>{event_type: "ecn_approved", ecn_id: "ECN-2026-001"}
    WH->>WH: 验证Webhook签名
    WH->>WH: 记录回调日志
    WH->>MQ: 发布消息到 plm.sync.exchange<br/>routing_key: plm.ecn.approved
    WH-->>PLM: 返回200 OK

    MQ->>SYNC: 消费消息
    SYNC->>PLM: GET /api/v1/changes/{ecn_id}<br/>获取变更详情
    PLM-->>SYNC: 返回变更详情JSON
    SYNC->>PLM: GET /api/v1/changes/{ecn_id}/affected-parts<br/>获取受影响对象
    PLM-->>SYNC: 返回受影响对象列表

    SYNC->>CAPP: 查询CAPP中是否已存在该变更记录
    alt 已存在（幂等检查）
        SYNC->>SYNC: 跳过，记录"重复同步"日志
    else 不存在
        SYNC->>CAPP: 写入变更通知记录
        SYNC->>CAPP: 更新受影响零件/工艺的变更标记
        SYNC->>NOTIFY: 发送企业微信通知<br/>通知相关工艺人员
    end

    SYNC->>SYNC: 更新同步状态为"成功"
    SYNC->>SYNC: 记录同步日志

    Note over PLM,CAPP: 场景2：定时全量/增量同步

    SYNC->>PLM: GET /api/v1/products?modified_since=2026-06-06T00:00:00<br/>增量查询变更产品
    PLM-->>SYNC: 返回变更产品列表

    PLM-->>SYNC: 返回EBOM数据
    SYNC->>CAPP: 更新/插入EBOM数据
```

### 2.5 PHP实现方案

#### 2.5.1 CAXA PLM API调用封装类

```php
<?php
/**
 * CAXA PLM API 调用封装类
 * 采用适配器模式，统一封装PLM接口调用
 */
class PlmAdapter
{
    private string $baseUrl;
    private string $username;
    private string $password;
    private ?string $accessToken = null;
    private int $tokenExpireTime = 0;
    private int $timeout = 30;
    private string $requestId;

    public function __construct()
    {
        $config = Config::get('plm');
        $this->baseUrl = rtrim($config['base_url'], '/');
        $this->username = $config['username'];
        $this->password = YOUR_PASSWORD'password'];
    }

    /**
     * 获取访问令牌
     */
    private function getAccessToken(): string
    {
        if ($this->accessToken && time() < $this->tokenExpireTime) {
            return $this->accessToken;
        }

        $response = $this->httpPost('/api/v1/auth/token', [
            'username' => $this->username,
            'password' => $this->password,
            'grant_type' => 'password'
        ]);

        $this->accessToken = YOUR_SECRET'access_token'];
        $this->tokenExpireTime = time() + $response['expires_in'] - 300; // 提前5分钟刷新

        return $this->accessToken;
    }

    /**
     * 获取产品结构树
     */
    public function getProductStructure(string $productId): array
    {
        return $this->httpGet("/api/v1/products/{$productId}/structure");
    }

    /**
     * 获取EBOM数据
     */
    public function getEBOM(string $productId): array
    {
        return $this->httpGet("/api/v1/products/{$productId}/bom");
    }

    /**
     * 获取零件详情
     */

    }
```

#### 2.5.3 增量同步机制

```php
<?php
/**
 * PLM增量同步处理器
 */
class PlmSyncHandler
{
    private PlmAdapter $plmAdapter;
    private SyncLogService $logService;

    /**
     * 执行增量同步
     */
    public function incrementalSync(): SyncResult
    {
        $result = new SyncResult();
        $result->syncType = 'plm_incremental';
        $result->startTime = microtime(true);

        try {
            // 1. 获取上次同步时间
            $lastSyncTime = $this->getLastSyncTime('plm');

            // 2. 查询PLM中变更的数据
            $modifiedProducts = $this->plmAdapter->getModifiedProducts($lastSyncTime);

            // 3. 逐个处理变更产品
            foreach ($modifiedProducts['items'] as $product) {
                try {
                    $this->syncProduct($product);
                    $result->successCount++;
                } catch (Exception $e) {
                    $result->failCount++;
                    $result->errors[] = [
                        'product_id' => $product['id'],
                        'error' => $e->getMessage()
                    ];
                    $this->logService->logError('plm_sync', $e);
                }
            }

            // 4. 更新同步时间戳
            $this->updateLastSyncTime('plm');

        } catch (Exception $e) {
            $result->status = 'failed';
            $result->errorMessage = $e->getMessage();
            $this->logService->logError('plm_sync', $e);
        }

        $result->endTime = microtime(true);
        $result->duration = $result->endTime - $result->startTime;

        return $result;
    }

    /**
     * 同步单个产品（含BOM和图纸）
     */
    private function syncProduct(array $productData): void
    {
        // 幂等性检查：根据PLM产品编码+版本判断是否已同步
        $existing = $this->findExistingProduct(
            $productData['code'],
            $productData['version']
        );

        if ($existing && $existing['plm_version'] === $productData['version']) {
            // 版本相同，跳过
            return;
        }

        // 同步EBOM
        $bomData = $this->plmAdapter->getEBOM($productData['id']);
        $this->syncBOM($bomData);

        // 同步图纸
        $drawings = $this->plmAdapter->getProductDrawings($productData['id']);
        $this->syncDrawings($drawings);

        // 更新产品记录
        $this->upsertProduct($productData);
    }
}
```

### 2.7 异常处理与重试机制

```php
<?php
/**
 * PLM同步异常处理与重试
 */
class PlmSyncRetryHandler
{
    private int $maxRetries = 3;
    private array $retryDelays = [5, 30, 120]; // 重试间隔（秒）

    /**
     * 带重试的同步执行
     */
    public function executeWithRetry(callable $syncOperation): mixed
    {
        $lastException = null;

        for ($attempt = 1; $attempt <= $this->maxRetries; $attempt++) {
            try {
                return $syncOperation();
            } catch (PlmApiException $e) {
                $lastException = $e;

                // 不可重试的错误（认证失败、参数错误等）
                if ($e->isNonRetryable()) {
                    throw $e;
                }

                // 记录重试日志
                $this->logRetry($attempt, $e);

                // 最后一次重试仍失败，投递到延迟队列
                if ($attempt === $this->maxRetries) {
                    $this->enqueueForRetry($syncOperation, $e);
                    throw $e;
                }

                // 等待重试间隔
                sleep($this->retryDelays[$attempt - 1]);
            }
        }

        throw $lastException;
    }

    /**
     * 投递到RabbitMQ延迟队列，稍后重试
     */
    private function enqueueForRetry(callable $operation, Exception $e): void
    {
        $queue = RabbitMQ::channel();
        $queue->publish(
            exchange: 'sync.retry.exchange',
            routingKey: 'plm.sync.retry',
            message: json_encode([
                'operation' => serialize($operation),
                'error' => $e->getMessage(),
                'retry_count' => $this->maxRetries,
                'next_retry_time' => date('Y-m-d H:i:s', strtotime('+1 hour'))
            ])
        );
    }
}
```

#### 3.5.2 事务一致性保证

```
MBOM下发事务一致性方案：

场景：CAPP审批通过后，MBOM需要同步到U8

方案：采用"本地消息表 + 补偿机制"保证最终一致性

1. CAPP工艺审批通过
   └─ 开启数据库事务
      ├─ 更新工艺状态为"已审批"
      ├─ 在"集成消息表"中插入一条MBOM下发消息（状态：待发送）
      └─ 提交事务

2. 消息发送器扫描消息表
   └─ 读取"待发送"状态的消息
      ├─ 调用U8 API提交MBOM
      ├─ 成功：更新消息状态为"已发送"
      └─ 失败：更新消息状态为"发送失败"，记录错误信息

3. 补偿任务（定时扫描）
   └─ 读取"发送失败"状态的消息
      ├─ 重试次数 < 最大重试次数：重新发送
      └─ 重试次数 >= 最大重试次数：标记为"需人工处理"，发送通知
```

### 5.2 同步任务调度

#### 5.2.1 调度器架构

```php
<?php
/**
 * 统一同步任务调度器
 * 支持定时触发、事件触发、手动触发
 */
class SyncTaskScheduler
{
    private array $adapters = [];  // 系统适配器实例
    private SyncLogService $logService;

    public function __construct()
    {
        $this->adapters = [
            'plm' => new PlmAdapter(),
            'u8' => new U8Adapter(),
            'mes' => new MesAdapter()
        ];
        $this->logService = new SyncLogService();
    }

    /**
     * 执行同步任务
     */
    public function executeTask(string $taskCode, array $params = []): SyncResult
    {
        // 1. 加载任务配置
        $taskConfig = $this->loadTaskConfig($taskCode);
        if (!$taskConfig || !$taskConfig['is_active']) {
            throw new SyncException("任务不存在或已禁用: {$taskCode}");
        }

        // 2. 防重入检查（同一任务不能并发执行）
        if ($this->isTaskRunning($taskCode)) {
            throw new SyncException("任务正在执行中: {$taskCode}");
        }

        // 3. 标记任务为运行中
        $this->markTaskRunning($taskCode);

        $result = new SyncResult();
        $result->taskCode = $taskCode;
        $result->startTime = microtime(true);

        try {
            // 4. 根据任务类型执行同步
            $handler = $this->getTaskHandler($taskCode);
            $result = $handler->execute($params, $result);

            // 5. 更新任务状态
            $this->markTaskSuccess($taskCode);

        } catch (Exception $e) {
            $result->status = 'failed';
            $result->errorMessage = $e->getMessage();
            $this->markTaskFailed($taskCode, $e->getMessage());
            $this->logService->logError($taskCode, $e);

            // 失败重试
            if ($result->retryCount < $taskConfig['max_retries']) {
                $this->scheduleRetry($taskCode, $taskConfig['retry_interval']);
            }
        }

        $result->endTime = microtime(true);
        $result->duration = $result->endTime - $result->startTime;

        // 6. 记录同步日志
        $this->logService->logSyncResult($result);

        return $result;
    }

    /**
     * 定时任务入口（Cron调用）
     */
    public function runScheduledTasks(): void
    {
        $tasks = $this->getDueScheduledTasks();
        foreach ($tasks as $task) {
            $this->executeTask($task['task_code']);
        }
    }

    /**
     * 事件触发入口（RabbitMQ消费者调用）
     */
    public function handleEvent(string $eventType, array $eventData): void
    {
        // 根据事件类型查找对应的同步任务
        $task = $this->findTaskByEvent($eventType);
        if ($task) {
            $this->executeTask($task['task_code'], $eventData);
        }
    }
}
```

#### 5.4.1 对账机制

```php
<?php
/**
 * 数据一致性对账处理器
 * 定期执行，比对CAPP与外部系统的核心数据是否一致

class DataReconciliationHandler
{
    /**
     * 执行对账
     */
    public function reconcile(string $system): ReconciliationResult
    {
        $result = new ReconciliationResult();
        $result->system = $system;
        $result->checkTime = date('Y-m-d H:i:s');

        switch ($system) {
            case 'plm':
                $result = $this->reconcileWithPlm($result);
                break;
            case 'u8':
                $result = $this->reconcileWithU8($result);
                break;
            case 'mes':
                $result = $this->reconcileWithMes($result);
                break;
        }

        // 生成差异报告
        if ($result->hasDifferences()) {
            $this->generateDifferenceReport($result);
            $this->notifyAdministrators($result);
        }

        return $result;
    }

    /**
     * CAPP与U8物料数据对账
     */
    private function reconcileWithU8(ReconciliationResult $result): ReconciliationResult
    {
        // 1. 获取CAPP中标记为"已同步"的物料列表
        $cappMaterials = $this->getCappSyncedMaterials();

        // 2. 逐个与U8比对
        foreach ($cappMaterials as $material) {
            try {
                $u8Material = $this->u8Adapter->getMaterial($material['material_code']);

                // 比对关键字段

                    'type' => 'missing_in_u8',

                    'severity' => 'error',
                    'message' => 'CAPP中存在但U8中未找到'
                ]);
            }
        }

        return $result;
    }
```

```php
<?php
/**
 * 敏感数据加密工具类
 */
class DataEncryption
{
    private string $algorithm = 'AES-256-GCM';
    private string $key; // 从安全配置中加载

    /**
     * 加密敏感字段
     */
    public function encrypt(string $plaintext): string
    {
        $iv = random_bytes(openssl_cipher_iv_length($this->algorithm));
        $ciphertext = openssl_encrypt(
            $plaintext,
            $this->algorithm,
            $this->key,
            OPENSSL_RAW_DATA,
            $iv,
            $tag
        );
        return base64_encode($iv . $tag . $ciphertext);
    }

    /**
     * 解密敏感字段
     */
    public function decrypt(string $encrypted): string
    {
        $data = base64_decode($encrypted);
        $ivLength = openssl_cipher_iv_length($this->algorithm);
        $tagLength = 16; // GCM tag length

        $iv = substr($data, 0, $ivLength);
        $tag = substr($data, $ivLength, $tagLength);
        $ciphertext = substr($data, $ivLength + $tagLength);

        return openssl_decrypt(
            $ciphertext,
            $this->algorithm,
            $this->key,
            OPENSSL_RAW_DATA,
            $iv,
            $tag
        );
    }
}
```

#### 6.3.3 限流中间件实现

```php
<?php
/**
 * 令牌桶限流器
 */
class RateLimiter
{
    private Redis $redis;

    /**
     * 检查是否允许请求
     */
    public function allowRequest(string $key, int $rate, int $burst): bool
    {
        $now = microtime(true);
        $bucketKey = "rate_limit:{$key}";

        // 使用Redis Lua脚本保证原子性
        $script = <<<'LUA'
            local bucket = redis.call('HMGET', KEYS[1], 'tokens', 'last_refill')
            local tokens = tonumber(bucket[1]) or 0
            local last_refill = tonumber(bucket[2]) or 0

            -- 补充令牌
            local elapsed = ARGV[1] - last_refill
            local new_tokens = math.min(ARGV[3], tokens + elapsed * ARGV[2])
            local current_time = ARGV[1]

            if new_tokens >= 1 then
                new_tokens = new_tokens - 1
                redis.call('HMSET', KEYS[1], 'tokens', new_tokens, 'last_refill', current_time)
                redis.call('EXPIRE', KEYS[1], 60)
                return 1
            else
                redis.call('HMSET', KEYS[1], 'tokens', new_tokens, 'last_refill', current_time)
                redis.call('EXPIRE', KEYS[1], 60)
                return 0
            end
        LUA;

        $result = $this->redis->eval(
            $script,
            [$bucketKey, $now, $rate, $burst],
            1
        );

        return (bool)$result;
    }

    /**
     * 获取限流响应头
     */
    public function getRateLimitHeaders(string $key, int $rate, int $burst): array
    {
        $bucketKey = "rate_limit:{$key}";
        $tokens = $this->redis->hGet($bucketKey, 'tokens');

        return [
            'X-RateLimit-Limit' => $burst,
            'X-RateLimit-Remaining' => max(0, (int)$tokens),
            'X-RateLimit-Reset' => time() + 1
        ];
    }
}
```

```php
            if ($this->ipMatch($ip, $allowedIp)) {
                return true;
            }
        }

        Log::warning("IP白名单拒绝访问", [
            'system' => $system,
            'ip' => $ip,
            'time' => date('Y-m-d H:i:s')
        ]);

        return false;
    }

    /**
     * IP匹配（支持CIDR格式）
     */
    private function ipMatch(string $ip, string $pattern): bool
    {
        if (strpos($pattern, '/') !== false) {
            // CIDR格式：203.0.113.10/24
            list($network, $mask) = explode('/', $pattern);
            return (ip2long($ip) & (~((1 << (32 - $mask)) - 1) & 0xFFFFFFFF))
                === (ip2long($network) & (~((1 << (32 - $mask)) - 1) & 0xFFFFFFFF));
        }
        return $ip === $pattern;
    }
}
```
