
# CAPP系统架构设计文档

## 1. 架构概述

### 1.1 设计目标
本系统采用**分层架构**设计，遵循高内聚低耦合原则，确保系统的可扩展性、可维护性和可部署性。

### 1.2 架构风格
- **架构模式**：集成式单体应用（Integrated Monolith）
- **设计模式**：MVC模式、工厂模式、策略模式
- **通信方式**：RESTful API + 消息队列

### 1.3 技术选型
| 分类 | 技术 | 版本 | 说明 |
| :--- | :--- | :--- | :--- |
| 语言 | PHP | 8.0+ | 无框架原生开发 |
| 数据库 | MySQL | 8.0+ | 关系型数据库 |
| 缓存 | Redis | 6.0+ | 会话管理、数据缓存 |
| 消息队列 | RabbitMQ | 3.9+ | 异步消息处理 |
| 前端 | HTML5/JS/CSS3 | - | 原生前端开发 |
| 安全 | JWT | - | 身份认证 |

## 5. 关键业务流程

### 5.1 企业微信扫码登录流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant Browser as 浏览器
    participant Server as CAPP服务器
    participant Wechat as 企业微信API

    User->>Browser: 点击"企业微信登录"
    Browser->>Server: GET /wechat/login
    Server->>Browser: 重定向到企业微信OAuth2.0授权页
    Browser->>Wechat: 用户扫码授权
    Wechat->>Browser: 返回授权码(code)
    Browser->>Server: GET /wechat/callback?code=xxx
    Server->>Wechat: 获取access_token和用户信息
    Wechat-->>Server: 返回用户信息
    Server->>Server: 检查用户是否存在
    alt 用户已存在
        Server->>Server: 更新用户信息
    else 用户不存在
        Server->>Server: 创建新用户
    end
    Server->>Server: 生成JWT token
    Server->>Browser: 设置cookie并跳转首页
```

### 5.2 工艺路线创建流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant Web as WebController
    participant Service as ProcessService
    participant Repo as ProcessRepository
    participant DB as MySQL

    User->>Web: POST /process/route/create
    Web->>Service: createRoute(data)
    Service->>Service: 校验数据完整性
    Service->>Repo: save(ProcessRoute)
    Repo->>DB: INSERT INTO process_route
    DB-->>Repo: 返回插入结果
    Repo-->>Service: 返回实体
    Service->>Service: 生成工艺文件
    Service-->>Web: 返回创建成功
    Web-->>User: 返回成功响应
```

### 5.3 AI工艺优化流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant Web as WebController
    participant AiService as AiService
    participant MaxKB as MaxKB API
    participant ProcessService as ProcessService

    User->>Web: POST /ai/optimize
    Web->>AiService: optimizeProcess(productId, params)
    AiService->>MaxKB: 查询相似工艺案例
    MaxKB-->>AiService: 返回案例数据
    AiService->>AiService: 分析历史工艺数据
    AiService->>AiService: 应用AI模型优化
    AiService->>ProcessService: 生成优化后的工艺路线
    ProcessService-->>AiService: 返回工艺路线
    AiService-->>Web: 返回优化建议
    Web-->>User: 展示优化结果
```

## 7. 安全设计

### 7.1 认证机制
- **JWT令牌**：无状态认证，有效期2小时
- **刷新令牌**：存储在Redis，有效期7天
- **会话管理**：支持强制下线、单点登录

### 7.2 权限控制
- **RBAC模型**：基于角色的访问控制
- **细粒度权限**：支持到按钮级别的权限控制
- **权限继承**：角色继承上级权限

### 7.3 数据安全
- **传输加密**：HTTPS/TLS 1.2+
- **存储加密**：敏感字段AES-256加密
- **输入校验**：参数过滤、SQL注入防护
