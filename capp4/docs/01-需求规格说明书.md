
# CAPP系统需求规格说明书

## 1. 项目概述

### 1.1 项目背景
本项目为**工业压缩机、压力容器研发设计生产企业**设计开发一套完整的**计算机辅助工艺规划系统（CAPP）**。该系统旨在提升企业工艺设计效率，实现工艺数据标准化管理，打通与CAXAPLM、U8、MES等系统的数据通道，结合AI技术辅助工艺决策。

### 1.2 企业业务特点
- **产品类型**：工业压缩机、压力容器（高压容器、中低压容器、特种容器）
- **业务流程**：研发设计 → 工艺规划 → 生产制造 → 质量检验 → 交付
- **核心需求**：工艺路线规划、工时定额、物料清单管理、生产指令下达

### 1.3 技术栈要求
- **语言**：PHP 8.0+
- **数据库**：MySQL 8.0+
- **架构**：无框架，原生PHP开发
- **前端**：HTML5 + JavaScript + CSS3
- **集成**：企业微信、CAXAPLM、U8、MES、MaxKB

## 3. 非功能需求

### 3.1 性能需求
- 系统响应时间：≤ 2秒
- 并发用户数：支持100+并发
- 数据导出：1000条数据导出 ≤ 10秒
- 数据库查询：复杂查询 ≤ 5秒

### 3.2 安全需求
- 数据传输：HTTPS加密传输
- 数据存储：敏感数据加密存储
- 访问控制：RBAC权限模型
- 日志审计：完整操作日志记录
- SQL注入防护：输入参数校验

### 3.3 可靠性需求
- 系统可用性：99.5%
- 数据备份：每日自动备份
- 故障恢复：≤ 1小时

### 3.4 兼容性需求
- 浏览器支持：Chrome 90+、Firefox 88+、Edge 90+
- 移动端支持：企业微信内置浏览器兼容

## 6. 业务流程

### 6.1 工艺路线设计流程
1. 产品设计完成 → 导入产品信息
2. 创建工艺路线 → 添加工序
3. 设置工时定额 → 配置物料消耗
4. 工艺文件生成 → 提交审批
5. 审批通过 → 下发至MES

### 6.2 企业微信登录流程
1. 用户扫码 → 获取授权码
2. 调用企业微信API → 获取用户信息
3. 验证用户身份 → 创建/更新系统用户
4. 生成会话 → 跳转系统首页

### 6.3 AI决策辅助流程
1. 用户发起工艺设计请求
2. 系统收集历史工艺数据
3. AI模型分析推荐 → 返回最优方案
4. 用户确认/调整 → 生成工艺路线
