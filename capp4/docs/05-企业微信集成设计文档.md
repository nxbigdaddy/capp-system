
# CAPP系统企业微信集成设计文档

## 1. 集成概述

### 1.1 集成目标
实现CAPP系统与企业微信的深度集成，包括：
- **扫码登录**：企业微信扫码一键登录
- **用户同步**：自动同步企业微信组织架构和用户
- **消息推送**：通过企业微信发送业务消息和通知

### 1.2 技术方案
- **OAuth2.0协议**：用于扫码登录认证
- **企业微信API**：用于用户同步和消息推送
- **定时任务**：定期同步企业微信数据

### 1.3 企业微信配置要求
| 配置项 | 说明 |
| :--- | :--- |
| 企业微信企业ID | 企业唯一标识 |
| 应用AgentID | 创建的企业微信应用ID |
| 应用Secret | 应用密钥 |
| 授权回调域名 | 登录回调地址 |

## 2. 企业微信扫码登录设计

### 2.1 登录流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant Browser as 浏览器
    participant CAPP as CAPP服务器
    participant Wechat as 企业微信API

    User->>Browser: 访问CAPP系统登录页
    Browser->>CAPP: GET /wechat/login
    CAPP->>CAPP: 生成state参数(随机字符串)
    CAPP->>Browser: 重定向到企业微信授权页
    Note over Browser,Wechat: redirect_url = https://open.weixin.qq.com/connect/oauth2/authorize?appid=CORP_ID&redirect_uri=REDIRECT_URI&response_type=code&scope=snsapi_base&state=STATE#wechat_redirect
    
    Browser->>Wechat: 用户扫码授权
    Wechat->>Browser: 返回授权码code和state
    Browser->>CAPP: GET /wechat/callback?code=xxx&state=xxx
    CAPP->>CAPP: 验证state参数
    
    CAPP->>Wechat: 获取access_token
    Wechat-->>CAPP: 返回access_token
    
    CAPP->>Wechat: 获取用户信息(根据code)
    Wechat-->>CAPP: 返回用户信息(userid, name, department等)
    
    CAPP->>CAPP: 查询系统用户(根据wechat_userid)
    alt 用户存在
        CAPP->>CAPP: 更新用户信息
    else 用户不存在
        CAPP->>CAPP: 创建新用户
    end
    
    CAPP->>CAPP: 生成JWT Token
    CAPP->>Browser: 设置Cookie并跳转首页
```

## 4. 消息推送设计

### 4.1 消息类型

| 消息类型 | 用途 | 优先级 |
| :--- | :--- | :--- |
| 审批通知 | 审批流程状态变更 | 高 |
| 任务通知 | 任务分配、待办事项 | 高 |
| 预警消息 | 生产异常、超期预警 | 高 |
| 系统公告 | 系统通知、公告 | 中 |
| 业务提醒 | 常规业务提醒 | 中 |

### 4.2 消息推送流程

```mermaid
sequenceDiagram
    participant CAPP as CAPP系统
    participant Queue as RabbitMQ队列
    participant Worker as 消息处理Worker
    participant Wechat as 企业微信API
    participant User as 用户

    CAPP->>Queue: 发送消息任务
    Queue->>Worker: 消费消息任务
    Worker->>Wechat: 调用消息发送API
    alt 发送成功
        Wechat-->>Worker: 返回成功
        Worker->>CAPP: 更新消息状态为已发送
    else 发送失败
        Wechat-->>Worker: 返回失败
        Worker->>Queue: 重试入队(最多3次)
    end
    Wechat->>User: 推送消息到企业微信
```

## 6. 安全设计

### 6.1 access_token安全
- **缓存机制**：access_token缓存到Redis，设置过期时间
- **定期刷新**：在过期前5分钟自动刷新
- **加密存储**：不在日志中打印access_token

### 6.2 授权验证
- **state参数**：防止CSRF攻击
- **redirect_uri校验**：验证回调地址是否在白名单内
- **权限检查**：获取用户信息后验证企业微信用户是否属于本企业

### 6.3 消息安全
- **消息加密**：敏感消息内容加密传输
- **权限控制**：只有有权限的用户才能发送消息
- **日志审计**：记录所有消息发送记录

## 7. 异常处理

### 7.1 常见错误码

| 错误码 | 说明 | 处理方式 |
| :--- | :--- | :--- |
| 40001 | access_token无效 | 重新获取access_token |
| 40002 | 不合法的凭证类型 | 检查API调用参数 |
| 40003 | 不合法的用户ID | 验证用户ID格式 |
| 40004 | 不合法的媒体文件类型 | 检查文件格式 |
| 40005 | 不合法的文件大小 | 限制文件大小 |
| 40006 | 不合法的文件类型 | 检查文件类型 |
| 60001 | 部门不存在 | 跳过该部门同步 |
| 60002 | 部门成员数量超过限制 | 分批同步 |
| 60003 | 部门不存在 | 跳过该部门用户同步 |

### 7.2 重试机制
- **网络超时**：重试3次，间隔分别为10s、30s、60s
- **API限流**：等待后重试
- **数据冲突**：记录错误日志，人工处理

### 8.2 登录控制器示例

```php
class WechatController extends Controller {
    public function login() {
        $state = md5(uniqid());
        session()->put('wechat_state', $state);
        
        $url = "https://open.weixin.qq.com/connect/oauth2/authorize?" . http_build_query([
            'appid' => config('wechat.corp_id'),
            'redirect_uri' => config('wechat.redirect_uri'),
            'response_type' => 'code',
            'scope' => 'snsapi_base',
            'state' => $state
        ]) . '#wechat_redirect';
        
        return redirect($url);
    }
    
    public function callback(Request $request) {
        $code = $request->get('code');
        $state = $request->get('state');
        
        if ($state != session()->get('wechat_state')) {
            return response()->json(['code' => 1003, 'message' => '验证失败']);
        }
        
        $wechatService = app(WechatService::class);
        $userInfo = $wechatService->getUserInfoByCode($code);
        
        // 查询或创建用户
        $user = User::firstOrCreate(
            ['wechat_userid' => $userInfo['UserId']],
            ['real_name' => $userInfo['name']]
        );
        
        // 生成JWT token
        $token = YOUR_SECRET);
        
        return response()->json([
            'code' => 200,
            'data' => ['token' => $token, 'user' => $user]
        ]);
    }
}
```
