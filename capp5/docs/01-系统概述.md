# CAPP系统 - 系统概述

> 版本：V1.0 | 日期：2026-06-07 | 状态：初稿

---

## 一、项目背景

### 1.1 公司概况

本公司专注于**工业压缩机**和**压力容器**的研发、设计与生产制造，产品广泛应用于石化、能源、军工、医药等领域。工业压缩机具有高纯度、无污染、高压缩比等特点，压力容器则涉及各类储罐、换热器、反应釜等特种设备，生产工艺复杂、质量要求严苛。

### 1.2 工艺设计现状与痛点

当前工艺设计主要依赖以下方式，存在诸多问题：

| 痛点领域 | 现状描述 | 影响 |
|---------|---------|------|
| 工艺文件编制 | Excel/Word手工编制，模板不统一 | 效率低、易出错、版本混乱 |
| 工艺知识传承 | 依赖老员工经验，散落在个人电脑 | 人员流动导致知识流失 |
| 审批流程 | 纸质或邮件传签，周期长 | 响应慢、难以追溯 |
| 工时定额 | 经验估算，缺乏数据支撑 | 准确度差、影响排产 |
| 系统孤岛 | PLM/ERP/MES各自独立，数据不通 | 重复录入、数据不一致 |
| 变更管理 | 缺乏变更通知机制 | 现场使用错误版本 |
| 工艺优化 | 缺乏数据分析和反馈闭环 | 持续改进困难 |

### 1.3 建设必要性

- 行业竞争加剧，需要通过信息化手段提升工艺设计效率和质量
- 特种设备制造对工艺合规性和可追溯性有强制要求
- 工业压缩机结构精密，工艺参数要求高，必须实现标准化管理
- 数字化转型的战略需求，需要打通设计-工艺-制造全链条数据

## 二、系统目标

### 2.1 核心目标

1. **工艺标准化**：建立统一的工艺数据模型和标准模板，实现工艺文件的规范化管理
2. **知识沉淀**：将分散的工艺知识结构化存储，形成企业核心知识资产
3. **效率提升**：通过工艺复用、智能推荐、自动化输出等手段，显著缩短工艺准备周期
4. **系统集成**：打通PLM→CAPP→ERP/MES的数据通道，消除信息孤岛
5. **智能辅助**：引入AI技术，辅助工艺决策、工序推荐、工时估算

### 2.2 量化目标

| 指标 | 现状 | 目标 |
|------|------|------|
| 工艺编制效率 | 基准 | 提升40%以上 |
| 工艺文件差错率 | 基准 | 降低60%以上 |
| 审批周期 | 3-5天 | 缩短至1天内 |
| 工艺复用率 | ＜20% | 达到60%以上 |
| 数据一致性 | 存在差异 | 100%数据源头统一 |

## 三、系统范围

### 3.1 功能边界

- ✅ **包含**：工艺路线管理、工艺规程管理、工时/材料定额、工艺资源管理、审批流程、变更管理、版本管理、文件输出、企业微信集成、CAXA PLM对接、U8对接、MES对接、MaxKB知识库对接、AI决策辅助
- ❌ **不包含**：CAD制图功能、CAE仿真分析、车间现场执行（由MES负责）、财务管理（由U8负责）

### 3.2 组织范围

覆盖以下部门/角色：
- 技术部（工艺工程师、工艺审核员）
- 生产部（生产调度、车间主任）
- 质量部（质量工程师）
- 物控部（物料管理员）
- 管理层（工艺总师、技术副总）

### 3.3 业务范围

- 工业压缩机整机及零部件的工艺设计
- 压力容器（储罐、换热器、反应釜等）的工艺设计
- 焊接工艺评定（PQR/WPS）管理
- 热处理工艺管理
- 无损检测工艺管理

## 五、系统定位

### 5.1 在信息化架构中的位置

CAPP系统处于企业信息化架构的核心工艺层，向上承接PLM的设计数据（产品结构、EBOM、图纸），向下传递工艺数据给MES（工艺路线、工序、SOP）和ERP（材料定额、工时定额）。

```
┌─────────────────────────────────────────────────────┐
│                   企业信息化架构                       │
├─────────┬─────────┬─────────┬──────────┬────────────┤
│   PLM   │  CAPP   │   ERP   │   MES    │   MaxKB    │
│ (CAXA)  │ (本系统) │  (U8)   │ (制造执行)│ (知识库)    │
├─────────┼─────────┼─────────┼──────────┼────────────┤
│ 产品设计 │ 工艺设计 │ 财务管理 │ 生产执行  │ 知识管理    │
│ EBOM    │ MBOM    │ 成本核算 │ 报工质量  │ AI决策     │
│ 图纸管理 │ 工艺路线 │ 物料库存 │ 设备管理  │ 智能体     │
│ 变更管理 │ 工时定额 │ 采购管理 │ 排产调度  │ RAG检索    │
└─────────┴─────────┴─────────┴──────────┴────────────┘
         │         │         │          │
         ▼         ▼         ▼          ▼
    ┌──────────────────────────────────────────┐
    │               企业微信（统一门户）          │
    │    扫码登录 | 消息通知 | 审批待办 | 用户同步  │
    └──────────────────────────────────────────┘
```

## 六、预期效益

### 6.1 直接效益

| 效益维度 | 具体表现 |
|---------|---------|
| 效率提升 | 工艺编制效率提升40%+，审批周期从3-5天缩短至1天 |
| 质量提升 | 工艺文件标准化率提升至95%，差错率降低60% |
| 成本节约 | 工艺变更响应时间缩短70%，减少因工艺错误导致的返工 |
| 知识资产 | 形成结构化工艺知识库，知识复用率60%+ |

### 6.2 间接效益

- 支撑企业数字化转型战略落地
- 提升客户满意度（更快的工艺准备响应）
- 增强企业核心竞争力
- 为智能制造打下数据基础
- 满足特种设备制造行业合规性要求（工艺可追溯）

### 6.3 实施策略

分三期建设：
1. **一期（基础功能）**：工艺路线管理、工艺规程管理、基础数据管理、审批流程、文件输出
2. **二期（集成对接）**：企业微信集成、CAXA PLM对接、U8对接、MES对接
3. **三期（智能升级）**：MaxKB知识库对接、AI决策辅助、智能助手
