## 一、对接概述

### 1.1 对接目标

用友U8+作为企业ERP系统，CAPP需要与U8进行双向数据交换，实现工艺数据到生产管理的数据贯通。

### 1.2 对接方式

U8+底层使用SQL Server数据库，CAPP采用两种对接方式：

| 方式 | 用途 | 适用场景 |
|------|------|---------|
| 数据库直连(只读) | 查询物料/库存/订单 | 实时性要求低的数据读取 |
| EAI接口 | 数据写入/事务操作 | 材料定额/工时定额下发等需要U8校验的写入操作 |
| WebService | 跨系统调用 | U8提供的标准WebService服务 |

### 2.2 物料档案同步 (U8 → CAPP)

从U8的物料档案表中同步物料基础信息到CAPP。

| U8表字段 (Inventory) | CAPP字段 | 说明 |
|----------------------|---------|------|
| cInvCode | code | 物料编码 |
| cInvName | name | 物料名称 |
| cInvStd | specification | 规格型号 |
| cInvDefine1 | material_type | 材质（自定义项） |
| cComUnitCode | unit | 主计量单位 |
| iInvPrice | reference_price | 参考单价 |
| cInvDefine2 | drawing_no | 图号（自定义项） |

```php
// src/Integration/U8/U8Client.php

class U8Client {
    private $u8Db;  // U8 SQL Server连接

    /**
     * 同步物料档案(增量)
     */
    public function syncMaterials($lastSyncTime = null) {
        $sql = "SELECT 
                    cInvCode, cInvName, cInvStd, cComUnitCode,
                    cInvDefine1, cInvDefine2, iInvPrice, dModifyDate
                FROM Inventory
                WHERE 1=1";
        
        $params = [];
        if ($lastSyncTime) {
            $sql .= " AND dModifyDate > :last_sync";
            $params[':last_sync'] = $lastSyncTime;
        }
        
        $stmt = $this->u8Db->prepare($sql);
        $stmt->execute($params);
        
        $materials = [];
        while ($row = $stmt->fetch(PDO::FETCH_ASSOC)) {
            $materials[] = [
                'code'           => $row['cInvCode'],
                'name'           => $row['cInvName'],
                'specification'  => $row['cInvStd'],
                'material_type'  => $row['cInvDefine1'],
                'drawing_no'     => $row['cInvDefine2'],
                'unit'           => $row['cComUnitCode'],
                'reference_price'=> $row['iInvPrice'],
                'source_system'  => 'u8',
                'source_id'      => $row['cInvCode'],
            ];
        }
    
        return $this->batchUpsertMaterials($materials);
    }
}
```

### 2.3 库存查询 (U8 → CAPP)

在工艺编制或材料定额编制时，实时查询物料库存。

```php
/**
 * 查询物料当前库存
 */
public function queryStock($materialCode) {
    $sql = "SELECT 
                i.cInvCode,
                i.cInvName,
                s.iQuantity,       -- 现存量
                s.iInQuantity,     -- 待入库量
                s.iOutQuantity,    -- 待出库量
                (s.iQuantity + s.iInQuantity - s.iOutQuantity) AS available_qty
            FROM Inventory i
            LEFT JOIN CurrentStock s ON i.cInvCode = s.cInvCode
            WHERE i.cInvCode = :code";

    $stmt = $this->u8Db->prepare($sql);
    $stmt->execute([':code' => $materialCode]);
    return $stmt->fetch(PDO::FETCH_ASSOC);
}

/**
 * 批量查询库存
 */
public function batchQueryStock(array $materialCodes) {
    $placeholders = implode(',', array_fill(0, count($materialCodes), '?'));
    $sql = "SELECT 
                i.cInvCode, i.cInvName, 
                s.iQuantity, s.iInQuantity, s.iOutQuantity,
                (ISNULL(s.iQuantity,0) + ISNULL(s.iInQuantity,0) - ISNULL(s.iOutQuantity,0)) AS available_qty
            FROM Inventory i
            LEFT JOIN CurrentStock s ON i.cInvCode = s.cInvCode
            WHERE i.cInvCode IN ({$placeholders})";

    $stmt = $this->u8Db->prepare($sql);
    $stmt->execute($materialCodes);
    return $stmt->fetchAll(PDO::FETCH_ASSOC);
}
```

public function syncProductionOrders() {

                mo.MoCode,           -- 生产订单号
                mo.MoDId,            -- 生产订单ID
                mi.cInvCode,         -- 物料编码
                mi.cInvName,         -- 物料名称

            INNER JOIN Inventory mi ON mo.InvCode = mi.cInvCode

            ORDER BY mo.CreateDate DESC";

    $stmt = $this->u8Db->prepare($sql);
    $stmt->execute();
    return $stmt->fetchAll(PDO::FETCH_ASSOC);
}

## 三、材料定额下发 (CAPP → U8)

### 3.1 下发流程

```
CAPP材料定额发布
  ↓
触发下发任务
  ↓
组装U8物料需求清单数据
  ↓
调用U8 EAI接口写入
  ↓
U8 MRP运算使用定额数据
  ↓
生成采购计划/生产领料计划
```

### 3.2 数据映射

| CAPP字段 | U8字段 | 说明 |
|---------|--------|------|
| material.code | cInvCode | 物料编码 |
| quota_material.quantity_per_unit | FQty | 单件用量 |
| quota_material.gross_weight | FUseQty | 毛重用量 |
| product.code | cPSPCode | 父件编码(产品) |

### 3.3 下发实现

```php
/**
 * 材料定额下发到U8
 */
public function syncMaterialQuota($routeId) {
    // 1. 获取CAPP材料定额数据
    $materialQuotas = (new QuotaService())->getMaterialQuotaByRoute($routeId);
    $product = (new ProductService())->getByRouteId($routeId);
    
    // 2. 组装U8物料清单(BOM)数据
    $bomItems = [];
    foreach ($materialQuotas as $quota) {
        $bomItems[] = [
            'cPSPCode'    => $product['code'],          // 父件编码
            'cInvCode'    => $quota['material_code'],    // 子件编码
            'FQty'        => $quota['quantity_per_unit'],// 基本用量
            'FUseQty'     => $quota['gross_weight'],     // 使用数量(毛重)
            'Scrap'       => $quota['waste_rate'],       // 损耗率
            'cMemo'       => 'CAPP材料定额自动下发',
        ];
    }
    
    // 3. 调用U8 EAI接口
    $eaiXml = $this->buildEaiXml('BOM', $bomItems);
    $response = $this->callEaiApi($eaiXml);
    
    // 4. 记录下发日志
    $this->logSync('u8', 'out', 'material_quota', count($bomItems),
                   $response['success'] ? count($bomItems) : 0,
                   $response['success'] ? 0 : count($bomItems));

    return $response;
}

/**
 * 构建U8 EAI XML格式
 */
private function buildEaiXml($type, $data) {
    $xml = '<?xml version="1.0" encoding="UTF-8"?>';
    $xml .= '<ufinterface sender="CAPP" receiver="U8" roottag="bom">';
    
    foreach ($data as $item) {
        $xml .= '<bom>';
        $xml .= '<cPSPCode>' . $this->xmlEscape($item['cPSPCode']) . '</cPSPCode>';
        $xml .= '<cInvCode>' . $this->xmlEscape($item['cInvCode']) . '</cInvCode>';
        $xml .= '<FQty>' . $item['FQty'] . '</FQty>';
        $xml .= '<FUseQty>' . $item['FUseQty'] . '</FUseQty>';
        $xml .= '<Scrap>' . ($item['Scrap'] ?? 0) . '</Scrap>';
        $xml .= '<cMemo>' . $this->xmlEscape($item['cMemo']) . '</cMemo>';
        $xml .= '</bom>';
    }
    
    $xml .= '</ufinterface>';
    return $xml;
}
```

## 四、工时定额下发 (CAPP → U8)

### 4.1 下发用途

CAPP的工时定额数据下发至U8，用于：
- **成本核算**：基于工时计算人工成本和制造费用
- **生产排程**：为排产提供工时依据
- **报价参考**：作为产品报价的成本依据

### 4.2 数据映射

| CAPP字段 | U8工艺路线表字段 | 说明 |
|---------|-----------------|------|
| route.code | cRouteCode | 工艺路线编码 |
| product.code | cInvCode | 物料编码 |
| operation.operation_no | iSeqNo | 工序行号 |
| operation.operation_name | cWcCode | 工作中心编码 |
| quota_time.total_time | iManHour | 标准工时(小时) |

### 4.3 下发实现

```php
/**
 * 工时定额下发到U8
 */
public function syncTimeQuota($routeId) {
    $route = (new ProcessRouteService())->getById($routeId);
    $operations = (new RouteOperationService())->getByRouteId($routeId);
    $timeQuotas = (new QuotaService())->getTimeQuotaByRoute($routeId);

    $routeItems = [];
    foreach ($operations as $op) {
        $quota = $timeQuotas[$op['id']] ?? null;
        $routeItems[] = [
            'cInvCode'  => $route['product_code'],
            'cRouteCode'=> $route['code'],
            'iSeqNo'    => $op['sort_order'],
            'cWcCode'   => $op['work_center_code'],
            'iManHour'  => $quota ? $quota['total_time'] / 60 : 0, // 分钟→小时
            'cMemo'     => $op['operation_name'],
        ];
    }

    $eaiXml = $this->buildEaiXml('ROUTE', $routeItems);
    return $this->callEaiApi($eaiXml);
}
```

## 五、工艺路线下发 (CAPP → U8)

完整的工艺路线（含工序序列）下发至U8，用于U8生产模块的工艺路线管理。

```php
/**
 * 工艺路线完整下发到U8
 */
public function syncFullProcessRoute($routeId) {
    // 1. 获取完整工艺路线数据
    $route       = (new ProcessRouteService())->getById($routeId);
    $operations  = (new RouteOperationService())->getByRouteId($routeId);
    $timeQuotas  = (new QuotaService())->getTimeQuotaByRoute($routeId);

    // 2. 组装U8工艺路线数据
    $routeData = [
        'header' => [
            'cInvCode'   => $route['product_code'],
            'cRouteCode' => $route['code'],
            'cRouteName' => $route['name'],
            'cVersion'   => $route['version'],
        ],
        'operations' => []
    ];

    foreach ($operations as $op) {
        $quota = $timeQuotas[$op['id']] ?? null;
        $routeData['operations'][] = [
            'iSeqNo'    => $op['sort_order'],
            'cWcCode'   => $op['work_center_code'],
            'cWoName'   => $op['operation_name'],
            'iManHour'  => $quota ? $quota['total_time'] / 60 : 0,
            'iPriority' => $op['is_key_point'] ? 1 : 0,
        ];
    }

    // 3. 调用U8接口写入
    return $this->callU8Api('/api/production/route/sync', $routeData);
}
```

## 六、异常处理

### 6.1 失败重试机制

```php
private function retryCall($callback, $maxRetries = 3, $delaySec = 30) {
    $attempt = 0;
    while ($attempt < $maxRetries) {
        try {
            return $callback();
        } catch (ConnectionException $e) {
            $attempt++;
            Logger::warning("U8连接失败，第{$attempt}次重试", ['error' => $e->getMessage()]);
            if ($attempt >= $maxRetries) throw $e;
            sleep($delaySec);
        } catch (Exception $e) {
            throw $e; // 非连接错误不重试
        }
    }
}
```

### 6.2 同步状态码

| 状态码 | 含义 |
|--------|------|
| 0 | 成功 |
| 1 | U8数据库连接失败 |
| 2 | U8数据不存在 |
| 3 | U8校验失败（编码不存在/权限不足） |
| 4 | U8接口返回异常 |
| 5 | 网络超时 |

### 6.3 重发机制

对于下发失败的数据，记录到待重发表 `capp_sync_retry`：

```sql
CREATE TABLE capp_sync_retry (
    id INT PRIMARY KEY AUTO_INCREMENT,
    target_system VARCHAR(30),     -- u8
    data_type VARCHAR(30),         -- material_quota/time_quota/route
    payload JSON,                  -- 原始下发数据
    error_message TEXT,            -- 错误信息
    retry_count INT DEFAULT 0,     -- 重试次数
    max_retries INT DEFAULT 5,     -- 最大重试次数
    next_retry_at DATETIME,        -- 下次重试时间
    status TINYINT DEFAULT 0,      -- 0=待重试 1=重试成功 2=放弃
    created_at DATETIME,
    updated_at DATETIME
);
```
