# CAPP系统 - 接口规范

> 版本：V1.0 | 日期：2026-06-07 | 状态：初稿

---

## 一、接口设计原则

| 原则 | 说明 |
|------|------|
| RESTful风格 | 使用标准HTTP方法(GET/POST/PUT/DELETE) |
| JSON格式 | 请求和响应统一使用JSON |
| 统一响应结构 | 所有接口返回统一的响应格式 |
| 版本化 | URL前缀 `/api/v1/` |
| 认证 | JWT Bearer Token（内部接口）/ AppKey+签名（外部接口） |
| 幂等性 | PUT/DELETE操作保证幂等 |

---

## 二、统一响应格式

### 2.1 成功响应

```json
{
    "code": 0,
    "message": "success",
    "data": {},
    "timestamp": "2026-06-07T16:00:00+08:00"
}
```

### 2.2 分页响应

```json
{
    "code": 0,
    "message": "success",
    "data": {
        "list": [],
        "pagination": {
            "page": 1,
            "page_size": 20,
            "total": 156,
            "total_pages": 8
        }
    }
}
```

### 2.3 错误响应

```json
{
    "code": 40001,
    "message": "参数验证失败",
    "errors": {
        "name": "名称不能为空",
        "code": "编码已存在"
    },
    "timestamp": "2026-06-07T16:00:00+08:00"
}
```

### 2.4 错误码定义

| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
| 40001 | 参数验证失败 |
| 40002 | 数据不存在 |
| 40003 | 数据已存在(冲突) |
| 40101 | 未认证(未登录) |
| 40102 | Token过期 |
| 40301 | 无权限 |
| 40401 | 接口不存在 |
| 50001 | 服务器内部错误 |
| 50002 | 数据库错误 |
| 50003 | 外部系统调用失败 |

## 三、认证方式

### 3.1 内部接口认证 (JWT)

**请求头**:
```
Authorization: Bearer eyJhbGciOiJIUzI1NiIs...
```

**JWT Payload**:
```json
{
    "user_id": 1,
    "user_name": "张三",
    "exp": 1717766400,
    "iat": 1717759200
}
```

**Token刷新**: 过期前30分钟内可调用刷新接口获取新Token。

### 3.2 外部接口认证 (AppKey + HMAC签名)

用于MES/U8等外部系统调用CAPP接口：

**请求头**:
```
X-App-Key: mes_integration
X-Timestamp: 1717759200
X-Signature: sha256_hex_string
Content-Type: application/json
```

**签名算法**:
```php
$signStr = $appKey . $method . $endpoint . $timestamp;
if ($body) $signStr .= json_encode($body);
$signature = hash_hmac('sha256', $signStr, $secret);
```

## 五、接口实现示例

### 5.1 分页查询接口

```php
// GET /api/v1/materials?page=1&page_size=20&keyword=缸体&type=self_made
public function index() {
    $page     = max(1, intval($_GET['page'] ?? 1));
    $pageSize = min(100, max(1, intval($_GET['page_size'] ?? 20)));
    $keyword  = trim($_GET['keyword'] ?? '');
    $type     = $_GET['type'] ?? '';
    
    $db = Database::getInstance();
    
    // 构建查询
    $where = "WHERE is_deleted = 0";
    $params = [];
    
    if ($keyword) {
        $where .= " AND (code LIKE :kw1 OR name LIKE :kw2)";
        $params[':kw1'] = "%{$keyword}%";
        $params[':kw2'] = "%{$keyword}%";
    }
    if ($type) {
        $where .= " AND type = :type";
        $params[':type'] = $type;
    }
    
    // 总数
    $countSql = "SELECT COUNT(*) FROM capp_material {$where}";
    $total = $db->query($countSql, $params)->fetchColumn();
    
    // 分页数据
    $offset = ($page - 1) * $pageSize;
    $dataSql = "SELECT * FROM capp_material {$where} ORDER BY id DESC LIMIT {$offset}, {$pageSize}";
    $list = $db->query($dataSql, $params)->fetchAll(PDO::FETCH_ASSOC);
    
    return $this->json([
        'code' => 0,
        'data' => [
            'list'       => $list,
            'pagination' => [
                'page'       => $page,
                'page_size'  => $pageSize,
                'total'      => (int)$total,
                'total_pages'=> ceil($total / $pageSize),
            ]
        ]
    ]);
}
```

### 5.2 数据校验

```php
// src/Common/Validator.php

class Validator {
    private $errors = [];
    private $data;
    private $rules;

    public function __construct($data, $rules) {
        $this->data  = $data;
        $this->rules = $rules;
        $this->validate();
    }

    private function validate() {
        foreach ($this->rules as $field => $ruleStr) {
            $rules = explode('|', $ruleStr);
            $value = $this->data[$field] ?? null;

            foreach ($rules as $rule) {
                $params = [];
                if (strpos($rule, ':') !== false) {
                    [$rule, $paramStr] = explode(':', $rule, 2);
                    $params = explode(',', $paramStr);
                }

                $method = 'validate' . ucfirst($rule);
                if (method_exists($this, $method)) {
                    $this->$method($field, $value, $params);
                }
            }
        }
    }

    private function validateRequired($field, $value) {
        if ($value === null || $value === '') {
            $this->errors[$field] = "{$field}不能为空";
        }
    }

    private function validateMax($field, $value, $params) {
        if (mb_strlen($value) > $params[0]) {
            $this->errors[$field] = "{$field}长度不能超过{$params[0]}";
        }
    }

    private function validateUnique($field, $value, $params) {
        $table = $params[0];
        $db = Database::getInstance();
        $exist = $db->query("SELECT COUNT(*) FROM {$table} WHERE {$field} = :val", [':val' => $value])->fetchColumn();
        if ($exist > 0) {
            $this->errors[$field] = "{$field}已存在";
        }
    }

    public function fails() {
        return !empty($this->errors);
    }

    public function errors() {
        return $this->errors;
    }
}
```

## 六、接口限流

```php
// src/Middleware/RateLimitMiddleware.php

class RateLimitMiddleware {
    private $limit = 100;   // 每窗口最多100次
    private $window = 60;   // 窗口60秒

    public function handle($request, $next) {
        $ip = $_SERVER['REMOTE_ADDR'];
        $cache = ServiceContainer::get('cache');  // Redis
        
        $key = "rate_limit:{$ip}";
        $current = $cache->get($key) ?: 0;
        
        if ($current >= $this->limit) {
            http_response_code(429);
            echo json_encode([
                'code'    => 42901,
                'message' => '请求过于频繁，请稍后重试',
                'retry_after' => $this->window,
            ]);
            exit;
        }
        
        $cache->incr($key);
        $cache->expire($key, $this->window);
        
        return $next($request);
    }
}
```
