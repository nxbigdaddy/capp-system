# CAPP 系统 - 移动端设计

> 版本：V1.0 | 日期：2026-06-07 | 状态：初稿

---

## 一、设计概述

### 1.1 目标平台

- **H5 页面**：基于企业微信内置浏览器或手机浏览器访问
- **扫码功能**：调用手机摄像头扫描二维码
- **响应式适配**：适配主流手机屏幕（375px - 414px 宽度）

### 1.2 使用场景

| 场景 | 用户角色 | 功能 |
|------|---------|------|
| 扫码查看工艺 | 操作工/检验员 | 扫描工件/工位二维码，查看当前工序卡片 |
| 接收通知 | 工艺员/审核人 | 企业微信推送，查看审批待办/变更通知 |
| 简单审批 | 工艺组长/总师 | 移动端查看工艺概要，一键通过/驳回 |
| 现场报工 | 操作工 | 扫描工位码，录入实际工时和完成数量 |

### 1.3 技术方案

- **前端**：原生 HTML5 + JavaScript + CSS3
- **扫码**：调用微信 JS-SDK 扫码接口（企业微信环境）或 HTML5 getUserMedia API（浏览器环境）
- **缓存**：LocalStorage 存储最近查看的工艺数据
- **离线支持**：简单页面缓存，网络恢复后同步

#### 函数设计

```php
// Mobile/HomeController.php
class HomeController extends Controller {
    
    // GET /mobile
    public function index() {
        // 移动端首页不需要强制登录，扫码查看可匿名
        $recentViews = [];
        if ($this->currentUser) {
            $recentViews = $this->getRecentViews($this->currentUser['user_id']);
        }
        
        $this->view('mobile/home', [
            'recentViews' => $recentViews,
            'isWechat' => $this->isWechatBrowser(),
        ]);
    }
    
    /**
     * 判断是否为微信/企业微信浏览器
     */
    private function isWechatBrowser() {
        $ua = $_SERVER['HTTP_USER_AGENT'] ?? '';
        return strpos($ua, 'MicroMessenger') !== false;
    }
    
    /**
     * 获取最近查看记录
     */
    private function getRecentViews($userId) {
        $stmt = Database::getMysql()->prepare("
            SELECT a.access_type, a.qr_code_id, r.code as route_code, r.name as route_name, r.version, a.created_at
            FROM capp_mobile_access_log a
            LEFT JOIN capp_qr_code q ON a.qr_code_id = q.id
            LEFT JOIN capp_process_route r ON q.target_id = r.id AND q.code_type = 'route'
            WHERE a.user_id = ?
            ORDER BY a.created_at DESC
            LIMIT 5
        ");
        $stmt->execute([$userId]);
        return $stmt->fetchAll();
    }
}
```

```php
// Mobile/RouteController.php
class RouteController extends Controller {
    
    // GET /mobile/route/:id
    public function detail($id) {
        $route = (new ProcessRouteService())->getDetail($id);
        
        if (!$route) {
            $this->view('mobile/error', ['message' => '工艺路线不存在']);
            return;
        }
        
        // 记录访问日志
        $this->logAccess('route', $id);
        
        $this->view('mobile/route-detail', [
            'route' => $route,
            'isWechat' => $this->isWechatBrowser(),
        ]);
    }
    
    private function logAccess($type, $targetId) {
        $db = Database::getMysql();
        $stmt = $db->prepare("
            INSERT INTO capp_mobile_access_log (user_id, access_type, device_info, ip_address)
            VALUES (?, ?, ?, ?)
        ");
        $stmt->execute([
            $this->currentUser['user_id'] ?? null,
            $type,
            $_SERVER['HTTP_USER_AGENT'] ?? null,
            $_SERVER['REMOTE_ADDR'] ?? null,
        ]);
    }
}
```

```php
// Mobile/ApprovalController.php
class ApprovalController extends Controller {
    
    // GET /mobile/approval/:instance_id
    public function detail($instanceId) {
        $this->requireAuth();
        
        $instance = (new ApprovalService())->getInstanceDetail($instanceId);
        if (!$instance) {
            $this->view('mobile/error', ['message' => '审批实例不存在']);
            return;
        }
        
        $route = (new ProcessRouteService())->getDetail($instance['business_id']);
        
        $this->view('mobile/approval-detail', [
            'instance' => $instance,
            'route' => $route,
        ]);
    }
    
    // POST /api/mobile/approvals/:instance_id/approve
    public function approve($instanceId) {
        $this->requireAuth();
        $data = $this->getJsonBody();
        
        (new ApprovalService())->approve($instanceId, $this->currentUser['user_id'], $data);
        Response::success();
    }
    
    // POST /api/mobile/approvals/:instance_id/reject
    public function reject($instanceId) {
        $this->requireAuth();
        $data = $this->getJsonBody();
        
        (new ApprovalService())->reject($instanceId, $this->currentUser['user_id'], $data);
        Response::success();
    }
}
```

## 五、移动端 API 接口

### 5.1 扫码查看接口

```php
// Mobile/ApiController.php
class ApiController extends Controller {
    
    /**
     * 获取工艺路线（扫码用，无需登录）
     */
    public function routeDetail($id) {
        $route = (new ProcessRouteService())->getDetail($id);
        
        if (!$route || $route['status'] !== 'published') {
            Response::error(40401, '工艺路线不存在或未发布');
        }
        
        // 简化返回数据
        $data = [
            'id' => $route['id'],
            'code' => $route['code'],
            'product_name' => $route['product_name'],
            'version' => $route['version'],
            'operations' => array_map(function($op) {
                return [
                    'operation_no' => $op['operation_no'],
                    'operation_name' => $op['operation_name'],
                    'work_center_name' => $op['work_center_name'],
                    'standard_time' => $op['standard_time'],
                ];
            }, $route['operations']),
        ];
        
        Response::success($data);
    }
    
    /**
     * 获取工序详情（扫码用）
     */
    public function operationDetail($routeId, $operationNo) {
        $operation = (new ProcessRouteService())->getOperationDetail($routeId, $operationNo);
        $card = (new OperationCardService())->getByRouteOperation($operation['id'] ?? 0);
        
        if (!$operation) {
            Response::error(40401, '工序不存在');
        }
        
        $data = [
            'operation_no' => $operation['operation_no'],
            'operation_name' => $operation['operation_name'],
            'work_center_name' => $operation['work_center_name'],
            'standard_time' => $operation['standard_time'],
            'operation_steps' => $card['operation_steps'] ?? '',
            'kcp_list' => json_decode($card['kcp_list'] ?? '[]', true),
            'safety_notes' => $card['safety_notes'] ?? '',
            'qr_code_url' => $card['qr_code_url'] ?? '',
        ];
        
        Response::success($data);
    }
    
    /**
     * 获取标签信息
     */
    public function labelDetail($productCode) {
        $product = (new ProductService())->findByCode($productCode);
        
        if (!$product) {
            Response::error(40401, '产品不存在');
        }
        
        // 获取当前生效的工艺路线
        $route = (new ProcessRouteService())->getActiveRouteByProduct($product['id']);
        
        $data = [
            'product_code' => $product['code'],
            'product_name' => $product['name'],
            'specification' => $product['specification'],
            'route_code' => $route['code'] ?? null,
            'route_version' => $route['version'] ?? null,
        ];
        
        Response::success($data);
    }
}
```

## 六、二维码设计规范

### 6.1 二维码内容格式

| 类型 | URL 格式 | 示例 |
|------|---------|------|
| 工艺路线 | `{base_url}/mobile/route/{route_id}?v={version}` | `https://capp.company.com/mobile/route/123?v=V1.0` |
| 工序卡片 | `{base_url}/mobile/operation/{route_id}/{operation_no}` | `https://capp.company.com/mobile/operation/123/10` |
| 产品标签 | `{base_url}/mobile/label/{product_code}?batch={batch_no}` | `https://capp.company.com/mobile/label/P-001?batch=20260607-01` |

### 6.2 二维码生成规则

```php
// 二维码生成已在 QrGenerator.php 中定义
```

## 七、安全与性能

### 7.1 移动端安全

- **扫码访问**：工艺路线/工序查看无需登录，但仅返回已发布数据
- **审批操作**：必须登录且验证权限
- **Token 存储**：LocalStorage 存储 JWT，有效期 2 小时
- **HTTPS 强制**：生产环境强制 HTTPS

### 7.2 性能优化

- **数据缓存**：最近查看的工艺数据缓存到 LocalStorage
- **图片懒加载**：工序卡片图片按需加载
- **分页加载**：列表数据分页，每页 10 条
- **接口压缩**：开启 Gzip 压缩
